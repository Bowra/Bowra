## Version ansehen und kopieren

- Öffnen Sie das Kontomenü unten links (auf dem Smartphone tippen Sie zuerst oben links auf die Menüschaltfläche; Ihr Konto steht unten im Bereich). Die letzte Zeile zeigt die aktuelle Version, zum Beispiel „{applicationName} 1.4.8“.
- Klicken Sie auf diese Zeile oder wählen Sie sie mit der Tastatur aus und drücken Sie die Eingabetaste, um die vollständigen Versionsangaben zu kopieren. Die Meldung „Versionsangaben kopiert“ bestätigt den Vorgang.
- Die Schaltfläche **Versionsangaben kopieren** oben auf dieser Seite kopiert denselben Text.

Wenn Sie Ihrer Teamadministration oder dem Support ein Problem melden, fügen Sie diese Versionsangaben bei. So lässt sich schnell erkennen, welche Version Sie sehen.

## Wenn sich die Versionen von Web-App und Server unterscheiden

Die Versionsangaben enthalten eine Zeile „Web-App“ und eine Zeile „Server“. Normalerweise sind beide gleich. Unterscheiden sie sich, läuft in Ihrem Browser noch eine ältere Fassung der Seite: Laden Sie die Seite neu, um die aktuelle Version zu laden. Speichern Sie vorher alles, was Sie gerade bearbeiten.

## Versionshinweise

Öffnen Sie **Versionshinweise** im Kontomenü zwischen Hilfe-Center und Sprache, um veröffentlichte Versionen auf einer eigenen Seite zu lesen. Zunächst werden so viele vollständige Versionsgruppen angezeigt, wie in die Navigation passen: mindestens eine und höchstens zehn. Bei einer Änderung der Fenstergröße wird die Anzahl neu berechnet; manuell geladene Versionen bleiben verfügbar. Auch der Link oben auf dieser Seite führt dorthin.

Die **Versionshinweise** führen nach veröffentlichter Version auf, was sich für Nutzerinnen, Nutzer und Administrationen sichtbar geändert hat, die neueste Version zuerst.

Klicken Sie unten im Versionsmenü auf **Mehr laden**, um jeweils drei ältere Versionen bis hin zu v1.5.0 anzuzeigen, ohne Ihre Leseposition zu ändern. Unten steht, wie viele Versionen angezeigt werden und wann der gesamte Verlauf sichtbar ist. Das Veröffentlichungsdatum steht im Menü und im Text bei jeder Version.

Suchen Sie links nach einer Versionsnummer oder einem Begriff in allen veröffentlichten Versionshinweisen, auch in noch nicht geladenen Versionen. Wählen Sie eine Version oder einen Abschnitt im Menü, um dorthin zu springen. Passende Abschnitte zeigen eine kurze Vorschau. Auf dem Smartphone stehen Suche und Navigation über dem Text. Die Suche zeigt nur passende Versionen und hebt Suchbegriffe im Text hervor. Leeren Sie die Suche, um Ihre vorherige Versionsliste und Leseposition wiederherzustellen. Beim Scrollen hebt das Menü den aktuellen Abschnitt hervor; die gerade gelesene Version bleibt bei einer Änderung der Fenstergröße verfügbar.
