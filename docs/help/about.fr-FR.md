## Voir et copier la version

- Ouvrez le menu du compte en bas à gauche (sur téléphone, touchez d’abord le bouton de menu en haut à gauche ; votre compte se trouve en bas du panneau). Sa dernière ligne indique la version actuelle, par exemple « {applicationName} 1.4.8 ».
- Cliquez sur cette ligne, ou sélectionnez-la au clavier puis appuyez sur Entrée, pour copier les informations de version complètes. Le message « Informations de version copiées » le confirme.
- Le bouton **Copier les informations de version** en haut de cette page copie le même texte.

Lorsque vous signalez un problème à l’administration de votre équipe ou au support, joignez ces informations de version : elles permettent de savoir rapidement quelle version vous voyez.

## Si les versions de l’application web et du serveur diffèrent

Les informations de version comportent une ligne « Application web » et une ligne « Serveur ». Elles sont normalement identiques. Si elles diffèrent, votre navigateur affiche encore une ancienne copie de la page : actualisez la page pour charger la dernière version. Enregistrez d’abord ce que vous êtes en train de modifier.

## Notes de version

Ouvrez **Notes de version** dans le menu du compte, entre le centre d’aide et la langue, pour consulter les versions publiées sur une page dédiée. Par défaut, la navigation affiche autant de groupes de version complets que l’espace le permet, entre un et dix. Ce nombre est recalculé lorsque la fenêtre change de taille ; les versions chargées manuellement restent disponibles. Le lien en haut de cette page y mène également.

Les **notes de version** présentent, version par version, les changements visibles pour les utilisateurs et les administrateurs, en commençant par la plus récente.

Cliquez sur **Charger plus**, en bas du menu des versions, pour afficher trois versions plus anciennes à la fois, jusqu’à v1.5.0, sans déplacer votre position de lecture. Le bas du menu indique le nombre de versions affichées et confirme quand tout l’historique est visible. La date de publication figure dans le menu et dans les notes de chaque version.

Recherchez à gauche un numéro de version ou des mots dans toutes les notes publiées, y compris les versions qui ne sont pas encore chargées. Sélectionnez une version ou une section du menu pour y accéder. Les sections correspondantes affichent un court aperçu. Sur téléphone, la recherche et la navigation se trouvent au-dessus des notes. La recherche affiche uniquement les versions correspondantes et met les mots recherchés en évidence. Effacez la recherche pour retrouver la liste et la position de lecture précédentes. Le menu suit la section que vous lisez lorsque vous faites défiler les notes ; la version en cours reste disponible si la fenêtre change de taille.
