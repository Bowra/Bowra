# Zugriff anfragen und Anfragen bearbeiten

Wenn Sie einen Bericht, Agent oder Skill einer anderen Person öffnen, auf den Sie noch keinen Zugriff haben, wird die Meldung **Sie haben noch keinen Zugriff** angezeigt. Sie können den Zugriff direkt dort anfragen, ohne jemanden bitten zu müssen, den Inhalt für Sie weiterzuleiten.

## Zugriff anfragen

1. Auf der Seite ohne Zugriff können Sie kurz angeben, wofür Sie den Zugriff benötigen. Die Begründung ist optional, darf höchstens 280 Zeichen lang sein und ist nur für die Person sichtbar, die die Anfrage bearbeitet.
2. Wählen Sie **Zugriff anfragen**. Auf der Seite erscheint anschließend **Anfrage läuft** mit dem Datum Ihrer Anfrage.
3. Sobald eine zuständige Person antwortet, erhalten Sie das Ergebnis im Benachrichtigungscenter. Wenn Sie dieselbe Seite erneut öffnen, wird dort ebenfalls der aktuelle Status angezeigt.

Die Seite weist absichtlich darauf hin, dass der Eintrag „nicht existiert oder nicht für Sie freigegeben wurde“: Zum Schutz fremder Inhalte verrät Bowra nie, ob ein Eintrag tatsächlich existiert. Unabhängig davon, ob er existiert, sehen Sie nach dem Absenden dieselbe Meldung **Anfrage läuft**.

Wenn auf der Seite keine Schaltfläche **Zugriff anfragen** angezeigt wird, sind Anfragen dort noch nicht verfügbar. Wenden Sie sich direkt an die Person, der der Inhalt gehört.

## Nach Ihrer Anfrage

- **Anfrage läuft**: Sie warten auf eine Antwort. Wenn Sie den Zugriff nicht mehr benötigen, wählen Sie **Anfrage zurückziehen**.
- **Sie haben jetzt Zugriff**: Wählen Sie **Öffnen**, um den Inhalt zu verwenden. Einen genehmigten Bericht können Sie lesen; einen genehmigten Agent oder Skill können Sie verwenden. Der Zugriff läuft standardmäßig nicht ab. Hat die zuständige Person eine Frist festgelegt, wird das Enddatum angezeigt.
- **Genehmigt, wird angewendet**: Die Anfrage wurde genehmigt, aber die Änderung braucht noch einen Moment, bis sie wirksam ist (häufig bei Agents). Sie erhalten eine Benachrichtigung, sobald der Zugriff aktiv ist.
- **Anfrage abgelehnt**: Eine optionale Nachricht der zuständigen Person wird unverändert angezeigt. Nach einer Ablehnung müssen Sie warten, bevor Sie erneut anfragen können. Auf der Seite sehen Sie, ab welchem Datum eine neue Anfrage möglich ist.
- **Anfrage nicht mehr aktiv**: Die Anfrage wurde innerhalb von 14 Tagen nicht bearbeitet oder der Inhalt ist nicht mehr verfügbar. Fragen Sie erneut an, wenn Sie den Zugriff weiterhin benötigen.

Benachrichtigungen und Seiten zeigen nur, was „eine zuständige Person“ entschieden hat, sowie deren Nachricht. Wer die Entscheidung getroffen hat, wird nie angezeigt.

Wenn Sie innerhalb kurzer Zeit zu viele Anfragen senden, wird **Zu viele Anfragen. Versuchen Sie es später erneut.** angezeigt. Warten Sie eine Weile und versuchen Sie es dann erneut.

## Eigene Anfragen ansehen

Öffnen Sie die Seite **Zugriffsanfragen** und wechseln Sie zu **Meine Anfragen**, um alle von Ihnen gesendeten Anfragen und deren Status zu sehen. Eine noch laufende Anfrage können Sie zurückziehen. Inhalte, für die Sie eine Genehmigung erhalten haben, können Sie öffnen.

## Anfragen anderer Personen bearbeiten

Wenn jemand Zugriff auf Inhalte anfragt, die Ihnen gehören, erhalten Sie im Benachrichtigungscenter die Meldung **Zugriffsanfrage zur Prüfung**. Wählen Sie **Prüfen**, um auf der Seite **Zugriffsanfragen** den Bereich **Zu prüfen** zu öffnen:

1. Jede Anfrage zeigt, wer den Zugriff anfragt, um welchen Inhalt es geht, die Begründung und welche Berechtigung bei einer Genehmigung erteilt wird (Lesen oder Verwenden). Falls die Anfrage zuvor abgelehnt wurde, wird die Anzahl der Ablehnungen angezeigt.
2. Sie können eine Nachricht hinzufügen. Sie wird der anfragenden Person bei einer Genehmigung oder Ablehnung genau so übermittelt, wie Sie sie geschrieben haben.
3. Wählen Sie **Genehmigen** oder **Ablehnen**. Bei einer Genehmigung wird der Zugriff automatisch erteilt. Sie müssen den Inhalt also nicht manuell freigeben.

Es stehen zwei Optionen zur Verfügung:

- **Zugriff nach 30 Tagen automatisch entfernen**: nur für Berichte und Skills. Wenn diese Option aktiviert ist, endet der Zugriff nach 30 Tagen. Andernfalls bleibt er bestehen, bis Sie ihn entfernen.
- **Bei Ablehnung keine weiteren Anfragen dieser Person für diesen Inhalt innerhalb von 30 Tagen annehmen**: unter **Weitere Optionen**. Verwenden Sie diese Option, wenn jemand wiederholt anfragt und Sie den Zugriff nicht genehmigen werden.

Beachten Sie:

- Nur die verantwortliche Person eines Agents kann Anfragen für diesen Agent bearbeiten. Nach der Genehmigung kann die Änderung noch dieselbe Prüfung wie eine reguläre Veröffentlichung durchlaufen. Währenddessen sieht die anfragende Person **Genehmigt, wird angewendet**. Hat der Agent unveröffentlichte Änderungen, veröffentlichen oder verwerfen Sie diese zuerst und genehmigen Sie danach die Anfrage.
- Bei Berichten und Skills können auch Team-Owner und Team-Admins Anfragen bearbeiten. Wenn die verantwortliche Person innerhalb von 72 Stunden nicht geantwortet hat, werden Team-Owner und Team-Admins erinnert.
- Bei drei oder mehr offenen Anfragen werden Benachrichtigungen zusammengefasst: **Sie haben N Zugriffsanfragen zu prüfen**.
- Bearbeitete Anfragen einschließlich ihrer Ergebnisse und Nachrichten stehen unter **Bearbeitet**.

## Team-Einstellungen, Admin-Konsole und Space-Einstellungen

Diese Seiten sind rollenbasiert zugänglich und können nicht online angefragt werden. Wenn Sie eine solche Seite nicht öffnen können, wird angezeigt, wer Ihnen helfen kann: Bei den Team-Einstellungen und der Admin-Konsole bitten Sie den Team-Owner, Ihre Team-Rolle zu ändern. Bei den Space-Einstellungen wenden Sie sich an die Admins des Space oder an einen Team-Owner oder Team-Admin.
