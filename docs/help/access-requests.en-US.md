# Request access and handle requests

When you open someone else's report, agent, or skill that you can't access yet, the page shows **You don't have access yet**. You can ask for access right there, without asking anyone to forward it.

## Request access

1. On the no-access page, you can write a short reason that says what you need it for. The reason is optional, up to 280 characters, and only the manager who handles the request can see it.
2. Select **Request access**. The page then shows **Request in progress** with the date you submitted.
3. When a manager responds, you get the result in the notification center. Going back to the same page also shows the latest status.

The page says the item "doesn't exist or hasn't been shared with you" on purpose: to protect other people's content, Bowra never tells you whether an item exists. Whether or not it exists, you see the same **Request in progress** after submitting.

If the page has no **Request access** button, requests aren't available there yet. Contact the owner of the content directly.

## After you request

- **Request in progress**: waiting for a manager. If you no longer need it, select **Withdraw request**.
- **You now have access**: select **Open** to use it. An approved report can be read; an approved agent or skill can be used. Access doesn't expire by default; if the manager set a limit, the page shows the end date.
- **Approved, taking effect**: a manager approved, but it takes a moment to apply (common for agents). You're notified once it takes effect.
- **Request declined**: the manager's note, if any, is shown as written. After a decline you need to wait before asking again; the page shows the date from which you can request again.
- **Request no longer active**: the request wasn't handled within 14 days, or the item is no longer available. Request again if you still need it.

Notifications and pages only tell you what "a manager" decided and their note. They never show who decided.

If you send too many requests in a short time, the page shows **Too many requests. Try again later.** Wait a while and try again.

## See your own requests

Open the **Access requests** page and switch to **My requests** to see every request you've sent and its status. You can withdraw a request that's still in progress, and open items you've been approved for.

## Handle requests from others

When someone asks for access to content you own, you get **Access request to review** in the notification center. Select **Review** to open **To review** on the **Access requests** page:

1. Each request shows who is asking, the item, their reason, and what they get if you approve (read or use). If they were declined before, the number of times is shown.
2. Add a note if you like. The note goes to the requester exactly as written, whether you approve or decline.
3. Select **Approve** or **Deny**. Approving grants access automatically, so you don't have to share the item by hand.

Two options are available:

- **Remove access automatically after 30 days**: reports and skills only. When checked, the access ends after 30 days; otherwise it lasts until you remove it.
- **When declining, stop accepting this person's requests for this item for 30 days**: under **More options**. Use it when someone keeps asking and you won't approve.

Keep in mind:

- Only the agent's owner can handle requests for an agent. After approval, the change may go through the same review as a normal release; meanwhile the requester sees **Approved, taking effect**. If the agent has unpublished changes, publish or discard them first, then approve.
- For reports and skills, team owners and admins can also handle requests. If the owner hasn't responded within 72 hours, team owners and admins are reminded.
- With three or more requests waiting, notifications are combined into one: **You have N access requests to review**.
- Handled requests, with their results and notes, are listed under **Handled**.

## Team settings, the admin console, and space settings

These pages are open by role and can't be requested online. When you can't open one, the page tells you who can help: for team settings and the admin console, ask the team owner to change your team role; for space settings, ask the space's admins, or a team owner or admin.
