# 申请访问与处理申请

打开别人的报告、智能体或技能时，如果你还没有权限，页面会显示「你还没有访问权限」。你可以在这里直接申请，不用另外找人转发。

## 申请访问

1. 在无权访问的页面上，可以写一句申请理由，说明你需要它做什么。理由是选填的，最多 280 个字，只有处理申请的管理者能看到。
2. 点击「申请访问」。提交后页面会显示「申请处理中」和提交日期。
3. 管理者处理后，你会在通知中心收到结果。回到原来的页面，也能看到最新状态。

页面上的说明会同时写「不存在，或还没有分享给你」。这是有意的：为了保护别人的内容，系统不会告诉你某项内容是否存在。无论内容是否存在，提交后看到的都是同样的「申请处理中」。

如果页面上没有「申请访问」按钮，说明这里暂时不能在线申请，请直接联系内容的负责人。

## 申请之后会怎样

- **申请处理中**：等待管理者处理。不再需要时，可以点「撤回申请」。
- **你已获得访问权限**：点「打开」即可使用。报告获批后可以阅读；智能体和技能获批后可以使用。权限默认不会过期；如果管理者设置了期限，页面会写明到哪天为止。
- **已批准，正在生效**：管理者已经同意，但还需要一点时间生效（常见于智能体）。生效后你会收到通知。
- **申请未通过**：如果管理者留了附言，会原样显示。被拒后需要等一段时间才能再次申请，页面会写明从哪天起可以再申请。
- **申请已失效**：申请 14 天内没有处理，或者内容已经不可用。需要的话可以重新申请。

通知和页面只会告诉你「管理者」的处理结果和附言，不会显示是谁处理的。

如果短时间内提交了太多申请，页面会提示「申请太频繁，请稍后再试」，过一会儿再提交即可。

## 查看自己发起的申请

打开「访问申请」页面，切换到「我发起的」，可以看到你提交过的所有申请和它们的状态。处理中的申请可以在这里撤回；已通过的申请可以直接打开。

## 处理别人的申请

如果有人申请访问你负责的内容，你会在通知中心收到「有访问申请待处理」。点击「处理」进入「访问申请」页面的「待我处理」：

1. 每条申请会写明申请人、内容名称、申请理由，以及批准后对方能得到什么（阅读或使用）。如果对方之前被拒过，也会提示次数。
2. 需要时填写附言。附言会随结果原样发给申请人，批准和拒绝都可以写。
3. 点「同意」或「拒绝」。批准后系统会自动授权，不用再手动分享。

还有两个可选项：

- **30 天后自动收回**：只用于报告和技能。勾选后，对方的权限 30 天后自动失效；不勾选则一直有效，直到你收回。
- **拒绝时，30 天内不再接收此人对该内容的申请**：在「更多选项」里。适合对方反复申请、你确定不会同意的情况。

注意事项：

- 智能体的申请只有智能体的负责人能处理。批准后，可能需要经过和平常发布一样的审核，期间申请人看到的是「已批准，正在生效」。如果智能体还有未发布的修改，需要先发布或放弃这些修改，再批准申请。
- 报告和技能的申请，团队负责人和管理员也可以代为处理。负责人 72 小时内没有处理时，系统会提醒团队负责人和管理员。
- 同时有 3 条以上待处理申请时，通知会合并成一条「你有 N 条访问申请待处理」。
- 已处理的申请可以在「已处理」里查看结果和附言。

## 团队设置、管理控制台和空间设置

这些页面按角色开放，不能在线申请。无权打开时，页面会写明谁能帮你：团队设置和管理控制台请联系团队负责人调整你的团队角色；空间设置请联系这个空间的管理员，或团队负责人、管理员。
