# 注销账号

打开**设置 → 账号 → 注销账号…**，输入此账号邮箱及当前密码。无密码登录的用户先退出并重新登录，再在五分钟内确认。

注销会永久停用账号并释放邮箱，无法撤销。同邮箱新注册是独立账号，不继承旧会话、文件、权限、连接或设置；仍需遵守现有注册或邀请规则。

个人会话历史和文件从注销请求起隔离保留 30 天，到期自动安排永久清理。存储故障可能延迟完成，管理员可根据注销任务排查。登录凭据立即失效，临时执行材料可能按原有政策更早到期。

归属团队的知识资料和共享资源由团队保留；仅分享给别人的个人文件仍随个人数据删除。请先移交团队所有权、最后管理员职责及启用中的共享智能体，并提前导出或下载需要保留的内容。

密码不正确时重新输入或先重置；提示团队或智能体须移交时，在相应团队设置完成后再返回。服务尚未就绪或提交结果不确定时，先联系管理员，避免重复操作。他人已经下载或独立复制的文件无法远程撤回。
