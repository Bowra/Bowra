# 使用管理控制台

从账号菜单打开**管理控制台**。侧栏会显示当前团队角色和部署可以使用的页面。

- **审批。**打开待处理项，核对发起人、Space、动作和参数，再批准或驳回。在历史中查看决定和执行结果。需要任务发起人按次确认的操作，仍由该成员在对话里的原卡片处理。
- **运行追踪。**从诊断信息取得轮次标识，在追踪页查询。查看有权限读取的状态和步骤。需要支持时，提供轮次标识和出错步骤。
- **用量与额度。**打开成员详情，查看余额和流水，按权限使用下载或额度调整操作。[查看和补充额度](credits.zh-CN.md)
- **访问控制。**管理组、组成员或资源授权前，核对团队和 Space。按名称查找资源和授权对象，选择权限、效果和可选的到期时间，保存前核对授权摘要。在有权查看的目录里找不到目标时，可改用准确标识。修改规则前，可以先用权限解释核对已有判定。[权限参考](permissions-reference.zh-CN.md)
- **审计日志。**Business 版可用时，按操作筛选团队事件。要查资源授权变化，在「访问与分享」下选择「新增或更新资源授权」或「撤销资源授权」。展开记录可查看事件代码以及记录里包含的权限详情。

团队角色决定可做哪些管理操作。Space 和内容访问仍按各自权限检查。

## 按组分发报告或 HTML 文件

1. 如需手动管理名单，团队负责人或管理员可以直接在**访问控制**中创建团队组，将空间字段留空，按团队成员 ID 添加人员。比如建一个「店长」组，人事调动时在组内移出原店长、添加接任者。部门或职位变化后，本地组名单仍需手动更新。
2. 打开报告或可分享的 HTML 成果，选择**分享**，选中组并确认。新成员可以打开原链接。移出组后，该成员在下一次访问时失去通过该组获得的权限。个人授权、其他组或全团队授权仍可能提供读取权限。
3. Business 版如需自动维护名单，在可用的**目录同步（SCIM 2.0）**中创建同步凭据，将**租户 URL** 和仅显示一次的**密钥**填入身份提供商。Entra 管理员在企业应用的**预配**设置中启用用户和组映射，测试连接，只分配预期同步的用户和组，再启动预配。团队入口须能通过 HTTPS 从预配服务访问。[微软 Entra 配置说明](https://learn.microsoft.com/en-us/entra/identity/app-provisioning/use-scim-to-provision-users-and-groups)
4. 已有账号先核对成员 ID 和已验证的邮箱，再关联目录对象。刷新同步组列表，依据目录 ID 区分同名组，选择**发布以供分享**。发布后，在上游维护直接成员。Bowhead 收到并提交调岗对应的组变更后，原链接随即按新名单判权。单独修改职位名称不会改变组成员。
5. 在到期前轮换密钥并更新上游配置。停用同步会保留最后一次确认的成员。需要立即收回材料时，在材料的分享窗口撤销该组授权。已经下载到本地的副本仍由接收者持有。

## 核对知识库授权

按知识库整理正在逐步开放。开启后，**访问控制**中还会显示只读的「知识库授权对照」，团队负责人和团队管理员可以查看。它列出作用于知识库范围或知识库文件的每一条资源授权：

- **适用于：**按名称显示成员、组、空间成员或团队所有人；已离开团队的成员、已移除的组和已删除的空间会注明。
- **对象：**某个空间或团队的知识库文件，或者一个文件及其所在的知识库。你无法打开的文件、他人「我的知识」中的文件以及空间的仅成员知识库不显示名称；已删除的文件和空间会注明。
- **现在的作用：**「允许」授权会把对象变成允许名单，对象上没有「允许」授权的人都会被拦下；「拒绝」授权拦下它的授权对象。这里同时显示本部署是强制执行授权，还是只记录日志。
- **对应的知识库成员（建议）：**要保持同样的访问，授权对象需要在哪些知识库上有什么权限；或者要继续把某人挡在外面，需要改用「仅成员」知识库。

这些授权在知识库规则之后继续生效：只会拦下访问，从不授予访问。这一部分不做任何改动。要修改或撤销授权，请使用上方的「资源授权」；对象或授权对象已不存在的授权可以撤销。
