# 浏览智能体榜单

在侧栏选择 **智能体 → 榜单**。「市场」「我的智能体」「榜单」是三个独立页面；点击「智能体」默认进入「我的智能体 → 我聘用的」。

- **热门**：按过去 28 天本团队实际使用的成员人数排名。
- **上升**：按最近 7 天相对前 7 天的活跃成员人数增长排名。
- **最近更新**：展示团队智能体介绍的保存更新，不代表首次上架或最热门。

用「分类：全部」按钮选择分类可缩小范围。点击「榜单说明」可展开或收起统计口径。点击「详情」查看智能体及本人可执行的动作；点击「返回排行榜」会保留原榜单和分类。

榜单需要当前部署提供团队统计，并有足够真实使用符合隐私要求。接口不可用、样本不足或统计过期时，不显示名次和使用人数。仍可查看最近更新或浏览智能体；请求失败时可点击「重试」。

统计可用时，榜单会根据成功的成员使用自动更新，无需人工维护。热门需要完整 28 天，上升需要前后两个完整的 7 天；首次积累期间，页面会提示正在积累完整统计窗口。每个展示的使用周期和当前采用人数都需分别达到五名合格成员。人数是团队聚合，热门不等于质量，也不会授予智能体或其数据访问权。

首次积累期间，如果最早完整窗口日期已知，页面会按你浏览器所在的时区显示。它表示统计窗口最早完成的时间，不保证当日一定出现榜单；合格成员人数仍需满足隐私要求。
