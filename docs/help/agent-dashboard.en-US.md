# Review the Agent overview

Team owners and administrators can open **Agent overview** from the **⋯** menu on the right of the **Agents** page header (in the top bar on phones); Marketplace, My agents and Top Charts all have this menu. Choose **Agents** in the breadcrumb to return to the directory.

The Agent overview summarizes the entries you can read in the current team's management view. It excludes other authors' private Agents and built-in Agents, so the entry count is not a count of everything owned by every team member.

- **Management entries** counts the entries read from your team view.
- **Team defaults** counts their enabled team-default settings. Choose **Manage defaults** to review or change those settings.
- **Listing checks blocked** counts entries whose display content needs review. The line below it shows how the other entries stand, for example "27 passed · 4 no evidence"; entries without check evidence count as no evidence. The note under the figures is a reminder that listing checks cover listing content only and do not establish quality or readiness to run.
- **Pending approvals** counts the team's pending release candidates. Choose **Open review queue** to review them through the existing approval process. You still cannot approve your own submission.

**Domain coverage** shows the number of entries per domain as labeled bars. One Agent can cover several domains, so domain counts can add up to more than the entry count. Choose **View exact values** under the chart for its data table; shortened chart labels retain their full domain names in the table.

**Needs attention** lists blocked entries and default settings whose Agent details are no longer accessible. Choose **Details** to inspect current evidence, then **Back to Agent overview** to return. For an inaccessible Agent, use **Team management** to review the remaining default setting.

The page reads current information when opened, when you choose **Refresh**, and when you return after at least a minute. A read failure shows a retry message instead of partial totals; a failed approval count is unavailable, not zero. Some server entries may be unavailable, in which case the page says its charts cover only returned entries. If a large directory cannot be read completely, use team management.

This overview does not collect usage, adoption, activity, growth, or execution-success statistics. It does not automatically approve releases or repair Agents.
