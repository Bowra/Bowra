# Consulter la vue d’ensemble des Agents

Les responsables et administrateurs d’équipe ouvrent la **Vue d’ensemble des Agents** depuis le menu **⋯** à droite de l’en-tête **Agents** (dans la barre supérieure sur téléphone) ; Marché, Mes agents et Classements proposent ce menu. Choisissez **Agents** dans le fil d’Ariane pour revenir au répertoire.

La vue d’ensemble résume les entrées que vous pouvez lire dans la gestion de l’équipe actuelle. Il exclut les Agents privés des autres auteurs et les Agents intégrés. Le nombre d’entrées ne représente donc pas tous les Agents appartenant à tous les membres.

- **Entrées de gestion** compte les entrées lues dans votre vue d’équipe.
- **Agents par défaut** compte leurs réglages par défaut activés. Choisissez **Gérer les valeurs par défaut** pour les examiner ou les modifier.
- **Contrôles bloqués** compte les fiches dont le contenu doit être examiné. La ligne en dessous indique l’état des autres fiches, par exemple « 27 validées · 4 sans preuve » ; les fiches sans preuve de contrôle comptent comme sans preuve. La note sous les indicateurs rappelle que les contrôles portent uniquement sur le contenu des fiches et ne prouvent ni la qualité ni la disponibilité d’exécution.
- **Approbations en attente** compte les versions candidates de l’équipe en attente de validation. Choisissez **Ouvrir la file de validation** pour suivre le processus habituel. Vous ne pouvez toujours pas approuver votre propre soumission.

**Couverture des domaines** affiche le nombre d’entrées par domaine sous forme de barres annotées. Un Agent peut couvrir plusieurs domaines : la somme peut donc dépasser le nombre d’entrées. **Voir les valeurs exactes** sous le graphique ouvre le tableau de données, où les noms de domaines abrégés dans le graphique sont affichés en entier.

**À traiter** présente les fiches bloquées et les réglages par défaut dont les détails de l’Agent ne sont plus accessibles. Choisissez les détails pour examiner les preuves actuelles, puis **Retour à la vue d’ensemble des Agents**. Pour un Agent inaccessible, utilisez **Gestion d’équipe** afin d’examiner le réglage restant.

La page lit les informations à l’ouverture, lorsque vous choisissez **Actualiser**, et lorsque vous revenez après au moins une minute. Une lecture incomplète affiche une invitation à réessayer plutôt que des totaux partiels. Un nombre d’approbations indisponible ne vaut pas zéro. Si certaines entrées ne sont pas retournées, la page précise que les graphiques couvrent uniquement les entrées reçues. Si un grand répertoire ne peut pas être lu entièrement, utilisez la gestion d’équipe.

Cette vue ne collecte pas les statistiques d’utilisation, d’adoption, d’activité, de croissance ou de réussite d’exécution. Elle n’approuve pas automatiquement les versions et ne répare pas les Agents.
