# 查看智能体概览

团队负责人和管理员可以在 **智能体** 页头右侧的 **⋯** 菜单（手机在顶部栏）选择 **智能体概览**；市场、我的智能体和榜单都有这个菜单。选择面包屑中的 **智能体** 返回目录。

智能体概览汇总当前团队管理视图中你能读取的条目，不含其他作者的私有智能体和内置智能体，因此条目数量不代表全体成员拥有的全部智能体。

- **管理条目**：成功读取的团队管理条目数量。
- **团队默认**：这些条目中开启团队默认配置的数量。选择 **管理默认配置** 查看或调整。
- **上架检查受阻**：展示内容需要复核的条目数量。下方一行写出其余条目的检查结果，例如「通过 27 · 暂无证据 4」；缺少检查证据的条目计入「暂无证据」。指标下方的说明提醒：上架检查只看展示内容，不代表智能体质量或运行就绪状态。
- **待审批**：当前团队待审的发布候选数量。选择 **打开审核队列** 按原流程处理，仍不能审批自己的提交。

**领域覆盖** 用带数值的横条展示各领域的条目数量。一个智能体可能覆盖多个领域，因此领域数量相加可以超过条目总数。选择图下方的 **查看精确数值** 打开数据表，图上缩短的领域名称会在表中完整显示。

**需要关注** 列出展示内容受阻的条目，以及无法再访问详情的团队默认配置。选择 **查看详情** 复核当前证据，再用 **返回智能体概览** 回到概况；无法查看详情的条目可通过 **团队管理** 检查遗留默认配置。

打开、手动 **刷新**、离开至少一分钟后返回页面时会重新读取。读取失败时提示重试，不展示部分数据得出的总数；待审批读取失败表示不可用，不是零。服务端省略条目时，页面说明数量和图表只统计返回条目。大目录未能读完时，可以进入团队管理查看。

此概况不采集使用量、采用人数、活跃、增长或执行成功率，也不会自动审批发布或修复智能体。
