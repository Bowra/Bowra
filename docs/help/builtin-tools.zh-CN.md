# 内置第三方工具

团队负责人和团队管理员可在“团队设置 → 工具源”中接入 Bowra 支持的第三方工具。当前支持 Tavily、北极九章和 Power BI；选择窗口和已配置列表会显示对应服务图标，方便区分。

“能力中心 → 工具”展示已启用连接的操作。未配置或已停用的 Google Workspace、Power BI 连接不会出现在该目录；Google Workspace 还要求部署功能已开启。管理员仍可通过“管理工具源”配置或重新启用支持的连接。浏览目录不会启用连接或授权外部账号。

## Tavily

选择“添加内置第三方工具”，选中 Tavily 后粘贴 API Key，点“验证并保存”。系统会先验证密钥，再加密保存。保存成功后可随时编辑密钥，或将工具启用、停用。

启用 Tavily 后，具备网络搜索能力的团队智能体才能使用它；停用后，新的搜索不会再使用 Tavily。API Key 不会显示给团队成员或智能体。

### 网络搜索

使用 Tavily 搜索时，可以直接在问题里说明范围，智能体会据此过滤结果，例如“只看最近一周的新闻”“只查政府网站”“排除某个网站”“要更深入的搜索”。新闻类结果会带发布日期。

### 读取网页与整站抓取

如果当前部署已开通这些能力（在智能体的“添加 Tool”里能看到“批量读取网页”等选项），Tavily 还能让智能体一次读取多个公开网页的正文，或先列出一个网站里有哪些页面再挑着读，也可以沿着链接把一个网站的多个页面一起抓下来，例如“读一下这三个链接并总结”“看看这个官网有哪些产品介绍页”“把这个文档站的安装说明都读一遍”。整站抓取默认一次抓约 20 页（最多 100 页）、可能要等两三分钟，消耗的额度也更多；只需要几个页面时，直接给出链接更快。

为防止信息被带到陌生网站，智能体只会读取你在对话里给出的链接、搜索结果里的链接，以及同一网站内列出或抓到的页面；网站页面里指向其他网站的外链只会列出，不会被继续读取。深度研究同样只会围绕你提到过的网站展开，问题里出现陌生网址时智能体会先去掉它。内网地址或需要登录的页面不在这些能力的范围内，智能体会改用直接打开网页的方式读取。

### 深度研究

同样在当前部署已开通这些能力时可用。需要系统性的外部调研时，可以明确说“做一次深度研究”，例如“深度研究一下近半年新能源车出海的公开动态”。智能体会把问题交给 Tavily 的研究引擎，几分钟后拿回一份带来源链接的报告，期间对话里会显示该步骤正在进行。一轮对话最多做一次深度研究；只有你明确要求“最深入、最全面”时，才会使用更贵的模式。

### 开启方式

读取网页、整站抓取和深度研究需要在智能体里分别开启：系统内置的数据分析、营销分析智能体默认可用读取网页与整站抓取，深度研究默认只开放给营销分析智能体；自己创建的智能体，在“配置 → 它能用什么 → 添加…”里切换到“添加 Tool”，勾选“批量读取网页”“列出站点页面”“抓取站点页面”“深度研究”。

### 额度

每次搜索、读取、抓取和研究都会消耗团队 Tavily 账户的额度：“更深入的搜索”和深度读取消耗加倍，整站抓取按页数计，深度研究消耗远多于普通搜索。额度用完或密钥失效时，智能体会在回答里说明网络搜索暂不可用，并提示联系团队管理员；此时请管理员到 Tavily 控制台充值或更换密钥，再在本页更新。额度用尽的密钥仍可保存，恢复额度后即可继续使用。

## 北极九章

选择“添加内置第三方工具 → 北极九章”，填写配置名称、Endpoint 和连接密钥。Endpoint 是北极九章服务根地址，例如 `https://openapi.datarc.cn`，不要填写具体接口路径。系统验证成功后加密保存密钥，列表按“北极九章 - 配置名称”显示。

同一团队可以添加多个北极九章连接，并在智能体的工具配置中分别分配。例如，可以把“北极九章 - 财务数据”分配给财务智能体，把“北极九章 - 销售数据”分配给销售智能体。改名不会解除已有分配；停用或删除后，智能体不会自动改用其他连接。

创建或编辑连接时，系统会读取密钥的接口权限、允许访问的工作区和到期时间，并在编辑窗口按权限、可用工具、工作区和有效期分组显示检测结果。工作区清单默认收起，可按需展开；也可以点击“重新检测”更新范围。旧连接在首次检测成功前、密钥验证失败后或密钥到期后，不会向 Agent 提供相关工具。

部分较早版本的北极九章不提供密钥权限信息。连接这类实例时，系统会用密钥读取它可以访问的工作区来完成验证，权限显示为“全部权限”，并提供全部三项能力；实际能否查询仍以北极九章中该密钥的权限为准。若提示连接密钥未通过验证，请检查密钥是否正确、是否过期；若提示 Endpoint 未提供北极九章接口，请确认填写的是北极九章服务根地址。

系统会按密钥权限分别提供“北极九章工作区查看”“数据结构查看”和“数据查询”。这些是一个连接内部的具体能力，不需要在智能体中逐项配置。

工作区名称匹配到多个候选时，请在卡片列出的工作区中选定一项，系统会继续处理原问题，也包括已交给分析师的任务。工作区选择卡只使用列出的候选，普通问题卡仍可填写自己的回答。不希望修改以后对话的默认工作区时，请取消勾选“设为默认”，只在当前对话使用。选择无法提交时，卡片会保留并说明原因；改选可用候选后继续即可。若访问权限已变化，请选择其他候选，或请团队管理员检查连接和权限。跳过选择卡不代表已完成切换。

## Power BI

选择“添加内置第三方工具 → Power BI”，给连接命名，填写 Microsoft Entra 的 Tenant ID、Client ID 和客户端密钥。可以指定工作区与语义模型 ID；留空时系统会尝试选择可访问的模型。保存时会验证能否查询，密钥加密保存，此后不会显示。一个团队可以添加多个连接，例如财务和销售各用不同模型。

连接前，请组织管理员在 Microsoft Entra 注册应用并创建客户端密钥；在 Power BI 管理门户允许该服务主体所属的安全组使用 Power BI API，再把服务主体加入目标工作区，并授予目标语义模型的 Build 权限。保存时如果提示没有访问权限，请依次检查租户、工作区和语义模型授权。

每个连接都有自己的 DAX 模板列表。负责人或管理员可从连接卡片的“DAX 模板”操作添加或移除模板。连接停用或删除后，获授该连接的 Agent 不会改用其他连接；删除连接也会删除其模板。

在智能体“配置 → 它能用什么”里选择所需的 Power BI 连接并保存。每个连接独立显示；Agent 只会使用已分配的连接。旧版服务主体连接会迁移到工具页；如果原连接使用更早的委托授权方式，则需要在工具页重新配置服务主体。随后到智能体配置中选择连接并保存。连接凭据只代表团队的服务主体，查询权限以该主体在 Power BI 中的权限为准。

## 分配给智能体

打开“智能体管理 → 我创建的 → 配置 → 它能用什么”，点“添加…”，再选择“添加 Tool”。团队工具按连接卡片显示：

- 卡片名称使用配置名称，例如“北极九章 - 财务数据”；
- 勾选一次卡片即可添加整个连接；
- 展开“查看包含的能力”可以确认该连接会提供哪些具体 Tool；
- 搜索支持连接名称和具体能力名称；
- “管理团队工具连接”会跳转到团队设置的工具页面。

保存智能体时，系统固化连接的具体 Tool。北极九章连接按最近一次保存的检测范围生成 Tool；之后不会在每次调用时重新检测或自动扩大范围，再次保存智能体时才会按当前连接范围刷新。外部密钥后来新增的权限不会自动加入已有智能体，原有接口若在外部失效，则在调用时返回对应错误。

例如，团队配置了两个连接：

```text
北极九章 - 财务数据
  北极九章工作区查看、数据结构查看、数据查询

北极九章 - 销售数据
  北极九章工作区查看、数据查询
```

智能体页面只显示两张连接卡，而不是五行名称相近的 Tool。底层仍保存带连接身份的精确 Tool，两个连接不会串用 Endpoint 或密钥。

查询数据时，实际范围同时受连接密钥、当前用户在北极九章中的成员权限和该智能体保存的具体 Tool 快照约束。如果只有一个可访问工作区，系统会自动选择；有多个工作区时，智能体会请用户明确选择。若提示找不到北极九章账号，请确认当前 Bowra 登录邮箱已在对应北极九章实例中创建并加入目标工作区。

连接密钥不会显示给团队成员或 Agent。私有部署可以填写企业内网 Endpoint；SaaS 部署只接受公网 HTTPS 地址。

北极九章连接或成员查询失败不会阻止你发起或继续无关工作，例如写作或发送邮件。任务需要北极九章时，Bowra 会说明数据访问问题，不会在未验证权限的情况下查询。连接密钥过期或被撤销时，请团队管理员在“团队设置 → 工具源”中更新密钥。登录后的账号同步失败也不会使 Bowra 登录失效。
