# Liens de conversation et navigation du navigateur

La barre d’adresse correspond toujours à ce que vous consultez : ouvrir une conversation ajoute cette conversation à l’adresse ; revenir à l’accueil pour commencer un nouveau travail rétablit l’adresse de l’accueil. Copier l’adresse à un collègue disposant de l’accès, actualiser la page ou suivre une notification ouvre la même conversation.

Les boutons précédent et suivant du navigateur suivent l’adresse : revenir à une conversation l’ouvre ; avancer vers l’accueil vous ramène à **Nouveau travail**, comme cette commande dans la navigation de gauche. Supprimer la conversation ouverte depuis l’accueil ou sélectionner le logo en haut à gauche vous ramène également à **Nouveau travail**. Le texte saisi sans être envoyé dans le champ de l’accueil est conservé.

Si le rapport actuel comporte des modifications non enregistrées, une confirmation apparaît avant le départ. **Enregistrer et changer** enregistre les modifications et ouvre l’accueil. **Rester sur ce rapport** vous maintient dans la conversation et rétablit son adresse ; les modifications sont conservées. Dans ce cas, l’historique du navigateur contient deux entrées consécutives pour cette conversation : le premier retour peut sembler sans effet. Revenez une seconde fois pour atteindre la page précédente.
