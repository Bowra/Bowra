# 会话链接与浏览器前进后退

地址栏始终对应你正在看的内容：打开一条会话时，地址里带着这条会话；回到首页开始新工作时，地址回到首页。把地址复制给有权限的同事、刷新页面或点通知跳转，都会打开同一条会话。

使用 `/bowhead/` 这类带路径的访问地址时，保留 `?session=…` 前面的斜杠。如果旧收藏链接把你带到异常的服务器端口，请重新打开团队给你的完整访问地址，并请管理员检查入口跳转，不要自行添加服务器内部端口。

使用浏览器的后退和前进时，页面会跟着地址切换：后退到某条会话就打开它，前进回到首页就回到「新工作」，和点左侧「新工作」效果一样。在首页删除正在打开的会话、或点左上角的品牌标志回到首页，也会回到「新工作」。首页输入框里之前没发出的内容会照常保留。

如果当前报告还有未保存的修改，离开前会先询问：选择「保存并切换」会保存修改后回到首页；选择「留在当前报告」则停在原会话，地址也会回到这条会话，已做的修改不受影响。这时浏览器历史里会紧挨着留下两条这条会话的记录，所以下一次点后退时页面看起来没有变化，再点一次即可回到更早的页面。
