# 对话页的拖放、快捷键与提示

本文介绍对话页上的拖放、快捷键与提示等操作方式。页面各部分的布局见[对话页的布局与操作](conversation-workbench.zh-CN.md)。

## 选择智能体、方法或结果

- 快捷引用可用时，输入 `@` 选择本条消息的智能体，输入 `/` 选择技能、结果契约或工具。从菜单中选择可用项后，它会成为输入框中的标签。
- **结果契约（Outcome）**描述你希望交付的结果。**插件（Plugin）**把工具和技能组合起来供智能体使用，在智能体的资源配置中管理；选择结果契约不会添加插件。
- 资源支持参数时，可点击已选标签编辑。本次选择只作用于这条消息，不改变智能体的已保存配置。

## 把文件拖进对话

- 把电脑上的文件拖到对话区域（对话列表和输入框所在的那一栏），会出现一块虚线框。框里写着「松开即可添加到这条消息」时松开鼠标，文件就会作为附件加到输入框里并开始上传，和点输入框左下角的「＋」选文件效果相同。
- 如果文件不能添加，虚线框会变成红色并写明原因，例如拖进来的都是视频、音频等不支持的类型，这条消息的附件已经太多，或者现在不能添加附件。此时松开不会添加任何文件。
- 一次拖进多个文件时，只要其中有能添加的就可以松开：能添加的照常上传，个别不支持的文件会在输入框里显示为一条带原因的附件，可以把它移除。
- 一条消息最多带 5 个附件。使用对象存储的部署中，普通文件最大为 2 GiB；使用本地存储的部署中，最大为 100 MiB。Word 和 PowerPoint 文件最大为 32 MiB，ZIP 压缩包最大为 500 MiB。可以添加表格、PDF、文档、图片与文本等常见格式。
- 回答进行中也可以拖入文件，它们会作为你下一条消息的附件。
- 成果区和报告里不接收拖入的文件，报告里的拖动仍用来调整章节顺序。
- 添加文件前请先选择空间，上传完成后再发送。切换空间、对话或账号会停止尚未完成的上传，请在目标对话中重新添加文件；已经添加成功的文件仍属于原草稿。
- ZIP 展开后的文件另有每条消息最多 100 个的限制。请拆分较大的压缩包，或移除一个分组后再发送。如果无法继续读取索引进度，附件会显示错误，可以移除或重试。
- 发送 ZIP 前，可以点击附件上的下箭头打开「文件包内容」。失败的文件排在最前，跳过的文件会写明原因；已索引超过 6 个时，其余收成「还有 N 个已索引」，仍在索引的文件只计入附件上的数字。手机上内容从屏幕底部弹出，点「完成」收起。索引完成后仍可展开查看。
- 附件上传失败时，附件上只写「失败」，完整原因显示在输入框下方，旁边的「复制诊断信息」可以把诊断信息发给管理员。
- 每个附件用线条图标表示类型，扩展名和大小写在文件名后面；文件名太长时先省略文件名。
- 同一个文件（同名且大小相同）再添加一次不会多出一个附件：原来的附件会闪一下边框，读屏会播报「这个文件已添加」。

## 调整对话与成果的宽度

- 电脑上，对话和成果之间的分隔线可以用鼠标拖动。
- 也可以用键盘：按 Tab 移到分隔线上，按左右方向键每次调整一点宽度，按 Home 把对话栏收到最窄，按 End 把对话栏放到最宽。读屏软件会读出对话栏占的比例。
- 双击分隔线，宽度回到默认比例。
- 调整后的宽度会记在这台电脑的浏览器里，下次打开仍保持。

## 放大成果区的快捷键

- 在 Mac 上按 ⌘⇧\（Command + Shift + 反斜杠），在 Windows 上按 Ctrl + Shift + \，可以把成果区放大到整个工作区，再按一次恢复。成果区右上角的放大按钮提示里也写着这个快捷键。
- 放大后左边会留一条窄栏，点它也能回到对话。按 Esc 不会恢复，Esc 用来关闭菜单和弹窗。
- 不带 Shift 的 ⌘\ 或 Ctrl + \ 仍用来收起或展开左侧导航栏。
- 这里的 \ 指美式键盘上反斜杠所在的那个键位。其他键盘布局上这个位置印的可能是别的字符；在支持读取键盘布局的浏览器里，放大按钮的提示会直接写出你键盘上的那个字符，否则会注明「美式键盘的 \ 键位」。
- 有菜单、下拉列表、弹窗或浮层打开时，这个快捷键不起作用，先关掉它们再按。
- 这个快捷键只在电脑宽屏、并且有成果时有效。Safari 浏览器自带的「显示所有标签页」也用 ⌘⇧\，如果在 Safari 里按下后打开的是标签页总览，请改用放大按钮。

## 「成果」上的小圆点

- 你停留在对话页、而成果区里出现了新的报告章节、数据表或文件时，手机上方的「成果」切换和电脑右侧收起后的「成果」窄栏会出现一个小圆点，读屏软件会读作「有新内容」。
- 打开成果区看过之后，小圆点就会消失。刷新页面后，还没看过的新内容仍会显示小圆点。

## 把某一轮分享给智能体负责人做评测用例

如果回答你的是别人负责的团队智能体，回答下方「复制」旁的「⋯」菜单里有「分享给负责人做评测用例」。分享后，这个智能体的负责人可以把这一轮（你的问题和你收到的回答）做成测试用例，用来检查智能体以后的回答。对话里的其他内容不会分享，负责人也看不到你的其他对话。

- 负责人在列表里看到你的名字和问题开头；只有在用它起草用例时才会读取回答。
- 想撤回时，打开同一个菜单，选「取消分享给负责人」，这一轮就会从负责人的列表中消失。负责人已经用它起草的用例是对方的副本，会留在对方的评测组里；如需删除，请直接联系负责人。
- 删除这段对话或离开它所在的空间后，分享也会自动失效。
- 只有你不负责的团队智能体才有这个菜单。内置智能体或你自己负责的智能体的回答没有这个菜单，你自己的对话本来就可以直接使用。

## 把团队智能体的回答标记为不好

团队智能体的回答下方，「复制」旁有一个点踩按钮。回答有错或没有帮助时可以用它：

1. 点按点踩按钮，会打开一个小对话框。里面都可以不填，直接提交也会记下。
2. 勾选适用的原因：「事实或数字不对」「没回答我问的」「漏了重要内容」「太简略」「太啰嗦」「格式或表达不好」或「其他」。也可以写最多 500 字的补充说明，说明你期望的回答。
3. 如果这个智能体由别人负责，对话框里还有「允许智能体负责人用这一轮做评测用例（负责人会看到问题、回答和你的反馈）」，下面写着负责人是谁。除非你已经分享过这一轮，否则它默认不勾选。只有想让负责人看到这一轮时才勾选：它和「⋯」菜单里的「分享给负责人做评测用例」是同一个同意，勾选后负责人还会看到你选的原因和补充说明。对已分享的轮次取消勾选，会取消分享。
4. 点「提交」。按钮会保持高亮，并出现带「撤销」的提示；撤销会收回这次点踩，以及刚刚加上的分享。

- 之后想撤销点踩，再点一次高亮的按钮。这样也会撤回给负责人的分享；需要时可以在「⋯」菜单里重新分享。
- 不勾选时，点踩只有你自己知道，智能体负责人看不到。
- 内置智能体的回答没有点踩按钮。

## 发送键不可用时的原因

- 发送键暂时不能点时，输入框下方会用一行小字写明原因，例如「等附件上传完成后才能发送」。原因消失后即可发送。
- 读屏软件在发送键上也会读出这条原因。
- 输入框下方同一时间只显示一条提示：发送失败等错误优先，其次是挡住发送的冲突，最后是一般说明。其余提示收在「还有 N 条提示」里，点开可以逐条查看并直接执行修复动作，例如「移除附件」「改为新请求」、附件超过上限时的「移除多余的 N 个」、Google Drive 未连接时的「去连接」（打开「我的连接」），以及草稿暂时没保存时的「重试保存」。处理掉一条后，下一条会自动显示。
- 从画布「在对话中修改」进入时，输入框正文上方会显示「正在修改」、草稿的文件名和版本（例如「正在修改 Q2 运营复盘.pptx 第 2 版草稿」）；点文件名可以在画布中打开这份草稿，点右侧的 × 可以不再修改，改为普通提问。
- 打开或关闭 Canvas 时，输入框可能短暂停顿，等待草稿保存完成。如果草稿恢复持续暂停，请保留页面，在本地存储可用后点击「重试恢复草稿」。最后编辑、已上传附件和选中引用会被保留；重试恢复不会发送消息。存储恢复前关闭或刷新页面，尚未保存的编辑可能丢失。

- 附件在任务开始前被拒绝时，输入内容会保留，方便移除附件或重新上传；修正附件时可保留原来选定的智能体和方法。一次工具调用被拒绝会显示为失败，即使后续修正调用后整个任务成功，也不会把先前的尝试改成成功。

文件上传期间，如果另一个窗口修改了草稿，上传仍可完成。请先检查并解决草稿冲突，再发送。保留本地草稿会保留已完成的附件；选择另一份草稿会替换本地输入和附件。

输入草稿包含消息文字、附件和选中引用。右侧 Agent 编辑器的「草稿已保存」指的是 Agent 配置，不是正在准备的消息。后台能力更新不会替你合并其他窗口的草稿；出现冲突时，请先核对再发送。

## 等待问题或文档结果

如果问题暂时还不能继续处理，请保留回答，稍后通过原控件重试。等待提示不代表回答已经保存。文档规划未能完成时，请查看文档编辑器中的已知原因和用量状态，已停止任务可能没有可继续回答的问题；此时尚未发布文件，修改后重新发送是另一次操作。

请在任务原来的问题卡上回答。任务支持保留已完成子任务时，回答会继续同一任务，不重跑已保留的工作。若原文件或访问权限已不可用，可能无法继续；请先查看提示，再决定是否发起新请求。重复点击不会替换已经保存的回答。

对于保留已完成子任务的任务，如果回答已保存但任务无法安全继续，重新打开对话仍会显示这一限制。请先核对已经完成的工作，并在可能时恢复所需文件的访问权限。确认原任务结果后再决定是否发起新请求；刷新不会重跑任务，也不会替换已保存的回答。

可使用 PowerPoint 模板流程时，模板只需附加一次，并在消息中说明它是模板。替换值可以直接写在消息或澄清回答里，不必额外上传数据文件。发布前请检查所有拟修改内容，尤其注意具体改的是标题、页脚还是表格里的数值。

如果想新建演示稿，请说明附件只作为样式或内容参考；这不代表保留原来的页面。模板更新不可用时，助手应说明限制，不能悄悄交付一份重建的 PPT。模板草稿的 PDF 来自对应已审阅演示稿，而非另一份报告。

如果希望编辑已上传模板前先检查或提问，请在消息中说明。有澄清时使用原问题卡回答，再到 Canvas 审阅草稿并明确确认后发布可编辑 PPT 和对应 PDF。请检查助手是否遵循了你的步骤并保留模板；通用文件或一条已完成的回复不等于经过审阅的模板草稿。如果只要摘要或参考附件另建演示稿，请直接说明。

## 报告改写的草稿与重试

- 在报告编辑时让 AI 改写一个章节或一段选中的文字，如果写了一半指令就关掉了输入框（点「×」、点到别处或按 Esc），再次在同一个章节打开时，刚才写的指令还在。每份报告的每个章节分别保存；发出后清空。刷新页面后不保留。
- AI 改写失败时，提示条上有「重试」，会用同样的指令对同一段文字再改写一次。如果这段文字在此期间已经被改动，提示条会直接收起，请重新选择要改写的文字。

## 报告里的键盘操作

- 编辑报告时选中一段文字，按 ⌥⏎（Mac 上 Option + Return，Windows 上 Alt + Enter）可以把焦点移到文字上方的格式工具栏，用左右方向键在按钮之间移动，按 Enter 或空格执行；按 Esc 回到正文，刚才选中的文字仍然选中。用中文输入法打字、候选词还没上屏时按下不会起作用。
- 章节菜单打开后，可以用上下方向键选择、Enter 执行、Esc 关闭。不可用的项也能用方向键停上去，读屏软件会读出原因。
- 把焦点移到角标上按 Enter，会打开这条来源；焦点在来源卡片里时按 Esc 关闭并回到角标。图表下方的来源行同样可以用 Enter 或空格打开、Esc 关闭。

## 本轮无法完成时

错误卡会说明已记录的原因，例如模型超时、请求过多、回答中断或达到执行上限，请按卡片上的操作处理。模型认证失败需要团队管理员检查访问配置，可复制诊断信息协助排查。额度不足会区分个人额度和团队额度。

如果错误卡提示系统处理出错，可点击「重试」。若再次发生，请展开「技术详情」，复制诊断信息并发给团队管理员，以便定位失败轮次。

某一步完成不等于整个请求完成，重新发送前先核对已经展示的工作。任务无法继续时，选择**编辑后发送**会在发送后发起新请求，不会继续原任务；未记录失败环节时，卡片会明确说明。

如果某一步没有可安全展示的具体错误，界面会说明该步骤执行失败。请核对已显示的步骤信息；若有技术详情，也可复制已记录的诊断。失败卡会区分服务执行中断和结果未能完整保存；模型执行环节有记录时才会显示。若问题再次发生，可将复制的诊断信息发给管理员继续排查。
