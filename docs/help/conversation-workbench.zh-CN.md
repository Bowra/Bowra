# 对话页的布局与操作

本文介绍对话页里表示进度、结果和操作的各个部分，以及报告工具条上的写作进度、状态与分享。

## 首页

- 首页是居中的一列，从上到下依次是：标题与一句当前概况、输入框、几张「从一项工作开始」的建议卡片，最后是待处理、进行中和最近产出的工作。输入框不再固定在页面底部，而是紧跟在标题下面。
- 用键盘浏览时，Tab 的顺序与看到的顺序一致：先到输入框，再到建议卡片，最后是工作列表。
- 你在当前空间只能查看、不能发起工作时，建议卡片显示为不可用，下方会写明原因。
- 点建议卡片、打开工作列表里的一项、从别处带着文件回到新工作，用法都和原来一样。

## 找到更早的会话

- 侧栏（手机上是会话列表）先显示你最近的会话。还有更早的会话时，「更早」分组最后一行是「更早的会话」。点一下，下一批 50 个会话会接在已显示的会话下面，列表不会跳动，键盘焦点移到新出现的第一个会话。没有更早的了，列表末尾会写「没有更早的会话了」。
- 滚到列表底部不会自动加载更早的会话。加载失败时，已显示的会话保持不变，点「重试」会重新加载同一批。
- 侧栏顶部的搜索框始终搜索你的全部会话，而不只是列表里已加载的那些。会话可以按标题找到，也可以按你自己写过的话找到，所以即使标题被改过也能搜到。命中来自你的提问而不是标题时，结果上会标「内容」，并显示命中词前后的几个字。
- 每个结果分组都会写出命中的数量。「会话」分组先显示 5 个，点「显示更多会话（还有 N 个）」每次再多显示 20 个。清空搜索框会回到原来的列表，已经加载出来的更早会话仍然保留。
- 某一类结果暂时搜不了时，会在它的位置写一行说明，其他结果不受影响。

## 运行进度

快速查数时，写清指标和期间，例如“上月营业额和客流量情况”。回答聚焦这些数值；需要品牌／门店拆分、原因、趋势或表格／图时，请明确提出。数值或范围无法核实时，回答会说明具体限制。

发送前可在输入框选择模型。个人选择也会同步到其他已打开的标签页；选择「使用团队默认」可清除个人选择。已经发送的任务保留开始时的模型选择。

续聊时请写清新的问题和要使用的文件。通过 `@` 选定的 Agent 会收到本轮请求。前面消息保留的 PPTX 是可用材料，本身不代表要生成新演示稿；需要制作演示稿时，请明确提出。

- 发送后，回答上方的进度框内容不变：第一行写进行到哪个阶段、第几步和已用时间，下面两行是刚完成的步骤，最后一行是正在做的事。进度框改为更轻的细边框，文字统一为界面字体，已完成步骤的勾改为灰色，遇到问题的步骤用提醒颜色标出。点第一行可以展开完整过程，再点一次收起。
- 要停止本次回答，点输入框右下角的「停止」（灰色底按钮，与发送键区分开）。点下后按钮会变成「正在停止…」，直到这一轮真正结束。
- 回答完成后，进度收成一行「N 步完成」，点它可以再展开过程。本轮没能完成时，进度收成一行「未完成 · 已完成的步数 · 用时」（知道计划步数时写成「3 / 5 步」），点它同样可以展开完整过程；原因和可用的恢复操作在下方的失败卡里。

即使任务后来完成，失败步骤仍保留在过程历史中。问题计数表示失败或部分完成的步骤数，不是重试次数。本轮完成且这些问题没有影响回答时，折叠行会用灰色写「N 个步骤已自动处理，不影响回答」；只有未完成的步骤可能影响回答时才显示醒目的提示，此时请核对回答涉及的数据。

本轮没能完成时，失败卡会说明已记录的原因；无法确定环节或原因时，也会明确说明。请按卡片提供的操作处理：「重试」再次尝试同一个问题；「编辑后发送」将问题放回输入框，修改后会发起新请求。较早的失败可能只能回填问题供你检查。「复制诊断信息」帮助管理员排查权限、额度或配置问题；「新建会话」在新会话里带上原问题。功能可用时，「继续执行计划」会核对原计划版本和空间后继续同一个计划；核对失败时请编辑请求。额度错误会说明需要处理哪一方的额度，请联系管理员核对后再尝试。

展开「技术详情」可查看已有的发生位置、界面版本和已记录时间，并复制诊断信息发给管理员。没有失败卡时，可点会话标题栏右侧的「⋯」（手机上在顶部栏），选择「复制诊断信息」，其中包含会话与对话轮次编号。同一菜单也可重命名、置顶和归档。任务运行时可以补充要求；暂停或结束后的历史失败，不代表下一次尝试正在进行。重新发送前，请核对已完成步骤、可用结果及相关文档状态。

如果是模型服务失败，卡片会分别写明问题判断和建议操作。有足够信息时，会指出是连接失败、账号被拒、模型或接口未找到，还是请求参数被拒。认证失败时，请联系团队管理员检查模型连接的 API 密钥和访问权限；系统不会自动重试同一个连接，已配置备用模型时仍可能尝试备用模型。等待超时或请求过多时，可稍后再试。点一次「技术详情」可查看服务方报错；展示前会过滤敏感内容。若没有可安全展示的原文，请复制诊断信息交给管理员排查；较早的失败记录可能没有服务方报错。

模型调用失败时，失败卡会直接显示已记录的原因、可用的 HTTP 状态码、经过敏感信息过滤的模型服务说明及处理建议。刷新或重新打开会话后，仍可看到这些信息。Responses 请求被拒绝时，请联系团队管理员检查接口类型和请求配置；只有网关或模型确实不支持 Responses 时，才改为 Chat Completions。HTTP 400 本身不能证明接口不兼容。调用结果尚未确认时，系统会停止自动重试，请联系管理员核实后再发送。服务未提供可安全展示的说明时，可用「复制诊断信息」协助排查。

## 长时间运行的任务

- **可以离开页面。** 任务在后台照常运行，回来后打开会话就能看到结果。连接中断时页面会自动重连，只有确认任务已经停止才显示失败。
- **进度。** 一分钟内没有新步骤时，运行条会写明哪个智能体在运行、走到第几步、这一轮用了多久，例如「仍在运行 · 数据分析专家 · 第 37 步 · 已用 18 分钟」。
- **完成提醒。** 你不在这个会话时，任务结束会在右下角弹出提示，点「打开」回到会话。第一次弹出时会问是否在标签页处于后台时也发系统通知；只有安全连接（HTTPS）的站点能开启。
- **部分完成与继续。** 任务碰到团队设置的运行上限时，智能体会交回已完成的部分，步骤列表会标出哪个智能体停在了哪个上限。点回答下方的「继续」，原来的智能体会带着它之前的全部进度接着做未完成的部分，不会从头再来。你也可以直接打字追问或说「继续」。每次继续都按团队当前的上限重新计算。保存的进度保留 30 天；如果进度已过期，或这个智能体及其可用工具在此期间发生变化（例如连接的服务已不可用），会由新的智能体按原任务重新开始，步骤里会写明原因。额度用完时，先补充额度再点「继续」。

## Agent 协作详情

只需回答的 Plan 会在聊天中交付结果，不生成报告章节；另外明确请求的图表和文件沿用原交付方式。停止操作确认后，尚未完成的协作事项显示已结束且依赖未解决，已核验事项保留已核验状态。部分核验通过的结果仍可能有用，不会因此自动把整个任务判成失败。

有计划的任务会同时核对步骤原目标和验收条件。明确要求的检查仍待完成，或无法确认是否完成时，即使数值正确，该步也可能只显示部分核验通过。核验徽标会说明哪些要求未达或无法确认及其原因，刷新后仍可查看；请结合步骤要求再决定是否采用结果。这不改变你选择的 Auto、Plan 或 No plan；已有历史结论不会重新计算。

Lead 主导的普通聊天中，参与任务的内置及你可用的自建 Agent 可以自动向同伴提出具体问题，无需安装插件或开启设置。任务包含 Agent 协作记录时，展开运行进度可以查看谁向谁提问及收到的回复。收到回复不等于依赖已核验：提问者还需要确认回复能否解决问题。已说明的限制，以及任务结束时尚未解决的依赖，也会保留显示。

点击证据引用可在结果区打开。详情按你当前的访问权限读取，不再可用的内容会隐藏。读取失败时可以刷新；刷新不会重新向 Agent 提问。协作记录位于原有任务进度中，无需打开单独的会议页面。

Auto 仍按原规则决定是否规划。Plan 中执行的步骤也能向可用同伴或 Lead 求助；Plan 模式仍须先由你批准再执行。只有当前已分配且可用的参与者能直接答复；其他 Agent 提到一个已结束或尚未开始的步骤，不会使它重新启动。

Lead 向你澄清时，直接回答原问题卡。支持继续的任务会保留原工作和协作记录；中断后不能安全继续时，任务会说明限制，打开历史不会重新执行。

## 回答下方的操作

- 「复制」和「编辑后发送」显示为两个小图标。鼠标停在图标上会显示名称。
- 最近一条完成的回答，这两个图标一直显示；更早的回答在鼠标移到这一轮或用键盘切换到按钮时才出现。手机和平板上一直显示。
- 点「复制」后，图标位置会短暂显示「已复制」。

## 引用角标

AI 回答里的网页引用有标题或来源名称时显示该名称；直接写成完整网址的链接会显示主机名，历史会话也适用。点击打开原网页；鼠标停在主机名上可查看完整地址，也可以右键选择浏览器的复制链接功能，手机上则长按链接。代码格式的网址仍完整显示。需要回答列出完整地址时，可以要求“把网址用代码格式列出”。

回答里的数字角标位置、编号和点开后的来源都不变。你无权查看或已经失效的来源，角标显示为带删除线的描边样式。

询问代码或消息格式时，请粘贴完整示例，并用代码块或行内反引号标明。回答引用示例时会保留代码格式；只有实际出现的提问卡片才需要提交澄清答案。

## 需要你回答或批准的卡片

对话中请你选择、补充信息或批准计划的卡片，在等你处理时带一圈提醒颜色的边框。回答或批准后，卡片收成一行结果留在对话里，刷新后也一样。

回答提问卡片时：

1. 点选一个选项，或在「其他，自己输入…」里写下答案。点选只是选中，发出前可以随时改选。
2. 点「继续」或按回车提交。一张卡有几个问题时，没选的问题可以留空，模型会按上下文判断。
3. 不想回答时点「跳过，让模型判断」；一张卡有几个问题时，这个按钮叫「全部跳过」。

文档任务缺少信息时，卡片顶部写着「需要补充信息 · 文档草稿」，主按钮是「继续生成」。回答后会保留原需求、模板和数据，并重新检查是否仍可使用。

Datarc 查询需要选择工作区时，请在卡片上选择本次数据来源并继续。等待选择不代表查询没有数据；系统重新检查访问权限后，会用你选择的数据来源继续同一任务。

提交答案失败时，卡片会保留你的选择并说明原因。如果提示结果尚未确认，请先刷新对话，核对选择是否已经保存，再决定是否重新提交；其他情况按卡片提供的操作处理。问题已过期或已处理时，「重新提问」会将原问题放回输入框供你修改，不会自动发送。

问题仍在等待处理时，你也可以继续发消息。助手会结合近期原需求、问题和已保存答案理解话题，例如“改成报告吧”可以承接刚才的天气 PPT 请求。这不会恢复之前的任务；要继续原任务，请在原卡片上操作。

在支持多轮澄清的环境中，助手可以在开始执行前继续询问必要信息，最多三轮。请回答最新卡片，之前的答案仍保留在同一任务中；通过 `@` 选定的 Agent 不会改变。重复提交旧卡片不会重新启动任务。这个三轮流程适用于执行开始前。

当前工作无法保存后续问题时，不会创建卡片，失败步骤会写明「澄清问题未能创建」。助手说明还缺少哪些信息后，你可以在对话中补充；已有结果仍保留，助手也可以继续处理。这与已回答受支持的执行后问题、再次提问被拒绝不同。已保存任务的访问或恢复检查失败时，对话会单独说明并保留你的答案，请按提供的操作处理。

在支持的任务中，助手也可以在一次或多次委托检查、计算完成后再问一次。这也包括同时进行、且均已结束并确认结果的独立检查。请在原卡回答：任务保留原文件和结果继续，不重跑已完成工作。如果文件、技能、智能体或 Canvas 内容已变化或无法访问，续跑会停止并保留答案。不要把答案当成新任务发送来恢复旧任务。

例如，你可以要求助手阅读 PPTX、根据内容计算，再询问汇报对象，而不修改或生成文件。这属于只读任务，不是模板生成。如果助手仍无法判断用途，请按失败提示说明你需要分析，还是保留版式修改。

这适用于受支持的系统和团队智能体。操作失败后，助手会收到具体错误，可以修正请求、重试或换用其他可用工具，已有结果仍可使用。在原卡回答会继续原任务，不会自动重跑之前的操作，也不代表确认了未知结果。各项操作仍遵循原有权限和审批流程。如果原任务未能保存，则无法恢复。

继续任务时会保留原始请求、之前的答案和原来使用的文件。如果某个文件已不可访问，任务会停止，不会悄悄改用其他文件。

如果回答后任务在开始执行前恢复失败，已保存的答案仍属于原任务，不会占用另一轮提问。只有卡片明确提供「重试」时，才可再次提交相同答案。只有上次尝试已安全停止，才能继续原任务，不会另外启动一份任务。

对话中出现「记忆建议」时，点「记住」把它保存为你的个人偏好，点「仅这次」只在本轮照做、不保存；可以改写的建议还有「改一下」。记住后，结果行里可以点「撤销」，也可以点「在记忆中查看」打开「个人设置 › 记忆」。撤销后结果行显示「已撤销」；撤销没成功时会写明并提供「重试」。

任务正在完成暂停时，刚出现的问题会保留在对话中。此时卡片写着「正在保存进度，几秒后就可以回答。」，选项暂时不能点；进度保存好后卡片会自动恢复，不需要刷新。任务无法继续且不允许重试时，对话会核对原答案的状态。确认已保存后，会明确提示「回答已保存」；请点「复制诊断信息」联系管理员，不要重复提交这份回答。暂时无法确认保存状态时，请先刷新对话核对，再决定是否重新提交。

支持的续跑也会保留提问时已带入的较早对话文件和结果。之后新固定的文件不会加入暂停中的任务。取消固定影响后续请求；删除所需文件或失去访问权限会阻止继续。

如果升级后某次澄清暂时无法继续，请保留当前会话并联系管理员检查兼容性。原问题和已保存答案会保留，系统不会自动把该答案作为新任务发送。

智能体读取你附上的 Word 或 PowerPoint 后提出问题时，在原卡回答即可基于已读内容继续；文件仍须可访问且未改变。标注「自由输入」的问题直接填写文字，不需要多选。尚未确认的操作仍保持未确认，但这本身不会阻止助手继续其他工作。

## 成果区

- 电脑上，对话和成果之间的分隔线在鼠标移上去时出现把手，可以拖动调整宽度。
- 把成果区放大后，左边会留一条窄栏，点它回到对话；关闭成果区后，右边的窄栏用来重新打开成果。
- 手机上，页面顶部用「对话 / 成果」切换两个页面。成果里除了报告，还有数据表和文件。
- 文件预览中的「全屏查看」会在电脑和手机上铺满浏览器内容区域。点「关闭」或按 Esc 返回，键盘焦点会回到「全屏查看」。支持 HTML 交互预览的环境会提供「交互／静态阅读」。交互支持筛选、标签切换、计算、图表和小游戏等离线控件，外部连接、提交和外部依赖会被阻止。静态阅读显示可用的静态内容。切换查看方式或重新加载会重置页面，全屏切换保留当前状态。脚本出错或依赖被阻止时，可切换静态阅读或下载未修改的原文件。

把文件拖进对话、用键盘调整宽度与放大成果、新成果的小圆点等操作，见[对话页的拖放、快捷键与提示](conversation-workbench-actions.zh-CN.md)。

## 审阅文档与找到文件

修改采用已核实的先前澄清回答时，来源显示「你的澄清回答」及相应答案；文件证据则显示文件名。澄清回答不代表你又上传了文件，发布前仍需核对修改是否符合你的意思。

没有报告时，**成果**直接列出可用的文档草稿和文件，选中后打开；进入列表不会发布。关闭文档审阅后，同一浏览器页签刷新仍保持关闭；需要继续审阅时，从该列表或 Canvas 标签栏右侧的 **+**（打开…）菜单重新选择。新的草稿仍可出现。

文档仍待澄清或未能完成时，不会自动打开空报告。电脑上点右侧「重开成果」，小屏幕上点「成果」。可以直接打开列表中的文档，也可以使用标签栏的 **+** 菜单。关闭最后一个自动打开的审阅时，若没有报告或你先前主动打开的成果，会回到对话。

在标签栏 **+** 菜单的「本次对话的文档草稿」中选择文档，核对预览及修改。勾选框和「确认并发布」固定在审阅底栏。对象标签（窄屏为标题切换器）和标签上的关闭按钮 × 保留在正文上方；关闭视图不会取消文档。

审阅中分别显示修改前、修改后及可用来源。「关于此预览」可查看渲染说明；存在字体替换时，可展开字体警告。完整预览停留约一秒即记为已看。有些草稿须查看全部页面，因为变更清单无法核验所有格式和内容，请按剩余页数逐页检查；其他草稿只要求查看修改页。看完要求的页面后，勾选「我已核对修改、数据来源和预览」，再「确认并发布」。请自己核对报告期间、旧示例内容和相关表格／图表数值；文件成功生成不代表这些选择一定正确。

发布后点「打开 PPTX」或「打开 PDF」，直接进入成果中的原文件，再使用原下载操作。草稿尚无输出名时使用简短名称及稳定后缀，原请求摘要另行显示；在编辑器展开「你的请求」可查看完整原请求。「新建智能体」显示在智能体创建编辑器内。

环境支持新建原生图表时，请说明每张图的指标、单位及放置位置。模板原来没有图表，也可以使用受支持的新可编辑图表。预览时核对标题、坐标尺度、负值和缺失观测；图表图片仍是图片。可用范围取决于当前环境的演示文稿能力。

需要修改尚未发布的待审稿时，使用可用的「在对话中修改」。这只会在原输入框选中该精确草稿，不会自动发送。写明修改要求并发送，新稿会从所选版本继续，保留此前的修改；发布前仍需重新检查新预览并确认。该动作不会修改已发布文件。

生成失败时，编辑器说明已知原因，并分别显示已结算用量及待核对／暂不可用的用量状态。「检查状态」只读取原任务；「返回对话」保留未发送输入，两者都不会重启生成或发送新请求。已停止任务不提供发布或改稿；可以先核对原对话，再决定是否发送新请求。

重新打开对话会恢复其原空间。另一浏览器页签切换空间，不会重定向你正在操作的对话。

如果文档提示无法复用此前的澄清回答，本次任务已停止，未发布文件。请发起新请求，重新附上模板，并明确写出已经确认的选择。「检查状态」或重开旧任务不会修复这些回答。

如果模板请求未被受理，该次提交没有创建文档草稿。请先检查请求，再决定是否重新发送；一段完成的文字说明不代表已有可下载文档。

## 右侧设置页面

功能可用时，空间管理员可在“空间设置 → 常规”选择“在 Canvas 中打开”，在 Chat 旁操作原空间偏好页面。周起始日和数据语言选择后即时保存；点对象标签（手机上点标题切换）回到已打开的智能体编辑器，其中的输入会保留。用标签上的关闭按钮 × 关闭视图；有未保存的名称或描述时，会先询问是否放弃。

支持对话建议时，选中偏好页，描述希望怎样修改**周首日**或**数据语言**。先完成手动保存，再在 Chat 或原控件旁审阅建议，选择**应用**；查看建议不会保存。确认应用或撤销后，页面读取已保存值，不会切换到其他对象。

对话在保存建议后中断时，先审阅已有建议，再决定是否重新发送。已保存的建议仍需本人确认；对话未完成不会撤回建议，也不会保存设置。

其他字段保留原手动控件。如果当前发送方式不支持设置编辑，消息会留在输入框。关闭后重开页面，不会将旧建议绑定到新页面实例；请从打开的页面重新发送。**刷新已保存设置**会重新加载页面，请先完成手动修改。

## 右侧智能体草稿

功能可用时，打开草稿或选择**新建智能体**，继续自己的已有草稿或新建一份。在同一页面修改名称、工作说明和工具，也可以描述修改并生成建议，无需切换编辑页面。查看变化字段，逐项选择或**选择全部支持的修改**，再明确采用。

点对象标签（手机上点标题切换）在草稿间切换，各自保留未完成的输入与已保存版本。点最前面的**成果**标签查看成果，编辑器仍保留；再点对象标签即可回到原对象。放不下的标签收在**更多**里。对话发送时固定当时选中的对象，之后切换不改变那条消息的目标。

保存草稿与**创建私有智能体**是不同动作。创建后，功能可用时选择**开始使用**，通过原新对话流程选择这个精确智能体，不会自动发送任务；管理按钮打开已创建智能体。

智能体草稿会自动保存，关闭标签时不再询问；只有保存仍在进行或保存失败时，才会询问继续编辑还是放弃未保存的修改。离开工作时逐一检查全部未完成编辑器。保存结果未知时，选择**核对已保存草稿**并保持页面打开，直到确认原保存结果，不要另生成一份来恢复。

## 报告

在桌面端，打开报告工具栏的「更多操作」，选择「缩小边距并加宽正文」，可以让报告使用更多空间；选择「恢复默认边距和正文宽度」即可恢复。这个阅读偏好保存在当前浏览器，不会改变保存的报告或导出文件。也可以拖动对话与成果区之间的分隔条，调整两边的宽度。

图表回答、报告及浏览器导出中的 Table 使用同一无外框阅读样式；仍从原图型按钮选择 Table。图表设置适配窄屏，内容较长时可滚动查看。

地区时间序列图可以按同一期间或原始行联动折线、散点和 Table。缩小期间后保留原系列名称与顺序，缺失观测继续显示缺失，不显示为零。“追问选中观测”携带完整原始键和原值。

- 图表回答可以把同一份已计算数据组织成多个互补视图，例如走势下接精确数据，或贡献图旁配排名。每个视图保留已有图型和更多按钮。窄屏按阅读顺序排列，下载文档按该顺序保留全部视图；可以在问题中说明需要的安排。新增简单计算列时，图下展示算式；输入缺失或分母为零的结果保持不可用，不会补成零。
- 编辑报告时，组合图里的各子图仍使用原图型按钮。打开原图表设置，选择**子图**，再调整该子图的标题、图型、图例或标签。选择**组合布局**可保存纵向阅读、两列等宽或两张子图的主图与详情，保留全部子图的阅读顺序和数据；保存时保留其他子图和来源，仍是一张组合图。不兼容的图型不保存并给出说明；只读图表不提供保存编辑。

- 在趋势图中移动指针可比较同一完整期间的可见系列。hover、固定详情与 Table 使用可读的完整量级数字：金额最多 2 位、普通小数最多 4 位、明确整数不留小数、百分比最多 2 位；明确要求固定精度时可保留末尾零。Table 的共用单位放在列标题，百分号仍随数值显示。
- 坐标轴按绘制范围选择共同量级，并保留刻度间真实差异；Card 和数值标签按自身数值选择量级。已知金额单位时，0.0009 亿元可在 Card 显示为 9 万元、hover 显示为 90,000 元。来源核对／原文件下载保留可得原始表示。分组符、小数符、币种身份及量级写法跟随当前语言，德语与法语分别处理。饼图占比明确指可见项目，隐藏项目后占比同步更新。
- 折线末尾显示系列名称；提前结束的系列同时写明实际最后期间。名称放不下时仍可从图例和查看数据中读取。标题或副标题明确给出单年范围时，月度刻度可以省略年份，数值读取保留完整期间。
- 指标单位不同或不完整、不能共轴时，图表显示原值表格并说明原因，可选择兼容图型比较。散点提示分别写明两个坐标的单位；热力图颜色图例写明编码指标单位。

- 报告上方的工具条变矮，编辑、导出和更多操作之间用细竖线分组；正在编辑时，右侧的「完成」是唯一的实心按钮，旁边小字显示「已保存」「保存中」或「保存失败」。
- 报告状态在工具条左侧。默认的「活跃」报告不显示状态标签，要标记为已核对或归档，打开工具条「⋯」；已核对、可能过时、已归档的报告会显示状态标签，点开可取消核对或恢复。别人分享给你、只能查看的报告里，标签只显示状态，不能修改。
- AI 正在写报告时，不再在报告顶部单独显示一条「进行中」横幅，写作进度（例如「正在更新报告 · 第 3 / 6 节」）写在工具条左侧。已经写完的章节正常显示、不再整体变淡；正在写的那一节左侧有一条彩色竖线，上方写着「正在写『章节名』」，下方有两行灰色占位条，写完后变成正式内容。读屏软件大约每 10 秒读一次写作进度。
- 写作过程中「导出」暂时不能用，工具条下方写着「写作完成后可以编辑和导出」。如果网络断开、正在重新连接，写作进度会换成「输出已暂停，正在重新连接」；如果连接没能恢复，会写「连接中断，已写的部分已保存」，点旁边的「刷新报告」可以重新载入报告当前的内容。你在输入框里点了「停止」、或这一轮写作失败时，工具条上的报告状态旁会一直写着「已停止」或「写作中断」，并说明已保存了几节（拿不到节数时写「已写的部分已保存」），直到下一次写作开始。
- 报告区域比较窄时（例如把成果栏拖窄），「导出」收进「更多」里的「导出」子菜单。在手机上看报告时，报告上方只有一条工具条：左边是返回成果列表的箭头和报告标题（标题太长时显示省略号，读屏软件会读出完整标题），右边是报告状态、「分享」和「更多」；「导出」和「编辑此报告」都在「更多」里。进入编辑后，上方恢复原来的成果栏，「完成」在工具条上。
- 工具条右侧新增「分享」按钮，打开的就是原来的分享设置（选择谁可以查看这份报告）。「更多」里的「复制权限链接」保留不变。只能查看的分享报告里、以及只读账号都没有「分享」按钮（报告库卡片上也一样）。
- 编辑时区块右上角「⋯」打开的章节菜单换成和其他菜单一致的样式：「删除…」标红并带省略号（仍会先请你确认）；光标不在这一节正文里时，「在此处分割」显示为不可用，下方写明原因。手机上这个菜单从屏幕底部升起。
- 修改历史里的操作写成「新增」「修改」「删除」「调整顺序」，下面一行写明是谁改的（例如「手动编辑」「AI 更新」）和改的是哪一节，不再显示内部编号；时间写成「9月26日 14:23」这样的短写法。用键盘时，可以用上下方向键在记录之间移动（Home、End 到第一条和最后一条），在一条修改上按回车展开或收起它具体改了什么，按 Tab 进入这条记录里的按钮。
- 报告正文里的角标与对话里的角标样式一致。你无权查看或已经失效的来源，角标显示为带删除线的描边样式；点开后仍会说明原因。只是暂时打不开预览的来源（例如查询结果没有保存下来）不划删除线，点开后会写「来源当前不可查看」。
- 鼠标停在角标上仍会出现来源卡片。点编号角标打开的来源详情从右侧滑出，背后的页面暂时不能操作，按 Esc、点空白处或「关闭」都能关掉，关掉后回到刚才的角标；手机上它从屏幕底部升起。来源详情里的文档摘录会按格式显示标题、列表、表格和代码，不再露出「##」「**」这类符号；较长的代码或表格可以左右滑动查看。摘录里的图片不会自动加载，显示为图片说明文字的链接，需要时点开查看。
- 代码运行或查询得到的来源，在来源详情里按表格显示数据（数字保留来源里的小数，空值显示「—」），其余输出按原来的分行显示；用这份来源画的报告图表也会一并显示。来源卡片上能直接看到前几行数据或输出，「来源关联不等于数字正确」的提醒只出现一次。来源是一次代码运行的结果、且报告里有这段代码时，卡片上会出现「查看运行结果」：打开的来源详情先写明是哪次运行、什么时候运行，接着显示运行结果，最下面可以展开看代码。较早生成的报告没有这条关联，只显示运行结果。
- 选中文字后，在「Aa」打开的字体、字号或字重列表里按 Esc，只会收起这个列表、回到格式工具栏；再按一次 Esc 收起工具栏、回到正文，选中的文字保留，工具栏不会马上又弹出来，换一段选区才会再出现。
- 鼠标停在角标上出现的来源卡片、选中文字后出现的格式工具栏、编辑时区块右上角的「AI 改写」和「⋯」，都换成了更轻的样式。格式工具栏里「改写」「缩短」「正式」排在最前，字体、字号、字重三个选项收进「Aa」按钮，点开才出现。AI 改写完成后，「接受」是唯一的实心按钮，「撤销改写」在它旁边。
- 图表下方的来源行点开的来源卡片不会再被报告边缘或工具条遮住；手机上它从屏幕底部升起。
- AI 生成的多图布局无法使用时，所有有效子图会按顺序纵向显示；指标、原值和来源仍保留。来源或指标无法确认时仍需纠正，系统不会填入猜测值。
- 可以要求同一份地区时间序列同时生成趋势图和趋势 Table，包含起止值、变化、迷你趋势线及原行明细；没有实体列的月度数据使用普通 Table。请说明每个指标单位；百分比水平使用 `%`，存储形状另行声明。
- PDF 中的图注和简短旧图提示跟随关联图表；大型组合图可分页，说明跟随其中最后一个图表或 Table。
- 在联动图中，点选／触摸图点、柱或 Table 行，会在声明的相关视图中高亮同一观测。聚焦绘图区后用方向键选择；Table 行支持 Enter／空格。**清除选择** 或 Esc 可重置。选择仅在本地，不保存、不查询；重新加载、数据或版本变化即清除。若所选观测不在另一子图显示范围内，会明确提示。报告下载保留已保存的完整范围。
- 图表提供 **开始**／**结束** 时，可选择实际保存日期，查看参与图表及 Table 中该时间段的观测；**显示完整时间段** 恢复全部已存数据，其他视图保留自己的范围。区间变化会清除单点选择，重新加载或版本／权限变化会恢复完整时间段。浏览不保存、不查询。报告导出保留完整保存范围；单图 PNG／CSV 下载使用显示区间且文件名带范围，PNG 内也会标记时间范围。
- 图表带时间帧播放控件时，可用日期选择或前后帧按钮查看已有日期。初始暂停，播放到最后一帧或图表离开屏幕时停止；返回后保持暂停。切换日期不会保存报告修改。单图下载及「追问这张图」使用当前日期，整份报告导出使用保存日期。附件可能包含其他日期，追问同时携带所选帧。
- 共享数值轴会让参与图表保留相同的刻度范围，隐藏系列或浏览较短时间段时也保持一致，原值不变。已保存的比较会拒绝导致刻度不兼容的图型修改；临时切到不支持的图型时会说明共享刻度不可用。
- 图表可标记实际观测点或已给定时间段。短标签位于图内，图下说明保留指标、原值及单位；缺失数值显示为“—”，不会补成零。时间段使用已有端点，不表示业务事件或目标。阅读步骤可定位对应说明；筛选掉的点或无法再核验的来源注释会隐藏。临时切换不兼容图型也会隐藏标记。
- 引导阅读按简短顺序展示相关视图。使用“上一步”和“下一步”依次查看；每次切换恢复完整已保存时间段。报告导出包含全部阅读顺序；数据或来源说明无法再核验时，步骤会隐藏。
- **追问这张图**会把问题和可引用的数据文件带入聊天草稿。检查引用后再发送；文件可能包含比当前图表显示更多的数据。文件无法引用时，问题会保留，并提示如何重试。
- 在支持联动的图表中，可先选中观测或时间范围再追问；可编辑问题和附件标记显示选择，悬停标记可查看完整范围。仍需你主动发送。再次选择会更新尚未修改的自动文字，手动编辑的问题会保留；文件可能包含选择范围之外的数据。图表更新或数据不可用时，重新打开图表并选择。
- 事件或报告期间的来源说明在来源面板和下载报告中直接显示正文与已提供的日期，仍可通过来源链接打开原文件。回答和报告中的图表使用相同的当前来源检查。折线末端显示系列名称，悬停查看原值。使用 CSV 生成图表时，请说明每个指标的单位，尤其是不同坐标轴使用不同单位时。
- 图表附有已核验的口径说明时，打开已有来源行，可在**来源与口径**中查看对应指标与来源原文；手机沿用底部面板。原文变化或不可访问时，说明与依赖的图表文字会隐藏并显示原因，保存的数值仍可阅读。下载报告也包含已核验的说明。
- 可以让 Agent 按支持的格式展示日期列，例如把 `2026-10-28` 显示为 `20261028`。原始数据和排序不变；如果格式需要来源没有的细节，或会让不同日期显示成一样，Agent 会保留原格式并说明如何修正。
- 来源已是 `20261028` 这样的八位日期时，也可以显示分隔符。悬浮保留可获得的来源数值和单位；Table 中不同单位的列若会显示成相同列名，则保留各自的原单位。
- 也可以让 Agent 调整图表或表格的小数位数。百分比和货币沿用已知来源含义；修改显示精度不会改变原值或单位。
- 数据完整的单指标独立图，可以让 Agent 在折线、柱状、横向柱状和表格之间切换。部分复杂图表或数据不完整的图表暂不支持通过此方式切换，会保留当前视图。
- 图表编辑无法完成时，Agent 可以重试或说明原因。同一轮实时执行中，报告会受到保护，避免通过替换图表或重写报告来绕过失败；如需单独替换，可在新消息中提出。
- 来源详情和修改历史从右侧滑出，宽度稍窄；修改历史里每条记录的「回滚到此版本」仍会先请你确认；只能查看的报告（只读账号或别人分享给你的）里只看修改记录，没有回滚和恢复按钮。
- 图表和指标卡使用克制的边框；原生 Table 在回答、报告和浏览器导出中没有外框。图表右上角「⋯」和图型按钮保留已有位置及操作。
- 在折线、堆叠面积、组合和双轴图的绘图区移动指针，靠近某个期间即可在同一提示框比较可见系列的数值和单位，无需精确碰到某个点。通过图例隐藏的系列和缺失观测不展示，真实零值保留。不使用 hover 时，可切换到表格核对已有数值。
- 系列很多的图表除了颜色，还会用纹理区分。从第 7 个系列起（如果团队图表样式里有不易区分的颜色，会更早开始），柱子、堆叠段、面积和饼图扇区会加上斜线、圆点或交叉线（折线改用虚线），图例里也显示同样的纹理。如果你在图表样式设置里打开了「色觉友好」，每个系列都会有自己的纹理或线型。下载的 PDF、Word、PowerPoint 和图片始终使用浅色图表配色，纹理与屏幕上相同。部分图表颜色做了微调，让相邻系列更容易分清，因此旧图表重新打开或下载时颜色可能略有不同。
- 指标卡片里一百万及以上的数值，大字改为显示约数（例如「≈856万」），精确数值以小字显示在下方，长数字不再被相邻卡片遮住一截。约数带上原来的单位（例如「≈¥856万」），精确数值按界面语言分组。普通一百万以下数值及百分比保留精确展示。已知预缩放金额可换成易读量级，主值缩略时，下方保留完整基础货币金额；未知单位不作反推。界面语言下约数仍放不下时（例如德语的「≈16,5 Mrd.」），这一格的大字会略微缩小。下载的文件同样如此。
- 按两级分类（例如省和市）画的堆叠柱状图，现在每个下级项目（市）一根柱，按上级（省）着色，图例只列上级；以前可能反过来把下级项目堆进上级的柱子里，比率之类的数也被加在一起。两个分类其实一一对应时（例如门店和门店面积），改画成普通柱状图。新生成的图表按此规则显示，已有图表不变。
- 热力图每行只会有一格有颜色时（例如每个门店只属于一个建议层级），改为画成每个项目一根柱、按分组着色的柱状图，数值可以直接按柱高比较。新生成的图表按此规则显示，已有图表不变。
- 数据不构成流向时（各行之间没有相连的节点，通常是把客流和金额这类不同单位的数并排放在了一起），不再画成桑基图，而是显示表格并说明原因，因为桑基图会把不同单位的数画成可以互相比较的宽度。已有的这类图表打开和下载时也会显示为表格。
- 饼图的每个扇区都保持自己的完整颜色，不再把重点以外的扇区调淡，扇区和图例可以一一对上；重点扇区改为略微向外移出，中间仍显示它的占比。打开或下载已有图表时也是如此。
- 瀑布图中下降项的数值标在它自己柱子的下方，上升项仍标在上方，不再贴着上一根柱子的底边；最大的一项和合计的标签也不会再被图表边缘截掉。瀑布图的网格线改为与其他柱状图一样跟随图表样式设置，因此虚线、浅色网格等设置现在也会作用到瀑布图上。打开或下载已有图表时也是如此。
- 散点图上的名称标签不再盖住其他点：放不下而不遮点时，这个名称就不标，在密集区域标出的名称可能比以前少，名称也可能放在点的左右两侧；图注里点名的那个点始终标出名称；把指针移到点上仍可查看名称。打开或下载已有图表时也是如此。
- 表格比显示区域宽时，右边缘会渐隐，提示右侧还有列可以横向滚动查看，被边缘切开的数字不会再像一个完整的数；横向滚动时第一列保持不动。下载的 PDF、PowerPoint 和图片中，过宽的表格会整体缩小以放下所有列，不再截掉右侧的列；特别宽的表格最多缩到六成，右边缘仍会渐隐，表格下方注明还有几列未显示。
- 下载的 PDF、PowerPoint 和图片里，类目很多的横向条形图不再把所有条目挤在一页里：只画出能清楚显示的项数（单一数值时约 30 项，多组并排的条形更少），选取数值（按绝对值）最大的那些、保持原来的先后顺序，图下注明按哪一列选取、显示了总数中的多少项。报告页面上仍显示全部条目，可以滚动查看。
- 在报告图表的图例里点掉的系列，你自己下载 PDF、PowerPoint 或图片时也不会出现，下载结果与你屏幕上看到的一致。这只影响你自己发起的下载：隐藏不会保存到报告里，其他人看到和下载的图表不受影响；刷新页面后隐藏会恢复。
- 导出的 PDF 和 PowerPoint 文件使用团队的颜色：默认是蓝色；管理员发布了团队自己的品牌颜色后，改用品牌颜色。即使品牌颜色很浅或很深，所有文字在背景上也保持清晰可读。个人外观设置不会改变导出的文件。团队更换品牌颜色之前导出的报告保留原来的颜色，重新导出即可使用新颜色。

## 文字与版式

- 你发送的消息中的长网址和标识符会在会话区域内自动折行；复制或重新编辑时仍保留原文。
- 回答、报告正文和帮助文章使用同一套正文字号与行距。报告正文比回答和帮助文章更宽，桌面报告菜单还提供更宽的选项；图表、表格和指标卡使用可用的内容宽度。
- 报告标题和章节标题默认使用无衬线字体。在「个人设置 › 外观」把字体选为「衬线展示」时，只有报告标题和章节标题改用衬线字体，正文不变。
- 回答和报告正文里中文与英文、数字之间会自动留出一点间距（较新的浏览器支持），复制出来的文字不变。
- 产品标志只在左栏顶部出现一次：首页不再显示标志与水印，回答上方只显示时间。版本号移到左下角账户菜单的最后一行，点一下即可复制。
- 导出的 PDF、Word、PowerPoint 和图片文件不受影响。

已准备的比较数据可以显示区间、独立的当前值／参考点及逐行对齐的数据列，也可以按相同刻度分面。点击行或点查看原始数值和来源；键盘可在行上按 Enter。缺失端点不会补零。情景名称和结果摘要来自已提供的假设，并非图表计算的预测。这些图沿用原控件，但会阻止丢失区间含义的图型切换或 Top-N 操作。文档导出按阅读顺序保留全部区间表行和分面，单张图片说明显示的行范围。

智能体可用不代表每项可选团队服务都已配置。未配置生图服务时，已有设计仍可改字或导出；新海报需要背景时，请联系团队管理员配置生图服务，或提供背景图片。回答会说明缺少的服务，这不代表该智能体已停用。
