# 创建和管理自己的智能体

需要纯文本答案时，请在智能体指令中说明格式，并将高级输出 schema 留空。分别检查智能体测评结果和完整聊天回复。已经保存的工程需求可以请 Coach 打开查看；查看回执不会启动连接接入，也不会创建尚缺少的工具。

启用辅导时，你可以先询问有哪些可用工具、技能或可复用团队插件，无需先建草稿。助手能查看资源说明和使用条件；找到资源不代表已测试通过或已加入智能体。接着可以请助手建立新草稿；检查已保存草稿及建议，采纳需要的字段，再确认私有创建。若面板未打开，请继续原已保存草稿，避免再建一份。

从主侧栏「智能体」选择当前可用的「创建智能体」。从「智能体 → 管理我的智能体」进入已有管理视图；切换聘用、创建、分享、归档或团队治理时，侧栏始终选中智能体。创建资格与团队管理员身份分开，团队治理不授予其他作者私有草稿的访问权。

你可以创建只供自己使用的智能体，核对配置后确认创建，再从管理页调整和使用它。创建入口和可用选项取决于团队开通的功能，下文按“页面显示某个入口或选项时”分别说明；页面没有提供的选项，请按页面实际显示的方式操作。智能体草稿保存在空间里：还没有空间时，「创建智能体」会说明原因；负责人和管理员可以直接去创建空间，成员请联系负责人或管理员把自己加入一个空间。

草稿辅导可用时，请先保存草稿并保持在对话中选中，再提出具体改进要求。助手可以读取草稿、查找合适的工具、校验修改并保存待审建议。草稿辅导已连接时，新建议会在几秒内出现在原稿中，不会覆盖你尚未保存的输入；核对后只采纳需要的字段。若草稿缺少配置而阻塞局部修改，Coach 应说明缺少什么，并在增加其他字段或工具前先询问。建议已保存不等于智能体已修改或创建。若助手处理期间你修改了草稿，请保存后针对当前草稿重新提出要求。Coach 技能创作可用时还可创建或编辑个人技能，保存直接改变个人包并提供独立恢复回执。接入新工具、发布团队技能和运行评估仍走各自支持的动作。

右侧支持切换配置对象时，请先选中草稿再发送修改要求。发送后切换对象不会改变这条消息的目标。当前对话不能修改所选草稿时，消息保留在输入框，草稿旁会显示提示；请直接在右侧编辑，或关闭草稿后发送普通消息。

修改你已有的 Agent 时，你有编辑权限的话，助手会直接把修改写进它的草稿，不再生成待采纳的提案，详见下文“让 Coach 修改已有智能体”。校验回执只表示实际执行的检查，不等于测评通过。请求中断且结果未知时，先恢复原请求，再决定是否发起新的生成。

保存显示名称后，对象标签随之更新；同名标签用实际智能体名称区分，窄屏选择器也会标出未保存状态。关闭当前智能体会返回最近选中的剩余智能体；关闭正在等待保存时，你后来选中的对象仍保留。原草稿读取显示不可访问时，字段及对话编辑会清除；可以重试读取，或回到已保存草稿列表。

教练评测可用时，先确认草稿里是你要的修改并完成 Agent 的 Safety Check，再请教练申请评测。“Coach 改完草稿后”设为“自动检查”时，Coach 会自己启动一次有上限的发布检查，见下文；你也可以直接请 Coach 测试它刚做的修改；设为“先问我”或需要你确认时，在“发布”页发布检查里的“教练评测申请”中核对要评测的改动、比较的两个版本、最多模型请求、最多版本对比次数、可运行时长和预计用量（只显示 token、模型请求次数和时长，没有历史数据时写“暂无用量估算”），然后选择 **允许并开始评测…**，在确认框里再核对一次上限和截止时间后开始。**以后再说** 只是收起卡片，申请仍在等待，到期后自动失效。打开或刷新页面不会启动评测。评测进行中可以看到已用模型请求和 token；**停止评测…** 会取消正在运行的对比，已发出的请求不退回。响应丢失时先刷新状态，再决定是否继续；评测完成不代表 Agent 已发布。

在“发布”页，页面一次只给一个主按钮，告诉你下一步：测试这次修改、重新测试，或发布为新版本 / 提交审批。测试运行时会显示已完成的用例数；测试完成后列出有变化的用例（变差的排在前面），点用例名可以对照两个版本的回答。停止测试、撤回提交等会丢失结果或已用请求的操作，都会先弹确认框说明后果。

Agent 还没有测评套件时，可以请 Coach 提出首批用例和套件名称。在“配置”页顶部的“待处理的提案”中检查任务、预期结果和评分，再采纳需要的用例；首次采纳会创建你的私有套件，仅提出建议不会创建。如果期间别处已创建套件，请 Coach 先检查它，再针对该套件提出新建议。保存用例不代表已经运行测评。

要停止尚未完成的个人 Skill 保存，可请 Coach 停止那个精确请求。它会确认尚未应用的修改已取消，或说明原保存已经生效；停止不代表撤销已保存 Skill。若较新的手工内容使结果无法确认，请保留原请求继续核对。仍有权限时，可以在同一空间的另一个对话中恢复原请求。

请 Coach 检查修改时，核对它实际完成了哪些检查。配置和依赖检查不会执行业务任务；即使字段合法，工具不可用或技能正在等待重新审批也可能阻止修改。需要验证行为时，请走支持的 Agent 测评流程并查看运行结果；仅检查草稿、技能或插件不等于试用。

发送修改请求被中断时，请保留原恢复提示，刷新后让页面核对结果。恢复仍对应发送时选中的草稿，即使后来已打开另一份草稿。发送已确认只表示请求已收到；请在原草稿查看建议或保存结果，确认实际改动。

你可以在同空间的另一段对话中，让 Coach 根据原回执核对之前的请求。查询不会重复保存或启动评测。结果仍未知时，保留原请求并使用其支持的恢复动作；回执已过期或不可用不能证明成功。

Coach 在右侧打开 Skill 编辑器时，可以使用技能页原有的保存操作。切回智能体会保留两边的编辑器。保存 Skill 不会自动把它加入智能体：加入智能体是单独的一步，在新建草稿上表现为待采纳的绑定建议，在已有智能体上由 Coach 写进草稿并可撤销。刷新页面读取的是已保存内容，需要保留本地修改时先保存；权限被收回时面板会清除资源。仅选中 Skill 面板尚不会向对话指定修改目标，请在请求中明确要修改的资源。

## 选择创建方式

- **右侧创建面板**：从智能体市场或管理页点“创建智能体”，会在当前工作右侧打开创建面板；已有对话和输入内容仍留在左侧。窄屏下可在“对话”和“创建智能体”之间切换。
- **在对话中请助手创建**：在对话里说“帮我建一个智能体”并说明它要处理什么、做什么、产出什么。用途不够具体时，助手会先请你补充一次；你也可以随时说“手动配置”或“取消创建”。用途清楚后，右侧会打开 AI 生成的草稿；你明确说出的名称会一并带入。
- **AI 起草**：在右侧面板描述要解决的问题，由 AI 生成草稿，你检查后再确认创建；也可以切换到手动填写。暂时无法生成草稿时，可以改为手动配置，已写的用途会带入。

面板支持已保存草稿时，对话创建先保存并打开一份草稿，再添加 AI 建议。请选择要采用的字段；建议不会自动覆盖你的修改。生成失败后可以继续编辑原草稿或在原稿上重试建议。原始创建要求作为用途保留，不会直接变为已确认工作说明。

无论哪种方式，你都需要亲自核对配置并确认创建。

保存途中继续输入，新输入保持“未保存”，直到它也成功保存。草稿会自动保存，关闭标签时不再询问；保存仍在进行或失败时，会询问继续编辑还是放弃未保存的修改。切换会话、团队或空间关闭旧草稿选择，不丢弃已存内容；可回原空间从“我的智能体”或草稿链接继续。提示对话编辑不可用时，请在右侧修改；重新打开草稿不会开启这项功能。

## 填写配置

在创建卡片中填写名称、用途和工作说明，再按页面提供的选项选择工具；技能仅在页面明确提供时可选。最后一步会列出已选工具，并标出团队工具的风险类别，请在确认创建前核对。选上会修改外部系统的工具或插件（例如邮件）就是你的授权：卡片会用一行字说明它会做什么，不会再让你勾选确认；实际使用时仍会检查使用者的权限和连接状态。

- 没有合适的工具时，获准使用纯文本助手的团队可以不选工具或技能；其他团队至少要选择一个工具，才能进入下一步。详见[配置 Agent 能力](permissions/configure-capabilities.zh-CN.md)中的纯文本助手说明。
- 选择技能时，请选择智能体需要的具体技能。“列出技能”这类无法限定技能范围的通用工具不能用于新建智能体。
- 工具、技能和插件：**工具**是它能做的一个动作（查数据、运行 Python、发邮件）；**技能**是做某类事时照着的方法和模板（「周报怎么写」）；**插件**是一组搭配好的工具和技能。先选插件，缺什么再单独加工具或技能。
- 每个插件都写明「适合…」、给一个例子，并列出它带来的内容，例如「带来：运行 Python · 带使用规范」。带使用规范的插件会自动附上规范。团队有团队插件时才显示「团队插件」分组。你用不了的插件不会列出；团队管理员还会看到团队已停用或尚未配置的插件，并可点链接去处理。已选中但后来变得不可用的插件仍保留勾选，取消勾选即可移除。插件之后有更新时，智能体下次运行会使用新内容。
- 按描述创建智能体时，草稿会按你的请求先选好插件并标「推荐」，同时用「适合…」一行说明原因；不需要的可以去掉。
- 在「配置」里点**添加…**，一个搜索框同时查找插件、工具和技能。
- **邮件和 Google 交付**：选上「邮件」或「Google 交付」插件，就是你授权这个智能体。保存并发布后，它会直接发邮件或写入 Google，不再每次问你；其他成员使用共享的智能体时也一样。对话里会写明发了什么、写到了哪里。主控智能体（Lead）发邮件、写 Google 前仍会先问你。团队管理员随时可以为整个团队停用这些工具。团队还没配置邮件服务时，「邮件」插件显示「未就绪」并说明原因，负责人或管理员可以从「去配置」进入「团队设置 › 邮件服务」；其他成员看不到它。
- 审阅 AI 生成的草稿时，也可以在同一处补选或去掉插件和技能；编辑已有智能体（包括从配置助手打开）时同样可以调整插件，只有改动过的选择才会保存。
- 如果智能体将来要核对你给出的网页，创建时只需说明“每次使用时由用户提供网址”，不必先填某一次任务的具体链接。请检查草稿是否选择了“读取网页”能力；“网络搜索”用于寻找其他网页，不能代替读取指定链接。运行时若网页无法读取，智能体会说明本次未能核实，你可以检查链接是否可访问，或直接提供页面内容后重试。
- 如果用途需要读取团队的业务数据（例如门店营业额、销售明细），即使描述里说的是“团队数据”，草稿也会选择系统自带的查询数据工具。
- 某项必需能力没有选中任何工具时，配置检查会显示未通过，并说明是哪项需求、为什么没有选上以及怎么补：按提示在工具列表中勾选合适的工具；对应工具处于锁定状态时，请联系团队管理员开通。补上之前不能创建。
- 保存时若工具或技能已不可用，卡片会保留你的填写内容，并提示返回检查、移除或更换资源。

新建的智能体仅自己可见，不会自动分享给同事，也不会出现在智能体市场；需要分享时，请到管理页查看当前可用的授权操作。

## 了解智能体可以使用哪些技能

普通对话中，内置执行智能体可按任务需要读取你已启用且没有待处理导入问题的个人技能。你也可以在提问时明确指定技能名称。这不会将技能自动添加到你创建的智能体。

自建智能体需要单独配置技能：直接选择，或通过所选插件包含。个人技能只能添加到使用范围为 **仅自己** 的智能体；与同事共享的智能体可选择内置技能或覆盖所有使用者的团队技能。某项技能不可选时，请阅读选项旁的原因，再调整智能体的使用范围或选择适用的团队技能。个人技能需要供团队使用时，参见[将 Skill 发布到团队](permissions/publish-skill.zh-CN.md)。

页面提供 **可选只读方法** 时，可以配置允许用户在单个任务中显式选择的方法。加入此列表不代表智能体每次都会采用；修改后需保存，并完成应用或发布流程才会生效。

添加技能后，智能体可以读取它；如果技能带有脚本，智能体还可以在隔离沙箱中运行这些脚本，不需要另外选择读取、运行或列出技能的工具。如果当前部署未开启技能脚本，编辑器会在该技能旁说明：智能体可以读取它，但在管理员开启前不能运行其中的脚本；开启后无需重新保存智能体。之前已发布的智能体保留原有权限，直到你再次发布。技能不会授予数据或连接权限，共享智能体也不会自动共享其所有者的个人技能。

智能体使用每个技能最新的已审批版本。所用技能更新后，智能体页面和发布审核会列出已更新的技能，并建议重新测评智能体。在技能页面为自己关闭某个团队技能，不会影响包含它的智能体；团队管理员对你设置的限制仍然生效。

保存或发布被阻止时，提示会逐项列出被阻止的技能或工具、原因和处理办法。常见原因：

- **已修改，正在等待重新审批**，或 **尚未通过审批**：请团队管理员审批当前版本，或移除该技能。
- **已被团队停用**：请团队管理员重新启用，或移除该技能。
- **技能文件无法读取**，或 **安全检查记录缺失或已损坏**：重新上传该技能。
- **这个名称已对应另一个技能**，或 **添加后已发生变化**：移除该技能后重新添加。
- **自带依赖包**：发布前由团队管理员复核。

技能说明中提到 `curl` 等命令时，发布审核只显示提示，不会阻止发布；脚本运行时没有网络访问。

运行中某个技能无法使用时，该步骤会写明技能名称、智能体想做的操作和原因，例如部署未开启技能脚本、团队管理员限制了你使用该技能、技能正在等待重新审批或已不存在。请按提示处理；原因解决前重复同一请求没有帮助。

## 选择文档技能

配置页提供技能选项时，选择智能体需要的具体文档技能：

- **Word documents**（`bowra-docx`）：新建可编辑标题、段落和表格。
- **PDF documents**（`bowra-pdf`）：新建文本／表格 PDF，读取嵌入文本；扫描页需要单独 OCR。
- **PowerPoint documents**（`bowra-pptx`）：新建可编辑标题、要点和表格幻灯片。
- **Excel workbooks**（`bowra-xlsx`）：值／日期工作表及单元格检查，不计算公式。

它们是标准内置技能。选择技能不授予文件访问权，也不改变已发布智能体；请按既有流程保存并应用新版本。这些基础技能不保留上传的 Office 模板，需要模板修改时使用页面提供的模板草稿流程。

在 Bowra Community 中，文档成功生成后会作为会话中的可下载文件出现；回答里提到文件名不代表文件已经生成。制作 PowerPoint 时，请要求新建基础文字／表格演示稿；如果你提供了需要保留的模板，智能体应先说明限制，询问是否接受独立的新演示稿，再生成文件。分享前请检查下载内容；此技能不提供幻灯片渲染或模板保真保证。

## 保存草稿与继续

在右侧创建面板中，进入手动创建时会先建立一份草稿，再显示可填写的配置；选择 AI 起草时也会先建立可恢复的草稿。页面暂时无法建立草稿时，点“重试创建草稿”，重试会继续这次创建任务。

- 填写后短暂停顿会自动保存，也可以点“保存草稿”。看到“草稿已保存”的提示，才表示修改已经保存在草稿中。自动保存失败时输入仍留在面板里，请按提示重试保存。
- 右侧草稿编辑时会自动保存，工具条显示“已保存”或“保存中”。只有保存仍在进行或保存失败时，关闭、切换页面、会话或空间才会询问“继续编辑”或“放弃未保存的修改”；放弃的只是这次未保存的修改，已保存的草稿会保留。保存失败时可点工具条的“重试保存”。
- 若其他标签页先保存了同一份草稿，页面会逐项显示编辑前、我的输入和最新保存的内容；逐项选择后再保存，不会直接覆盖别处的修改。
- 从通用创建入口进入时，可以继续当前空间尚未完成的草稿，或明确开始一份新草稿。草稿列表会显示名称、来源、状态、最近保存时间和有效期，便于区分多份任务；继续手动草稿会直接回到右侧手动编辑器。
- 在“我的智能体”切到“我创建的”，也可以找到尚未完成、仍可继续的 AI 和手动草稿。只有存在可继续的草稿时，才会显示“继续创建”区域。草稿打开后，当前页面地址可以用于刷新并继续查看这份草稿。
- 提示找不到草稿时，请检查当前空间，或点“查看我的草稿”找其他草稿，也可以重新创建。已过期的草稿不能继续。临时读取失败时，可以在卡片里重试。

## 用 AI 起草

1. 选择 AI 起草，填写目标并生成建议。生成期间可以停止等待、手动填写；结果稍后会出现在同一份草稿中。
2. 逐项比较当前内容与 AI 建议，只勾选要采用的字段，或忽略整条建议；已有修改不会被自动替换。AI 需要更多信息时，请在右侧回答，或修改目标后重新生成。
3. 如果推荐的工具不适合你的任务，可以在“能力与工具”中打开工具目录，搜索并勾选你有权使用的其他工具，也可以取消原来的建议。页面会标出你自己补选的工具和暂不可选的原因；改完后点“保存并检查”。目录暂时打不开时，已填写和选择的内容会保留，请稍后重试；保存时若提示工具已不可用，请按提示移除或更换。技能能否在这里补选，以页面实际提供的选项为准。
4. 核对后确认创建。

需要改为自己填写时，选择“手动配置”：右侧已改的内容会保存在同一份草稿中，原目标会带入工作说明，并在路由说明中保留简要内容；如果你在对话中明确说过名称，名称也会保留。转换后仍可从原地址或“我创建的”继续。提示版本冲突时，请先检查并重新加载。请求失败时，页面会重新核对草稿状态；草稿已无法继续生成时，可以转为手动配置，原目标和补充答案会一起带入。修改名称或工作说明不会清除原有的工具推荐理由。

## 在对话中修改草稿

团队已开通草稿对话编辑时，AI 生成并进入复核的草稿、以及已保存的手动草稿，会连接当前对话。右侧显示“当前对话已连接”时，你可以在左侧说明要修改的字段，保存成功后右侧会刷新，再核对并确认创建；若右侧提示在右侧修改，请直接在右侧编辑。

- 右侧有未保存的修改时，新消息会留在输入框，并提醒你先保存或放弃右侧的修改；处理后重新发送即可。
- 对话中的修改不会覆盖你正在填写的内容；版本有冲突时按提示重新加载。
- 尚未连接的手动卡片仍请在右侧编辑，左侧回复不会自动修改它。

## 创建之后

在 Canvas 编辑器中，对象名称和关闭入口位于 Tab。创建后同一 Tab 显示已保存配置及可用的下一步操作。重新打开时，读取名称和配置期间可能先显示“已创建的智能体”。读取失败时点**重新读取配置**，只会重新加载原智能体，不会再创建一个；关闭 Tab 只关闭视图。

创建会直接把它发布为 v1：默认只有你能用，创建回执上会写“已发布 v1 · 只有你能用”（创建时指定了成员则写“指定成员可用”），并给出两步：先试一试，回执提供“开始使用”时点它，否则在对话输入框输入 @、选中这个智能体再提问；回执还会按类别写出它能用什么，例如“1 个插件 · 3 个工具”，插件只算一次，不按它带来的工具计数；想更放心，在“评测”里加几条用例；想分享，在“配置 › 谁能用”改可见范围，团队可见可能需要管理员审批。

创建成功后，点“管理智能体”可以直接打开刚创建的智能体，查看和调整配置；也可以稍后从“我的智能体”找到它。创建后加入个人列表，不代表你主动聘用了它。原有智能体会打开原有配置页，已纳入版本管理的智能体会打开版本工作台。

版本工作台有三个页签：**配置**、**评测**和**发布**；页面只显示团队已开通的页签。旧的“变更建议”“验证与发布”“版本历史”页签已经合并进来，旧链接会自动跳到对应位置。

- **配置**：一页分为三个可折叠的部分。“它做什么”包括名称、介绍、工作说明、内置工具使用规范和模型；底部折叠的“高级”里是可选的“主要职责”，私有智能体一般不需要，设了值时折叠行会显示它（共享智能体设了主要职责或需要审批时默认展开，第一行说明审批人能看到什么）；“它能用什么”包括插件、技能、工具和连接，点**添加…**会在侧边抽屉中打开目录，这里和保存卡片上的数量都包含已选插件带来的工具和技能，资源全部来自插件的智能体不会显示为“还没有添加”；“谁能用、怎么上架”包括可用范围、可选方法、上架信息、复制策略和输出约定，默认收起。某个部分里有阻止发布的问题时，它的标题会变红并写明原因。页面顶部的“待处理的提案”列出来自外部流水线和用户反馈、等待你审阅并合并的修改，没有时不显示；“配置”页签上会显示待处理的数量。每项修改都会把当前值和提议的值并排显示；上次发布后还没保存过草稿时，会和已发布版本对比，合入时会基于它生成草稿。**合入所选变更** 不可用时，卡片会写明原因，例如还没有选择任何修改。它上方的“N 条点踩待处理”列表，每一行是成员点了踩、并同时分享给你的一轮：“点踩”标签和问题开头，下面是谁、什么时候、选的原因和补充说明（没写时显示“没有补充说明”）。**用它来改进智能体** 会打开一个新对话，@Coach 并把问题、原因和补充说明放进输入框，你发送前不会发出任何内容。**忽略** 会移除这一项，可以撤销。无论哪种，这一项都会离开列表、不再计入“配置”页签上的数量，这一轮仍可在 **从对话起草** 中使用。成员取消分享或撤销点踩时，这一项也会消失。成员没有分享的点踩不会到你这里；只从「⋯」菜单分享、没有点踩的轮次只出现在 **从对话起草** 中。这些条目不会发送收件箱通知。
- **评测**：管理评测组（原“验证与发布”中的评测组）。
- **发布**：先显示“本次改动”卡片，按部分列出改了什么，并标注改动来自 Coach、手动、外部流水线还是反馈，再列出评测组和发布检查状态，每项都可以跳到对应页签；草稿和已发布版本一样时会写明。下面是发布检查和发布操作，页面底部是版本历史，可以选择“基于此版本新建草稿”。
- **外部流水线**：外部流水线通过团队 OpenAPI 密钥管理，不在工作台里设置；它提交的修改会以“外部流水线提案”出现在“待处理的提案”中。停止外部流水线访问智能体：在团队设置 › OpenAPI 禁用或注销它用的密钥。

- **开始使用**：页面提供“开始使用”时，点它会打开新对话并选中这个智能体，再输入本次任务；详情页和管理列表中可用的智能体也有相同入口。若当前版本或权限已变化，页面会提示你返回管理页检查，不会把一段名称文本当作已选中的智能体。已有的未发送草稿会保留。
- **修改配置**：在配置页调整并选择**保存草稿**；保存不会改变大家正在用的已发布版本。刚创建的智能体已经发布为 v1，首次进入版本工作台时可能还没有草稿。若页面提示修改只保留在浏览器中，请先保存，再进入“发布”页。
- **内置工具使用规范**：在版本工作台“配置”页的“它做什么”部分开启后，智能体运行时还会遵循 Bowra 为其可用工具编写的使用规范，例如查询业务数据的规则；默认关闭。与其他配置一样，需要保存草稿并发布新版本后才起作用；开启或关闭都会形成新版本，审核人会看到这项变更。
- **应用新版本**：仅自己使用的智能体，验证后点“应用新版本”，新版本只用于你自己，不会上架市场。面向同事的版本按页面提示操作：显示“启用新版本”时会改变当前可用版本及其可见范围，这不等于主动上架市场，目前市场仍按团队可见范围展示；需要审批时显示“提交管理员审批”。请先核对可见范围和变更影响，详见[发布 Agent](permissions/publish-agent.zh-CN.md)。
- **谁能用、怎么上架**：“配置”页的这一部分默认收起，用于设置可用范围、可选方法、介绍与分类等上架信息、复制策略和输出约定。
- **评测**：页面提供“评测”页时，评测显示“未通过”或“未完整完成”，点“查看未通过原因”。提示评测环境故障时，本次结果不能判断智能体质量，请稍后重试，持续出现时联系管理员；提示评测超出了时间上限时，是有用例没跑完就被中止，并非故障，点“重新测试”即可，反复出现时把超时的用例拆成更小的任务；评测未通过的用例则需要检查任务和预期。不要只根据“通过 0 条”判断是配置问题。发布检查会自动使用最新保存的测试用例。若页面提示评测策略已更新，说明页面加载后又保存或新增了测试用例；页面会切换到当前策略，请再点一次“测试这次修改”。测试之后又保存了用例或修改了草稿时，结果会标成“结果已过期”，点“重新测试”即可用最新的草稿和用例重测；发布、记录风险决定或提交审批要等这次测试完成。用例过期时，提示会写出用例、所在评测组和过期日期：请在“评测”页把它从评测组删除（编辑用例会保留过期时间；仍需要时作为新用例重新添加），保存后再试。
- **结果里的期望要点**：打开用例的回答后，每次运行都会列出这个用例的要点，标明“满足”“未满足”或“未评分”，并附上判定依据的回答原句；已满足的要点折叠在该次运行下。判定有误时（无论误判满足还是不满足），点“判错了”。这会记下这份回答，之后校验这条要点时必须作出相反判定，页面可能同时给出 Coach 建议的改写；本次对比结果不变，改好要点后重新测试。没通过好、坏回答校验的要点会标为只作参考，并说明原因。发布检查把“有要点没满足（由模型评分）”列为风险时，风险下方会列出没满足的要点和对应原句，每条旁边有“判错了”；你可以记录风险后发布，也可以标记判错，或两者都做。

### 编写评测用例

- **从对话起草。** 在“评测”页选择 **从对话起草**，从你问过这个智能体的问题里选最多 32 个。每个问题会成为一条用例，题目就是你当时的原话，Coach 会建议好回答应该包含什么。列表里有你自己已完成的对话，以及成员在回答的「⋯」菜单里单独分享给你的某一轮，标有「某某 分享」。你看不到成员的其他对话；分享来的这一轮，只有在你用它起草用例时才会读取回答。成员可以随时取消分享，这一轮随即从列表消失；你已经用它起草的用例是你的副本，会留在你的评测组里。检查起草的用例后保存评测组；开始评测之前不会运行任何东西。
- **之前的默认设置。** 2026 年 10 月 15 日之前保存的用例，可能仍然不允许调用工具，会查询数据的智能体可能只因为正常查数而不通过。这时评测组会显示受影响的用例数和 **改为当前默认设置**。更新会保存一个新的评测组版本，去掉这项设置和旧的严格数字检查；之前的结果保持不变。
- **没有直接来源的数字。** 用例的回答下方可能出现一条提示，列出在智能体读取的数据或任务里找不到的数字。由数据计算得出的数字（例如合计、占比、取整后的值）也会列在这里，所以这条提示不会让用例不通过，也不会拦截发布。可以用它找出值得核对的数字；如果要求回答给出某个数字，请在用例里添加数据事实要点。
- **看懂发布检查。** “发布”页在逐条用例的变化上方，显示运行了多少条用例，以及候选和已发布版本各自的通过率。某个版本的用例都没有得出结论（例如结果不确定）时，显示“暂无结论”。

### 让 Coach 修改已有智能体

在对话中点名一个你拥有的智能体，说明要改什么；也可以在版本工作台页签旁点**让 Coach 帮我改**，或在发布检查未通过时点**让 Coach 修**，会打开新对话，输入框中已放入 **@Coach** 和请求文字；在你补充并发送前不会发出任何内容。你有这个智能体的编辑权限（与手动保存草稿所需的权限相同）时，Coach 会直接把修改写进它的草稿，不需要再逐条采纳；右侧会打开该智能体的编辑器。没有编辑权限时，Coach 只在聊天里给出建议，不会改动任何内容。

你也可以直接找 Coach：在输入框输入 **@** 并选择 **Coach**，或在智能体市场中找到 Coach。其他请求不会自动交给 Coach。团队停用 Coach 后，这两处都不再显示它。

- 修改只写入草稿，不会发布或应用：新版本仍要在“发布”页通过发布检查后才生效。
- 画布里还有未保存的修改时，这条消息不会发给 Coach，输入框上方会出现提示：点**保存并继续**会先保存画布再把同一句话发出去；点**放弃修改**则丢掉画布里的修改，之后再发送。
- 每次 Coach 写入草稿后，回答下方会有一行回执，写明改到草稿的处数，点**在画布查看**可打开该智能体。
- Coach 加入的技能如果还依赖其他技能，必须一起加入；缺少时 Coach 不会写入，会告诉你需要哪些技能。
- Coach 写入草稿后，已打开的该智能体编辑器会自动刷新；编辑器里有未保存的输入时不会刷新。
- 工具或技能失效、缺少权限时，先在“它能用什么”中修复。

画布里的智能体编辑器从上到下依次是“Coach 的修改”、配置的三个部分（它做什么、它能用什么、谁能用、怎么上架），以及发布检查卡片（可在这里开始检查和发布）。

- “Coach 的修改”每行对应一个字段。**撤销**只还原 Coach 写入的值，不会动你自己的修改；已撤销的行提供**重新应用**。**全部撤销**一次撤销所有行。
- Coach 改过之后你也改了同一个字段时，这一行显示“你也改过”和**查看冲突**。对话框列出 Coach 改之前的值、Coach 写的值和现在的值，你可以选择：
  - **去配置里手动改**：到配置中自己修改这个字段。
  - **保留现在的**：保留你的值，这一行从“Coach 的修改”中移除，之后算作手动修改；草稿不变。
  - **还原到 Coach 改之前**：确认后作为一次普通保存，用 Coach 改之前的值覆盖你现在的值。
- 有字段处于冲突时，**全部撤销**不会撤销任何内容，并提供“只撤销其他 N 处”。
- 画布有未保存的修改时，撤销相关按钮会等待，请先保存或放弃。

#### Coach 改完草稿后

在“个人设置 → 账号 → 智能体”，或画布编辑器的“⋯”菜单里，选择 Coach 改完草稿后怎么做。这项设置只影响你自己让 Coach 做的修改。

- **自动检查**（默认）：Coach 写完草稿后，针对这次修改启动一次发布检查，上限固定为最多 200 次模型请求、1 次版本对比、30 分钟。估算可能超过 200 次请求时不会启动，而是请你核对后自己开始。新的自动检查会替换仍在进行的旧检查；旧检查准备的候选版本如果还没有提交，会一并撤回。已经提交审批的候选版本不会被撤回：这时检查不会启动，页面会请你先到“发布”页撤回它。已经用掉的请求仍计入用量。
- **先问我**：Coach 只申请检查，由你在发布检查卡片中核对用量后开始，与上文“教练评测申请”相同。

无论选择哪种方式，检查通过都不会自动发布或应用。

## 写下好回答应该做到什么

在**评测**页签里，每条测试用例都可以列出评分要点，用平常话写好回答应该做到什么。要点有三类：

- **判断标准**：在回答里能看到的东西，例如「和去年同月比较」。
- **数据事实**：回答应该给出的数字，例如「给出华东区上季度营收」。它会和这次运行里智能体实际读到的数据对照。
- **必须做的动作**：回答前必须调用的工具，例如查询销售数据。从这个智能体自己能用的工具里选，名称和「配置」页一致；选了几个时，调用其中任一个即做到。

**让 AI 建议测试用例**会为每条用例起草几条要点；Coach 提议用例时也会建议要点。建议的要点会标明来源，点**确认**之后才算数；你自己写的要点在保存评测组时即视为确认。改完记得点**保存效果测试**。

如果已发布版本已经回答过这道题，在用例的要点下方选「在已发布版本的回答上看看怎么判」，会显示那份回答，以及每条建议要点在它上面会怎么判，并附上依据的原句。觉得判得不对，就先改写要点再确认。这份回答是你认可的好回答时，点**标为好回答**，它会帮助核对这条要点能否分清好回答和坏回答。

每条确认过的要点都带一个标记：「会阻止发布」表示必须做的动作（指定了工具的要点）没做到时会阻止发布；「仅供参考」表示数据事实和判断标准没做到时只作参考，状态里还会写明正在校准或这类要点的评分还在验证中等原因。添加要点时，选好类型后也会显示同样的标记。在用例下方选「添加要点」新增，在要点的「⋯」菜单里编辑或删除，编辑时也可以改它的类型和工具，不用删掉重加；改完问题点「收起」。用例和要点的修改要点下方吸底栏里的「保存效果测试」才会用于评测，吸底栏会写明还有几处修改没保存。写法建议：一条要点只写一件事，写回答里看得见的东西，不要写今天数据里的具体数字，数据每次运行都会变。

不想自己写要点时，可以直接告诉 Coach 哪里不好，再在真实回答上核对它的判断，见[和 Coach 一起改进智能体](agent-evaluation-with-coach.zh-CN.md)；那里也说明了每条用例的「留出」开关。

## 翻译智能体介绍

如果智能体管理页提供介绍翻译，选择原文语言和另一种翻译语言：简体中文、英语、德语或法语。你可以自己填写译文名称和介绍，也可以让 AI 起草。检查译文后先保存草稿，再确认译文。确认后的内容随下一次发布生效，并经过与原文相同的检查和审批。

已有译文后，原文语言不能再更改。原文发生变化时，请重新检查、保存并确认译文。翻译只改变公开名称和介绍，不改变智能体的运行指令或权限。只有智能体所有者能管理它的译文。

## 在对话中使用智能体

主控智能体会在任务匹配、当前权限和资源允许时安排它参与对话。**在输入框里仅输入智能体名称，不能保证本次任务一定由它执行。** 需要检查是否实际使用时，可以展开该次回答的运行过程，查看实际参与的智能体。

输入框提供快捷引用时：

- 输入 `@` 选择要参与本次任务的智能体；需要某项技能时，输入 `/` 再选择。全选已有输入后直接键入 `@` 或 `/`，也会替换原内容并打开对应列表；粘贴这些字符不会自动打开列表。只选技能时，系统会尝试安排适合且当前可用的智能体。发送前检查已选的名称和附件。
- 智能体在处理前或处理过程中提出澄清时，请在当前对话的提问卡片中作答。若附件已被撤回或内容变更，请重新提交任务；想换智能体或技能时，也请作为一项新任务重新发送。
- Tab 可以补全普通的历史文字；历史消息里的 `@`、`/` 名称不会通过 Tab 恢复为已选引用。请从列表重新选择资源，并以“已选引用”的数量核对。
- 对历史消息点“编辑后发送”时，原问题会填入空白输入框，已有草稿不会被覆盖。回填的 `@`、`/` 名称只是文字，原引用和附件不会自动恢复；请重新选择所需智能体、技能和附件，核对“已选引用”数量后再发送。若提示团队权限已变化，也请先重新选择。原任务中的澄清卡仍应直接在卡片上回答，无需重发。
- `/` 列表里的技能显示灰色时，请看该项下方的原因。提示“尚未提供可用于快捷引用的只读内容”时，即使智能体平时能读取该技能，也暂时不能在输入框里点选它；需要技能维护者补充可引用的内容后才能使用。
- 智能体依赖的技能已变更，或你已失去访问权限时，智能体也可能显示为不可用。所有者需要更新依赖，按正常验证流程应用新的智能体版本；重新选择智能体不会更新它的配置。

需要逐项计算公式时，请在问题中明确说明。所选智能体提供了可核对的代入式时，聊天回答会排版显示公式和结果；较宽的公式可以横向滚动查看。无法核对的公式不会自动补写。

## 创建失败时

创建失败时，卡片会保留已填写的内容，供你修改或重试。创建后想调整工具或工作说明，请从该智能体的管理页进入；是否影响已在使用的版本，以页面显示的当前状态为准。

缺少所需工具且 Coach 交接可用时，可以要求保留需求及对应的原智能体草稿。团队负责人／管理员通过原连接页面预览连接、选择工具并填写凭据；不要在对话里发送密钥。接入后请 Coach 核对实际工具，再回到原草稿提出建议。页面已打开或工具可用不代表业务试用通过；等待期间修改过草稿时，核对针对当前版本的新建议。中断后先恢复原需求，不重复创建连接。

Coach 可用时，可以请它查看团队 Plugin，或帮助管理员用可用 Tool 和 Skill 组合 Plugin。先核对共享影响：修改 Plugin 可能影响随后使用它的其他 Agent。只想修改一个 Agent 时，应修改该 Agent 的资源选择。保存 Plugin 后，仍需为 Agent 选择它，并验证目标任务。

Coach 为创建草稿建议技能或插件时，请明确选择对应字段采纳。后续手工保存保留这些选择，也可在工具步骤移除。创建时会重新检查当前版本与权限；资源变化后请重新核对和验证，新增外部写操作需确认后再创建。草稿保存或私有创建成功不代表已完成业务试用。

缺失工具也可以属于共享插件。请 Coach 保留原插件及其版本；工具可用后，由管理员检查当前共享影响再保存绑定。记录需求不会修改插件。

Coach 评测建议可用时，可以只补充测试用例，不修改 Agent。如果还没有质量测试套件，先在“评测”页建立。到 Agent“配置”页顶部的“待处理的提案”中审阅建议，编辑任务、预期结果和评分，再选择采纳或忽略。套件被其他编辑修改后，请让 Coach 重新提案。保存或采纳用例不会运行测试，也不代表 Agent 已通过测试。

也可以让 Coach 查看你拥有的评测运行，解释失败检查、覆盖缺口和未完成结果，不修改 Agent 或重新运行测试。配置或访问权限变更后，历史通过结果可能不再适用；未知成本仍保持未知，汇总不包含原始输出。

Coach 提供操作结果时，可以在 Canvas 中查看原保存、提案或测评请求，其他编辑器会保留输入。标签名按结果写明操作：保存成功时如「技能已保存」，失败时如「插件没能保存」，结果未定时只写操作名（如「技能保存」）；结果卡片说明当时的状态；之后的修改不会反映在这里。卡片上的「打开技能」「打开插件」「去智能体中审阅」等按钮会在旁边打开对应的编辑器或草稿；Coach 已直接写入智能体草稿的修改显示「在智能体中查看」。工具条上的 **刷新** 只读取当前状态；用标签上的关闭按钮 × 关闭结果，不会停止正在进行的工作。结果未知时仍需使用该请求支持的恢复动作；访问权限失效后，视图会清除内容。

Coach 在 Canvas 中打开 Skill 或 Plugin 时，可以与 Agent 草稿同时保留。返回草稿会保留两边未保存的输入。分别保存资源，再核对 Agent 的绑定修改。Plugin 修改需要团队管理员权限，可能影响其他使用它的 Agent；只改名称不会升级已选 Skill。保存冲突时会保留输入，便于与当前版本比较。

你拥有的 Agent 尚未开始编辑时，Coach 可以先从当前已发布版本建立编辑草稿，再把修改写进去；已有草稿修改会保留。你可以在“Coach 的修改”中逐项撤销。让 Coach 检查已保存的创建草稿，不需要先改一个字段，也不会执行业务测试。

Coach 在 Canvas 打开已有智能体后，可直接编辑并保存配置；切换其他已打开对象会保留输入。如果其他地方已更新智能体，请先处理保存冲突。编辑器从上到下显示“Coach 的修改”、配置的三个部分和发布检查卡片（含教练评测申请）。评测组、自动化、版本历史和个人 Tool 连接请从工具条“⋯ › 在管理页打开”进入管理页。

要讨论当前选中的 Skill、Plugin 或智能体，请先保存或放弃本地修改，再在普通对话发送消息。切换 Tab 不会改变这条消息的原目标；若保存版本或权限已变化，请检查原编辑器后重新发送。Coach 写入的智能体修改可在“Coach 的修改”中撤销，评估预算仍通过原有按钮确认；询问资源不会自动发布或运行。

如果其他人修改了已保存资源，可在该编辑器选择**重新载入保存版本**。你可以继续编辑，或仅放弃当前编辑器的本地修改；其他打开对象的输入仍会保留。

打开草稿后，缩窄或放大窗口会保留当前未保存输入和未发送的对话。保存失败时，请按页面提示核对或重试；窗口变化不代表已保存。用户明确指定的名称应保留原样；界面语言不会自动决定智能体以后回答的语言，采纳前仍请核对生成的工作说明。

需要每行一项的简短回答时，可在指令中说明所需的行格式。聊天在生成过程中和重新打开后都会保留段落内的换行。
