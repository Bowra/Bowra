# 查看和补充额度

社区版无需商业激活，不内置用户数上限。额度仍是管理员控制的用量预算；部署运营方另行承担模型和基础设施成本。此处套餐名称表示用量档位，不表示购买了社区版订阅。

当你看到「额度已用完」的提示，或想知道自己还能用多少，从这里开始。团队负责人和管理员可以在后半部分找到为成员补充额度的步骤。

## 额度怎样计算

- 每次让 Bowra 进行分析都会消耗额度：发送消息、回答澄清卡片后继续、在飞书 / Slack / Teams 中提问、试运行流程和定时任务都算在内。
- 额度按这一轮实际处理的内容量计算，在这一轮结束后扣除。
- 新开始的工作按每个模型分别统计输入、命中缓存的输入和输出 token，各自乘以该次模型调用记录的额度系数，合计后除以 1000，最后统一向上取整一次。三个系数默认都是 1。历史流水保留原来的计算结果。如果服务商把缓存命中 token 独立于普通输入上报，即使三个系数都为 1，新版计算结果也可能与旧版不同。
- 你的个人额度来自团队额度池。个人额度或团队额度池任意一个用完，都不能再开始新的分析。
- 每月初，个人额度和团队额度池会按套餐恢复到本月配额。上月没用完的部分不结转，超出的部分也不会带到下个月。

## 查看剩余额度

- 页面顶部右侧显示你的剩余额度（仪表图标后面的数字）。余额低于配额的 20% 时变色提醒，并写出还剩多少比例；低于 5% 时显示为警示色，并写「即将用完」。
- 点一下额度（或用键盘选中后按回车）会打开额度概览：套餐、本期配额已用多少的进度条、配额重置的日期，额度偏低时还会给出提醒。按 Esc 或点别处即可关闭。在手机或较窄的窗口里，额度在导航菜单底部，概览从屏幕底部弹出。如果你的角色可以查看团队额度，概览里还有「查看用量明细」，打开你自己的用量记录。
- 打开账号菜单，进入**个人设置 → 账号**，「额度」一栏显示本月剩余和本月配额。

## 额度用完后会怎样

- **新的分析不会开始。** 发送消息、回答澄清卡片、在飞书 / Slack / Teams 中提问、试运行流程时，会提示你的额度（或团队额度）已用完。
- **已经开始的那一轮会在下一步停下。** 正在工作的智能体会交回已完成的部分并说明还没做完什么，补充额度后可以回复「继续」。这一轮到停下为止的用量照实扣除，所以余额可能显示为负数，例如 -50，表示本月已超出配额 50。之后补充的额度会先抵扣这部分。
- **回答澄清卡片时**：卡片会留在原处，提示额度已用完。补充额度后，在同一张卡片上再选一次即可继续，不用重新提问。
- **分析进行中追加的消息**：如果这一轮结束时额度已经用完，追加的内容不会自动接着分析，而是显示为一条未完成的记录，提示额度已用完。补充额度后选择**重试**即可继续。
- **定时任务**：到点时额度已用完，本次运行会被跳过，不计为失败；补充额度后按计划继续运行。

需要补充额度时，请联系团队负责人或团队管理员。

## 为成员补充额度

适用于团队负责人和团队管理员。

1. 打开账号菜单，选择**管理控制台 → 额度与账务**。
2. 在**用户列表**中找到该成员，在操作中选择**发放额度**。
3. 填写数额（原因可选），选择**发放**。发放的额度从团队额度池调拨，团队额度池的余额会同步减少。
4. 如果提示团队额度池余额不足，先选择**调整团队额度**，填写新配额和理由并确认，再回到第 2 步发放。

也可以在操作中选择**修改配额 / 套餐 / 余额**，直接调整该成员的配额或余额。

如需保存某位成员的额度记录，在**用户列表**中打开该成员的详情，选择**下载额度流水 CSV**。下载的文件只包含这位成员的流水；额度主页的**下载 CSV**菜单提供团队范围的导出。

用量明细会显示新模型扣费记录所用的模型。展开一行可查看输入、缓存输入、输出用量和调用时记录的系数；一轮使用多个模型时会分别列出。若部分用量无法匹配已确认的模型调用记录，会显示为「未知模型」，并按三个系数均为 1 计算；历史记录也可能没有模型名称。成员额度流水 CSV 也包含模型名称和已记录的模型用量。

### 确认结果

用户列表中该成员的「余额 / 配额」会更新。余额为负的成员会先抵扣超出部分，例如余额 -50 时发放 100，余额变为 50。成员刷新页面后，顶部的额度随之更新，即可继续使用。

### 团队额度池用完时

团队额度池用完后，团队里所有人都不能开始新的分析，即使个人还有余额。请先选择**调整团队额度**提高团队配额。

**周期重置**会一次性重置全团队的余额（或余额和配额）。操作不可逆，24 小时内只能执行一次，执行前请确认影响的人数。
