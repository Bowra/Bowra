# Datarc-Datenquelle verbinden und verwenden

## Verbindung einrichten

Team-Eigentümer und Administratoren öffnen **Team-Einstellungen → Datenquellen**. Fügen Sie eine Datarc-Quelle mit Name, Basisadresse, Schlüssel und gegebenenfalls Konto-ID hinzu. Prüfen Sie die Verbindung vor dem Speichern. Ist schon eine Quelle aktiv, entscheiden Sie, ob Sie die neue Quelle archivieren oder die bisherige ersetzen.

Pro Team ist eine Datarc-Quelle aktiv. Über ihr Zeilenmenü können Sie den Schlüssel wechseln oder die Quelle archivieren. Über die archivierten Quellen finden Sie gespeicherte Verbindungen zur erneuten Aktivierung. Prüfen Sie nach einem Wechsel eine Abfrage und die betroffenen geplanten Aufgaben.

## Daten für eine Unterhaltung auswählen

Wenn der Chat nach einem Datarc-Arbeitsbereich fragt, wählen Sie aus den für Sie verfügbaren Bereichen. Speichern Sie die Wahl, wenn sie künftig als Standard dienen soll. Der Bowhead-Bereich regelt die Zusammenarbeit. Der Datarc-Arbeitsbereich bestimmt im Rahmen Ihrer Berechtigungen den Datenumfang. Fehlt eine Quelle, prüfen Sie Team, aktive Verbindung und Datarc-Zugriff. [Eine Analyse starten](getting-started.de-DE.md)
