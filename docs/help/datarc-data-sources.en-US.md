# Connect and use a Datarc data source

## Set up the connection

Team owners and administrators open **Team settings → Data Sources**. Add a Datarc source with its name, base URL, access key and, when applicable, account ID. Run the connection check before saving. If a source is already active, choose explicitly whether to keep it active and archive the new source, or activate the new source in its place.

Only one Datarc source is active for the Team. Use the source’s row actions to rotate its key or archive it. **Show archived** displays saved sources you can activate again. When replacing a source, verify an actual query and any scheduled tasks that relied on it.

## Choose the data for a conversation

When Chat asks for a Datarc workspace, select from the workspaces available to you. Use **Remember my choice** if you want the selection as a default for future tasks. A Bowhead Space controls who can collaborate. The Datarc workspace you select controls the query’s data scope, subject to your data access. If a source or workspace is missing, check your Team, its active connection, and your Datarc access. [Start an analysis](getting-started.en-US.md)
