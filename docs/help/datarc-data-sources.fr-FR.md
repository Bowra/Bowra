# Connecter et utiliser une source Datarc

## Configurer la connexion

Les propriétaires et administrateurs ouvrent **Paramètres de l’équipe → Sources de données**. Ajoutez une source Datarc en indiquant le nom, l’adresse de base, la clé et, le cas échéant, l’identifiant de compte. Testez la connexion avant d’enregistrer. Si une source est déjà active, choisissez d’archiver la nouvelle ou de remplacer l’ancienne.

Une seule source Datarc est active pour l’équipe. Le menu de sa ligne permet de renouveler sa clé ou de l’archiver. Affichez les sources archivées pour retrouver une connexion à réactiver. Après un remplacement, vérifiez une requête réelle et les tâches planifiées qui utilisaient la source.

## Choisir les données d’une conversation

Lorsque le chat demande un espace de travail Datarc, choisissez parmi ceux qui vous sont accessibles. Mémorisez le choix si vous souhaitez en faire la valeur par défaut. L’espace Bowhead détermine qui collabore. L’espace de travail Datarc détermine le périmètre de la requête dans la limite de vos droits. Si une source manque, vérifiez l’équipe, la connexion active et les droits Datarc. [Lancer une analyse](getting-started.fr-FR.md)
