# 连接并使用 Datarc 数据源

## 设置连接

团队负责人和管理员打开**团队设置 → 数据源**。添加 Datarc 数据源，填写名称、基础地址、访问密钥及适用时的账号 ID。保存前测试连接。已有活跃数据源时，明确选择保留现有来源并归档新来源，或启用新来源来替换它。

团队同时使用一个活跃的 Datarc 数据源。通过数据源的行操作轮换密钥或归档。打开「显示已归档」查找已保存、可重新启用的来源。切换后，验证一条真实查询和依赖该来源的定时任务。

## 为对话选择数据

对话需要选择 Datarc 工作区时，从你有权使用的工作区中选择。希望以后默认使用该项时，勾选「记住我的选择」。Bowhead 的 Space 管理协作范围，Datarc 工作区决定查询的数据范围，并受你的数据权限约束。找不到来源或工作区时，核对当前团队、活跃连接和 Datarc 权限。[开始一次分析工作](getting-started.zh-CN.md)
