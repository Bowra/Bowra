# 发送邮件

团队在“团队设置 → 邮件服务”中保存了自己的发信配置后，你可以在对话中请 Bowra 发送带纯文本正文和文件附件的邮件；在主控对话中，每封邮件都要你本人在页面上确认后才会发出。本文前半部分面向发信的成员，后半部分面向配置邮件服务的团队负责人和团队管理员。

## 在对话中发送邮件

在对话中明确说明收件人、主题和正文，请 Bowra 发送邮件。例如：“请发送邮件给 customer@example.com，主题是项目进展，正文是……”。也可以让 Bowra 把本次对话中的分析结果整理成邮件发出。

你说“发我邮箱”时，Bowra 可以读取你本人的账户邮箱，无需再次输入；你明确指定的收件地址优先。账户没有邮箱时，Bowra 会请你补充收件地址。发送确认仍会显示实际地址，请核对后再发送。

### 发送前确认

每封邮件发出前，页面会弹出“确认发送邮件”窗口，完整显示收件人、主题、正文，以及附件的名称和大小。请核对无误后点击“确认发送”；点击“不发送”或在提示的时间内没有操作，邮件都不会发出，Bowra 也会在对话中如实说明没有发送。邮件发出后无法撤回。

只有发起这次对话的你本人能看到并确认这封邮件。主控不会在定时任务、飞书等无法在网页上确认的场景发送邮件。

### 邮件里的数字

邮件正文里的金额、百分比等数字必须来自本次对话实际查到的数据，或者你在消息里直接给出的数字。如果 Bowra 起草的正文里有数字在本次数据中找不到，这封邮件不会弹出确认，Bowra 会先改正这些数字再请你确认。

如果想把之前对话里的分析结果发出去，请在本次对话中让 Bowra 重新查询一次相关数据，再发送邮件。

### 附上报告或其他文件

请说明要附上当前对话中已经上传或生成的文件，例如：“把这份 PPT 报告作为附件发我邮箱。”文件必须属于你本人，并且在当前对话和空间中可用。要发送画布报告，请先让 Bowra 导出为支持的文件；画布本身不能直接作为附件。

支持 PPTX、DOCX、XLSX、PDF、CSV、TXT、PNG 和 JPEG。每封邮件最多 5 个文件，合计不超过 10 MiB；超出时请压缩文件或分开发送。文件不存在、已删除、格式不受支持或无法读取时，整封邮件都不会发送，不会擅自省略附件。邮件服务商可能另有大小限制。

确认前请核对收件人、文件名、大小和文件内容。邮件主题和正文的数字核对不代表附件内容已被核验。确认后发送的是你确认前展示的文件内容，即使你决定期间存储中的文件发生变化也不会替换；发送前文件已不可用时则不会发出邮件。

自建智能体的 Owner 已选择并发布“邮件”资源时，运行按该授权直接发送，不再逐封确认；文件权限和附件限制相同。

### 未配置邮件服务时

如果团队没有保存自己的邮件服务配置，Bowra 会提示该服务暂时不可用。“当前生效的发信配置”显示继承实例默认时也是这样：实例默认配置只用于邀请、邮箱验证、密码重置等系统邮件，不用于在对话中发信。请联系团队负责人或团队管理员按下文完成配置。

## 配置团队邮件服务

团队负责人和团队管理员可以在“团队设置 → 邮件服务”中为团队配置发信用的 SMTP 服务。配置完成后，邀请新成员、邮箱验证、密码重置和通知邮件会优先使用团队自己的配置发送，成员也可以按上文在对话中发送邮件。

### 配置步骤

1. 打开“团队设置 → 邮件服务”。“当前生效的发信配置”会显示团队已配置、继承实例默认，还是尚未配置。
2. 在“SMTP 连接”中填写邮件服务商提供的 SMTP 服务器、端口和加密方式。常用端口为 465（SSL/TLS）、587 或 2525（STARTTLS）。
3. 在“身份验证”中填写 SMTP 用户名和密码 / 授权码。多数邮件服务需要专用的 SMTP 密码或应用授权码，而不是登录密码。密码保存后不会再显示，再次保存时留空即沿用已保存的密码。
4. 在“发件人身份”中填写邮件服务商授权的发件地址和发件人名称。Bowra 不提供默认发件域名，未配置已授权的发件地址时无法投递。然后点击“保存”；也可以点击“保存并测试”，保存后立即发送测试邮件。
5. 点击“发送测试邮件”，测试邮件会发到你本人的邮箱。收到即表示配置可用；没收到时也请检查垃圾箱。

不再需要团队配置时，点击“清除配置”（只有团队保存了自己的配置时才显示），之后系统邮件会改用实例默认的发信配置（如果有），在对话中发送邮件则会暂时不可用。

### 注意事项

- 云端（SaaS）版本只能使用可从公网访问的邮件服务器，端口限定为 25、465、587 或 2525。填写公司内网地址或其他端口时，保存会提示地址被安全策略拦截或端口不受支持，请改用邮件服务商提供的公网 SMTP 地址。
- 私有化部署可以使用公司内网的邮件服务器和其他端口。
- 只有团队负责人和团队管理员可以查看和修改邮件服务配置，普通成员看不到这个入口。
