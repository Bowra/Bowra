# Dateien finden und verwalten

Öffnen Sie **Bibliothek → Dateien**. Unter **Dateien** stehen Uploads und gelieferte Dateien, unter **Ausführungsdaten** während der Ausführung gespeicherte Dateien und im Papierkorb gelöschte Dateien. Wechseln Sie bei Bedarf die Registerkarte und suchen oder filtern Sie die Liste.

Wählen Sie den Dateinamen für Details, Vorschau, Download und verfügbare Aktionen der Wissensdatenbank. Fehlt die Vorschau, laden Sie bei entsprechender Berechtigung das Original herunter. Bei einer im Chat überarbeiteten Datei öffnen Sie den Versionsverlauf in den Ergebnissen, um eine erhaltene frühere Version herunterzuladen. [Eine Dateiversion finden](conversation-workbench.de-DE.md)

Wählen Sie mehrere Zeilen für die unten angezeigten Sammelaktionen. Nach dem Löschen können Sie den Vorgang rückgängig machen oder aus dem Papierkorb wiederherstellen. Endgültiges Löschen lässt sich nicht rückgängig machen. Bei blockierenden Verweisen aus der Wissensdatenbank oder aus Dokumenten prüfen Sie zuerst die Verweise. Für die Suche als Wissensquelle fügen Sie die Datei im gewünschten Geltungsbereich hinzu und warten, bis die Indexierung abgeschlossen ist. [Wissensdatenbank verwenden](knowledge-base.de-DE.md)
