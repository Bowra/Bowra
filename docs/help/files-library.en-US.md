# Find and manage files

Open **Library → Files**. Use **Assets** for uploaded files and delivered outputs, **Run data** for files saved during execution, and **Trash** for deleted files. Switch tabs if a file is missing from the current list. Search by name and narrow the list with the available filters.

Select the file name to open its preview and details. Use the available preview, download or knowledge-base actions. If the preview is unavailable, download the original where permitted. For a file revised in conversation, open the latest version and use **Version History** in Results to download a retained earlier version. [Find or download a file version](conversation-workbench.en-US.md#find-or-download-a-file-version)

You can select multiple rows for the bulk actions shown at the bottom. After deletion, use **Undo** or restore the file from **Trash**. Permanent deletion cannot be undone. If a knowledge-base or document reference blocks removal, inspect the file’s references before retrying. A file in the library becomes searchable as a knowledge source after you add it to the intended scope and indexing is ready. [Use the knowledge base](knowledge-base.en-US.md)
