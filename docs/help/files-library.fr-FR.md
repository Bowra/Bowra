# Rechercher et gérer des fichiers

Ouvrez **Bibliothèque → Fichiers**. Les fichiers importés et livrés figurent dans **Ressources**, les fichiers sauvegardés pendant une exécution dans **Données d’exécution**, et les fichiers supprimés dans **Corbeille**. Changez d’onglet si nécessaire et utilisez la recherche ou les filtres.

Ouvrez une ligne pour consulter les détails et les actions disponibles. Si l’aperçu est indisponible, téléchargez l’original si vous y avez accès. Pour un fichier révisé dans le chat, ouvrez l’historique des versions dans les résultats afin de télécharger une version antérieure conservée. [Trouver une version d’un fichier](conversation-workbench.fr-FR.md)

Sélectionnez plusieurs lignes pour afficher les actions groupées. Après une suppression, annulez-la ou restaurez le fichier depuis la corbeille. Une suppression définitive est irréversible. Si une référence de la base de connaissances ou d’un document bloque la suppression, vérifiez les références. Pour rendre un fichier interrogeable comme source, ajoutez-le au périmètre voulu et attendez la fin de l’indexation. [Utiliser la base de connaissances](knowledge-base.fr-FR.md)
