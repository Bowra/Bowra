# Rechercher et gérer des fichiers

Ouvrez **Bibliothèque → Fichiers**. Les fichiers importés et livrés figurent dans **Ressources**, les fichiers sauvegardés pendant une exécution dans **Données d’exécution**, et les fichiers supprimés dans **Corbeille**. Changez d’onglet si nécessaire et utilisez la recherche ou les filtres.

Sélectionnez le nom du fichier pour ouvrir son aperçu, ses détails et les actions disponibles. Si l’aperçu est indisponible, téléchargez l’original si vous y avez accès. Pour un fichier révisé dans le chat, ouvrez l’historique des versions dans les résultats afin de télécharger une version antérieure conservée. [Trouver une version d’un fichier](conversation-workbench.fr-FR.md)

Cochez les cases à côté des noms de fichier pour afficher les actions groupées. Après une suppression, annulez-la ou restaurez le fichier depuis la corbeille. Une suppression définitive est irréversible. Si une référence de la base de connaissances ou d’un document bloque la suppression, vérifiez les références. Pour rendre un fichier interrogeable comme source, ajoutez-le au périmètre voulu et attendez la fin de l’indexation. Lorsque les bases de connaissances sont activées, **Ajouter à la base de connaissances** demande plutôt une base, qui détermine qui peut rechercher le fichier ; **Voir dans la base de connaissances** ouvre la base où se trouve le fichier, avec ce fichier sélectionné. Si cette base se trouve dans « Mes connaissances », dans l’espace actuel ou dans l’équipe, la colonne **Base de connaissances** affiche aussi son nom. [Utiliser la base de connaissances](knowledge-base.fr-FR.md)

## Livrables et stockage

Lorsque la page Fichiers ouvre **Livrables**, le dernier fichier compatible apparaît dans l’aperçu sur ordinateur. Sur téléphone, touchez son nom. Recherchez un nom ou filtrez par espace, conversation, date ou format. Consultez les fichiers importés, les données d’exécution ou tous les fichiers pour retrouver les autres documents. Les détails affichent les références et versions conservées.

**Gérer le stockage** affiche votre consommation, les motifs de conservation et la corbeille avec la date de récupération de chaque fichier. Une version restaurée après nettoyage automatique reste conservée jusqu’à ce que vous autorisiez à nouveau le nettoyage.

Les propriétaires et administrateurs d’équipe peuvent choisir 30 jours, 90 jours, la désactivation ou la valeur du déploiement dans **Conservation et nettoyage des fichiers**. Vérifiez l’aperçu puis choisissez si les fichiers existants admissibles doivent être inclus. L’espace est libéré après la suppression définitive.
