# 查找和管理文件

打开**资料库 → 文件**。上传文件和交付成果在「资产」，执行过程中保存的文件在「运行数据」，已删除的文件在「回收站」。当前列表找不到时，切换相应标签，再按名称搜索或使用筛选。

点击文件名查看预览和详情，并使用可用的预览、下载或知识库操作。没有预览时，可在权限允许的情况下下载原件。对话中修订过的文件会打开最新版，可在成果的「版本历史」中下载仍保留的旧版。[查找或下载文件版本](conversation-workbench.zh-CN.md)

勾选文件名旁的复选框后可使用下方的批量操作。删除后可立即撤销，或从回收站恢复。永久删除无法恢复。如果知识库或文档引用阻止删除，先查看文件引用。要让文件可以作为知识来源被搜索，请把它加入所需范围并等待索引就绪。开启按知识库整理后，**加入知识库**改为选择一个知识库，文件能被谁检索由那个知识库决定；**在知识库中查看**会打开文件所在的知识库并选中这份文件。知识库在「我的」、当前空间或团队中时，「知识库」一列还会显示它的名称。[使用知识库](knowledge-base.zh-CN.md)

## 交付物与存储管理

文件页默认打开「交付物」时，桌面端会预览最近一份支持预览的交付物，手机上点文件名即可阅读。可以按文件名搜索，或按空间、来源会话、日期及格式筛选。要查找没有交付记录的文件，请打开「上传文件」「运行数据」或「全部文件」。在「详情」里可以查看引用和保留的版本。

「管理存储」显示个人用量、保留原因及回收站。每份已删除文件都有自己的恢复截止日。选择「保留此版本」可以阻止自动清理该运行文件。恢复自动清理的文件后，只有再次允许自动清理，该文件才会重新参与清理。

团队负责人和管理员可以打开「团队设置 → 文件保留与清理」，选择 30 天、90 天、关闭或部署默认值，然后预览影响。应用时可以选择包含本次预览中符合条件的历史文件。进入回收站的文件仍可恢复，永久删除后才释放存储。
