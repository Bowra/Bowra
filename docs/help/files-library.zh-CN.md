# 查找和管理文件

打开**资料库 → 文件**。上传文件和交付成果在「资产」，执行过程中保存的文件在「运行数据」，已删除的文件在「回收站」。当前列表找不到时，切换相应标签，再按名称搜索或使用筛选。

点击文件名查看预览和详情，并使用可用的预览、下载或知识库操作。没有预览时，可在权限允许的情况下下载原件。对话中修订过的文件会打开最新版，可在成果的「版本历史」中下载仍保留的旧版。[查找或下载文件版本](conversation-workbench.zh-CN.md)

勾选文件名旁的复选框后可使用下方的批量操作。删除后可立即撤销，或从回收站恢复。永久删除无法恢复。如果知识库或文档引用阻止删除，先查看文件引用。要让文件可以作为知识来源被搜索，请把它加入所需范围并等待索引就绪。[使用知识库](knowledge-base.zh-CN.md)
