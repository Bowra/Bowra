# Eine Analyse starten

Nutzen Sie diese Anleitung, wenn Bowra Material analysieren, eine Frage strukturieren oder einen Bericht erstellen soll. Sie müssen nicht alle Agents, Skills oder Berechtigungseinstellungen kennen, bevor Sie beginnen.

## Bevor Sie beginnen

- Melden Sie sich mit Ihrem eigenen Konto an und wählen Sie das richtige Team und den richtigen Bereich.
- Legen Sie ein klares Ziel, die Zielgruppe, den Zeitraum und die Entscheidungskriterien fest.
- Stellen Sie nur Dateien, Felder und Kontext bereit, die für diese Aufgabe nötig sind. Geben Sie niemals Passwörter, Tokens oder andere Geheimnisse in einem Chat oder Anhang an.

## Aufgabe starten

1. Wählen Sie in der linken Navigation **Neue Arbeit**.
2. Prüfen Sie oben das Team und den Bereich. Wenn Kolleginnen und Kollegen mitarbeiten sollen, stellen Sie sicher, dass sie diesem Bereich angehören.
3. Beschreiben Sie das gewünschte Ergebnis und ergänzen Sie Kontext, Umfang und Kriterien. Beispiel: „Vergleiche den Umsatz in Ostchina in diesem Quartal mit dem Vorquartal, erläutere die wichtigsten Ursachen und gib der Geschäftsleitung drei Empfehlungen.“
4. Fügen Sie nur relevante Dateien hinzu und erklären Sie, wie jede Datei verwendet werden soll.
5. Senden Sie die Anfrage und prüfen Sie Ablauf und Ergebnis. Verfeinern Sie Bedingungen oder Umfang in derselben Arbeit. Erstellen Sie nur für eine neue Fragestellung eine neue Arbeit.

## Während der Analyse Fragen beantworten

In einer normalen Unterhaltung kann ein Agent eine Fragekarte anzeigen, um einen Zeitraum, eine Kennzahlendefinition oder eine andere Bedingung zu bestätigen. Beantworten Sie jede Frage, ergänzen Sie bei Bedarf eigene Angaben und senden Sie die Antworten ab, damit die Analyse fortgesetzt wird. Die Karte bedeutet, dass die Analyse auf Ihre Eingabe wartet; sie ist kein Hinweis darauf, dass die Analyse abgeschlossen ist. Wenn keine Karte erscheint, antworten Sie mit den in der Unterhaltung angezeigten Fragen und ergänzen Sie weitere Details.

## Agent, Methode oder Tool auswählen

Wenn der Editor ein Auswahlmenü für Kurzbefehle anzeigt, geben Sie `@` ein, um einen Agent auszuwählen, und `/`, um eine verfügbare Methode, ein Tool oder eine Capability auszuwählen. Deaktivierte Einträge sind nicht verfügbar; die Erklärung im Menü zeigt den Grund. Ausgewählte Ressourcen erscheinen als Chips im Editor. Wählen Sie einen Chip aus oder fokussieren Sie ihn mit der Tabulatortaste und drücken Sie die Eingabetaste, um erforderliche Parameter auszufüllen. **Parameter anwenden** aktualisiert den Entwurf; die Aufgabe muss anschließend noch gesendet werden.

Wenn eine Aufgabe einen Datarc-Arbeitsbereich benötigt, wählen Sie bei der Aufforderung einen Eintrag aus der Liste aus. Die ursprüngliche Aufgabe und ihre Anhänge bleiben während der Auswahl verfügbar. Eine zurückgezogene Datei, geänderte Berechtigung oder abgelaufene Aufgabenmaterialien können die Fortsetzung verhindern.

## Persönliche Einstellungen

Die persönlichen Einstellungen sind direkt aufrufbare Seiten. Öffnen Sie **Persönliche Einstellungen** im Kontomenü oder verwenden Sie die passende Adresse: Konto `/settings/profile/`, Sicherheit `/settings/security/`, Darstellung `/settings/appearance/`, Memory `/settings/memory/` oder Export `/settings/export/`. Sie können diese Adressen als Lesezeichen speichern oder direkt von einer anderen Seite öffnen.

## Prüfen, ob ein Ergebnis verwendbar ist

Bevor Sie ein fertiges Ergebnis teilen, prüfen Sie, ob es die Frage beantwortet, den gewünschten Zeitraum und die Filter berücksichtigt, wichtige Zahlen mit den Schlussfolgerungen verknüpft und die passenden Freigaben für Bericht, Anhänge und Quelldaten hat. Ein geteilter Bericht gewährt Kolleginnen und Kollegen keinen Zugriff auf Ihre private Unterhaltung, sämtliche Anhänge oder Ihre Datenidentität.

**Meine Berichte** in der Seitenleiste zeigt jeweils 50 Berichte. Rechts in der Werkzeugleiste steht, wie viele Berichte zur aktuellen Suche und den Filtern passen („N gefunden“ während einer Suche). Unter der Liste steht „N von M angezeigt“; mit **Mehr laden** folgt der nächste Block. Bereits angezeigte Berichte und der Bereich **Mit mir geteilt** darunter bleiben erhalten. Sind alle angezeigt, steht dort „Alle N Berichte angezeigt“. Eine Änderung von Suche, Space, Sortierung oder **Nicht generierte anzeigen** beginnt wieder mit dem ersten Block. Schlägt das Laden fehl, wählen Sie **Erneut versuchen**; die bereits angezeigten Berichte bleiben stehen.
