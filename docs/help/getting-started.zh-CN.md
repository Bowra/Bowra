# 开始一次分析工作

当你要让 Bowra 协助分析资料、整理问题或产出报告时，从这篇开始。它不要求你先理解所有 Agent、Skill 和权限设置。

## 完成团队启用

团队负责人和管理员可以从用户菜单打开「团队启用状态」。页面会突出显示下一项核心配置。选择对应操作进入设置页，完成后通过「返回启用状态」回到引导并刷新。

已完成的检查、能力配置与推荐项、团队信息默认收起，展开后可以查看配置、权限和检查说明。需要关注的警告会保持可见，即使核心检查已经完成。推荐项不影响核心启用进度；部分能力仍需完成对应配置才能使用。

五项核心检查满足后，页面显示「团队已就绪」。你可以进入 Bowra，也可以稍后回来复查。已配置连接不代表外部服务此刻一定可用。

## 开始之前

- 确认当前登录的是你自己的账号，并选择了正确的团队和空间。
- 准备一个明确的目标：希望回答什么问题、面向谁、时间范围是什么。
- 只提供完成工作所必需的文件、字段和业务背景。不要在对话或附件中写入密码、令牌或其他密钥。

## 发起工作

### 用上传的 PPT 作为模板

模板请求默认可用，管理员仍可关闭，实际生成需要文档服务正常运行。入口可用时，从 Canvas 标签栏的 **+**（打开…）菜单查看本对话当前及历史草稿，在同一右侧 Canvas 打开。「已受理」不代表文件完成；请勿仅因仍在准备或看不到审阅入口而重复提交。

团队启用模板生成功能后，上传或引用普通 `.pptx`，在消息里明确它是模板，并提供数据及修改要求。例如：「把附件 PPT 当作模板，根据 CSV 更新各地区数量，保留版式和其他文字。」无需填写模板配置表。更换模板时，上传或引用另一份文件，在新请求中明确使用哪一份即可。

移除卡片不会删除模板、已保存草稿或已发布文件。已有 PPTX 和 PDF 仍可通过原文件控件访问，并受当前权限约束。PDF 来自对应 PPTX，下载不会重新生成文件。

先审阅实际页面和修改，再明确确认发布。关闭草稿 Tab 只关闭视图，可从标签栏的 **+** 菜单重开，不批准或取消任务。确认结果不确定时，使用草稿里的核对／重试动作，不要重新生成。发布后的源文件与 PDF 可通过成果中的原文件控件访问。切换 Tab 保留输入，也不会改变在途确认的对象。

文档有待回答问题时，打开草稿查看问题，并按提示在同一对话回答。原始要求、模板和数据会保留，并重新检查权限及文件是否变化；更换文件须重新明确发起请求。文档服务不可用时请联系管理员，更换模板不能修复服务。

支持的修改限于普通文字和简单非合并表格，不支持复杂图表、嵌入对象或任意重排模板。渲染使用 LibreOffice，不代表 PowerPoint 原生兼容认证。确认时不会再次调用模型；模型请求结果不明确时，用量保留待结算状态，不显示成免费。

1. 在左侧导航选择 **新工作**。
2. 核对顶部显示的团队和空间。需要协作时，先确认同事也已进入这个空间。
3. 用一句话说明预期结果，再补充背景、范围和判断标准。例如：“比较华东区本季度与上季度的销售变化，说明主要原因，并给出适合管理层阅读的三条建议。”
4. 需要使用文件时，只添加与本次问题有关的资料，并在问题中说明每份资料的作用。
5. 发送后查看过程和结果。需要继续时，直接在同一工作中补充条件、纠正范围或要求改写；需要重新开始时，再创建一项新工作。

## 回答分析中的问题

普通对话中，专业 Agent 需要确认时间范围、指标口径等条件时，会显示问题卡片。请逐项选择，必要时填写自己的答案，再提交继续。卡片出现表示分析正在等待你的信息，并不代表分析已经完成。若未能显示卡片，请根据对话中的问题补充说明。

- 只有一个单选问题时，点选答案即提交；需要补充具体数值或文字时，在卡片里的「自己输入回答…」中填写，再点「发送」。
- 有多个问题或可以多选时，逐项作答后点「确认并继续」。
- 暂时无法回答某一题时，可以点「跳过本题」；也可以点「跳过全部, 让模型判断」，由模型根据上下文决定。跳过后结果可能只覆盖一部分。
- 想修改原问题时，点「换个问法 →」：卡片会关闭，原问题回到输入框，编辑后重新发送。

回答后可以刷新页面，查看问题、你的回答和后续结果。

## 发送后显示「发送状态待确认」时

正常发送期间只会显示等待状态。如果发送后网络中断，页面暂时无法判断任务是否已经开始，才会在输入框旁显示「发送状态待确认」。这时输入会暂停编辑，原内容会保留。

- 选择「核对并重试」可以检查原发送的结果；需要继续发送时会沿用这次提交，避免重复创建任务。
- 不想继续等待时，选择「放弃本次并继续编辑」。若原任务其实已经开始，页面会带你进入该会话；未开始时才会恢复草稿编辑。
- 若核对暂时失败，稍后再试，原内容不会因此清除。

带有 `@` 或 `/` 引用的草稿可能同时显示一份只读副本。你可以选择「查看引用与参数」，或用「复制文字」「复制完整草稿」保留内容。发送状态仍未确认时，先使用输入框旁的处理动作。

## 选择 Agent、方法或工具并填写参数

如果输入框显示快捷选择菜单，可以输入 `@` 选择 Agent，输入 `/` 选择当前可用的方法、工具或能力。灰色项目暂时不可用，以菜单提示为准。

同名资源可以通过来源标签区分。暂不可用的项目会显示原因。如果某类资源加载失败，仍可选择已显示的可用项目，也可以选择「重试」重新加载。

可以只选择可用的团队或系统 Agent，不必同时添加方法。智能体已包含的技能可以直接引用普通说明，无须另设参数表单。如果没有兼容的智能体，请选择已包含该技能的智能体，或请负责人添加。选择说明不会授予脚本执行权限。支持的任务出现问题卡片时，请在原卡片上回答，继续使用原 Agent 和已选方法，无需再次选择。另发一条消息，或选择「换个问法」后重新发送，会发起另一项任务，不是回答待处理的卡片。如果权限或任务资料发生变化，可能无法继续，请按卡片提示处理。

选择后，资源会成为输入框中的标签。需要填写公司、年份等条件时，点击可编辑的标签，或用 Tab 聚焦后按 Enter 打开参数面板。填写必填项并修正提示中的错误，再选择 **应用参数**。这一步只更新草稿，确认正文和附件后还需要发送任务。新任务和追加任务都可以同时保留所选标签与文件；有文件时可以不另填正文，但仍建议说明期望结果。可读取的文本会作为本次任务资料交给所选 Agent；文件解析失败时不能据此判断内容。图片是否可用以当前任务提示为准。

指定 Agent、使用 Skill 或团队提示模板的任务，首次查询数据或查看数据结构、指标、维度时，如果出现北极九章工作区选择卡片，可选择后继续原任务，保留暂停前使用的附件文本资料；如果文件被撤回、权限发生变化或任务资料已失效，会提示无法继续。其他问题请按实际出现的卡片回答；任务无法继续时，不要将重新发送视为原任务恢复。

如果不想继续选择，可使用卡片上的 **换个问法** 结束原任务的等待，再编辑问题。卡片过期后，原任务会结束并提示无法继续；已经发生的用量仍保留。重新提交前，请核对输入框中的资源标签和附件。

选择 **取消** 会保留原参数；应用后可以在输入框中撤销修改。如果资源已更新、停用或你已失去访问资格，面板会提示无法读取参数，原稿会保留。请先核对当前团队、空间和资源，再决定是否重新选择。

菜单中可用的内置 Agent 也支持这种选择方式和问题卡片；可以单独选择，也可以搭配可用的方法。

其他 Agent 协助完成任务时，仍可使用它们原有的方法；你为主 Agent 选择的方法不会自动分配给它们。

其他任务运行时，也可以追加带 Agent 或方法的任务。排队任务开始后会保留原选择；如果它提出问题，请在该任务的问题卡片上回答以继续。尚未开始的任务可以在待执行列表中取消。

Agent 读取方法后询问缺失数值时，请在问题卡片上回答。已支持的文本文件、PDF 中提取的文字、XLSX 预览以及 PNG、JPEG、WebP 图片会保留在原任务中，无需再次上传。如果文件已变更或无法访问，任务可能无法继续。PDF 使用可提取的文字；如需分析扫描页或图表，请另行提供图片或数据。Excel 预览仅展示每个工作表的前 30 个非空行；分析完整工作簿需要 Agent 具备相应的文件读取工具。

使用 Word 或 PowerPoint 时，请先完成 DOCX 或 PPTX 上传，并说明文件用途。已配置附件读取工具的 Agent 可以按需读取文字，提问时保留已读结果；请在原问题卡片上回答并继续。读取文字不等于理解图表、图片或页面布局，也不会自动按模板生成新文档。恢复期间，已变更、删除或无法访问的文件不能被静默替换。

当 `/` 菜单中的图片生成可用时，选择它并描述你需要的图片，也可以在其他任务运行时将请求加入队列。如果任务询问风格等缺失信息，请在原问题卡片上回答，继续使用原来的选择。图片任务应交付实际生成的图片，只有文字描述不代表已完成。

如果方法菜单中的 **ROE 杜邦归因** 可用，可以选择它，将盈利能力拆为净利率、资产周转率和权益乘数。请尽量提供公司、期间、营收、净利润、平均总资产和平均股东权益；必要数值缺失时，可按问题卡片补充。有额外数据时，也可分析五步杜邦或价值创造。选择方法不会额外开通脚本或数据连接。

如果 `/` 中有可用的团队工具或工具源，请先用 `@` 选择团队 Agent，再填写所需参数。可以立即发送，也可以加入队列。如果任务在使用工具前，或在已支持的工具读取后询问缺失信息，请在原问题卡片上回答，原 Agent 和工具参数会继续保留。继续任务时会复用已保存的成功读取结果；如果结果已过期或访问权限发生变化，可能无法继续。选择工具源后，Agent 可按需使用其中可用的工具；选择某个具体工具时，该工具需要成功执行才算完成。任务失败不代表工具从未调用，重新发送前请先核对任务结果。

### 使用团队提示模板

如果 `/` 菜单提供可用的 **MCP 提示模板**，先用 `@` 指定一个团队 Agent，再选择一至三个模板，点击标签填写模板要求的条件，最后发送任务。当前只支持团队提供的免登录模板；同一次任务中不能再混选 Skill、工具或能力标签。Agent 原有的方法仍可使用。

当前任务运行时，也可用同样方式追加提示模板任务；它会在当前任务结束后独立执行。追加时可保留上传文件；选择模板并附上文件后，不必为了发送再补一段文字。可在待执行列表中取消尚未开始的任务。在待执行列表选择 **排队内容**，可核对当时选中的资源和排队状态；选择 **查看正文和参数** 才会读取原始要求与参数。可用 **刷新记录** 核对最新状态，收起后再次打开会重新读取。排队或建立任务不代表执行成功。已无权查看的资源会隐藏，原文超过保留期限时可能不可读。如果执行前模板或 Agent 已不可用，任务会提示无法继续，请确认权限和所选资源后重新提交。

模板在发送后展开，用作这次任务的参考材料。填写参数不会调用外部服务；任务完成后可在使用证据中查看执行情况。若任务询问缺失信息，请在原问题卡片上回答；原 Agent、模板参数和支持的附件会保留。继续时会复用已保存的模板内容和已完成的方法读取；权限变化或材料过期可能导致无法继续。计划入口暂未开放，菜单会显示不可用。遇到失败请保留草稿并查看提示，不要仅凭标签已插入就判断模板已执行。

## 怎样判断结果可用

某个 Agent 完成自己的部分，不代表整个任务已经结束。请以任务的最终状态和回答为准。未能获取的用量或费用是未知值，不是零。

送达状态未知表示尚未确认调用结果，不代表调用失败或没有产生费用。重新发送前请核对最新任务记录；即使任务已停止，迟到的响应仍可能更新记录。

如果使用计划预览，在多个页面同时修改或开始执行时，可能会提示计划已变化。请刷新计划、核对最新步骤后再确认；系统不会自动把冲突的旧修改重试到新计划上。连续修改会按顺序保存，请保存完成后再确认执行。确认时如果计划已被其他页面修改，会显示最新计划，核对后需再次确认；不会直接执行你尚未确认的新步骤。保存失败且无法刷新时，请先刷新并核对步骤。已经开始执行的计划不能再保存预览中的旧修改。计划受阻后，修订、重新规划或跳过步骤会按你确认后的步骤继续；若期间计划已被其他页面修改或启动，请刷新核对，不会自动执行另一版。快捷引用是否可用于计划，请以当前环境的可用菜单为准。

结果完成后，先检查以下四点：

1. 是否回答了原问题，而不是只复述资料。
2. 时间范围、筛选条件和数据来源是否与你的要求一致。
3. 关键数字、结论和建议之间是否能对应。
4. 要分享给同事时，报告、附件和原始数据的访问范围是否分别合适。

可从左侧的 **我的报告** 找到已保存的报告。其他成员能否继续查看附件或重新取数，仍取决于各自的资源与数据权限。

「我的报告」每次显示 50 份。工具栏右侧写着符合当前搜索和筛选的总数（搜索时写「找到 N 份」）；列表底部写「显示 N / 共 M 份」，点 **加载更多** 接着显示下一批，已显示的报告和下方的「分享给我的」都不受影响。全部显示后底部会写「已显示全部 N 份」。修改搜索词、空间、排序或「显示未生成内容」时，列表从第一批重新开始。加载失败时点 **重试**，已显示的报告会保留。

## 查看后续任务

会话中有排队等待执行的后续任务时，页面会显示任务列表。尚未打开会话或没有后续任务时，不显示此列表。若提示暂时无法读取，请选择“重试”。

## 重发邮箱验证邮件

个人设置现在是可直接打开的页面。可从账号菜单进入 **设置**，或使用对应地址：账号 `/settings/profile/`、安全 `/settings/security/`、外观 `/settings/appearance/`、记忆 `/settings/memory/` 和导出 `/settings/export/`。你可以保存这些地址或从其他页面直接打开。

收到待确认或即将过期的记忆建议通知时，点击通知可打开**设置 → 个人 → 记忆**。请在那里查看并处理待确认的建议。

在 **设置 → 个人 → 账号** 中，已验证的邮箱直接显示“已验证”，无需重发验证邮件，也不会显示重发按钮。

在 **设置 → 个人 → 账号** 中，尚未验证的邮箱可选择“重发验证邮件”。发送中请等待，看到已提交发送的提示后检查收件箱和垃圾邮件。重复发送需间隔一分钟；若显示失败或一直未收到，请联系团队管理员检查邮件服务。

如果当前环境支持在计划模式中使用方法，可选择团队 Agent 和可用的只读方法，描述任务后先查看计划，再确认执行。确认前可以编辑步骤；计划有变化时需要重新确认。主步骤保留所选 Agent 和方法，辅助步骤使用自己的资源。不能跳过必需的主步骤或把它换给其他 Agent；需要更换时请新建请求。首批路径不接受附件或其他类型的资源引用。等待期间若权限改变或任务材料被清除，计划不能使用替代材料继续。

回答语言设为自动或跟随输入时，确认计划后仍依据原任务的语言回答；你明确设置的回答语言或团队要求仍然优先。只需回答的计划会在对话中交付结果，要求报告的计划会生成报告。

## 查找设置和能力

从账户菜单的「设置」进入个人偏好与自己获准管理的团队、空间设置。原页面地址都可继续使用。

能力中心概览是一页，按资源分区：插件、技能、工具、连接与定时任务、智能体。每个分区直接显示真实内容和状态，「查看全部」打开完整列表；团队负责人和管理员还能在分区里进入对应的管理页面。打开右上方的「只看我的」，只留下你停用过的插件和你自己的技能、连接与定时任务。需要创建智能体时，从「智能体 → 创建智能体」进入；具有创建资格的普通成员也可以使用。在目录中看到资源不代表获得运行或配置权限。

获准的管理员从账户菜单进入「管理控制台」，通过其侧栏切换运行追踪／执行审批、资源治理与当前可用的管理页。发布审核与个人连接确认仍在各自原页面处理。使用「返回工作」回到任务。

从主侧栏资料库后的「智能体」直接浏览市场或进入「管理我的智能体」；全部智能体管理 Tab、详情和编辑均保持一级智能体入口选中。能力中心目录为概览、技能与流程、我的连接、定时任务；工具和团队插件的目录与配置均归属概览。技能分类和“我的”筛选保留在技能页面内部。工具、团队插件、技能与流程、智能体页会按权限提供对应管理按钮，并提供返回资源页的链接。
