# Google Workspace

连接 Google Workspace 后，智能体可以在你本人的 Google 权限下读取你给出的 Google 文档、表格和演示文稿，查看你的日历，并在你明确要求时直接把结果写回 Google（不再另行确认）。每位成员只会用到自己的授权，别人（包括团队管理员）无法读取或使用你的 Google 数据。

## 管理员：配置团队连接

只有团队负责人和团队管理员可以配置。Google 连接使用你们公司自己的 Google Cloud 应用，Bowra 不提供公共应用。

1. 在 Google Cloud 控制台创建一个 OAuth 客户端，应用类型选“Web 应用”，用户类型选“Internal”（仅限本组织）。
2. 打开“团队设置 → 工具 → 内置第三方工具”，选择 Google Workspace。把页面上显示的“已获授权的重定向 URI”填到 OAuth 客户端的 Authorized redirect URIs，把“已获授权的 JavaScript 来源”填到 Authorized JavaScript origins。使用 Google 接受的稳定 HTTPS 地址。优先使用团队已验证的公开入口；没有时页面使用当前访问地址。把页面显示的完整回调 URI 原样登记到 Google。
3. 在 OAuth 同意屏幕中声明页面列出的权限范围。
4. 回到 Bowra，填写 Client ID、Client Secret 和贵公司的 Google Workspace 域名，按需开启能力：
   - 基础（必选）：读写成员在 Bowra 中选中的文件，新建文档、演示和表格；
   - 按链接读取：读取成员给出链接的任意文档、表格和演示；
   - 修改已有文档与演示、写入已有表格：修改成员有编辑权的已有文件；
   - 日历：查看成员本人的日历事件（默认关闭）。
5. 如需在对话和知识库中使用“从 Google Drive 选择”，在 Google Cloud 创建一个浏览器 API Key，网站限制里同时加入团队访问地址和 `https://docs.google.com/*`，再把 API Key 和项目编号填入 Bowra。
6. 点“用我的 Google 账号授权”，用你自己的公司账号完成一次授权，确认配置正确后再启用连接。

卡片上会显示已授权的成员人数。更换 Client ID 或 Client Secret 会撤销所有成员的 Google 授权，大家需要重新连接。Bowra 不会申请读取邮件或浏览整个云端硬盘的权限。

如果贵公司在自己的反向代理或安全网关上设置了内容安全策略，请放行 `accounts.google.com`、`apis.google.com` 和 `docs.google.com`，否则“从 Google Drive 选择”无法打开。

## 成员：连接你的 Google 账号

团队启用 Google 连接后，在“我的连接”中点“连接 Google”，用 Bowra 登录邮箱对应的公司 Google 账号授权即可。如果 Google 账号邮箱与 Bowra 邮箱不一致，或不属于公司域名，授权会被拒绝。

需要时你可以在“我的连接”中断开连接。授权过期，或团队管理员开启了新能力时，卡片会提示你重新连接或更新授权。

## 在对话中使用

- 读取文件：把 Google 文档、表格或演示文稿的链接贴进对话，或用输入框左下角的“+”菜单（窄屏时在“更多工具”里）选“从 Google Drive 选择”，选中的文件会以“文件名 链接”插入到光标处。智能体会以你的权限读取；内容很长时会分段读取。Google 文档链接指定标签页时只读取该页；未指定时读取全部标签页，包括嵌套标签页。
- 查看日历：直接问，例如“我下周有哪些会”。需要团队开启日历能力。
- 写回 Google：明确要求即可，例如“把这份分析写成一份 Google 文档”“把结果追加到这个表格”。智能体会直接写入；拿不准写到哪个文件、替换哪一节，或者表格目标区域已有数据时，会先问你。写入只在网页对话中进行。写入成功后，右侧画布会出现这个文件的卡片，卡片上写着写入时间：默认显示写入时的内容快照，用卡片里的「快照 / 实时预览」切换查看 Google 中的最新版式（需要浏览器已登录对应的 Google 账号，部分浏览器无法显示；预览下方始终有一行提示：如果没有显示，可能是 Google 不允许嵌入或需要登录，可以切回快照或在 Google 中打开），也可以点「在 Google 中打开」在新标签页打开文件。

写入前系统会核对内容里的数字是否来自本轮取到的数据，核对不上时不会写入。如果写入请求已发出但结果未知，回答末尾会提示你到 Google 中核实，系统不会自动重试。写错时可以在 Google 文档或演示的版本历史中恢复。

Google 文档有多个标签页时，请提供要修改的标签页链接。链接未指定标签页时，智能体会先请你选择，再执行写入；查找替换只影响选中的标签页。表格中的公式即使显示为空，也算已有数据；同意覆盖后，写入内容中的空值会清空对应单元格。

## 导入知识库

在知识库打开上传窗口，点拖放区下方的“或 从 Google Drive 导入”，选中文件后导入。一次最多导入 20 个文件，多选的部分需要再导入一次。Google 文档、表格和演示会转换为对应的 Office 文件；超过 10 MB 的文件无法从 Google 导出，请先在 Google 中拆分或另存。导入后的文件与原文件不再同步，原文件更新后请重新导入。

## 常见问题

- 看不到“连接 Google”：团队尚未启用 Google 连接，请联系团队管理员。
- 提示无法打开某个文件：可能你没有该文件的访问权限，或团队没有开启“按链接读取”。可以改用“从 Google Drive 选择”选中该文件。
- “从 Google Drive 选择”打不开：请通过团队登记的访问地址打开 Bowra，或请管理员检查 API Key 的网站限制。

JavaScript 来源使用页面显示的浏览器 origin，包含实际非标准端口。通过多个地址访问时，把每个浏览器来源加入 Google 应用和 API Key 限制。团队入口元数据不阻止打开配置页或发起授权；Google 仍要求回调地址与其登记值精确一致。
