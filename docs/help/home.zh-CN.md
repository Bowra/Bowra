这里帮助你把一件工作做完，也说明团队如何安全地协作。先选择你现在的目标；不需要先读完所有文章。

## 这部说明书怎样组织

说明书只保留三层：帮助首页、主题栏目和可完成的任务文章。文章中的小节用于解释选择、步骤、确认结果和排障，不再在侧栏继续叠层。

- **开始使用**：第一次在 Bowra 中发起工作、提供上下文并查看结果。
- **界面与操作**：菜单、列表操作、手机上的弹窗与撤销、会话链接和语言设置。
- **团队与访问**：团队、空间和成员怎样决定协作范围。
- **Agent 与 Skill**：怎样发布、聘用、配置和维护可复用的工作方法。
- **安全与数据**：数据在何时按谁的身份访问，AI 代码如何在离线沙盒中执行。
- **参考**：当你需要快速核对角色、操作范围或排查权限时使用。

## 先记住三个边界

1. **团队和空间**决定你在哪里协作；它们不自动授予外部业务数据权限。
2. **Agent、能力、结果契约、Skill 和工具**分别说明由谁执行、选哪组资源、承诺什么结果以及怎样完成；能使用 Agent 不等于能编辑或发布它。
3. **数据身份**决定查询能看到什么；分享 Agent、报告或空间不会把作者的数据权限转给别人。

当页面提示没有访问资格，先确认当前账号、团队和空间，再记录提示文字和资源名称，按[排查访问问题](permissions/troubleshoot-access.zh-CN.md)寻找对应处理人。

提示额度已用完时，按[查看和补充额度](credits.zh-CN.md)确认影响并联系负责人或管理员补充。
