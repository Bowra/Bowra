# 使用知识库

把资料放进知识库后，助手回答对话问题时可以检索相关资料作为依据。你也可以明确要求它查询某份文档或某个主题。只想存放、不需要在对话中被检索的文件，放在**资料库 → 文件**即可；那里的文件也可以随时选择「加入知识库」。

根据知识资料回答时，助手可以利用有权限的来源名称、已有章节标题和简短开头摘录定位相关内容，并按任务需要检索依据。来源预览不代表已经审阅整份文档。

重新打开对话时，文档引用会按你当前的权限重新检查。已撤权或移出收录的来源不再显示可访问的引用和文件名。

## 来源导航说明与分类

打开已就绪文件的详情，可查看来源说明和分类。它们帮助助手判断该检索哪些资料，不代表已经通读全文。具有原文件维护权限的用户可以填写人工说明、选择最多八个分类，并在文件原有范围内维护分类及别名。分类最多两层；初始列表未显示所需分类时，可搜索分类。

人工说明优先。清空并保存后，会恢复仍有效的自动说明。来源变化后，请核对当前版本并重新填写已过期的人工说明，旧内容不会自动重新发布。生成状态刷新会保留未保存的草稿。

自动说明是可选项，默认关闭。团队负责人或管理员可在 **团队设置 → 模型 → 分配** 中选择 **来源说明** 模型。此后，新发布为可搜索状态的来源可以从有界原文片段生成简短说明；保存设置不会补跑历史文件。文件维护者也可对当前已发布文件主动点击 **生成说明**，调用所选模型并消耗额度。生成失败不会影响文件搜索。主动重试前请刷新核对，尤其是在上次模型请求结果未知时。

在文档矩阵中编辑列，将 **来源导航用途** 设为 **说明** 或 **主题**，可以复用符合条件的已有结果。此设置不会运行抽取。复用仍受原 Matrix 权限及来源版本限制，已编辑或过期单元格不适用，也不会把 Matrix 文本发布为文件的公共人工说明。

助手只获得当前用户、Space 和 Agent 可用来源内的小目录。覆盖范围不清楚时，可以查询分页来源目录；任务需要资料依据时，再读取原始内容。没有匹配结果不代表资料或主题不存在，无关任务无需固定检索知识库。

## 页面布局

知识库页分成四类内容，点一项即可切换。这四项以标签排在内容上方；窗口较窄时，它们排成一行可以左右滑动的按钮。

- **文件**：放进知识库的全部文件，在这里上传、查找、查看详情和管理。
- **文档矩阵**：把多份文件放进一张表，每一列是一个问题，逐格给出答案和出处。
- **提取结果**：按提取表从文件中提取出的结果，每张提取表一份。
- **模板**：内置模板、你存下的模板、团队模板库里的模板，以及提取表，都在这里新建和管理。

页头的**添加知识**在任何一项里都能用，点击后会回到「文件」并打开上传窗口。

开启按知识库整理后，四个标签改为「知识库 / 文档矩阵 / 提取表 / 模板」，见下一节。

## 按知识库整理和分享资料

这项功能由管理员逐步开放。开启后，知识库页的第一个标签是**知识库**；没有这个标签时，页面仍按本文其他各节的说明使用。

开启后，资料按有名字的知识库整理。每个知识库有名称、说明、所在位置、谁能使用和成员名单；除空间和团队的默认知识库外，还有一位所有者。一份文件只属于一个知识库；要换地方，把它移到其他知识库。

### 知识库放在哪里

- **我的**：只有你能使用，在你所有的空间里都能用。每人都有一个**我的知识**，也可以再新建几个，整理自己的资料。「我的」知识库不能分享；要和别人共用，把文件移到空间或团队的知识库。
- **当前空间**：只在这个空间的对话、智能体和文档矩阵里使用。每个空间都有一个以空间名称命名的知识库。
- **团队**：团队里的所有空间都能使用。每个团队都有一个**团队知识库**。

我的知识、以空间命名的知识库和团队知识库是系统建好的默认知识库，标着「默认」。它们不能改名、改说明、删除或转让，谁能使用也是固定的：空间的默认知识库是空间成员可编辑（只读成员只能使用），团队知识库是团队所有人可使用。可管理的人仍可以在成员名单里给个别人更高的权限，例如让某位成员向团队知识库添加文件。

文档矩阵和以前一样，只接受空间和团队知识库里的文件，不接受「我的」知识库里的文件；管理员开启仅自己可见的矩阵后，你自己仅自己可见的矩阵可以放入「我的」知识库里的文件，见「仅自己可见的矩阵」。

### 谁能使用、三种权限

你能使用一个知识库，可能是因为它的「谁能使用」包括你，也可能是因为你在它的成员名单里，或者你是它的自动管理者。几项同时适用时，按最高的权限算。

- **谁能使用**：「我的」知识库只有你自己。空间知识库可以是**仅成员**（只有名单里的人），或**空间所有成员**，后者还要选空间成员默认可使用还是可编辑。团队知识库可以是**仅成员**，或**团队所有人**（只能使用）。
- **成员名单**：可以添加个人和组；团队知识库还可以添加空间，表示这个空间的成员。空间知识库只能添加这个空间的成员；要跨空间共用资料，请在团队里新建知识库。成员离开空间后，他在这个空间知识库名单上的条目暂不生效，重新加入后恢复。
- **自动管理者**：空间管理员可以管理本空间的所有知识库；团队负责人和管理员可以管理所有团队知识库，他们加入某个空间后，也可以管理这个空间的默认知识库。自动管理者不能从名单中移除。团队负责人和管理员不会因为团队身份看到空间里「仅成员」的知识库。

三种权限：

- **可使用**：在对话、智能体和文档矩阵中检索和引用；查看、预览和下载文件；核对来源。
- **可编辑**：还可以添加文件，移出或删除自己添加的文件，维护这些文件的说明和分类，重试解析。
- **可管理**：还可以管理所有文件、成员名单、谁能使用，以及名称和说明。

所有者是对知识库负责的那一位管理者，不能从名单中移除；空间和团队的默认知识库没有所有者，由自动管理者管理。只有所有者和自动管理者可以转让所有权和删除知识库。空间只读成员在空间知识库里最多只能使用：可以检索、查看和下载，不能添加或删除文件。

### 找到知识库和文件

**知识库**标签按「我的」「当前空间」「团队」分组，列出你能使用的知识库。每行写明名称、说明、谁能使用、你的权限、文件数（有失败的文件时会标出）和更新时间。团队索引提示仍显示在列表上方，规则不变。

- 在搜索框输入文字，按知识库名称或文件名查找。不同的知识库可以同名，请结合分组和说明区分。
- 打开**内容深搜**并按 Enter，会在你能使用的所有知识库里按内容查找。结果是一张文件表，多一列**知识库**，写明每份文件所在的知识库。
- 行末的 **⋯** 按你的权限提供**分享**（不能管理时是**谁能访问**）、**设置**和**删除知识库**。

页头有**新建知识库**和**添加文件**（未开启时叫**添加知识**）。提取表和它们的提取结果都在**提取表**标签里；**模板**只放文档矩阵的模板。

### 新建知识库

1. 在知识库页点**新建知识库**。
2. 填写名称。说明可以不填，但写清这些资料是关于什么的，助手会参考它判断什么时候检索。
3. 选择放在哪里：我的、当前空间或团队。你不能选的位置也会列出，并写明原因。所有人都能在「我的」里新建；空间管理员和空间成员可以在空间里新建，只读成员不行；只有团队负责人和管理员可以在团队里新建。
4. 选择谁能使用。选项随所在位置变化；选「空间所有成员」时，默认是可使用。点**创建**。

创建后会打开这个空的知识库，可以直接添加文件，或从「文件」中选择。

### 一个知识库的页面

点知识库名称打开它的页面。页头写明所在位置、名称、说明、谁能使用、你的权限和更新时间；能编辑时有**添加文件**；能管理时有**分享**，其他人看到的是**谁能访问**。

页面有自己的地址，可以收藏或发给同事。打开地址不会授予访问权限：没有权限的人看到「找不到这个知识库」，和知识库不存在时完全一样。

页面分三个标签：

- **文件**：这个知识库里的文件。用法和下文「查找文件」「文件详情」相同：按文件名搜索、内容深搜、按状态、类型和日期筛选、排序、翻页，选中多份文件后批量操作。这里没有「范围」筛选和「范围」列，多了**添加人**一列。
- **成员**：「谁能使用」一组写明谁能使用、空间成员的默认权限和在哪里能用；下面的名单列出每位成员的权限和来源（所有者、自动、直接添加、组或空间）。底部解释三种权限。
- **设置**：名称、说明、所有者（**转让所有权…**）和**删除知识库…**。

知识库还没有文件时，能编辑的人会看到添加文件和从「文件」中选择的入口，其他人会看到可以联系谁。只能使用时，页面不显示**添加文件**和**分享**，并写明需要添加或修改资料时该联系谁。

### 分享和管理成员

能管理的人点**分享**：

1. 在「谁能使用」里选择范围。
2. 在「添加成员或空间」里按名字搜索个人、组或空间（只有团队知识库可以添加空间），选好权限后点**添加**。
3. 在名单里修改某人的权限，或把他移除。移除后会出现带**撤销**的提示，至少停留 8 秒。

改动立即生效，下一次检索就按新的设置进行。对话框底部写明一共多少人可以使用，其中多少人可以编辑、多少人可以管理。**复制链接**只复制知识库的地址，不会给任何人权限。

其他人点**谁能访问**，看到同样的内容，但不能修改。「我的」知识库不能分享。

### 改名、转让和删除

- **改名、改说明**：能管理的人在**设置**里修改后保存。
- **转让所有权**：所有者或自动管理者可以把所有权转给另一位已经能管理这个知识库的人。原所有者仍符合条件时，保留管理权限。默认知识库和「我的」知识库不能转让。
- **删除知识库**：所有者或自动管理者点**删除知识库…**，确认框会写明有多少个文件。删除后，这些文件离开知识库，不再被检索，原文件仍保留在「文件」中。默认知识库不能删除。有文件无法移出时，知识库会保留，提示会说明原因。

### 添加文件

在知识库页面点**添加文件**时，上传窗口的「添加到」默认是你所在的知识库；在知识库列表点**添加文件**时，默认是当前空间的默认知识库。可选的知识库按「我的」「当前空间」「团队」分组；不能添加文件的知识库也会列出，但不能选，并写明原因。嵌入模型检查、支持的格式和大小、ZIP、Google Drive、取消和错误说明都和下文「上传文件」相同。

### 把文件移到其他知识库

1. 在文件详情点**移到其他知识库…**，或在**文件**标签选中文件后选择**移到其他知识库…**。
2. 选择目标知识库。列表按「我的」「空间」「团队」分组，写明各自谁能使用；只能选你可以编辑的知识库。
3. 选好后，窗口会写明移动后有多少人会获得访问、多少人会失去访问。确认后点**移动**。

自己添加的文件，需要你在原知识库可编辑；别人添加的文件，需要可管理。移动后，原文件、版本、引用、文档矩阵和提取结果都会保留，谁能访问改按新知识库计算。失去访问的人不再能看到这份文件的名称和内容，引用对他们显示为来源受限。

### 从「文件」或对话中加入

在**资料库 → 文件**点**加入知识库**时，改为选择一个知识库（规则同上面的「添加到」），而不是选择范围。点**在知识库中查看**会打开文件所在的知识库，并选中这份文件。

在对话中请助手把文件加入知识库时，请说明加入哪个知识库。没有说明，或你不能编辑那个知识库时，助手会先问你，再加入。

### 文件详情和引用

文件详情里的可见范围换成**所属知识库**（点击打开这个知识库）和**谁能访问**（一句话说明，点**查看成员**打开它的「成员」标签）；**更改可见范围**换成**移到其他知识库…**。其他内容不变。

对话会检索你在当前空间能使用的所有知识库：你的「我的」知识库、当前空间的知识库和团队知识库，不需要在对话里选择知识库。引用卡片和报告出处的规则不变，没有权限的人只看到来源受限；**在知识库中打开**会打开文件所在的知识库，并选中这份文件。全局搜索的「知识」一组同样只列出你能使用的知识库里的文件。

### 提示和手机

- 开启后第一次打开知识库页时，会提示一次：资料已按原来的范围整理好，个人文件在「我的知识」，空间文件在以空间命名的知识库，团队文件在「团队知识库」，谁能看到什么没有变化。
- 空间只读成员还会看到一条提示：现在只能使用空间知识库，不能添加或删除其中的文件；需要时请联系空间管理员。
- 在手机上，知识库列表和文件表改为逐行列表，页头按钮会换行，标签可以左右滑动；分享和需要填写多项的窗口从底部弹出。

如果管理员之后又关闭了这项功能，空间和团队里新建的知识库中的文件会暂时无法检索和打开，直到重新开启；默认知识库和「我的」知识库里的文件照常可用。

## 选择谁能看到

开启按知识库整理后，上传时改为选择「添加到」哪个知识库，谁能看到由那个知识库决定，见上一节。

上传时先选可见范围：

- **个人**：只有你自己能看到和检索。
- **空间**：当前空间的成员都能检索。切换空间后，看到的是那个空间的资料。
- **团队**：全团队都能检索。只有团队管理员可以上传到团队范围。

只有空间管理员身份不会获得团队范围的上传权限；需要团队资料时，请联系团队管理员加入。

空间的只读成员可以查看和检索空间资料，但不能向空间知识库添加文件，也不能修改或删除其中的文件（包括自己以前加入的）；自己的个人资料不受影响。需要添加时，请联系空间管理员调整角色。

## 上传文件

1. 进入**资料库 → 知识库**，点右上角**添加知识**。
2. 上传窗口会检查团队是否已启用嵌入模型。如果提示尚未配置，团队管理员可以点**配置嵌入模型**；其他成员请联系团队管理员。配置完成后回到窗口点**重新检查**，检查通过才能上传。
3. 选择可见范围，一次拖入或选择一个文件。要导入多个文件，请逐个上传或先打包为 ZIP。支持 PDF、Word、PPT、Excel、CSV、Markdown、TXT、图片和 ZIP，单个文件最大 200 MB。ZIP 中不支持的文件会跳过，导入结果会列出原因；文件夹不会作为文件入库。
4. 上传完成后会有提示，文件出现在列表中并开始处理。处理完成、状态变为「可用」后，就能在对话中被检索。

选择空文件或超过 200 MB 的文件时，上传窗口会说明原因并提示如何处理；重新选择文件即可继续。

Excel 和 CSV 每个文件最多检索前 5000 行（多个工作表合计）。超出的行不会进入知识库，对话中引用这类表格时会注明只用到了前 5000 行；需要完整数据时，请把表格拆成多个文件再上传。

## 从「文件」加入知识库

**资料库 → 文件**的「知识库」一列显示每个文件在知识库中的情况：

- **已加入 · 状态**：文件已在知识库中，状态含义见下方「文件状态」。点**在知识库中查看**、**查看处理进度**或**去知识库重试**，会打开知识库中的这份文件。
- **建议加入知识库**或**未加入**：点**加入知识库**，选择谁能检索到它（个人、当前空间或团队）后确认。加入后，提示中的**查看处理进度**可以直接跳到这份文件。

加入知识库不会移动或复制文件，它仍保留在「文件」中。

开启按知识库整理后，**加入知识库**改为选择一个知识库，**在知识库中查看**打开文件所在的知识库，见上文「从「文件」或对话中加入」。

**加入知识库**窗口也会在确认前检查团队嵌入模型。未配置时按上面的指引处理；此前文件仍保存在「文件」中。

上传到「文件」或在聊天中附加文件只会保存原文件；被分类为长期资料也不会自动入库。请选择**加入知识库**、从知识库页面上传，或明确要求 Agent 将指定文件加入知识库并说明可见范围。Agent 会检查原始请求和当前权限，目标或范围不明确时需要澄清。处理完成后才可检索。聊天 ZIP 仅保留为一个原文件，不会解包或索引；如需导入其中的文档，请使用知识库页面。**移出知识库**会保留原文件；旧的加入请求不会在移除后再次入库，新明确请求可以重新加入。

「文件」中的文件有新版本后，知识库仍保留当时加入的那一版，并会提示有新版。需要更新时，在**文件**中选择**添加第 N 版**，加入所需范围。确认新版就绪后，如果不再希望搜索到旧版，可以删除旧条目。

## 文件状态

团队更换嵌入模型后，如果知识库索引正在更新或最近一次更新失败，「文件」视图会显示团队索引提示。这是团队范围的索引更新，与单个文件的处理状态不同。更新失败时，团队负责人或管理员可选择「查看并重试」，检查目标并确认后重新开始；其他成员可联系团队管理员。没有待处理的索引更新时，不显示此提示。

| 状态   | 含义                                                                                           |
| ------ | ---------------------------------------------------------------------------------------------- |
| 上传中 | 文件还在传输                                                                                   |
| 排队中 | 等待处理，文件多时需要稍等                                                                     |
| 处理中 | 正在读取和整理内容，大文件或扫描件会久一些                                                     |
| 可用   | 已处理完成，可以在对话中被检索                                                                 |
| 失败   | 没能处理完成。鼠标停在状态上可以看到原因；有权限时点状态旁的重试按钮，或点开文件查看原因并重试 |

「可用」表示基础内容已经可以检索；如果还要提取表格字段，提取结果可能稍后出现。「可用」不保证原文件预览此刻一定能打开。页面显示来源状态时，列表会优先显示「已暂停用于新任务」「原件暂时不可核对」或「来源待检查」，鼠标停在状态上可以看到最近一次检查的时间。

失败时，按提示处理：

- **文件格式不受支持**：转换成上面列出的格式后重新上传。
- **文件中没有可检索的文字内容**：检查文件是否为空，或是否只有图片而没有文字。
- **处理被中断** 或 **处理超时**：点**重试**。文件特别大时，可以拆分后再上传。
- **处理服务暂不可用**：稍后再试；如果一直失败，请联系团队管理员。
- **处理时未找到原文件**：先联系上传者或管理员恢复原件。有文件管理权限时，恢复后可点状态旁的重试按钮、在文件行的更多菜单点**重试解析**，或在详情里点**重试**。系统会先检查原件能否找到；仍然缺失时不会开始处理，并提示你恢复原件或重新上传。重试成功后，先前针对这份文件的失败提示会收起。

## 查找文件

开启按知识库整理后，下面这些操作在每个知识库页面的**文件**标签里进行，那里没有「范围」筛选；要跨知识库查找，用知识库列表的搜索和内容深搜。

- 用列表上方的范围切换「个人」「空间」「团队」。范围是工具行里的**范围**筛选（在手机上收在**筛选**里）；空间会写出当前空间的名字，并说明这个范围谁能检索。
- 使用**范围**筛选时，如果有**全部**选项，可以一次列出你能检索的个人、当前空间和团队文件，表格里的**范围**一列标出每份文件属于哪里。页面会记住你上次选的范围；第一次打开时显示当前空间。
- 在搜索框输入文字，按文件名查找。
- 打开**内容深搜**并按 Enter 后，会按文件内容在当前范围内查找。搜索框旁会写出在哪个范围找到了几个文件；每个结果显示命中的片段，片段前标出所在位置（第几页、哪个章节或第几段）。手机上的列表放不下片段，每个结果改为写出命中位置，例如「第 3 页 · 搜索命中」。
- 深搜没有结果时，可以换个说法，点按钮换到其他范围继续搜，或点**按文件名搜**关闭内容深搜。
- 可以按状态、类型和上传日期筛选，页面提供排序选项时也可以调整排序。筛选按钮上会写出已选的值；要一次取消某一组，打开它的菜单点**清除状态**或**清除类型**。
- 选了两个及以上条件（关键词、每个状态、每个类型、日期各算一个）时，工具行下方会列出已选条件，可以逐个点 × 去掉，或点**清除全部**。范围不在这一行里。
- 在手机上，点**筛选**会从底部打开面板，里面分范围、状态、类型、日期几组，选中即生效；点**显示 N 个文件**回到列表。排序和**内容深搜**留在工具行上。
- 上传成功后，列表会自动切到所选的上传范围（正在看**全部**时保持在**全部**），清除搜索与筛选，并按最新上传时间显示第一页，不用手动切换范围寻找新文件。ZIP 里的文件仍在解析时，可点**返回文件列表**继续查看处理状态；全部处理结束后点**完成**，列表也会这样刷新。

如果页面地址会随搜索和筛选变化，它会记住搜索、筛选、排序、页码和正在打开的文件：浏览器后退可以回到上一组结果，刷新后仍停在原处。把地址发给同事只能让有权限的人看到这些文件，不会授予访问权限。

页面按上面的方式记住地址时，列表也支持完整的键盘操作：用 Tab 移到筛选按钮后按 Enter 打开，方向键选择选项，Space 勾选，Esc 关闭菜单。列表里的勾选与打开是两个独立动作：在行上按 Space 选择文件，在文件名上按 Enter 打开详情。

## 文件详情

开启按知识库整理后，详情里的变化见上文「文件详情和引用」。

点列表中的文件打开详情，可以看到状态、可见范围、上传者、上传时间和大小。

- 要把共享文档加进正在写的对话，点 **+ → 从资料库选择**，然后打开「团队资料」或「当前空间」。选中的版本会以附件副本加入草稿。你也可以请助手直接检索知识库。对于你自己在当前空间上传的文件，仍可在详情中点**在对话中使用**开启新对话。
- 文件在对话中被引用过时，标题下会显示被引用的次数。
- 从内容深搜结果点进来时，命中的片段排在最前面并高亮显示。
- 在文档矩阵里点单元格的「查看原文」，会在当前页打开这份文件的详情，出处那一段排在最前；关掉后仍回到矩阵。
- 处理中的文件会显示进度，可以关掉详情，处理会继续。处理失败时，详情里写明原因，并可以直接**重试**。
- 有权限时，还可以在详情里更改可见范围、提取到表或删除文件。更改别人加入的文件的可见范围时，需要写明至少 10 个字的原因。
- 预览打不开时，详情会显示原因；有**重试预览**时可以直接重试，不用关闭详情。文件内容能读取、只是暂时无法显示时，可以改为下载原文件。没有权限或文件已不可访问时，请先确认访问权限或联系文件管理者。

## 核对文件来源与恢复原件

文件详情提供**来源核对**时，点**检查来源**，可以查看当前原件和索引的情况。检查不会自动反复运行；需要最新结果时点**重新检查**。结果分三项显示：

- **原件**：能找到原件时，仍不表示已经验证它与索引内容完全一致；显示未找到原件时，本次存储检查正常但没有这份原件，请联系上传者或管理员核对；显示暂时无法核对时，可能是存储服务、网络或访问问题，不能据此认定文件已经丢失。
- **索引**：记录的片段数量与当前一致且抽样片段可读，不保证全文完整或每条引用都能核对。
- **来源对应关系**：显示尚未验证时，表示当前还不能证明索引来自这份原件。每条引用仍需结合原文单独核对。

检查不会自动重新解析文件；文件变化后需要重新检查。页面还可能写明这份文件是否可用于新任务：原件暂时无法核对时，使用此前验证过的索引，结果会附带提醒；已暂停用于新任务时，请先按详情里的说明处理，不必反复重试矩阵。

有管理权限且页面提供恢复操作时：

- **恢复原件**：选择与原件内容完全相同的文件；恢复后会重新检查，不会重新解析，也不产生模型费用。
- 内容不同时，按提示作为新文件上传，旧文件和历史出处都会保留。
- **重新解析并核对**：重新处理原件并生成可供检索的内容，可能产生模型费用；操作前请阅读页面说明。

任务运行中来源发生变化时，相关的新结果可能暂停。已有的人工修改和已核对标记会保留；原件短暂不可访问但仍能使用此前核对过的内容时，结果会附上提醒。提醒不是原文已核对的证明。

## 批量重新解析

页面提供**批量重新解析…**时，在文件列表的当前页勾选你有管理权限的文件，再选择它。先核对文件数、大小和模型用量说明，再确认开始。每批最多 20 份、合计 100 MB，逐份处理；这次只重新建立可搜索的内容，不重新抽取表格。

进度集中显示在页面上，不会为每份文件单独弹出提示；刷新后可以继续查看当前账号在当前团队和空间里的任务。任务中断时，先恢复访问或处理来源问题，再点**检查权限并继续**，系统不会自动反复重试。选择**停止后续文件**后，已经开始的文件可能继续完成，已经发出的模型请求可能产生费用。

历史矩阵值和引用不会因为来源异常自动重算。失去文件访问权限后，对应的文件名、原文和矩阵值会隐藏，恢复权限后可以重新查看。

## 用文档矩阵对多份文件逐一提问

1. 点**文档矩阵**，再点**新建矩阵**，选择要放进矩阵的文件；也可以在「文件」里选中多份文件，点**打开为矩阵**。
2. 加一列问题（例如「合同金额是多少？」），选好答案类型后运行。每一行是一份文件，每一格是这份文件对这个问题的回答。
3. 点单元格查看答案和出处，可以修改答案或标记为已核对；点「查看原文」会在当前页打开文件详情，出处那一段排在最前。出处后面写明原文位置：PDF 和演示文稿写第几页，Word、Excel、Markdown 等没有固定页码的文件写第几段；引用的原文在文件里找不到时不写位置。较早运行的格子可能仍显示 AI 估计的页码，重跑后会按原文重新标注。
4. 运行按文档长度消耗额度，开始前会提示预计消耗。

一个矩阵默认最多 20 列、500 份文件；超过上限时，提示会写明实际上限和当前数量。列名不能为空，也不能和同一矩阵里的其他列重名；只差前后空格或全角、半角写法的名字也算重名。

「文档矩阵」列表里每个矩阵占一行，写明行来源、文件数 × 列数、上次运行时间和创建者；点矩阵名称即可打开。

### 创建后修改矩阵

以下操作在电脑上进行；手机上只能查看矩阵。

- **添加文件**：点表格下方的**添加文件**，按文件名搜索，文件按「当前空间」「团队」分组。已在矩阵里的文件、个人文件和还在处理中的文件会列出来，并写明不能加入的原因；个人文件只能放进仅自己可见的矩阵（由管理员开启，见下文「仅自己可见的矩阵」），在你自己仅自己可见的矩阵里可以直接勾选。一次最多添加 100 份。新加的文件排在表格末尾，格子显示「未运行」；点**运行**时只处理还没运行或失败的格子，已有结果不会重跑。
- **移出文件**：鼠标移到文件那一行，点 **⋯** → **移出矩阵…**；也可以勾选多行后点**移出矩阵**，一次最多 100 份。确认框会写明会删除多少个格子，其中多少个人工改过、多少个已核对。文件本身仍在知识库里，之后可以重新添加；正在进行的运行会跳过移出的文件。
- **改名**：点顶部的矩阵名称，或点 **⋯** → **改名**，输入新名称后按 Enter 保存，按 Esc 保留原来的名称。名称不能为空。
- **删除矩阵**：点 **⋯** → **删除矩阵…**。确认框会写明会删除多少个格子的结果；正在进行的运行会停止，已经用掉的额度不会退回。文件本身不受影响。

空间成员可以添加文件、改名，也可以移出没有人工修改和核对的文件。要移出含人工改过或已核对格子的文件，或删除矩阵，需要矩阵创建者、空间管理员或团队管理员；也可以先在格子里撤销这些修改和核对，再移出。

### 仅自己可见的矩阵

这项功能由管理员逐步开放。开启后，新建矩阵时在点**创建**的那一步选择**谁能看到**：

- **空间成员**（默认）：和以前一样，当前空间的成员都能在列表和首页看到并打开这个矩阵，每行仍按各人对文件的权限显示。
- **仅自己**：只有你能看到和使用这个矩阵，空间管理员和团队管理员也看不到。选文件时会多出你的个人文件；列表和矩阵页顶部显示**仅自己可见**。

已有矩阵由创建者在电脑上点 **⋯** → **设为仅自己可见** 或 **设为空间成员可见**，确认后生效。

- 设为仅自己可见时，确认框会写明有哪些成员在这里修改、核对过格子或运行过矩阵：他们的修改和核对会保留，但他们将无法再打开这个矩阵。其他成员的运行还没结束时不能更改，请等运行结束后再试；某一列设置了来源导航用途时，请先把它改为「无」。
- 设为空间成员可见时，矩阵里不能有个人文件。提示会列出这些文件，请先把它们移出矩阵再试。
- 仅自己可见的矩阵不能设置来源导航用途；存为模板时也不能包含个人文件，提示会列出要先移出的文件。它的运行同样计入空间同时运行的上限。
- 注销账号时，你仅自己可见的矩阵会连同格子、运行记录和历史一起删除；对空间成员可见的矩阵仍然保留。
- 如果管理员之后关闭了这项功能，已有的仅自己可见矩阵仍然只有你能看到，个人文件照常可用，但不能再新建，也不能更改谁能看到。

### 运行与重跑

点**运行**会处理所有未完成的格子，也就是还没运行或失败的格子；已有结果不会重跑。点**运行**旁边的 **▾** 可以选择范围，前三项后面写着会处理多少格：

- **只跑未完成的**：和直接点**运行**一样。
- **只跑过期的**：列的问题改过、或文件有了新版本后，结果已过期的格子。
- **只跑失败的**：只重跑失败的格子。
- **先在 3 份文件上试跑…**：只处理前 3 份还有未完成格子的文件。看过结果、觉得问题写得合适，再运行其余文件。这次运行在任务汇总里标着「试跑」。
- **全部重跑…**：重新提取所有格子，但已核对和人工改过的格子会保留，菜单里写明保留多少个。要重跑已核对的格子，先撤销核对，或打开格子点**重跑此格**。

列头菜单里的**运行此列**和**整列重跑…**只处理这一列，规则相同。

开始前的确认框会写明：

- 每一列要处理多少格、预计多少额度。读取文档的花费由各列共用，单独列一行；开了交叉校验的列要把每份文件再读一遍，花费往往最高，确认框会提示。
- 合计、你的余额、预计用时（运行期间可以离开页面），以及最长的一份文件占预计花费的比例。
- **先在 N 份文件上试跑**：勾选后只运行前几份文件，显示的花费也换成试跑的花费。

打开格子后，**重跑此格**和**重试此格**按钮上写着大约要花多少额度。单格重跑会直接开始，不弹出确认框，并且会替换人工改过或已核对的值。

因超时、模型服务临时出错或系统中断而失败的格子，会在本次运行结束前自动重试一次，重试前会等待半分钟到一分钟。失败的尝试不扣额度，重试成功后按正常方式计费。如果大多数调用都失败，像是模型服务暂时不可用，就不会自动重试，任务汇总会说明原因，请稍后用**只跑失败的**再试。「模型输出无法解析」的格子已经扣过额度，不会自动重试，需要手动重跑。

### 核对结果

表格上方的工具栏帮你逐格核对 AI 的答案：

- **已核 x / y**：显示在工具栏右侧，表示你能查看的格子里已经核对了多少格。
- **在表里搜索**：按文件名和答案查找行。
- **状态**：只看含有未核、已编辑、低置信、交叉校验不一致、失败或过期格子的行。低置信指置信度低于 70%，或答案引用的原文在文件里找不到；交叉校验不一致指开了交叉校验的列两次提取的结果不同。
- **添加筛选**：按某一列的值筛选。文字和选项列可以选「等于」「包含」；数字列可以选「等于」「大于」「小于」，日期列可以选「等于」「晚于」「早于」；任何列都可以选「为空」。点已有的筛选可以修改或移除它。
- **排序**：按文件名或任意一列排序，没有值的行排在最后。
- 搜索、筛选和排序会写进页面网址，返回或刷新后仍然保留，把网址发给同事也能看到同样的视图。点**清除过滤**或按 Esc 可以重新显示全部行。筛选时不显示你无权查看的文件行。

列头菜单里的**整列标记已核…**会把这一列中已完成且未过期的格子一次全部标为已核，人工改过的格子也包括在内；未完成、失败或已过期的格子不会标记。确认框会写明要标记多少格；被筛选隐藏的行也会一起标记。完成后的提示会写明哪些格子没有标记以及原因。

打开格子后，侧板顶部显示这一列的完整问题；下方的**历史**列出最近 50 条记录：谁在什么时候修改、保留为文本、标记或撤销了核对，以及 AI 何时提取、重跑或自动重试。历史只记录做了什么，不保存格子当时的值；此功能上线之前的修改没有历史。从矩阵移出文件时，它的格子历史会一并删除。

整列标记已核需要空间成员；只读成员可以查看进度、筛选、排序和历史。手机上只显示核对进度。

### 导出 Excel

点矩阵顶部的**导出 Excel**，把矩阵下载为以矩阵名称命名的 Excel 文件，工作表名和表头使用你的界面语言。**答案**表每个文件一行、每个问题一列，数字、日期和是非答案保存为真正的数字、日期和逻辑值，可以直接排序、筛选和求和；已核的答案标为绿色，人工修改但还没核对的标为黄色。**出处**表每个格子一行，列出文件、列名和问题、答案、状态、AI 的置信度、原文位置（第几页或第几段，已知时）和引用的原文。**说明**表写明矩阵名称、导出时间、导出人、隐藏了多少格以及各状态的含义。文件只包含你在矩阵里能看到的内容：你无权查看的文件显示为「（无权查看）」，不导出它的值。文字一律按文本保存，看起来像公式的内容不会被执行；超过 32,000 个字符的内容会截断并标注「（已截断）」。所有空间角色（包括只读成员）都可以导出；请在电脑上操作，手机上不显示这个按钮。导出的文件是导出那一刻的矩阵，之后不会自动更新。

### 看懂矩阵里的状态

- **未运行**：这个问题还没有处理。
- **处理中**：任务正在进行。
- **抽取失败**：打开格子查看原因，再决定是否重试。超时等临时性失败已经自动重试过一次。
- **未提取到值**：已经处理过这个问题，但没有提取出结果。请核对原文，不能据此认定原文里没有答案。

矩阵的多个任务会收在一处任务汇总里，展开**运行记录**可以查看每个任务的详情。重新进入已经完成的矩阵，不会再次显示旧的成功提示；有失败时，汇总会保留待处理数量，可以展开后选择**查看失败**，工具栏的「状态」随之切到「失败」。列头分两行显示完整列名；鼠标移到列头上、点击或用键盘聚焦列头，即可读到这一列的完整问题；打开格子后也会显示完整问题。在手机上点格子查看详情，关闭后回到矩阵。

切换空间后，矩阵会重新检查当前空间的访问权限。原矩阵在当前空间不可用时，请返回列表选择其他矩阵，或切回原来的空间；权限恢复后可以点**重试**。

一组常用的问题列可以用矩阵顶部的**存为模板**保存下来，之后在「模板」里**套用为矩阵**，一次带出整组列。你创建的模板可以**发布到团队模板库**，团队里其他空间的成员就能**复制到我的空间**使用；只有问题列会被发布，文件和答案不会离开你的空间。

## 用提取表把文件里的字段整理成表

有一类格式相近的文件（例如每月的利润表、合同）时，可以建一张**提取表**，写明要从这类文件里取出哪些字段（例如营业收入、净利润）。之后每份放进这张表的文件，都会按这些字段提取成一行，结果可以在知识库里查看，也可以在对话里直接查询。

1. 在知识库里点**模板**，再点**新建模板**，选**提取表（上传时自动提取）**，用一句话描述要提取的字段，确认字段后保存。
2. 在文件详情或列表的更多菜单里点**提取到表**，回答「把这份文件提取到哪张表？」；批量选中多个文件时也可以一起提取。上传 Excel 表格时，也可以直接在「提取表」里选这张表。
3. 提取完成后，在**提取结果**里查看，每一格都能跳回原文核对，原文位置的写法与文档矩阵相同。
4. 不想再提取某份文件时，在**提取到表**里选**不提取到表**，文件仍保留全文检索。

提取结果只显示你能读取的文件，其他成员个人文件的结果不会出现在知识库或对话里。

提取按每日额度排队进行，文件多时需要稍等。「模板」页里有两类内容：模板是矩阵里可复用的一组问题列，在矩阵里存为模板后可以套用到新矩阵；提取表是上传时自动提取的一组字段，结果在「提取结果」里查看。开启按知识库整理后，提取表和提取结果都在**提取表**标签里，新建时点那里的**新建提取表**；「模板」只放矩阵模板。

## 在回答和报告中查看出处

对于你在当前 Space 上传的可用文件，可在详情中选择**在对话中使用**。Bowra 会核对原件并准备附件，再打开新对话；原件不可用时，请恢复原件后重试。

回答或报告用到知识库里的文档时，相关句子后面会带一个出处编号，点开就能核对原文。

### 在对话里

提供直接知识读取的环境中，处理当前任务的助手可以自行查阅文档并继续其他工作，你仍可明确选择研究 Agent。多次搜索没有新增证据时，助手停止搜索并说明缺口；这不表示知识库为空。

对话回答用到知识库内容时，相关句子后会出现带文档小图标的角标，编号与数据引用连续。

- 点角标，在句子下方展开来源卡：文件名、位置（页、章节或第几段）和原文片段，与回答相关的部分会高亮。再点角标或 **×** 收起。角标在表格里时，来源卡展开在表格下方；回答生成完成后才能展开来源卡。
- 点**在知识库中打开**，打开该文件的详情，被引用的片段排在最前面。文件已被删除，或你没有它所在空间的访问权限时，知识库页顶部会提示无法打开该文件。
- 文件重新处理过、当时引用的那段已不在时，来源卡提示「原文已更新」，请在知识库中查看最新内容。
- 你没有该文件的查看权限时，角标置灰，只提示来源受限，不显示文件名和内容；文件已删除时提示来源已失效。
- 文件重新处理后，当时引用的片段仍可读取时，来源卡会标明它属于历史处理结果，不会自动替换成新片段。

### 在报告里

- 把鼠标移到正文的出处编号上，会显示文件名、位置和原文；点**在知识库中打开**可以跳到该文件，被引用的那段排在最前。
- 报告末尾的「数据来源」里，知识库条目同样显示文件名、位置、原文摘录和打开入口。
- 能看到什么取决于你自己对该文件的权限，而不是写报告的人的权限。报告分享给同事后，没有该文件权限的人只会看到「来源受限」和「该来源仅对有权限的成员可见」，看不到文件名和原文。

### 来源暂时无法核对时

回答或报告附有「原件暂时无法核对」一类的提醒时，结果使用的是此前已核对过的内容；请在原件恢复访问后检查结论。报告正文里的这类提醒会随正文一起保存；导出完整报告时，请一并保留这条说明。重新打开出处时，会按你当前的访问权限读取原文，没有访问权限时不能通过引用查看原文。

## 删除文件

从文件详情删除时，确认后立即生效，无法撤销。在文件列表里勾选文件删除，或用行尾菜单删除时，确认后屏幕上方会出现带「撤销」的提示，至少停留 8 秒；点「撤销」后文件不会被删除，仍留在列表中。删除后，这些资料不会再被对话检索。

## 上传时遇到问题

上传窗口会写明没传上去的原因，窗口不会关闭，已选的可见范围也会保留。

如果任一窗口暂时无法确认知识库是否可用，请点**重新检查**；仍然失败时，请联系团队管理员检查团队模型设置。检查未通过时不会上传或加入文件。

- **「无法加入知识库」**：文件格式不受支持。窗口里会列出支持的格式；可以先把文件导出为 PDF 再上传。
- **「上传在传输中被断开」**：文件传到一半连接被切断，多半是公司访问网关限制了上传文件的大小。如果小文件能传、大文件总是失败，请联系负责部署的管理员放宽限制；偶然断开时点**重试**会重新上传同一个文件。
- **「网络连接失败」**：文件还没开始传就失败了。检查网络连接后点**重试**。

上传过程中可以点**取消上传**停止。

上传时如果无法确认登录信息，弹窗会说明失败，不再一直显示加载中。选择**重新加载登录信息**可以重新读取；身份确认前不能上传，这条提示本身不表示你没有空间访问权限。

经过有限次数的检索仍未找到相关依据时，回答会说明哪些问题尚无法核实；这不代表知识库为空。你可以提供文档名称或更具体的问题，帮助缩小检索范围。

资料较多时，近期且已维护说明或分类的来源会优先进入助手的初始来源提示。助手也可以按分类名称查询来源目录；没有出现在提示中，不代表文件不可用。

## 对话期间知识来源发生变化

资料被删除、重新解析，或你对它的访问权限发生变化后，同一会话里的后续提问仍会继续进行。新的检索只会用到当前仍可用的资料。助手在这段对话里之前读到的内容仍可能被参考，先前的回答也仍留在会话里。其中来自已变化资料的内容请自行核对；需要完全排除这些内容时，请新建会话。

## 暂停期间知识来源发生变化

如果等待你回答的任务提示“知识来源已变化”，说明这个任务读过的资料已经变化。请新建会话，基于当前可用资料重新提问。资料、来源说明或访问权限发生变化后，先前的上下文可能无法继续使用；助手会先核对当前来源再继续处理。 刷新或回放对话时，会显示同样的来源变化状态。
