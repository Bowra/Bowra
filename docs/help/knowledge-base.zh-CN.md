# 使用知识库

把资料放进知识库后，助手回答对话问题时可以检索相关资料作为依据。你也可以明确要求它查询某份文档或某个主题。只想存放、不需要在对话中被检索的文件，放在**资料库 → 文件**即可；那里的文件也可以随时选择「加入知识库」。

根据知识资料回答时，助手可以利用有权限的来源名称、已有章节标题和简短开头摘录定位相关内容，并按任务需要检索依据。来源预览不代表已经审阅整份文档。

## 页面布局

知识库页分成四类内容，点一项即可切换。这四项以标签排在内容上方；窗口较窄时，它们排成一行可以左右滑动的按钮。

- **文件**：放进知识库的全部文件，在这里上传、查找、查看详情和管理。
- **文档矩阵**：把多份文件放进一张表，每一列是一个问题，逐格给出答案和出处。
- **提取结果**：按提取表从文件中提取出的结果，每张提取表一份。
- **模板**：内置模板、你存下的模板、团队模板库里的模板，以及提取表，都在这里新建和管理。

页头的**添加知识**在任何一项里都能用，点击后会回到「文件」并打开上传窗口。

## 选择谁能看到

上传时先选可见范围：

- **个人**：只有你自己能看到和检索。
- **空间**：当前空间的成员都能检索。切换空间后，看到的是那个空间的资料。
- **团队**：全团队都能检索。只有团队管理员可以上传到团队范围。

只有空间管理员身份不会获得团队范围的上传权限；需要团队资料时，请联系团队管理员加入。

## 上传文件

1. 进入**资料库 → 知识库**，点右上角**添加知识**。
2. 上传窗口会检查团队是否已启用嵌入模型。如果提示尚未配置，团队管理员可以点**配置嵌入模型**；其他成员请联系团队管理员。配置完成后回到窗口点**重新检查**，检查通过才能上传。
3. 选择可见范围，一次拖入或选择一个文件。要导入多个文件，请逐个上传或先打包为 ZIP。支持 PDF、Word、PPT、Excel、CSV、Markdown、TXT、图片和 ZIP，单个文件最大 200 MB。ZIP 中不支持的文件会跳过，导入结果会列出原因；文件夹不会作为文件入库。
4. 上传完成后会有提示，文件出现在列表中并开始处理。处理完成、状态变为「可用」后，就能在对话中被检索。

选择空文件或超过 200 MB 的文件时，上传窗口会说明原因并提示如何处理；重新选择文件即可继续。

Excel 和 CSV 每个文件最多检索前 5000 行（多个工作表合计）。超出的行不会进入知识库，对话中引用这类表格时会注明只用到了前 5000 行；需要完整数据时，请把表格拆成多个文件再上传。

## 从「文件」加入知识库

**资料库 → 文件**的「知识库」一列显示每个文件在知识库中的情况：

- **已加入 · 状态**：文件已在知识库中，状态含义见下方「文件状态」。点**在知识库中查看**、**查看处理进度**或**去知识库重试**，会打开知识库中的这份文件。
- **建议加入知识库**或**未加入**：点**加入知识库**，选择谁能检索到它（个人、当前空间或团队）后确认。加入后，提示中的**查看处理进度**可以直接跳到这份文件。

加入知识库不会移动或复制文件，它仍保留在「文件」中。

**加入知识库**窗口也会在确认前检查团队嵌入模型。未配置时按上面的指引处理；此前文件仍保存在「文件」中。

上传到「文件」或在聊天中附加文件只会保存原文件；被分类为长期资料也不会自动入库。请选择**加入知识库**、从知识库页面上传，或明确要求 Agent 将指定文件加入知识库并说明可见范围。Agent 会检查原始请求和当前权限，目标或范围不明确时需要澄清。处理完成后才可检索。聊天 ZIP 仅保留为一个原文件，不会解包或索引；如需导入其中的文档，请使用知识库页面。**移出知识库**会保留原文件；旧的加入请求不会在移除后再次入库，新明确请求可以重新加入。

## 文件状态

团队更换嵌入模型后，如果知识库索引正在更新或最近一次更新失败，「文件」视图会显示团队索引提示。这是团队范围的索引更新，与单个文件的处理状态不同。更新失败时，团队负责人或管理员可选择「查看并重试」，检查目标并确认后重新开始；其他成员可联系团队管理员。没有待处理的索引更新时，不显示此提示。

| 状态   | 含义                                                                                           |
| ------ | ---------------------------------------------------------------------------------------------- |
| 上传中 | 文件还在传输                                                                                   |
| 排队中 | 等待处理，文件多时需要稍等                                                                     |
| 处理中 | 正在读取和整理内容，大文件或扫描件会久一些                                                     |
| 可用   | 已处理完成，可以在对话中被检索                                                                 |
| 失败   | 没能处理完成。鼠标停在状态上可以看到原因；有权限时点状态旁的重试按钮，或点开文件查看原因并重试 |

「可用」表示基础内容已经可以检索；如果还要提取表格字段，提取结果可能稍后出现。「可用」不保证原文件预览此刻一定能打开。页面显示来源状态时，列表会优先显示「已暂停用于新任务」「原件暂时不可核对」或「来源待检查」，鼠标停在状态上可以看到最近一次检查的时间。

失败时，按提示处理：

- **文件格式不受支持**：转换成上面列出的格式后重新上传。
- **文件中没有可检索的文字内容**：检查文件是否为空，或是否只有图片而没有文字。
- **处理被中断** 或 **处理超时**：点**重试**。文件特别大时，可以拆分后再上传。
- **处理服务暂不可用**：稍后再试；如果一直失败，请联系团队管理员。
- **处理时未找到原文件**：先联系上传者或管理员恢复原件。有文件管理权限时，恢复后可点状态旁的重试按钮、在文件行的更多菜单点**重试解析**，或在详情里点**重试**。系统会先检查原件能否找到；仍然缺失时不会开始处理，并提示你恢复原件或重新上传。重试成功后，先前针对这份文件的失败提示会收起。

## 查找文件

- 用列表上方的范围切换「个人」「空间」「团队」。范围是工具行里的**范围**筛选（在手机上收在**筛选**里）；空间会写出当前空间的名字，并说明这个范围谁能检索。
- 使用**范围**筛选时，如果有**全部**选项，可以一次列出你能检索的个人、当前空间和团队文件，表格里的**范围**一列标出每份文件属于哪里。页面会记住你上次选的范围；第一次打开时显示当前空间。
- 在搜索框输入文字，按文件名查找。
- 打开**内容深搜**并按 Enter 后，会按文件内容在当前范围内查找。搜索框旁会写出在哪个范围找到了几个文件；每个结果显示命中的片段，片段前标出所在位置（第几页、哪个章节或第几段）。
- 深搜没有结果时，可以换个说法，点按钮换到其他范围继续搜，或点**按文件名搜**关闭内容深搜。
- 可以按状态、类型和上传日期筛选，页面提供排序选项时也可以调整排序。筛选按钮上会写出已选的值；要一次取消某一组，打开它的菜单点**清除状态**或**清除类型**。
- 选了两个及以上条件（关键词、每个状态、每个类型、日期各算一个）时，工具行下方会列出已选条件，可以逐个点 × 去掉，或点**清除全部**。范围不在这一行里。
- 在手机上，点**筛选**会从底部打开面板，里面分范围、状态、类型、日期几组，选中即生效；点**显示 N 个文件**回到列表。排序和**内容深搜**留在工具行上。
- 上传成功后，列表会自动切到所选的上传范围（正在看**全部**时保持在**全部**），清除搜索与筛选，并按最新上传时间显示第一页，不用手动切换范围寻找新文件。ZIP 里的文件仍在解析时，可点**返回文件列表**继续查看处理状态；全部处理结束后点**完成**，列表也会这样刷新。

如果页面地址会随搜索和筛选变化，它会记住搜索、筛选、排序、页码和正在打开的文件：浏览器后退可以回到上一组结果，刷新后仍停在原处。把地址发给同事只能让有权限的人看到这些文件，不会授予访问权限。

页面按上面的方式记住地址时，列表也支持完整的键盘操作：用 Tab 移到筛选按钮后按 Enter 打开，方向键选择选项，Space 勾选，Esc 关闭菜单。列表里的勾选与打开是两个独立动作：在行上按 Space 选择文件，在文件名上按 Enter 打开详情。

## 文件详情

点列表中的文件打开详情，可以看到状态、可见范围、上传者、上传时间和大小。

- 文件可用时，点**在对话中使用**会新开一个对话并带上这份文件。这个入口只对你自己在当前空间上传的文件提供；其他文件在对话中照样会被自动检索。
- 文件在对话中被引用过时，标题下会显示被引用的次数。
- 从内容深搜结果点进来时，命中的片段排在最前面并高亮显示。
- 在文档矩阵里点单元格的「查看原文」，会在当前页打开这份文件的详情，出处那一段排在最前；关掉后仍回到矩阵。
- 处理中的文件会显示进度，可以关掉详情，处理会继续。处理失败时，详情里写明原因，并可以直接**重试**。
- 有权限时，还可以在详情里更改可见范围、提取到表或删除文件。
- 预览打不开时，详情会显示原因；有**重试预览**时可以直接重试，不用关闭详情。文件内容能读取、只是暂时无法显示时，可以改为下载原文件。没有权限或文件已不可访问时，请先确认访问权限或联系文件管理者。

## 核对文件来源与恢复原件

文件详情提供**来源核对**时，点**检查来源**，可以查看当前原件和索引的情况。检查不会自动反复运行；需要最新结果时点**重新检查**。结果分三项显示：

- **原件**：能找到原件时，仍不表示已经验证它与索引内容完全一致；显示未找到原件时，本次存储检查正常但没有这份原件，请联系上传者或管理员核对；显示暂时无法核对时，可能是存储服务、网络或访问问题，不能据此认定文件已经丢失。
- **索引**：记录的片段数量与当前一致且抽样片段可读，不保证全文完整或每条引用都能核对。
- **来源对应关系**：显示尚未验证时，表示当前还不能证明索引来自这份原件。每条引用仍需结合原文单独核对。

检查不会自动重新解析文件；文件变化后需要重新检查。页面还可能写明这份文件是否可用于新任务：原件暂时无法核对时，使用此前验证过的索引，结果会附带提醒；已暂停用于新任务时，请先按详情里的说明处理，不必反复重试矩阵。

有管理权限且页面提供恢复操作时：

- **恢复原件**：选择与原件内容完全相同的文件；恢复后会重新检查，不会重新解析，也不产生模型费用。
- 内容不同时，按提示作为新文件上传，旧文件和历史出处都会保留。
- **重新解析并核对**：重新处理原件并生成可供检索的内容，可能产生模型费用；操作前请阅读页面说明。

任务运行中来源发生变化时，相关的新结果可能暂停。已有的人工修改和已核对标记会保留；原件短暂不可访问但仍能使用此前核对过的内容时，结果会附上提醒。提醒不是原文已核对的证明。

## 批量重新解析

页面提供**批量重新解析…**时，在文件列表的当前页勾选你有管理权限的文件，再选择它。先核对文件数、大小和模型用量说明，再确认开始。每批最多 20 份、合计 100 MB，逐份处理；这次只重新建立可搜索的内容，不重新抽取表格。

进度集中显示在页面上，不会为每份文件单独弹出提示；刷新后可以继续查看当前账号在当前团队和空间里的任务。任务中断时，先恢复访问或处理来源问题，再点**检查权限并继续**，系统不会自动反复重试。选择**停止后续文件**后，已经开始的文件可能继续完成，已经发出的模型请求可能产生费用。

历史矩阵值和引用不会因为来源异常自动重算。失去文件访问权限后，对应的文件名、原文和矩阵值会隐藏，恢复权限后可以重新查看。

## 用文档矩阵对多份文件逐一提问

1. 点**文档矩阵**，再点**新建矩阵**，选择要放进矩阵的文件；也可以在「文件」里选中多份文件，点**打开为矩阵**。
2. 加一列问题（例如「合同金额是多少？」），选好答案类型后运行。每一行是一份文件，每一格是这份文件对这个问题的回答。
3. 点单元格查看答案和出处，可以修改答案或标记为已核对；点「查看原文」会在当前页打开文件详情，出处那一段排在最前。
4. 运行按文档长度消耗额度，开始前会提示预计消耗。

### 看懂矩阵里的状态

- **未运行**：这个问题还没有处理。
- **处理中**：任务正在进行。
- **抽取失败**：打开格子查看原因，再决定是否重试。
- **未提取到值**：已经处理过这个问题，但没有提取出结果。请核对原文，不能据此认定原文里没有答案。

矩阵的多个任务会收在一处任务汇总里，展开**运行记录**可以查看每个任务的详情。重新进入已经完成的矩阵，不会再次显示旧的成功提示；有失败时，汇总会保留待处理数量，可以展开后选择**查看失败**。列名较长时，点击或用键盘聚焦列头即可读到完整问题；打开格子后也会显示完整问题。在手机上点格子查看详情，关闭后回到矩阵。

切换空间后，矩阵会重新检查当前空间的访问权限。原矩阵在当前空间不可用时，请返回列表选择其他矩阵，或切回原来的空间；权限恢复后可以点**重试**。

一组常用的问题列可以在矩阵的列设置里**存为模板**，之后在「模板」里**套用为矩阵**，一次带出整组列。你创建的模板可以**发布到团队模板库**，团队里其他空间的成员就能**复制到我的空间**使用；只有问题列会被发布，文件和答案不会离开你的空间。

## 用提取表把文件里的字段整理成表

有一类格式相近的文件（例如每月的利润表、合同）时，可以建一张**提取表**，写明要从这类文件里取出哪些字段（例如营业收入、净利润）。之后每份放进这张表的文件，都会按这些字段提取成一行，结果可以在知识库里查看，也可以在对话里直接查询。

1. 在知识库里点**模板**，再点**新建模板**，选**提取表（上传时自动提取）**，用一句话描述要提取的字段，确认字段后保存。
2. 在文件详情或列表的更多菜单里点**提取到表**，回答「把这份文件提取到哪张表？」；批量选中多个文件时也可以一起提取。上传 Excel 表格时，也可以直接在「提取表」里选这张表。
3. 提取完成后，在**提取结果**里查看，每一格都能跳回原文核对。
4. 不想再提取某份文件时，在**提取到表**里选**不提取到表**，文件仍保留全文检索。

提取按每日额度排队进行，文件多时需要稍等。「模板」一词只指矩阵里可复用的一组问题列：在矩阵里存为模板后，可以套用到新矩阵。

## 在回答和报告中查看出处

回答或报告用到知识库里的文档时，相关句子后面会带一个出处编号，点开就能核对原文。

### 在对话里

提供直接知识读取的环境中，处理当前任务的助手可以自行查阅文档并继续其他工作，你仍可明确选择研究 Agent。多次搜索没有新增证据时，助手停止搜索并说明缺口；这不表示知识库为空。

对话回答用到知识库内容时，相关句子后会出现带文档小图标的角标，编号与数据引用连续。

- 点角标，在句子下方展开来源卡：文件名、位置（页、章节或第几段）和原文片段，与回答相关的部分会高亮。再点角标或 **×** 收起。角标在表格里时，来源卡展开在表格下方；回答生成完成后才能展开来源卡。
- 点**在知识库中打开**，打开该文件的详情，被引用的片段排在最前面。文件已被删除，或你没有它所在空间的访问权限时，知识库页顶部会提示无法打开该文件。
- 文件重新处理过、当时引用的那段已不在时，来源卡提示「原文已更新」，请在知识库中查看最新内容。
- 你没有该文件的查看权限时，角标置灰，只提示来源受限，不显示文件名和内容；文件已删除时提示来源已失效。
- 文件重新处理后，当时引用的片段仍可读取时，来源卡会标明它属于历史处理结果，不会自动替换成新片段。

### 在报告里

- 把鼠标移到正文的出处编号上，会显示文件名、位置和原文；点**在知识库中打开**可以跳到该文件，被引用的那段排在最前。
- 报告末尾的「数据来源」里，知识库条目同样显示文件名、位置、原文摘录和打开入口。
- 能看到什么取决于你自己对该文件的权限，而不是写报告的人的权限。报告分享给同事后，没有该文件权限的人只会看到「来源受限」和「该来源仅对有权限的成员可见」，看不到文件名和原文。

### 来源暂时无法核对时

回答或报告附有「原件暂时无法核对」一类的提醒时，结果使用的是此前已核对过的内容；请在原件恢复访问后检查结论。报告正文里的这类提醒会随正文一起保存；导出完整报告时，请一并保留这条说明。重新打开出处时，会按你当前的访问权限读取原文，没有访问权限时不能通过引用查看原文。

## 删除文件

从文件详情删除时，确认后立即生效，无法撤销。在文件列表里勾选文件删除，或用行尾菜单删除时，确认后屏幕上方会出现带「撤销」的提示，至少停留 8 秒；点「撤销」后文件不会被删除，仍留在列表中。删除后，这些资料不会再被对话检索。

## 上传时遇到问题

上传窗口会写明没传上去的原因，窗口不会关闭，已选的可见范围也会保留。

如果任一窗口暂时无法确认知识库是否可用，请点**重新检查**；仍然失败时，请联系团队管理员检查团队模型设置。检查未通过时不会上传或加入文件。

- **「无法加入知识库」**：文件格式不受支持。窗口里会列出支持的格式；可以先把文件导出为 PDF 再上传。
- **「上传在传输中被断开」**：文件传到一半连接被切断，多半是公司访问网关限制了上传文件的大小。如果小文件能传、大文件总是失败，请联系负责部署的管理员放宽限制；偶然断开时点**重试**会重新上传同一个文件。
- **「网络连接失败」**：文件还没开始传就失败了。检查网络连接后点**重试**。

上传过程中可以点**取消上传**停止。

上传时如果无法确认登录信息，弹窗会说明失败，不再一直显示加载中。选择**重新加载登录信息**可以重新读取；身份确认前不能上传，这条提示本身不表示你没有空间访问权限。

经过有限次数的检索仍未找到相关依据时，回答会说明哪些问题尚无法核实；这不代表知识库为空。你可以提供文档名称或更具体的问题，帮助缩小检索范围。
