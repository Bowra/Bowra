# Bereiche erstellen und verwalten

## Einen Bereich erstellen, archivieren oder wiederherstellen

Team-Eigentümer und Administratoren öffnen **Team-Einstellungen → Bereiche**. Erstellen Sie einen Bereich und weisen Sie über sein Zeilenmenü vorhandene Teammitglieder als Bereichsadministratoren zu. Wer diese Rolle verliert, bleibt reguläres Bereichsmitglied. Archivieren Sie einen Bereich, um ihn aus der aktiven Liste zu nehmen. Über dieselbe Liste stellen Sie ihn wieder her. Hat er keinen aktiven Administrator mehr, wählen Sie bei der Wiederherstellung ein berechtigtes Teammitglied aus.

## Den aktuellen Bereich konfigurieren

Wechseln Sie zum gewünschten Bereich und öffnen Sie **Einstellungen → Bereich → Allgemein**. Bereichsadministratoren bearbeiten Name und Beschreibung sowie die Spracheinstellungen. Der Wochenbeginn bestimmt die wöchentliche Gruppierung von BI-Ergebnissen. Die Datensprache beschreibt die Quelldaten. Ihre persönliche Antwortsprache wählen Sie auf der Kontoseite.

Über den Bereichszugriff fügen Sie Teammitglieder hinzu und ändern deren Rollen. Gemeinsame Definitionen und Vorgaben gehören in die KI-Arbeitsanweisungen. [Bereichszugriff gewähren](permissions/space-access.de-DE.md) · [KI-Arbeitsanweisungen](space-instructions.de-DE.md)

## Einen Bereich verlassen

Öffnen Sie die Einstellungen zum aktuellen Bereich im Bereichsmenü und wählen Sie **Aktuellen Bereich verlassen…**. Dadurch entfällt der über diesen Bereich gewährte Zugang. Für einen erneuten Beitritt benötigen Sie die Freigabe einer Administration. Als letzter aktiver Administrator müssen Sie zuerst eine weitere Person ernennen.

## Wenn kein Bereich verfügbar ist

Nehmen Sie auf der ersten Bereichsseite eine angezeigte Einladung an. Wenn das Erstellen angeboten wird und Sie berechtigt sind, benennen und erstellen Sie einen Bereich. Andernfalls bitten Sie die Team-Administration um Zugriff.
