# Create and manage Spaces

## Create, archive, or restore a Space

A Team owner or administrator opens **Team settings → Spaces**. Create the Space, then use the row’s administrator action to assign existing Team members. Removing someone as a Space administrator keeps their regular membership. Archive a Space when you want it out of the active list. Restore it from the same list. If it has no active administrator, choose an eligible Team member during restoration.

## Configure the current Space

Select the Space you intend to edit before opening **Settings → Space → General**. Space administrators can change the name and description, and review the multilingual settings. The **Week start day** controls how dates are grouped in weekly BI results. The data language describes the source data. To change personal answer language, use the account page.

Use **Space access** to add existing Team members or adjust their roles. Use **AI work instructions** for shared definitions and guidance. [Space access](permissions/space-access.en-US.md) · [AI work instructions](space-instructions.en-US.md)

## Leave a Space

Open settings in the current Space’s switcher and choose **Leave Current Space…**. Leaving removes the access granted through that Space. Ask an administrator for access if you need to rejoin. If you are its last active administrator, appoint another before leaving.

## If no Space is available

On the first Space screen, accept an invitation when one is listed. If the page offers creation and you have the required access, name and create a Space. If neither route works, ask a Team administrator to grant Space access.
