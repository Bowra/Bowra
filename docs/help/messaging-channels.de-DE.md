# Einen Nachrichtenkanal für das Team verbinden

Team-Eigentümer und Administratoren öffnen den gewünschten Kanal unter **Team-Einstellungen → Nachrichtenkanäle** und folgen der Anleitung für ihre Installation. Benötigt der Kanal einen Rückruf, richten Sie eine extern erreichbare Adresse ein. [Öffentliche Zugangsadressen konfigurieren](public-entries.de-DE.md)

Unter **Verbunden** stehen aktive und betriebsbereite Kanäle. Unter **Verfügbare Kanäle** können Sie die Einrichtung starten, fortsetzen oder den Status eines aktiven Kanals prüfen. **Demnächst verfügbar** führt Kanäle auf, deren Einrichtung noch nicht verfügbar ist.

- **Feishu.** Speichern Sie die App-Zugangsdaten und wählen Sie die unterstützte Ereignisverbindung. Folgen Sie den Anweisungen für die App-Konsole und führen Sie die Prüfungen vor der Freigabe durch. Mitglieder bestätigen ihr eigenes Bowhead-Konto über die Karte, die der Bot nach ihrer Nachricht sendet.
- **Slack.** Richten Sie die Slack-App ein, registrieren Sie den Rückruf und installieren Sie den Bot im gewünschten Slack-Arbeitsbereich. Testen Sie eine Direktnachricht oder eine Erwähnung in einem Thread. Für persönliches Slack-MCP gibt es einen separaten Autorisierungsablauf.
- **Microsoft Teams.** Richten Sie den Azure Bot ein, registrieren Sie die vollständige externe HTTPS-Adresse einschließlich Bereitstellungspfad und veröffentlichen Sie die App für persönliche Chats im Mandanten.

Testen Sie mit einem berechtigten Mitgliedskonto und prüfen Sie den Status des jeweiligen Kanals. Nachrichten werden dem konfigurierten Bowhead-Team zugeordnet und verwenden die Berechtigungen des Mitglieds.

Prüfen Sie bei Datenfragen, ob Ihr verknüpftes Konto auf den betreffenden Datarc-Arbeitsbereich zugreifen kann. Wenn eine Rückfrage Sie zu Bowhead im Web weiterleitet, setzen Sie die ursprüngliche Unterhaltung dort fort.

## Persönliche Chats in Teams verwenden

1. Schreiben Sie dem Bot und melden Sie sich bei Aufforderung in Teams an. Öffnen Sie **Teams verbinden**, melden Sie sich mit dem passenden Geschäftskonto bei Bowhead an und bestätigen Sie. Der Link gilt zehn Minuten. Bisher per E-Mail zugeordnete Mitglieder bestätigen einmal. Senden Sie Ihre Frage anschließend in Teams.
2. Wählen Sie den Space für Ihre Frage. Mit `/space` wechseln Sie vor der nächsten Frage den Space. Jeder Space hat einen eigenen Verlauf. Wechseln Sie zurück, um ein dort wartendes Ergebnis zu erhalten.
3. Wählen Sie auf der Fragekarte die Antworten oder geben Sie Text ein. **Absenden und fortfahren** setzt die ursprüngliche Aufgabe fort. Eine bereits im Web gespeicherte Antwort bleibt gültig. Wenn die Karte auf Bowhead Web verweist, öffnen Sie dort die ursprüngliche Unterhaltung.
