# 接入团队消息渠道

团队负责人和管理员从**团队设置 → 消息渠道**打开各渠道的配置页，按当前部署显示的步骤操作。渠道需要回调时，请先准备外部服务能访问的地址。[设置公开入口](public-entries.zh-CN.md)

**已连接**显示已启用且正常运行的渠道。在**可连接**中开始接入、继续接入，或检查已启用渠道的状态。**即将支持**中的渠道目前还不能配置。

- **飞书。**保存应用凭据，选择所支持的事件接入方式。按飞书配置页进行开发者后台配置，完成页面检查和发布验证后，再让成员使用机器人。成员首次给机器人发消息后，从收到的绑定卡片确认自己的 Bowhead 账号。
- **Slack。**配置 Slack 应用，登记团队机器人回调，在目标 Slack 工作区安装。按当前设置测试私信或在频道线程里提及 Bowhead。如启用个人 Slack MCP，请按单独的个人授权指引操作。
- **Microsoft Teams。** 按页面指引设置 Azure Bot，将完整的外部 HTTPS 消息地址（含部署前缀）登记为回调地址，并在租户中发布支持个人聊天的应用。

配置完成后，用有资格使用该渠道的成员账号测试，查看该渠道的状态或报错。消息进入配置的 Bowhead 团队，并使用该成员已有的访问权限。

询问数据时，请确认已关联的账号有权访问对应的北极九章工作区。如果澄清卡提示前往 Bowhead 网页，请打开原对话继续。

## 使用 Teams 私聊

1. 给机器人发消息。按提示完成 Teams 登录，打开「确认绑定 Teams」，以工作邮箱匹配的 Bowhead 账号登录并确认。链接十分钟内有效。升级前依靠邮箱匹配的成员也需要确认一次。返回 Teams 后，重新发送问题。
2. 选择这次提问使用的空间。发送 `/space` 可以切换空间，再发送下一条问题。不同空间各自保存对话。如果之前的空间还有结果等待投递，切回后可以接收。
3. 看到「提交并继续」时，选好选项或填写所需文字后提交，原任务会继续。如果已在网页答过，系统沿用首次保存的答案。若卡片提示前往网页，请在 Bowhead 的原对话中处理。
