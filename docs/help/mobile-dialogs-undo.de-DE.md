# Dialoge und Rückgängig auf Mobilgeräten

Dieser Leitfaden beschreibt zwei Dinge: wie Fenster zum Eingeben von Informationen auf Smartphones und anderen schmalen Bildschirmen von unten erscheinen und welche Aktionen sich direkt nach ihrer Ausführung rückgängig machen lassen. Am Computer erscheinen Dialoge in der Bildschirmmitte.

## Eingabefenster öffnen sich von unten

Fenster mit mindestens zwei Feldern, einer Liste oder längeren Inhalten – etwa zum Einladen von Mitgliedern, Hinzufügen einer Verbindung, Bearbeiten einer Erinnerung oder Konfigurieren eines Tools – öffnen sich auf Smartphones als Bedienfeld, das von unten nach oben gleitet:

- Die meisten Bedienfelder haben oben eine Schaltfläche **×** zum Schließen. Unten können Sie auch **Abbrechen** auswählen. **Abbrechen**, **Speichern** und ähnliche Schaltflächen bleiben unten sichtbar. Sie müssen also nicht bis zum Ende scrollen, um sie zu erreichen.
- Sie können das Bedienfeld auch schließen, indem Sie den kurzen Griff oben nach unten ziehen. Lassen Sie ihn nach einer kurzen Bewegung los, kehrt das Bedienfeld an seine vorherige Position zurück.
- Während etwas gespeichert oder übermittelt wird, lässt sich das Bedienfeld erst schließen, wenn der Vorgang abgeschlossen ist.
- Öffnet sich die Tastatur, bewegt sich das Bedienfeld darüber. Das gerade bearbeitete Feld und die Schaltflächen unten bleiben sichtbar.
- Solange das Bedienfeld geöffnet ist, können Sie die Seite dahinter weder bedienen noch scrollen.

Fenster, in denen Sie nur eine Sache bestätigen oder einen einzelnen Namen ändern sollen, erscheinen weiterhin in der Bildschirmmitte. Beispiele sind **Diesen Bericht löschen?** und das Umbenennen.

Einige Fenster, etwa zum Einladen von Mitgliedern, fragen beim Schließen nach, ob Ihre Eingaben verworfen werden sollen. Wählen Sie **Abbrechen**, um zurückzukehren und die Eingabe fortzusetzen.

## Aktionen rückgängig machen

Nach den unten aufgeführten Aktionen erscheint oben auf dem Bildschirm eine Meldung mit **Rückgängig** rechts. Sie bleibt mindestens acht Sekunden sichtbar und verschwindet nicht, solange sich der Mauszeiger darüber befindet. Wählen Sie **Rückgängig**, um den Eintrag wiederherzustellen; die Liste wird aktualisiert.

| Aktion                                                                                                                                | Wo                                                               | Nach dem Rückgängigmachen                                                                                   |
| ------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| Unterhaltung löschen oder archivieren                                                                                                 | **⋯** der Unterhaltung in der Seitenleiste                       | Die Unterhaltung erscheint wieder in der Liste                                                              |
| Wissensbasisdateien löschen (ausgewählt in der Liste oder über das Zeilenmenü); die Rückgängig-Meldung erscheint nach der Bestätigung | Dateiliste der Wissensbasis                                      | Die Dateien werden nicht gelöscht und bleiben in der Liste                                                  |
| Datei löschen                                                                                                                         | Dateiseite                                                       | Die Datei wird aus dem Papierkorb in die Liste zurückgeholt                                                 |
| Erinnerung in den Papierkorb verschieben                                                                                              | Erinnerungsseite                                                 | Die Erinnerung kehrt in die gespeicherte Liste zurück                                                       |
| Gespeicherte Erinnerungen leeren                                                                                                      | **Daten und Datenschutz** auf der Erinnerungsseite               | Erinnerungen werden wie zuvor wiederhergestellt                                                             |
| Standardeinstellungen für persönliche Darstellung wiederherstellen                                                                    | **Darstellung** in den persönlichen Einstellungen                | Ihre vorherigen Darstellungseinstellungen werden wiederhergestellt                                          |
| Bereich archivieren                                                                                                                   | **⋯** in einer Zeile unter **Bereiche** in den Teameinstellungen | Der Bereich ist wieder aktiv, und durch das Archivieren pausierte geplante Aufgaben werden wieder aktiviert |

Hinweise:

- Verpassen Sie die Rückgängig-Meldung, können gelöschte Dateien und in den Papierkorb verschobene Erinnerungen innerhalb von 30 Tagen aus dem Papierkorb wiederhergestellt werden. Gelöschte Erinnerungen lassen sich unter **Kürzlich geleert** wiederherstellen.
- Erinnerungen werden ohne Bestätigung in den Papierkorb verschoben und Dateien auf der Dateiseite sofort gelöscht. Danach erscheint **Rückgängig**. Bei einer Datei, auf die ein Bericht verweist, erscheint vorher weiterhin ein Hinweis, dass Downloads im Bericht danach nicht mehr funktionieren.
- Ein Bereich wird ohne Bestätigung sofort archiviert; danach erscheint **Rückgängig**. Verpassen Sie die Meldung, wählen Sie in der Bereichsliste **Wiederherstellen**. Durch das Archivieren werden die geplanten Aufgaben in diesem Bereich pausiert; Rückgängigmachen oder Wiederherstellen aktiviert sie wieder (sie laufen ab diesem Zeitpunkt nach ihrem Zeitplan), selbst pausierte Aufgaben bleiben pausiert. Mitglieder müssen den Bereich beim nächsten Öffnen eventuell erneut auswählen.
- Endgültiges Löschen sowie das Löschen eines Berichts, Skills, einer geplanten Aufgabe oder einer Datei aus den Details einer Wissensbasisdatei lassen sich nicht rückgängig machen. Dafür ist zuerst eine Bestätigung erforderlich.

## Meldung schließen

Meldungen verschwinden von selbst. Sie können sie auch über **×** rechts schließen. Auf einem Smartphone können Sie eine Meldung außerdem nach oben, links oder rechts wischen. Schließen Sie eine Meldung mit **Rückgängig**, lässt sich die Aktion danach nicht mehr rückgängig machen. Einträge im Papierkorb und an ähnlichen Orten können Sie weiterhin wie oben beschrieben wiederherstellen.
