# Fenêtres mobiles et annulation

Ce guide explique comment les fenêtres de saisie s’ouvrent depuis le bas sur un téléphone ou un écran étroit, et quelles actions peuvent être annulées juste après leur exécution. Sur ordinateur, les fenêtres s’ouvrent au centre de l’écran.

## Panneaux de saisie

Les fenêtres avec au moins deux champs, une liste ou un contenu long, comme inviter des membres, ajouter une connexion, modifier un souvenir ou configurer un outil, s’ouvrent sur téléphone depuis le bas :

- La plupart ont un bouton « × » en haut ; vous pouvez aussi choisir **Annuler** en bas pour fermer. **Annuler**, **Enregistrer** et les boutons similaires restent en bas, accessibles sans aller à la fin du contenu.
- Faites glisser la petite barre supérieure vers le bas pour fermer. Un déplacement insuffisant ramène le panneau en place.
- Pendant un enregistrement ou un envoi, le panneau reste ouvert jusqu’à la fin de l’action.
- Lorsque le clavier s’ouvre, le panneau se place au-dessus pour garder visibles le champ actif et les boutons du bas.
- La page derrière le panneau est inactive et ne défile pas.

Une confirmation simple, comme « Supprimer ce rapport ? », ou la modification d’un seul nom reste au centre de l’écran.

Certaines fenêtres, notamment les invitations, demandent si vous souhaitez abandonner votre saisie en les fermant. Choisissez **Annuler** pour revenir et poursuivre la saisie.

## Actions annulables

Après les actions ci-dessous, un message avec **Annuler** à droite apparaît en haut pendant au moins 8 secondes et reste visible au survol. Cette commande restaure l’élément et actualise la liste.

| Action                                                                                                                      | Où                                             | Après annulation                                                                  |
| --------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------- | --------------------------------------------------------------------------------- |
| Supprimer ou archiver une conversation                                                                                      | « ⋯ » dans la barre latérale                   | La conversation revient dans la liste                                             |
| Supprimer des fichiers de la base de connaissances, par sélection ou menu de ligne ; le message apparaît après confirmation | Liste des fichiers de la base de connaissances | Les fichiers restent dans la liste                                                |
| Supprimer un fichier                                                                                                        | Page Fichiers                                  | Le fichier revient de la corbeille                                                |
| Déplacer un souvenir vers la corbeille                                                                                      | Page Mémoire                                   | Le souvenir revient dans la liste enregistrée                                     |
| Effacer les souvenirs enregistrés                                                                                           | **Données et confidentialité**, page Mémoire   | Les souvenirs sont restaurés tels qu’ils étaient                                  |
| Rétablir l’apparence personnelle par défaut                                                                                 | **Apparence**, paramètres personnels           | Les anciens réglages reviennent                                                   |
| Archiver un espace                                                                                                          | « ⋯ » dans **Espaces**, paramètres de l’équipe | L’espace redevient actif et les tâches suspendues par l’archivage sont réactivées |

À savoir :

- Si vous manquez le message, les fichiers et souvenirs supprimés peuvent être restaurés depuis la corbeille pendant 30 jours. Les souvenirs effacés peuvent être restaurés dans **Effacements récents**.
- Déplacer un souvenir vers la corbeille ou supprimer un fichier sur la page Fichiers s’exécute directement, puis propose **Annuler**. Un fichier lié dans un rapport affiche d’abord un avertissement : les téléchargements depuis le rapport cesseront de fonctionner.
- Archiver un espace s’exécute directement et propose **Annuler**. Ensuite, vous pouvez toujours choisir **Restaurer** dans la liste des espaces. L’archivage suspend les tâches planifiées de cet espace ; l’annulation ou la restauration les réactive et elles suivent leur calendrier à partir de ce moment. Les tâches mises en pause manuellement le restent. Les membres devront peut-être resélectionner l’espace à leur prochaine visite.
- La suppression définitive, celle d’un rapport, d’un Skill ou d’une tâche planifiée, et celle d’un fichier depuis ses détails dans la base de connaissances ne peuvent pas être annulées. Elles demandent confirmation.

## Fermer un message

Les messages disparaissent seuls ou avec le « × » à droite. Sur téléphone, vous pouvez aussi les balayer vers le haut, la gauche ou la droite. Fermer un message d’annulation met fin à cette possibilité immédiate ; les restaurations depuis la corbeille et les autres emplacements décrits restent disponibles.
