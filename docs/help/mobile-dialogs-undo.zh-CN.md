# 手机上的弹窗与撤销

本文说明两件事：手机（屏幕较窄时）上填写内容的窗口怎样从屏幕底部弹出；以及哪些操作完成后可以立即撤销。电脑上的弹窗在屏幕中间显示。

## 填写内容的窗口从底部弹出

需要填写两项以上内容、带列表，或内容较长的窗口（例如邀请成员、添加连接、编辑记忆、配置工具），在手机上会以一块从底部弹出的面板显示：

- 多数面板顶部有「×」关闭按钮；也可以点底部的「取消」。「取消」「保存」等按钮一直留在底部，内容再长也不用滚到最后才能点到。
- 按住面板顶部的短横线向下滑，也能关闭面板；轻轻一拖松手，面板会回到原位。
- 正在保存或提交时，面板暂时不能关闭，等操作完成即可。
- 点输入框弹出键盘时，面板会升到键盘上方，正在输入的一项和底部按钮都保持可见。
- 面板打开时，后面的页面不能操作，也不会跟着滚动。

只需要确认一件事的窗口（例如「删除这份报告？」），以及只改一个名字的窗口，仍在屏幕中间显示。

有些窗口（例如邀请成员）在已经填写内容时关闭，会先询问是否放弃；选「取消」可以回到窗口继续填写。

## 哪些操作完成后可以撤销

下面这些操作完成后，屏幕上方会出现一条提示，右侧带「撤销」。提示至少停留 8 秒；鼠标悬停或键盘聚焦到提示内按钮时会暂停计时，鼠标与焦点离开后按剩余时间继续。点「撤销」即可恢复，列表会随之刷新。

| 操作                                                                     | 在哪里                         | 撤销后                                             |
| ------------------------------------------------------------------------ | ------------------------------ | -------------------------------------------------- |
| 删除会话、归档会话                                                       | 侧栏会话的「⋯」                | 会话回到列表                                       |
| 删除知识库文件（在文件列表里勾选或用行尾菜单删除；确认后才出现撤销提示） | 知识库文件列表                 | 文件不会被删除，回到列表                           |
| 删除文件                                                                 | 文件页                         | 文件从回收站回到列表                               |
| 把一条记忆移入回收站                                                     | 「设置 › 记忆」                | 记忆回到已保存列表                                 |
| 清空已保存记忆                                                           | 「设置 › 记忆」›「数据与隐私」 | 按清空前的内容恢复                                 |
| 归档空间                                                                 | 团队设置「空间」行尾「⋯」      | 空间恢复为启用中，因归档暂停的定时任务一起重新开启 |
| 恢复个人外观默认设置                                                     | 个人设置的「外观」             | 回到之前的外观设置                                 |

说明：

- 工作完成或停止后才能删除、归档会话。删除或撤销暂时受阻时，请按提示中的具体原因处理；删除失败的会话仍保留在列表中。
- 错过了撤销提示也不要紧：删除的文件与移入回收站的记忆 30 天内可以在回收站里恢复，清空的记忆可以在「最近清空」里恢复。
- 把记忆移入回收站、在文件页删除文件时不弹出确认框，直接执行并出现「撤销」；被报告引用的文件删除前仍会先提醒报告里的下载会失效。
- 归档空间不弹出确认框，直接归档并出现「撤销」。错过了撤销提示，也可以在空间列表里选择「恢复」。归档时会暂停这个空间里的定时任务，撤销或恢复时这些任务会一起重新开启（从恢复的时刻起按计划运行），你自己暂停的任务保持暂停；成员下次进入时可能需要重新选择这个空间。
- 永久删除、删除报告、删除技能、删除定时任务、在知识库文件详情里删除文件等操作不能撤销，执行前会先弹出确认框。

## 关闭提示

提示会自动消失，也可以点右侧的「×」关闭；在手机上用手指把提示向上或向左右轻扫也能关闭。关闭带「撤销」的提示后，这次操作就不能再撤销了（仍可按上面的说明从回收站等处恢复）。
