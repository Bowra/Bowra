# Benachrichtigungen

Öffnen Sie die Glocke oben auf der Seite. Eine Zahl zählt Vorgänge, die Ihre Aufmerksamkeit erfordern. Ein Punkt zeigt ungelesene Updates an.

## Einen Eintrag bearbeiten

Unter den offenen Aktionen stehen Vorgänge wie Freigaben und Rückfragen. Öffnen Sie den Eintrag oder wählen Sie die angebotene Aktion. Lesestatus und Bearbeitungsstatus sind getrennt. Ein Vorgang bleibt offen, bis er erledigt ist oder sich aufgelöst hat. Unter den Updates stehen etwa Entscheidungen und geteilte Inhalte. Die Aktion zum Archivieren entfernt den Eintrag aus Ihrer eigenen Liste. Bei mehreren Teams zeigt der Eintrag sein Team an und wechselt beim Öffnen dorthin. Öffnet sich eine eigene Team-Adresse, wählen Sie die Benachrichtigung dort erneut.

## Hinweise im Browser

Dringende offene Vorgänge können in einem geöffneten Bowhead-Tab als Hinweis erscheinen. Erlauben Sie Benachrichtigungen im Browser, wenn sie auch bei einem geöffneten Hintergrund-Tab angezeigt werden sollen. Das setzt eine sichere HTTPS-Adresse voraus. Bei mehreren Tabs wird ein Eintrag einmal angekündigt. Ereignisse von Zeiten ohne geöffneten Tab sehen Sie an der Glocke. Die Benachrichtigungen lassen sich in den Website-Einstellungen des Browsers ausschalten.
