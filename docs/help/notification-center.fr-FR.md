# Consulter les notifications

Ouvrez la cloche en haut de la page. Le nombre indique les éléments qui demandent une action. Un point signale des mises à jour non lues.

## Traiter un élément

La liste d’actions rassemble notamment les approbations et les demandes de précision. Ouvrez l’élément ou choisissez l’action proposée. La lecture et le traitement ont des états distincts. Un élément reste ouvert jusqu’à son traitement ou sa clôture. Les mises à jour regroupent entre autres les décisions et les contenus partagés. L’archivage retire l’élément de votre propre liste. Si vous appartenez à plusieurs équipes, l’élément indique la sienne. Lorsqu’une adresse d’équipe s’ouvre, sélectionnez de nouveau la notification depuis la cloche sur cette adresse.

## Notifications du navigateur

Les éléments urgents peuvent apparaître dans un onglet Bowhead ouvert. Autorisez les notifications du navigateur pour en recevoir aussi avec un onglet ouvert en arrière-plan, sur une adresse HTTPS. Un élément est annoncé une seule fois même si plusieurs onglets sont ouverts. Les éléments arrivés quand Bowhead était fermé restent accessibles depuis la cloche. Pour couper ces notifications, modifiez les paramètres du site dans le navigateur.
