# Erinnerungs-E-Mails

Wenn eine Freigabe noch offen und ungelesen ist oder eine geplante Aufgabe auf Ihre Antwort wartet und die Benachrichtigung ungelesen ist, kann Bowhead nach 30 Minuten eine Erinnerungs-E-Mail senden. Pro Eintrag gibt es eine Erinnerung. Gelesene, archivierte oder bereits erledigte Einträge erhalten keine Erinnerung.

## Erinnerungen einstellen

Öffnen Sie **Einstellungen → Konto** und schalten Sie Erinnerungs-E-Mails in den Einstellungen ein oder aus. Die Änderung wird sofort gespeichert und erfasst auch bereits fällige Erinnerungen. Ergebnis-E-Mails und dringende Meldungen geplanter Aufgaben werden gesondert gesteuert.

## Versand einer Aufgaben-E-Mail prüfen

Öffnen Sie die geplante Aufgabe und ihren Laufverlauf. Unter dem Lauf steht, ob eine Ergebnis- oder Warn-E-Mail gesendet wurde. Prüfen Sie bei ausbleibender Zustellung den angegebenen Grund. Für Erinnerungen benötigen Sie eine aktive Teammitgliedschaft und einen eingerichteten E-Mail-Dienst.
