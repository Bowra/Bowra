# 为团队启用 Agent 并配置能力

从「能力中心」打开「工具」或「团队插件」查看目录；获授权的团队管理员可在对应页面选择「管理工具源」或「管理团队插件」。管理页的返回链接回到目录，侧栏始终选中对应资源；从概览「团队管理」进入则返回原团队视角。浏览不会授予执行权限。

当你需要调整团队可用的系统内置子代理，或判断某项功能由谁开通时，使用本指南。成员创建的 Agent 由各自作者通过 [版本发布](publish-agent.zh-CN.md) 维护。

## 用 AI 起草纯文本助手

若页面提供 AI 草稿复核，你可以明确说明“仅整理我提供的文字，无需查询数据或联网”。生成纯文本方案后：

1. 检查草稿的用途和工作说明。
2. 确认页面说明无需工具或技能，勾选“只处理我提供的文字”的确认项。
3. 选择 **创建智能体**。若修改了草稿，保存检查后需要重新确认。

用途需要查询数据、读取文件或执行脚本时，请配置对应资源或改用手动配置。空工具列表本身不代表可以完成这些任务。页面未开放纯文本 AI 起草时，按已提供的手动入口操作。

## 创建只处理文字的助手

如果手动创建页面提示“仅处理你提供的文字时，可以不选工具和技能”，你可以创建摘要、翻译或文字整理助手：

1. 填写名称、路由说明和工作说明，明确它只处理你提供的内容。
2. 在选择工具时保持空选，继续到配置；技能也可以不选。
3. 检查配置并选择 **创建智能体**。新建内容默认仅自己可用。

没有这条提示时，请按当前页面要求操作。未配置工具的助手不能自行查询数据、访问外部系统或执行脚本；需要这些能力时，选择你有权使用的资源。已有助手的版本更新继续按管理页面提供的保存和发布流程操作。

## 开始之前

你是团队负责人或团队管理员，并能进入 **智能体 → 管理内置智能体**。

修改系统内置子代理配置作用于当前团队。若只想暂停自己聘用的某个 Agent，请使用 [个人停用](use-agent.zh-CN.md)，避免改变团队配置。

## 启用或停用系统内置子代理

1. 打开 **智能体 → 管理内置智能体**，找到目标智能体所在行。
2. 使用该行的启用开关调整状态。
3. 如果出现停用影响确认，阅读说明并确认目标后再提交。
4. 等待列表更新。确认状态文字显示为“已启用”或“已停用”。列表同时标出“系统默认”和“已改动”，方便识别团队自定义配置。

这个页面只展示系统随产品提供的智能体；自己创建、分享或从其他渠道获得的智能体，请到对应智能体的管理页面处理。某些智能体承担团队的关键能力（例如唯一能写画布报告的智能体），停用前会说明影响。停用只影响当前团队，之后可以随时重新启用。

列表中包含 **Coach** 和 **配置智能体**。这两个智能体只能启用或停用，以及修改名称和描述。配置对话框不显示其他字段，因为它们的模型、技能和指令由产品决定。停用后的内置智能体不再出现在智能体市场和对话的 @ 列表中，系统也不会再把新任务交给它。如果尝试修改智能体不允许的字段，保存会失败，提示会写出是哪个字段。

如果当前配置版本已经变化，页面会读取最新配置并再次执行本次启停，避免覆盖刚保存的其他设置；若短时间内版本再次变化，页面会提示配置已更新，请重试。

## 设置运行上限

创建和配置 Agent 时统一使用这里的团队上限，不再单独设置每个 Agent 的步数。

团队负责人和团队管理员可以在 **团队设置 › 智能体 › 运行上限** 里统一设置上限，对团队里所有智能体（内置和自定义）生效：

- **单轮时长上限**：一轮对话最多运行多久，默认 30 分钟，可设 10 分钟到 10 小时。助手会比这个时间早 5 分钟停下，留时间给 Lead 写回答。
- **单次模型调用时限**：默认“跟随单轮时长”，使用智能体当前剩余时间。也可选择“最多”，设置 30–36000 秒的较短上限；不能延长整轮时间，模型连接自己的超时仍会生效。
- **单个任务步数上限**：一个智能体做一件事最多走多少步，Team 默认 **不限**。页面显示有效部署策略时，Team/部署有限上限取较小值，分别约束 Lead 和每位助手。一步是一次模型决策，同次决策的多个工具调用不算多个模型步骤。显示的本地停滞时间用于保护没有活跃操作或推进的等待，模型与工具等待有各自的超时。
- **每轮工具调用上限**：一轮对话里所有智能体调用工具的总次数，默认 300 次，每种工具都一样计数。

1. 打开 **团队设置 › 智能体**，切到 **运行上限** 标签。
2. 修改需要调整的值。超出范围时，输入框下方会写出允许的范围，保存按钮不可用。
3. 选择 **保存**。新值从下一轮对话开始生效，正在进行的对话不受影响。想回到默认值时，选择 **恢复默认**。

达到上限时，对话显示具体原因并保留已知结果；有限步骤停止还会显示已用/允许次数。先检查这些结果，再缩小剩余请求范围。只有对话提供受支持的续跑入口时才使用「继续」，并非每次停止都能原地续跑。恢复 Team 默认值不会移除页面显示的部署上限。上限设得越大，单次任务能做得越多，但等待时间和用量也会相应增加。

## 设置沙箱和 HTML 上限

团队所有者和管理员还可以在 **团队设置 › 智能体 › 运行上限** 调整：

- **沙箱计算**：默认执行时长（初始为 120 秒）和最长执行时长（初始为 600 秒）。默认时长不能超过最长时长；页面显示的部署上限是硬边界，提高它需要部署维护者操作。
- **HTML 报告**：单个嵌入 HTML 文件的大小上限，包含内嵌图片与数据。初始为 25 MiB，最大 50 MiB。较大的文件和复杂表格需要更多浏览器内存与处理时间。已保存的团队值及部署默认值继续生效；若旧上限阻止预览，请调高此项并保存。它限制整个文件的大小，与模型输出 token 数是不同设置。

页面显示部署默认值和允许范围。编辑后选择 **保存沙箱和 HTML 上限**。需要重新继承部署默认值时，选择 **使用部署默认值**，核对数值后再保存。任务运行与沙箱／HTML 区域的更改分别保存。其他管理员先保存时，页面会保留你的更改；请放弃更改并重新加载最新设置，再进行编辑。

沙箱更改对新任务生效，运行中的任务保留启动时的上限。HTML 预览在下次加载时采用报告所属团队的设置。提高时长可以帮助较慢的计算，但不能修复不可用的执行器；执行结果未知时，应先核对原任务再重试。

## 调整职责和自动阅读的技能

1. 在目标子代理所在行选择 **配置**。表单按“名称与用途”“运行设置”“团队指导”分组；滚动表单时，“取消”和“保存”始终可见。
2. 根据需要修改 **显示名称**、**路由描述** 或 **追加团队口径**，让系统和使用者更清楚它的用途。
3. 在 **主要职责** 中选择界面提供的受支持选项；需要跟随产品默认设置时，选择对应的默认项。
4. 在 **自动阅读的技能** 中选择该子代理需要的方法。先确认技能本身可用且适合团队使用。
5. 需要时调整 **模型档位**（分析、写作、数据建模或轻量任务；只影响这一个内置智能体）。步数、时长和工具调用次数在 **运行上限** 标签里统一设置，见下一节。
6. 选择 **保存**。
7. 重新打开 **配置**，确认保存值与预期相符；再用有权访问测试空间和数据的账号执行一个符合用途的任务。

想撤回团队对某个内置智能体的改动时，打开该已改动行的 **⋯ → 恢复默认**。只想查看某个智能体的标识和模型而不做修改时，打开该行的 **⋯ → 详情**；能看到列表的成员都可以打开。

“主要职责”帮助系统优先选择合适的 Agent。选择职责或 Skill 不会增加成员的数据访问权限，也不保证外部工具已配置完成。

### 操作失败时

- 提示配置版本已经变化时，请在最新配置上重试。
- 提示团队配置尚未就绪或暂不可用时，请联系系统管理员检查服务升级状态，待服务恢复后重试。
- 提示系统内置智能体已移除时，该行会从当前列表中移除，无需继续操作。

页面无法可靠读取团队设置时不会开放修改，避免把系统默认值误当成团队当前配置。

系统内置子代理的工具、返回格式约定和可调用同伴由产品定义，不能在这个弹窗中任意替换。需要独立维护工作方式时，应由作者创建和发布自定义 Agent。

## 只调整自己可用的 Skill

1. 打开 **能力中心 → 技能与流程**，在相应分组中找到 Skill。自己的技能和固化流程可通过 **我的** 筛选查看；团队流程页的个人流程链接也会打开这个筛选。
2. 调整该 Skill 的启停开关，等待保存完成。
3. 刷新页面，确认开关状态保持为你的选择。

**团队技能** 分组的开关只影响你的会话。如果团队已全局停用该 Skill，你的个人开关不能将它恢复为团队可用状态。

## 如何选择文档类 Skill？

**文档与导出**中的内置 Skill 按用途分组：

| 分组           | 适用用途                                                  |
| -------------- | --------------------------------------------------------- |
| 方法与写作参考 | 阅读、编辑和写作文件的方法；实际操作取决于可用能力。      |
| 基础文档生成   | 从文字、列表和表格新建基础文件，不修改你上传的模板。      |
| 已有报告导出   | 把画布上已有的报告下载为 Word、PDF、PowerPoint 或 Excel。 |

分组不会增加访问权限或开启尚未提供的功能。自己的 Skill 和团队 Skill 保留原有分组与名称。

运行过程中的**创建新演示稿**表示从提供的内容新建基础可编辑 PPTX。导出已有 Canvas 报告是另一项操作。Community 不提供私有 PowerPoint 模板草稿 Plugin。

## 要开通其他功能，去哪里？

| 需要处理的事情                            | 入口或负责的人                                                 | 应确认的结果                                             |
| ----------------------------------------- | -------------------------------------------------------------- | -------------------------------------------------------- |
| 团队模型、搜索或图像等服务配置            | 团队负责人/管理员：**团队设置 → 模型**，按页面支持的配置项操作 | 对应服务配置和验证成功                                   |
| 团队外部工具来源及连接                    | 团队负责人/管理员：**能力中心 → 工具 → 管理工具源**            | 工具来源有效、连接可用，目标成员具备业务使用资格         |
| 北极九章连接                              | 团队负责人/管理员：**团队设置 → 数据源**                       | 当前数据源连接启用；成员还需本人数据身份与数据授权       |
| 页面提示功能尚未开启                      | 部署维护者                                                     | 当前版本与功能开放配置满足要求                           |
| 某成员创建的 Agent 的职责、Skill 或提示词 | 该 Agent 的作者：**我创建的 → 管理配置**                       | 修改通过相应检查并发布生效                               |
| 平台没有提供的新能力定义                  | 产品维护者                                                     | 确认产品是否支持；普通成员没有独立发布平台能力定义的入口 |

这是配置定位表；各服务具体的凭据填写和接入验证需要按对应服务配置执行。

## 查看能力说明时应注意什么？

Agent 详情中的结果契约（Outcome）用于说明它承诺完成哪类结果，并可能显示实现证据和当前可用性。团队插件则是管理员维护的 Tool 与 Skill 组合，可由 Agent 作者选择。两者都不能代替实际的功能、工具和数据授权。

若需要通过细粒度规则限制某人使用 Tool、Skill 或内置能力，请由团队治理者和部署维护者确认该规则是否已强制执行，并用目标身份验证。部分部署只记录通用规则的拒绝判断，不能仅凭规则已保存就认为调用已被阻止。
