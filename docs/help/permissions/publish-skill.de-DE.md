# Team-Skill veröffentlichen

Ein Skill ist eine wiederverwendbare Methode. Persönliche Bearbeitung, Einreichung im Team, Freigabe und Aktivierung durch einzelne Mitglieder sind verschiedene Aktionen.

## Zum ersten Mal einreichen

1. Öffnen Sie **Meine Skills** und bearbeiten sowie speichern Sie Ihre persönliche Version.
2. Wählen Sie **Im Team einreichen**, sobald diese Option verfügbar ist.
3. Prüfen Sie Name, Beschreibung, Anweisungen, Abhängigkeiten und vorgesehenen Einsatz und reichen Sie den Skill ein.
4. Ist eine Freigabe erforderlich, prüft eine teamverantwortliche oder administrierende Person die Einreichung im Teamablauf.

Nach der Freigabe können Mitglieder die Teamversion finden. Ob der Skill in einer Sitzung verwendet werden kann, hängt zusätzlich von den teamweiten Verfügbarkeitseinstellungen und der persönlichen Aktivierung ab.

## Skill aktualisieren

Bearbeiten und speichern Sie Ihren veröffentlichten Skill und reichen Sie die Aktualisierung ein. Bis sie genehmigt und veröffentlicht ist, verwenden Kolleginnen und Kollegen normalerweise weiterhin die bestehende veröffentlichte Version. Gehen Sie nicht davon aus, dass das Speichern eines persönlichen Entwurfs die Teamversion ändert.

Nach der Genehmigung verwenden Agents, die den Skill nutzen, die neue Version beim nächsten Lauf; ihre Eigentümer sehen, dass ein verwendeter Skill aktualisiert wurde, mit der Empfehlung, den Agent erneut zu evaluieren. Wird die Teamversion selbst direkt bearbeitet und erneut zur Prüfung gestellt, können Agents, die sie enthalten, sie nicht verwenden und nicht damit gespeichert oder veröffentlicht werden, bis Teamverantwortliche oder -administratoren sie erneut genehmigen.

## Ablehnung, Abbruch und direkte Teamverwaltung

Lesen Sie bei einer Ablehnung die Rückmeldung, überarbeiten Sie Ihre persönliche Version und reichen Sie sie erneut ein, sobald sie bereit ist. Brechen Sie eine ausstehende Einreichung nur ab, wenn der Ablauf diese Aktion anbietet. Eine direkte Teamänderung durch die Administration ändert die Teamversion. Stimmen Sie sich mit der ursprünglich erstellenden Person ab, damit spätere Aktualisierungen einander nicht überschreiben.

Fehlt **Im Team einreichen**, prüfen Sie, ob es sich um Ihre gespeicherte persönliche Version handelt und ob die Teamfunktion verfügbar ist. Eine Nutzungsliste für einen Skill zeigt nur Agents und Ressourcen, die Sie sehen dürfen. Die Ansicht gewährt keine Berechtigung zum Bearbeiten, Deaktivieren oder Löschen.
