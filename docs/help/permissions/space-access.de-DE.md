# Zugriff auf einen Bereich gewähren

Nutzen Sie diese Anleitung, wenn eine Kollegin oder ein Kollege in einem Bereich mitarbeiten soll. Sie benötigen die Berechtigung, den betreffenden Bereich zu verwalten. Die Rolle als Teamadministration allein macht Sie nicht zur Bereichsadministration.

## Bevor Sie beginnen

Prüfen Sie, ob Team und Bereich stimmen, welches Konto die Kollegin oder der Kollege verwendet und welche Arbeit erledigt werden soll. Wählen Sie die Rolle mit den geringstmöglichen Berechtigungen, die dafür ausreicht. Die Aufnahme in einen Bereich gewährt keinen Zugriff auf externe Geschäftsdaten oder private Ressourcen.

## Mitglied hinzufügen

1. Öffnen Sie den Zielbereich und wählen Sie **Bereichseinstellungen → Mitglieder**.
2. Wählen Sie **Mitglied hinzufügen**, suchen Sie die Kollegin oder den Kollegen und wählen Sie eine Rolle aus.
3. Speichern Sie die Änderung.
4. Bitten Sie die Person, die Seite zu aktualisieren, den Bereich auszuwählen und zu prüfen, ob die vorgesehenen Einstiege sichtbar sind.

Verwenden Sie **Mitwirkende Person** für gewöhnliche Arbeit, **Leseberechtigte Person** für eine Prüfung ohne Bearbeitung und **Bereichsadministration** nur für Personen, die Mitgliedschaft oder unterstützte Bereichseinstellungen verwalten müssen.

## Zugriff ändern oder entfernen

Öffnen Sie die Mitgliederliste, wählen Sie das Mitglied aus, ändern Sie die Rolle oder entfernen Sie den Zugriff und speichern Sie. Öffnen Sie die Liste erneut, um die Änderung zu bestätigen. Durch das Entfernen endet der künftige Zugriff über diesen Bereich. Die eigenen Arbeiten der Person werden dadurch nicht gelöscht; andere Team-, Ressourcen- oder Datenberechtigungen werden ebenfalls nicht automatisch widerrufen.

Wenn Sie den Einstieg zur Mitgliederverwaltung nicht sehen, wenden Sie sich an eine aktuelle Bereichsadministration. Kann die Kollegin oder der Kollege den Bereich öffnen, aber keinen Agent verwenden oder Daten abfragen, folgen Sie [Zugriffsprobleme beheben](troubleshoot-access.de-DE.md).
