# 给同事开通空间访问权限

当同事已经加入团队，需要进入销售、财务等空间工作时，使用本指南为其分配空间角色。

## 开始之前

- 你是要管理的空间的管理员；空间处于可用状态。
- 对方是当前团队的有效成员。尚未加入团队时，请先由团队负责人或管理员在 **团队设置 → 成员** 中邀请或添加对方。

团队负责人或团队管理员也可以从团队成员页管理空间授权，操作见本文后半部分。

## 选择合适的空间角色

| 角色     | 什么时候选                                       |
| -------- | ------------------------------------------------ |
| 成员     | 对方需要在空间内开展日常工作、读写获准协作的内容 |
| 只读成员 | 对方只需要查看已获准读取的内容                   |
| 管理员   | 对方需要维护空间设置、成员及其角色               |

角色作用于这个空间。空间内的私有会话、文件及外部数据仍按各自的权限开放。

## 添加成员到空间

1. 选择要管理的空间，打开头像菜单中的 **空间设置**。
2. 在设置导航中选择 **空间访问**。
3. 检查 **访问权限对象** 显示的空间名称。若需要切换，在此选择目标空间；这只切换正在管理的名单。
4. 在 **添加现有团队成员** 区域，从 **团队成员** 列表选择同事，并核对姓名或邮箱。
5. 在 **角色** 中选择所需角色，然后选择 **添加到空间**。
6. 看到“成员已添加到空间”后，在 **活跃成员** 列表中确认同事和角色均正确。

请同事刷新空间列表，确认能进入该空间。若需要运行分析，还应确认其 Agent 和数据访问条件，见 [排查访问问题](troubleshoot-access.zh-CN.md)。

## 调整或移除已有权限

**调整角色：** 在 **活跃成员** 列表中找到同事，在其角色下拉框中选择新角色。选择后会提交保存，没有另外的“保存”按钮；等待列表刷新，再确认新角色。需要改回时，在同一处重新选择原角色。

**移除成员：** 在同事所在行选择 **移除**，核对确认框中的对象，再选择 **移除**。完成后确认该成员从当前空间名单中消失。此操作移除的是空间访问资格，不是团队账号。

空间需要保留管理员。若提示对方是唯一管理员，先为另一位合适成员授予管理员角色，再处理原管理员。

## 团队管理员从哪里操作？

如果你有团队治理权限，可按以下路径操作，不必先进入目标空间的内部设置：

1. 打开 **团队设置 → 成员**，找到同事。
2. 在该成员的 **更多** 菜单中选择 **管理空间权限**。
3. 在 **已授权空间** 中查看现有权限；若要添加，选择 **添加空间**，搜索目标空间，选择角色，再选择 **授权**。
4. 在已授权空间列表中确认目标空间及角色正确。

对已授权空间，调整角色后选择 **保存角色** 才会生效；选择 **移除** 可撤销该空间授权。此处的授权操作不会替你取得该空间的内部管理身份。

## 在团队设置中管理空间

团队负责人和管理员可在 **团队设置 → 空间** 创建空间，并查看团队内各空间的成员数、管理员数和状态。空间内的内容仍只对具备相应空间权限的成员开放。

- 空间多时，可以输入名称或内部 ID 搜索，按全部、启用中或已归档筛选，并在列表底部翻页。**每页** 可显示 20、50 或 100 个空间；修改搜索条件、状态或每页数量会回到第一页。
- 列表暂时加载失败时，页面会显示错误和 **重试** 按钮。搜索请求失败不表示没有匹配的空间，可以再次点 **搜索** 重试相同条件。
- 在空间行上可以管理管理员、归档或恢复空间。归档会直接执行，并在屏幕上方给出「撤销」，撤销即立刻恢复空间。归档会暂停该空间的新工作和成员修改，也会暂停其中的定时任务。恢复时如果没有在任的空间管理员，需要先指定一位启用中的团队成员；恢复空间时，因归档而暂停的定时任务会一起重新开启，并从恢复的时刻起按计划运行，归档期间错过的运行不会补跑；成员自己暂停的任务保持暂停。如果任务所属成员已开启的定时任务达到上限，这个任务会保持暂停并说明原因。

## 从通知处理空间分配

团队负责人或管理员收到“有成员需要分配空间”通知后，点击通知可打开 **团队设置 → 空间**。较早收到的通知在升级后也可使用。核对成员当前的空间访问情况后，可按上方“团队管理员从哪里操作？”的步骤分配空间和角色。

## 遇到问题

| 你看到的情况                       | 怎样处理                                                                                 |
| ---------------------------------- | ---------------------------------------------------------------------------------------- |
| 头像菜单没有“空间设置”             | 确认当前选中的空间；请团队负责人/管理员检查你是否被授予该空间管理员角色                  |
| 找不到要添加的同事                 | 先查活跃成员名单，确认是否已加入；若不在名单中，请团队管理员确认对方已加入团队且账号有效 |
| 没有可添加的团队成员               | 请先完成团队成员邀请；空间页不能直接创建账号                                             |
| 空间已归档或找不到                 | 请团队负责人/管理员确认空间状态；归档空间不能继续修改内部配置                            |
| 能进入空间，仍看不到某份文件或数据 | 请资源拥有者检查分享范围，或请数据权限维护者检查外部数据授权                             |
