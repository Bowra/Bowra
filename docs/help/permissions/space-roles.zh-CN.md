# 空间角色与协作权限

空间是团队内组织工作的地方，例如销售分析空间或财务空间。你在一个空间中的角色，决定你在这里承担的协作和管理职责。

**加入空间、管理空间和获得某份内容的访问权限，是三件不同的事。** 加入空间不代表能看到所有人的对话、报告和文件，也不代表自动获得外部业务数据权限。

## 三种空间角色有什么区别？

| 角色       | 适合什么工作                                   | 管理职责                                               |
| ---------- | ---------------------------------------------- | ------------------------------------------------------ |
| 空间管理员 | 除了日常协作，还需要维护空间                   | 管理空间设置、添加已有团队成员、调整空间角色或移除成员 |
| 成员       | 在空间中开展日常工作，使用和维护获准操作的内容 | 不负责空间设置和成员管理                               |
| 只读成员   | 以查看已获准内容为主的协作                     | 不负责空间设置和成员管理；知识矩阵和结构化记录不可编辑 |

具体内容能否查看、编辑、下载或执行，还取决于这份内容的授权及当前页面提供的操作。空间角色并不代替每份内容的权限判断。

同一个人在不同空间中可以有不同角色。例如，你在销售空间是管理员，在财务空间是只读成员；切换空间后，可用的管理入口和操作可能不同。

## 如何加入空间？由谁调整角色？

先确认你已加入对应团队，再联系目标空间的管理员，说明你需要参与的工作。空间管理员可以从已有团队成员中添加你，并选择合适的空间角色。团队负责人或管理员也可以安排空间访问。

已有空间角色需要调整时，请联系空间管理员或团队管理员。只需要参加日常协作时，通常选择成员；需要维护空间设置和名单时，再安排空间管理员。

具体步骤见[给同事开通空间访问](space-access.zh-CN.md)。空间需要保留管理员，交接时应先安排接任人。

## 加入空间后，能看到哪些内容？

| 内容             | 你需要知道的边界                                                             |
| ---------------- | ---------------------------------------------------------------------------- |
| 对话与任务       | 加入空间不会让所有同事的对话自动向你开放；团队管理人员另有相应的任务管理职责 |
| 报告与文件       | 按内容归属和分享范围开放；能查看不一定能编辑                                 |
| 空间知识         | 可访问的空间知识用于协作；个人知识不会仅因同处一个空间就自动共享             |
| 智能体与工作方法 | 还需要具备相应使用资格；能使用不等于能修改作者配置                           |
| 外部业务数据     | 仍需相应数据授权；空间管理员身份不会替代数据权限                             |

同事把报告分享给你，不一定意味着你已加入报告所在的空间；反过来，加入空间也不会自动获得每份报告的访问权。

## 空间管理员和团队管理员有什么区别？

空间管理员负责一个空间的内部协作。团队管理员负责团队成员、空间安排和团队配置。两种角色分别授予：团队普通成员可以担任空间管理员，团队管理员也可能没有某个空间的内部设置权限。

如果你能打开团队设置，却找不到当前空间的设置入口，请确认当前选中的空间，并请有权管理的人核对你的空间角色。更多区别见[团队角色与权限](team-roles.zh-CN.md)。

## 空间归档或被移出后，会发生什么？

**空间归档**后，不能继续在其中开展新的工作或修改空间配置。已获准查看的历史内容仍按原有权限开放。需要重新开展工作时，请联系团队负责人或管理员确认是否恢复空间；恢复后，因归档而暂停的定时任务会一起重新开启，成员自己暂停的保持暂停。

**被移出空间**后，你不再具有这个空间的成员资格，但团队账号不会因此被删除。移出空间也不等于删除已经产生的历史内容，或自动撤销每一份内容的分享。某份历史报告或文件是否仍可打开，取决于它当前的访问授权。

如果是人员交接，请同时确认空间成员安排、相关内容的分享范围和任务交接。需要继续参与工作时，联系空间管理员或团队管理员重新安排访问。

## 遇到问题，怎样处理？

| 情况                                 | 建议                                                         |
| ------------------------------------ | ------------------------------------------------------------ |
| 看不到要加入的空间                   | 确认当前账号和团队，再请空间管理员或团队管理员检查成员安排   |
| 能进入空间，但打不开某份内容         | 联系内容拥有者确认分享对象和权限                             |
| 能查看内容，却找不到编辑操作         | 确认空间角色及这份内容的编辑权限；不要仅凭能查看就判断能编辑 |
| 另一个空间能用的功能，在这里不能用   | 核对当前空间角色、可用资源及数据授权                         |
| 已是空间管理员，仍无法配置模型或工具 | 这些通常属于团队配置，请联系团队负责人或管理员               |
| 空间已恢复，定时任务没有继续运行     | 请任务负责人检查任务状态和运行条件                           |
