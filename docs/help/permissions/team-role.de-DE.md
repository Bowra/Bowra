# Teamadministration zuweisen

Nutzen Sie diese Anleitung, um Aufgaben der Teamverwaltung zu übertragen. Teamadministratoren dürfen unterstützte teamweite Einstellungen und die Mitgliedschaft verwalten. Wählen Sie deshalb Personen aus, die diese Verantwortung übernehmen müssen. Für eng begrenzte Aufgaben genügt eine Bereichsrolle.

## Bevor Sie beginnen

Sie müssen die teamverantwortliche Person sein oder die Produktberechtigung haben, Teamrollen zu ändern. Prüfen Sie das Konto der Person und die konkreten Aufgaben, die sie übernehmen soll. Eine Teamrolle gewährt weder Zugriff auf persönliche MCP-Verbindungen noch Eigentum an privaten Ressourcen oder die Datenidentität einer anderen Person.

## Rolle ändern

1. Öffnen Sie **Team-Einstellungen → Mitglieder**.
2. Suchen Sie das Mitglied und wählen Sie **Teamrolle ändern**.
3. Wählen Sie **Teamadministration** und speichern Sie.
4. Öffnen Sie den Mitgliedseintrag erneut und prüfen Sie die angezeigte Rolle.

Die neue Teamadministration kann die Funktionen verwalten, die für diese Rolle verfügbar sind. Für einen bestimmten Bereich kann weiterhin eine zusätzliche Rolle als Bereichsadministration erforderlich sein. Für jede Aufgabe muss sie ihr eigenes Konto und ihre eigene Datenberechtigung verwenden.

Um die Person wieder zur gewöhnlichen Mitgliedsrolle zurückzustufen, wiederholen Sie diese Schritte und wählen **Mitglied**. Tun Sie dies, sobald die Verwaltungsaufgabe endet, und prüfen Sie anschließend, ob die Person in Bereichen weiterhin eine Administratorrolle hat.
