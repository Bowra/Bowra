# 将成员设为团队管理员

当你希望同事协助管理团队成员、模型、工具和其他团队配置时，可将其设为团队管理员。

## 开始之前

- 你是当前团队的 **负责人**。
- 对方已加入团队，账号有效。
- 团队处于允许修改配置的状态。

如果同事只负责某个空间，请改用 [分配空间管理员](space-access.zh-CN.md)。

## 修改团队角色

1. 打开头像菜单中的 **团队设置**，选择 **成员**。
2. 找到目标成员，用姓名和邮箱核对身份，然后选择该行的 **修改角色**。
3. 在 **选择新团队角色** 中选择 **管理员**。
4. 根据需要填写 **原因**，例如“协助维护团队模型与工具配置”。
5. 选择 **确认修改角色**。
6. 返回成员列表，确认对方的角色显示为“管理员”。如果提交失败，先按提示处理，再刷新列表确认，避免只凭弹窗关闭判断成功。

## 修改后对方能做什么？

对方可以处理获准的团队配置和日常成员管理，也可审批提交给团队的 Agent 或 Skill。团队角色的再分配仍由团队负责人处理。

对方的空间身份、他人 Agent 编辑权和外部业务数据权限不会因此自动增加。需要这些权限时，分别按对应指南处理。

## 改回普通成员

在同一入口选择 **成员**，填写至少 10 个字符的原因，再选择 **确认修改角色**。完成后检查成员列表。

如果提示涉及最后一位管理员的保护，请先安排另一位管理员。团队负责人不能在这个弹窗中直接降级；变更负责人需使用单独的负责人转让操作。

## 遇到问题

| 你看到的情况                       | 怎样处理                                                             |
| ---------------------------------- | -------------------------------------------------------------------- |
| 可以邀请成员，但不能修改团队角色   | 你可能是团队管理员；请团队负责人执行角色修改                         |
| “确认修改角色”不可选               | 检查是否选择了不同于当前的角色；若原因被标为必填，至少填写 10 个字符 |
| 对方有管理员角色，但打不开空间设置 | 另行检查对方在目标空间是否具有管理员身份                             |
