# 团队角色与权限

团队角色决定你在团队中承担哪些管理职责。大多数日常工作不需要管理员身份：只要已加入相应空间，并获得所需内容和数据的使用权限，就可以开展获准的工作。

团队角色和空间角色分别设置。例如，你可以是团队成员，同时担任销售空间的管理员。了解空间内的区别，请看[空间角色与协作权限](space-roles.zh-CN.md)。

## 四种团队角色有什么区别？

| 角色       | 主要职责                                                                   | 需要区分的边界                                     |
| ---------- | -------------------------------------------------------------------------- | -------------------------------------------------- |
| 负责人     | 负责团队关键管理事项，也能处理日常管理；调整成员的团队角色、交接负责人身份 | 一个团队只有一位负责人                             |
| 管理员     | 协助管理成员、空间、模型、工具及其他团队配置，处理相应审批                 | 不能代替负责人调整团队角色或转让负责人身份         |
| 审计管理员 | 具有团队只读可见范围                                                       | 企业审计工作台和导出由商业版提供                   |
| 成员       | 使用获准的空间、智能体、知识和其他业务功能                                 | 没有团队管理职责；仍可管理自己拥有且获准编辑的内容 |

管理功能的具体范围取决于团队已开通的服务和当前页面提供的操作。额度与计费管理由负责人或团队管理员处理（操作步骤见[查看和补充额度](../credits.zh-CN.md)）。

## 谁能管理什么？

| 你要完成的事情                     | 通常由谁处理                                                       |
| ---------------------------------- | ------------------------------------------------------------------ |
| 邀请同事加入团队、处理团队成员问题 | 负责人或管理员                                                     |
| 修改一个人的团队角色、交接负责人   | 负责人                                                             |
| 创建或归档空间、安排空间管理员     | 负责人或管理员                                                     |
| 配置团队模型、工具和数据连接       | 负责人或管理员                                                     |
| 查看用量、处理额度问题             | 负责人或管理员                                                     |
| 修改某个空间的名称、设置或成员     | 该空间的管理员；团队负责人或管理员也可从团队成员管理中安排空间访问 |
| 分享或编辑某份报告、文件或智能体   | 按这份内容的拥有者、分享范围和可用操作判断                         |

## 如何查找团队成员？

负责人或管理员可以打开「团队设置 → 成员」，在成员列表顶部的「搜索成员」输入框中输入昵称或邮箱的全部或部分内容。列表会即时显示匹配的成员，英文大小写不影响搜索。

清空搜索栏即可重新显示全部成员。如果没有匹配结果，可以换一个昵称或邮箱关键词再试。

## 成为管理员，就能查看和修改所有内容吗？

不能把管理身份理解为对所有内容的无限访问权。团队管理人员可以按职责查看任务追踪或管理分享，但具体报告、文件和智能体仍有各自的访问与编辑范围。

管理模型或数据连接，也不等于获得外部系统的全部数据权限。查询业务数据时，仍取决于你的数据身份和相应授权。

同样，能够使用同事分享的智能体，不代表可以修改它的配置。需要修改时，请联系该智能体的拥有者。

## 我只负责一个空间，需要成为团队管理员吗？

通常不需要。空间管理员适合维护某个空间的设置和成员；团队管理员负责更广的团队管理。

例如，只负责销售空间的同事，可以保持团队成员身份，同时担任销售空间管理员。这样既能处理本空间的协作安排，也不会承担模型、工具等团队配置职责。

## 如何确认或调整我的角色？

如果不确定自己的团队角色，可以请团队负责人或管理员核对。需要调整团队角色时，请说明你要承担的职责，由负责人处理。

负责人可参考[设置团队管理员](team-role.zh-CN.md)完成操作。如果只是需要进入某个空间，应申请空间访问，而不是先升级团队角色。

## 遇到访问问题，先联系谁？

- **不能加入团队、需要调整团队角色**：联系团队负责人或管理员；角色调整由负责人处理。
- **找不到空间、需要协助空间管理**：联系目标空间管理员或团队管理员。
- **打不开某份报告、文件或智能体**：联系内容拥有者核对分享范围。
- **无法查询业务数据**：联系负责该数据的人员核对数据授权。
