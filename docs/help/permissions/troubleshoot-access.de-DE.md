# Zugriffsprobleme beheben

Wenn ein Einstieg fehlt, ein übernommener Agent nicht ausgeführt werden kann oder eine Datenabfrage abgelehnt wird, beginnen Sie mit dem beobachteten Problem und wenden Sie sich an die zuständige Stelle für diesen Bereich.

## Zuerst drei Punkte prüfen

1. Prüfen Sie das aktuelle Konto, Team und den Bereich.
2. Bestimmen Sie die fehlgeschlagene Aktion: Ressource finden, bearbeiten, veröffentlichen oder Aufgabe ausführen.
3. Notieren Sie den genauen Meldungstext, den Ressourcennamen und die Uhrzeit. Senden Sie in einer Supportanfrage keine Passwörter, Geheimnisse oder vollständigen Geschäftsdaten.

## Agent ist sichtbar, kann aber nicht ausgeführt werden

Öffnen Sie **Meine übernommenen Agents**. Aktivieren Sie einen als deaktiviert markierten Agent erneut. Wurde der Zugriff entzogen, bitten Sie die erstellende Person, die Zielgruppe zu prüfen, und die Administration, Team- und Bereichsmitgliedschaft zu prüfen. Ist der Agent übernommen, aber nicht verfügbar, lesen Sie den Verfügbarkeitshinweis. Die erstellende Person prüft Veröffentlichung und Abhängigkeiten, die Teamadministration die Teamverbindungen. Versuchen Sie es nach der Behebung in einem freigegebenen Bereich erneut.

## Agent läuft, kann aber keine Datarc-Daten abfragen

1. Eine teamverantwortliche oder administrierende Person prüft unter **Team-Einstellungen → Datenquellen**, ob eine Datarc-Verbindung aktiviert ist.
2. Die zuständige Datarc-Administration bestätigt, dass Ihr Bowra-Benutzer eine gültige Datenidentität hat. Verwenden Sie niemals das Konto einer anderen Person als Zugriffsnachweis.
3. Wählen Sie bei entsprechender Aufforderung einen Datarc-Arbeitsbereich aus der Liste, die Ihrer Identität zur Verfügung steht. Fehlt er, muss die zuständige Datenadministration den Zugriff dieser Identität anpassen.
4. Wiederholen Sie die ursprüngliche Abfrage im richtigen Bereich und prüfen Sie den Datenumfang. Ein leeres Ergebnis kann auch durch Filter, Zeitraum oder Datenqualität verursacht werden.

Der Bowra-Bereich und ein Datarc-Arbeitsbereich sind unterschiedliche Objekte. Der Zugriff auf den einen bedeutet nicht automatisch Zugriff auf den anderen.

## Bearbeitung oder Veröffentlichung nicht möglich

Prüfen Sie, ob Sie die Ressource erstellt haben, ob Sie die persönliche Version statt einer Teamdetailseite bearbeiten und ob Ihre Änderung gespeichert ist. Während eine Freigabe aussteht, verwenden Kolleginnen und Kollegen weiterhin die alte Version. Teamverantwortliche oder Teamadministratoren kümmern sich um Freigaben und teamweite Konfigurationen. Bei nicht verfügbaren Funktionen oder Bereitstellungsproblemen wenden Sie sich an die für die Bereitstellung zuständige Administration.

## Bericht sichtbar, Anhänge oder Quelldaten nicht verfügbar

Prüfen Sie die Berechtigungen für Bericht, Anhänge und Quelldaten jeweils separat. Ein geteilter Bericht kann seine erstellten Inhalte zeigen, ohne Zugriff auf die private Unterhaltung, Dateien oder Datenidentität der erstellenden Person zu gewähren. Fragen Sie die für die Datei oder den Bericht zuständige Person nach Anhängen und die Datenadministration nach einer neuen Abfrage.

Wenn eine Richtlinienregel gespeichert erscheint, ein Aufruf aber weiterhin ausgeführt wird, prüfen Sie die Ressource und Aktion der Regel. Fragen Sie anschließend die für die Bereitstellung zuständige Administration, ob der Durchsetzungsmodus aktiviert ist. Überprüfen Sie die Korrektur mit einem eingeschränkten Konto.
