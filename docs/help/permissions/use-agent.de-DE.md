# Agent übernehmen und verwenden

Verwenden Sie einen veröffentlichten Agent aus dem Agent-Verzeichnis, wenn er mit Ihnen geteilt wurde. Durch das Übernehmen wird er Ihrem persönlichen Arbeitsbereich hinzugefügt. Sie werden dadurch weder zur erstellenden Person noch erhalten Sie zusätzlichen Datenzugriff.

## Agent übernehmen

1. Öffnen Sie das Agent-Verzeichnis in einem Bereich, in dem Sie arbeiten dürfen.
2. Prüfen Sie Zweck, Verfügbarkeit, Abhängigkeiten und Zielgruppe des Agents.
3. Wählen Sie **Übernehmen**. Prüfen Sie, ob der Agent unter **Meine übernommenen Agents** erscheint.
4. Wählen Sie den Agent in einer neuen oder bestehenden Aufgabe aus und geben Sie das Ziel sowie relevantes Material an.

Die Aufgabe wird mit Ihren eigenen Team-, Bereichs-, Ressourcen- und Datenberechtigungen ausgeführt. Ein Agent kann übernommen, aber vorübergehend nicht verfügbar sein, wenn sich seine Version, Abhängigkeiten oder die Teamkonfiguration ändern.

## Agent pausieren oder entfernen

Öffnen Sie **Meine übernommenen Agents** und wählen Sie **Deaktivieren**, wenn der Agent in Ihren Sitzungen nicht verwendet werden soll. Sie können ihn später wieder aktivieren, sofern er weiterhin geteilt und verfügbar ist. Wählen Sie **Entfernen** oder **Nicht mehr verwenden**, um ihn aus Ihrem Arbeitsbereich zu entfernen. Diese Aktionen betreffen nur Ihre Nutzung, nicht den veröffentlichten Agent oder andere Mitglieder.

Teamverantwortliche und Teamadministratoren können unterstützte Standard-Agents auf Teamebene konfigurieren. Ein Standard-Agent setzt die Datenberechtigung eines Mitglieds jedoch nicht außer Kraft. Ist ein Agent sichtbar, kann aber nicht ausgeführt werden, folgen Sie [Zugriffsprobleme beheben](troubleshoot-access.de-DE.md).
