# Recruter et utiliser un Agent

Choisissez dans le répertoire un Agent publié partagé avec vous. Le recrutement l’ajoute à vos outils de travail personnels, sans vous rendre auteur ni accorder d’accès supplémentaire aux données.

## Recruter

1. Ouvrez le répertoire depuis un espace où vous pouvez travailler.
2. Vérifiez objectif, disponibilité, dépendances et public.
3. Choisissez **Recruter** et vérifiez sa présence dans **Recrutés par moi**.
4. Sélectionnez-le dans une tâche nouvelle ou existante, puis indiquez objectif et documents pertinents.

La tâche utilise vos propres autorisations d’équipe, d’espace, de ressources et de données. Un Agent recruté peut devenir temporairement indisponible après une modification de version, de dépendances ou de configuration.

## Mettre en pause ou retirer

Dans **Recrutés par moi**, **Désactiver** empêche son utilisation dans vos sessions. Réactivez-le s’il reste partagé et disponible. **Retirer** ou **Annuler le recrutement** le retire de votre sélection personnelle. Ces actions ne changent ni l’Agent publié ni l’usage des autres membres.

## État « Indisponible »

Le marché, **Recrutés par moi** et les détails affichent **Indisponible** avec une raison principale. Après résolution, l’état se rétablit sans nouveau recrutement. Si l’Agent n’est pas encore recruté, **Recruter** est proposé.

| Raison                                                 | Action                                                                                                                                                             |
| ------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Désactivé ou archivé                                   | Son propriétaire l’a désactivé ou archivé, ou a quitté l’équipe. Contactez-le ou annulez le recrutement dans **Recrutés par moi**.                                 |
| Restreint par un administrateur                        | Un administrateur de l’équipe a restreint votre utilisation de cet Agent. Contactez-le si vous avez des questions.                                                 |
| Correction nécessaire par le propriétaire              | La version actuelle doit être corrigée par son propriétaire. Si vous êtes propriétaire ou administrateur, la page vous indique comment accéder à sa configuration. |
| Non partagé avec vous                                  | Cet Agent n’a pas été partagé avec vous.                                                                                                                           |
| Hors de cet espace                                     | Vous n’appartenez pas à l’espace actuel. Choisissez un espace auquel vous appartenez ou demandez l’accès à un administrateur de l’espace.                          |
| Recrutement nécessaire                                 | Vous n’avez pas encore recruté cet Agent ; choisissez **Recruter**.                                                                                                |
| Désactivé par vous                                     | Vous l’avez mis en pause dans **Recrutés par moi**. Choisissez **Activer**, ou **Réactiver** dans les détails, pour le rétablir.                                   |
| Dépendance restreinte ou accès refusé à une dépendance | Une ressource nécessaire est restreinte pour vous ou vous n’y avez pas accès. Contactez un administrateur.                                                         |
| Dépendance indisponible                                | Une ressource nécessaire est actuellement indisponible ; son propriétaire ou un administrateur doit la réparer.                                                    |

**Impossible de confirmer** signifie que Bowra ne peut pas vérifier la disponibilité pour le moment. Choisissez **Réessayer** dans la liste ou les détails plus tard. Seul ce cas peut se résoudre en attendant ; les autres nécessitent de traiter leur cause.

### Partiellement limité

Si l’Agent reste utilisable mais qu’un outil est indisponible, **Partiellement limité** accompagne l’état normal et nomme l’élément, ou indique une dépendance indisponible si son nom ne peut être affiché. Seules les fonctions reposant sur cet outil sont bloquées. Le propriétaire ou un administrateur doit le réparer ; vous pouvez continuer à utiliser l’Agent déjà recruté.

Ces états reflètent votre situation et peuvent différer pour vos collègues. Vous pouvez toujours annuler le recrutement depuis **Recrutés par moi**.

## Valeurs par défaut de l’équipe

Propriétaires et administrateurs configurent les Agents par défaut pris en charge, sans remplacer les autorisations personnelles de données. Pour un Agent visible mais inutilisable, consultez [Résoudre les problèmes d’accès](troubleshoot-access.fr-FR.md).
