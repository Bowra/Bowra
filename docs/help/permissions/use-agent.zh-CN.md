# 聘用和管理分享给你的 Agent

当同事向你分享 Agent，或团队中已有可用 Agent 时，你可以聘用它，让系统在适合的任务中选用。聘用后可单独管理自己的启停状态。

在侧栏选择 **智能体 → 市场** 查找智能体，选择 **智能体 → 我的智能体** 进行管理。管理页顶部依次提供 **我聘用的**、**我创建的**、**分享给我的**、**已归档**，获授权用户还会看到 **团队治理**。各页签都有独立地址，可收藏、直接打开，并通过浏览器前进和后退切换。点击「智能体」默认进入「我聘用的」。

## 开始之前

你已加入当前团队，并且属于该 Agent 的使用受众。开展任务时，还需要进入你有权工作的空间。

## 聘用 Agent

1. 打开 Agent 市场，查找目标 Agent；也可进入管理页面的 **分享给我的**，查找同事分享的 Agent。
2. 打开详情，阅读它的介绍、能力和当前可用性提示，确认用途与你的任务相符。
3. 选择 **聘用**。
4. 进入管理页面的 **我聘用的**，找到该 Agent。确认它没有显示“我已停用”“当前不可用”，也不是“访问已撤销的智能体”。
5. 回到有权使用的空间，提出适合该 Agent 的任务；查看任务执行记录，确认系统是否选择了它、是否完成预期工作。

成员创建的 Agent 要正常使用，必须同时满足：有当前生效版本、Agent 已启用、你在当前可见范围内、你自己的聘用处于启用状态。任一条件变化都会使它暂时不可用，直到条件恢复。聘用也不保证每个问题都会分派给它，更不会授予额外的数据权限。标为 **系统包含** 的内置 Agent 无需个人聘用。若出现依赖、连接或数据权限问题，按 [访问排障](troubleshoot-access.zh-CN.md) 处理。

## 暂时不想使用时

1. 在 **我聘用的** 中找到 Agent，选择 **停用**。
2. 确认状态变为“我已停用”。
3. 需要恢复时，在同一位置选择 **启用**，然后确认当前状态。

这些操作只影响你自己的使用关系，不修改作者的 Agent，也不影响同事的个人开关。

要解除聘用关系，可选择 **解聘**。提交前读清页面的影响预览；涉及定时任务时，按页面要求选择处理方式。完成后检查它已不在当前聘用列表或显示已解聘状态。

自己创建的 Agent 被解聘后，到 **管理我的智能体 → 我创建的** 找到它，直接点 **聘用**，不必先进入详情。这个按钮只在当前 Agent 允许聘用时显示；如果没有，请查看该行的不可用原因，并确认 Agent 本身已启用、当前版本已生效。

## 团队管理员设置默认 Agent

团队负责人/管理员可为全团队设置默认 Agent。团队默认会为符合条件的成员建立个人聘用关系；成员仍可以选择停用或解聘，当前可见范围和数据权限仍须满足。标为 **系统包含** 的内置 Agent 无需个人聘用。

1. 打开 Agent 管理页面，选择 **团队治理**。
2. 找到已启用、面向全团队且满足安全与依赖要求的 Agent，选择 **设为团队默认**。
3. 阅读页面展示的影响人数和范围，再完成确认。
4. 回到团队治理列表，确认该 Agent 已标为团队默认。

移除时使用 **取消团队默认** 并确认结果。取消默认不会强制解除成员已有的个人聘用关系。

## 智能体显示「当前不可用」时怎么办

在智能体市场、**我聘用的** 列表和智能体详情页里，目前不能替你工作的智能体会显示“当前不可用”，并用一句话说明原因。同一时间只显示一个最需要你知道的原因。如果你的聘用仍有效，当前版本、启用状态或可见范围恢复后，使用资格可能自动恢复。如果你已解聘，或聘用访问状态已被撤销，则要在出现 **聘用** 按钮后重新聘用。

| 原因                                         | 怎样处理                                                                                     |
| -------------------------------------------- | -------------------------------------------------------------------------------------------- |
| 已停用或已归档                               | 智能体被负责人停用、归档，或负责人已离开团队。可以联系负责人，也可以在 **我聘用的** 里解聘它 |
| 管理员已限制你使用                           | 团队管理员限制了你使用这个智能体。如有疑问，请联系管理员                                     |
| 需要负责人处理                               | 请联系负责人或团队管理员检查已发布版本和安全状态                                             |
| 未向你开放                                   | 这个智能体没有分享给你                                                                       |
| 你不在当前空间                               | 你不是当前空间的成员。切换到你所在的空间，或请空间管理员为你开通访问                         |
| 需要聘用                                     | 你还没有聘用它，选择 **聘用**；其他使用条件也须同时满足                                      |
| 你已停用                                     | 你自己在 **我聘用的** 里停用了它。点 **启用**（详情页为 **重新启用**）即可恢复               |
| 有依赖已被管理员限制、缺少一项依赖的使用权限 | 它要用到的一项资源，管理员限制了你使用，或你目前没有使用权限。请联系管理员                   |
| 有依赖目前不可用                             | 它要用到的一项资源目前不可用，需要负责人或管理员修复                                         |

如果显示的是“暂时无法确认”，表示系统一时无法确认它能否使用。稍后在 **我聘用的** 列表或详情页点 **重试** 即可。只有这一种情况适合稍后再试，其余原因等待不会自行恢复。

### 部分能力受限

智能体仍然可以使用，但它要用到的某个工具目前不可用时，会在正常状态旁显示“部分能力受限”，并写出是哪一项（无法显示名称时写“有依赖目前不可用”）。这时与该工具相关的能力用不了，其余照常；需要负责人或管理员修复该工具。已经聘用的可以照常使用。

这些状态按你本人的情况判断，其他同事看到的状态可能不同。你随时可以在 **我聘用的** 里解聘不再需要的智能体，任何原因下都不受影响。

## 遇到问题

| 你看到的情况               | 怎样处理                                                                   |
| -------------------------- | -------------------------------------------------------------------------- |
| 市场和“分享给我的”都找不到 | 请作者确认目标团队、分享对象和发布状态；保存草稿不足以让你看到             |
| 显示“当前不可用”           | 按下文“智能体显示「当前不可用」时怎么办”查看原因和处理方式                 |
| 显示“访问已撤销的智能体”   | 联系作者确认受众是否变化，同时检查自己的团队与空间资格                     |
| 想修改提示词或配置         | 联系作者；使用权限不提供编辑入口。来源允许复制时，可考虑建立自己的独立副本 |
| 能聘用，但数据查询失败     | 检查自己的数据身份和北极九章工作区权限；作者分享不包含其个人数据授权       |

相关内容：[作者怎样发布](publish-agent.zh-CN.md) · [给同事分配空间权限](space-access.zh-CN.md)

使用内置分析智能体时，请说明是查询一个具体事实，还是需要完整分析。事实问题可以得到附来源的简洁回答；需要表格、图表、文件或报告时，请明确提出。风险审查和投资评估仍需相应证据，资料不足时会说明限制。

制作营销物料时，请说明是生成新图、修改已有海报文字，还是导出当前版本；有多个设计时请明确目标。制作新演示稿时，请说明提供的内容已经定稿，还是需要进一步分析。保留上传演示稿版式的修改，仍按原文档草稿与审阅流程办理。

模型在尚未执行任何操作时没有返回答案或行动，Bowra 会在任务原有限制内恢复一次；仍无法继续时，任务会显示空答或响应上限错误。请选择**重试**，若再次出现，请复制诊断信息交给管理员。请求已经完整时，无需补充无关的时间或维度。

知识库问题没有匹配依据时，智能体会有限地尝试相关改写，然后说明哪些问题仍未核实，并保留已有来源支持的事实。“未检索到相关依据”不等于知识库为空；需要重新检索时，可提供文档名称或更具体的主题。

按已确认内容制作新演示稿时，请给出页数、每页标题、正文及配色。顾问会保留该范围，完成渲染和下载验证后提供可编辑 PPTX。制作过程中若文件登记失败，恢复时可复用已渲染内容，避免重新生成。修改已有模板仍需原有的草稿和审阅步骤。
