# 连接个人 MCP 服务

你可以把自己的远程 MCP 服务连接到 Bowra，让自己拥有的智能体在你运行时使用外部工具。连接仅你本人可见；团队负责人和管理员不能代你查看、配置或批准调用。

## 添加连接并选择工具

1. 打开左侧「能力中心」，进入「我的连接」（路径为 `/connections/`）。
2. 填写连接名称和远程 MCP 地址，选择无需认证、Bearer Token 或 API Key。API Key 可填写服务要求的请求头名称。
3. 点击「连接并发现工具」。连接成功后勾选所需工具，点击「保存工具选择」。凭据保存后不能读取；修改连接时留空可保留原凭据。若更换认证方式，则须填写新凭据。连接并发现工具期间，请等待操作完成后再修改表单。

只支持远程 HTTP(S) MCP，不支持本地命令。云端部署要求公网 HTTPS；企业内网部署可使用内网地址。请只连接你信任的服务，并使用权限最小的凭据。

## 连接我的 Slack

当团队管理员已启用 Slack 集成且部署方开放此能力时，「我的连接」会显示「连接我的 Slack」。点击后使用自己的 Slack 账号完成授权，Slack 连接与授权令牌只属于你本人。团队管理员负责 Slack App 的一次性配置和 Slack 工作区批准，但不能查看或使用你的个人授权。回到「我的连接」后，页面会说明连接成功或失败原因；请按提示重新授权。若仍失败，请联系团队管理员在「团队设置 → 集成 → Slack」最后的“开放个人 Slack MCP”步骤，确认已登记个人 OAuth 回调地址、配置 User Token Scopes，并在新增权限后重装 Slack App。

连接成功后，先在 Slack 连接中选择工具，再把工具绑定到自己拥有的智能体。首期仅请求搜索、读取消息/频道/文件和读取用户资料所需权限；发送消息、创建频道、Canvas 写入等操作不在此连接范围内。

## 为自己拥有的智能体绑定工具

在「我的连接」的「我的智能体工具」，或该智能体配置的工具区域，选择具体工具并保存绑定。智能体必须是你在当前团队拥有的、已发布的版本。共享给指定成员或全团队时无需移除个人工具绑定；只有你自己运行时会装配这些工具，其他成员运行时不会包含这些工具，也不能使用你的连接。若新版本修改了智能体定义，须重新选择个人工具；仅改变可见范围的新版本会沿用绑定。

随后在自己的聊天中把任务交给该智能体。普通主助手、其他成员运行的共享智能体和他人的智能体不会获得你的个人连接。授权被撤销后，未开始执行的调用会跳过；已开始的调用可以结束，连接配置和最小调用记录仍保留。切换团队后，连接仍属于你，但须为该团队自己拥有的智能体重新配置绑定，并具备当前空间的执行权限。

## 确认每次调用

默认情况下，所有远程工具都需要你逐次确认。确认窗口显示智能体、连接、工具、操作说明和完整参数。请检查哪些信息将发送到外部服务，以及操作是否会修改、删除或公开数据。

- 「允许本次调用」只允许当前参数的一次执行。
- 「本次会话中始终允许」会自动允许当前会话内同一个工具的后续调用；不会影响其他工具或新的会话。结束会话、刷新或停用连接后，这项允许会失效。
- 「拒绝并跳过」不执行该次调用。
- 两分钟内没有决定，调用会过期并跳过。

外部服务可能产生不可撤销的动作。连接属于个人并不意味着可以把团队敏感数据发给该服务，请遵守所在团队的数据使用要求。

## 修复、停用与删除

使用「修改连接 / 刷新工具」修复认证或重新发现工具。刷新会撤销工具选择，需要重新确认工具及受影响的智能体绑定。工具消失时会显示不可用，请移除或替换。

停用或删除连接会阻断后续调用；已经开始的调用可以结束。删除还会清除凭据，最小调用记录会保留；确认删除前，页面会列出仍绑定该连接工具的智能体。

如果提示外部操作结果未知，请到该服务核实。Bowra 不会自动重发该动作，避免重复写入或删除；不要在尚未核实前再次批准相同操作。个人连接由你自行修复，无需找团队管理员代为更新凭据。

在“我的连接”底部查看最近调用，点击“刷新调用记录”更新状态。记录不包含完整参数或返回内容。若结果未知，请先到外部服务核实。
