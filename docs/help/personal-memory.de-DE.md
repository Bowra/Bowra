# Persönliche Erinnerungen verwalten

Öffnen Sie **Einstellungen → Memory**, um persönliche Vorgaben zu prüfen, die Bowhead in Ihren Unterhaltungen wiederverwenden kann.

## Vorschläge prüfen

Speichern Sie einen Chat-Vorschlag mit **Merken**, oder übernehmen Sie ihn nur für die aktuelle Anfrage. Wenn eine Bearbeitungsoption angezeigt wird, können Sie den Wortlaut vor dem Speichern ändern. Offene Vorschläge finden Sie auch auf der Memory-Seite. Prüfen Sie die ursprüngliche Unterhaltung, wenn sie verfügbar ist.

## Gespeicherte Erinnerungen ändern oder entfernen

Öffnen Sie das Zeilenmenü des Eintrags und bearbeiten Sie ihn oder verschieben Sie ihn in den Papierkorb. Dort können Sie ihn innerhalb von 30 Tagen wiederherstellen oder endgültig löschen. Wenn Sie Erinnerungen gesammelt geleert haben, prüfen Sie unter den letzten Löschvorgängen, ob eine Wiederherstellung möglich ist. Kontrollieren Sie danach die gespeicherte Liste.

Erinnerungen gehören zu Ihrem eigenen Konto. Gemeinsame Vorgaben pflegen Berechtigte in den KI-Arbeitsanweisungen des Bereichs. [KI-Arbeitsanweisungen](space-instructions.de-DE.md)
