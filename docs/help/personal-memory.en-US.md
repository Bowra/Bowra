# Manage personal memory

Open **Settings → Memory** to review preferences Bowhead can reuse in your conversations.

## Review suggestions

When a suggestion appears in Chat, choose **Remember** to save it or **Just this time** to apply it to the current turn. Use **Change it** when offered to correct the wording before saving. Pending suggestions can also be reviewed from the Memory page. Review the source conversation when it is available and keep only information you want reused.

## Correct or remove saved memory

Find the item in your saved list. Use its row menu to edit it or move it to the trash. Restore an item from the trash within 30 days, or delete it permanently there. If you clear memories together, check **Recent clears** for the available restore action. Use the current list to confirm whether the intended items were restored.

Memory follows your account. To write instructions that apply across a Space, use its AI work instructions if you have permission. [AI work instructions](space-instructions.en-US.md)
