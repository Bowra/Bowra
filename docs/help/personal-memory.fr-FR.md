# Gérer sa mémoire personnelle

Ouvrez **Paramètres → Mémoire** pour consulter les préférences que Bowhead peut réutiliser dans vos conversations.

## Examiner les suggestions

Dans le chat, choisissez de mémoriser une suggestion ou de l’appliquer uniquement à l’échange en cours. Si une option de modification est proposée, ajustez le texte avant de le sauvegarder. Les suggestions en attente figurent aussi sur la page Mémoire. Consultez la conversation source si elle est disponible.

## Corriger ou retirer un souvenir

Dans la liste des souvenirs enregistrés, ouvrez le menu de l’élément pour le modifier ou le placer dans la corbeille. Vous pouvez le restaurer sous 30 jours ou le supprimer définitivement depuis la corbeille. Après un effacement groupé, consultez les effacements récents pour voir si une restauration est possible, puis vérifiez la liste.

La mémoire appartient à votre compte. Pour définir des consignes communes à un espace, utilisez les instructions de travail IA si vous en avez l’autorisation. [Instructions de travail IA](space-instructions.fr-FR.md)
