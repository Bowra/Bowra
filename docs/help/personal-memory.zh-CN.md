# 管理个人记忆

打开**设置 → 记忆**，检查 Bowhead 可在你的对话中重复使用的偏好。

## 处理建议

对话出现建议时，选择**记住**可保存，选择**仅本次**只用于当前轮次。如果提供**改一下**，可先修改措辞再保存。待处理建议也可在记忆页查看。来源对话可打开时，可回看语境，只保存希望以后沿用的内容。

## 更正或移除记忆

在已保存列表中找到条目，通过行菜单编辑或移入回收站。条目可在 30 天内从回收站恢复，也可在那里永久删除。批量清空后，查看「最近清空」是否可恢复，并在列表核对需要的条目是否已找回。

记忆跟随个人账号。要为整个 Space 写统一指引，有权限的成员可更新 AI 工作说明。[AI 工作说明](space-instructions.zh-CN.md)
