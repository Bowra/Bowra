# Gérer son compte et ses paramètres personnels

Ouvrez **Paramètres** depuis le menu du compte. Les pages personnelles s’appliquent à votre compte.

## Compte

Modifiez votre nom affiché, puis enregistrez. La ligne de l’e-mail indique s’il a été vérifié et permet de renvoyer la confirmation. Réglez séparément la langue de l’interface et celle des réponses. Sous **Agents**, choisissez si Coach vérifie automatiquement un brouillon après modification ou vous demande d’abord votre accord. La rubrique de facturation affiche votre niveau et vos crédits. [Paramètres de langue](language.fr-FR.md) · [E-mails de rappel](notification-emails.fr-FR.md)

## Sécurité

Ouvrez **Sécurité → Modifier le mot de passe** et saisissez l’ancien puis le nouveau. Les autres appareils sont déconnectés après la modification. Si vous avez oublié le mot de passe, utilisez le lien de réinitialisation. Si vous vous connectez uniquement via un fournisseur externe, gérez le mot de passe chez ce fournisseur.

Dans **Sessions actives**, consultez la dernière activité enregistrée pour chaque appareil. Les connexions qui partagent les mêmes informations de navigateur et la même adresse réseau figurent sur une seule ligne. Le menu de la ligne permet de révoquer ces sessions. Sur l’appareil actuel, la session en cours reste ouverte. La déconnexion de tous les appareils ferme aussi cette session.

## Apparence

Choisissez le mode système, clair ou sombre, puis ajustez couleurs, fond, police, taille du texte, densité, angles ou animations. La page affiche l’apparence effective et sa provenance. Effacez un choix personnel pour reprendre le réglage par défaut. **Effacer l’apparence personnelle** efface le thème et les préférences de lecture personnels. Les styles et options d’accessibilité des graphiques se règlent séparément. [Choisir ou publier un style de graphique](chart-styles.fr-FR.md)

## Exportation

Ouvrez le rapport et choisissez **Exporter**, dans **Plus** sur un écran étroit. Sélectionnez un format proposé. La page d’exportation personnelle explique les options. Pour compléter un PowerPoint existant, envoyez-le comme modèle dans le chat. [Remplir ou mettre à jour un modèle PowerPoint](powerpoint-templates.fr-FR.md)
