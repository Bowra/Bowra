# Fill or update a PowerPoint template

Editing an existing presentation requires a configured sandbox runtime with the necessary PowerPoint libraries. Preview and PDF export require their respective toolchains.

Use an existing PPTX when you want to keep its slide structure and update specific content.

## Send the request

1. Attach the PPTX in Chat, or name a PPTX already available in the conversation. If you attach multiple files, name the template and the data file separately.
2. Say which slides, text, tables or charts to update and which parts to preserve. Provide the replacement values or identify the connected data source and reporting period to use. For example, “Update slides 3–5 in Quarterly review.pptx with October sales from sales.xlsx. Keep the slide order, layout and other slides.”
3. If Bowra asks a question, answer on the question card. When you want sample figures, explicitly allow them and check which values the answer identifies as illustrative.

## Review and download

Open the finished PPTX from the answer or **Results**. Use the slide previews and **Full view** to check the layout, then download the editable PPTX. Ordinary Chat delivers the file directly in Results.

Check the reporting period, totals, chart titles, axes and percentage formats, plus any leftover sample text or figures. A partial check covers only the slides it names. Before distributing the deck, open it in the presentation app you plan to use, especially if the preview mentions substituted fonts.

In the same conversation, name the delivered PPTX and ask for specific corrections or for a PDF of that file. If the answer says part of the work is incomplete, check the file it delivered and name the outstanding slides or items in your follow-up.
