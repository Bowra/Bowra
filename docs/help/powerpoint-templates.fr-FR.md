# Remplir ou mettre à jour un modèle PowerPoint

La modification d’une présentation existante nécessite un sandbox équipé des bibliothèques PowerPoint requises. La prévisualisation et l’export PDF ont leurs propres dépendances.

Utilisez un fichier PPTX existant pour conserver la structure des diapositives tout en actualisant certains contenus.

## Envoyer la demande

1. Joignez le PPTX dans le chat, ou nommez un PPTX déjà disponible dans la conversation. Si vous joignez plusieurs fichiers, indiquez séparément le modèle et le fichier de données.
2. Précisez les diapositives, textes, tableaux ou graphiques à modifier ainsi que les éléments à conserver. Fournissez les valeurs de remplacement ou indiquez la source de données connectée et la période à utiliser. Par exemple, « Mets à jour les diapositives 3 à 5 de Bilan trimestriel.pptx avec les ventes d’octobre de Ventes.xlsx. Conserve l’ordre, la mise en page et les autres diapositives. »
3. Si Bowra demande une précision, répondez sur la carte de question. Si vous autorisez les valeurs d’exemple, indiquez-le explicitement et vérifiez les chiffres que la réponse signale comme illustratifs.

## Vérifier et télécharger

Ouvrez le PPTX terminé depuis la réponse ou les **Résultats**. Vérifiez les diapositives dans l’aperçu et en plein écran, puis téléchargez le PPTX modifiable. Dans une conversation ordinaire, le fichier apparaît directement dans les **Résultats**.

Vérifiez la période, les totaux, les titres des graphiques, les axes et les formats de pourcentage ainsi que les éventuels textes ou chiffres d’exemple restants. Une vérification partielle couvre les seules diapositives indiquées. Avant de diffuser le fichier, ouvrez-le dans le logiciel de présentation prévu, surtout si l’aperçu signale des polices de remplacement.

Dans la même conversation, nommez le PPTX livré pour demander des corrections précises ou un PDF de ce fichier. Si la réponse signale que le travail est incomplet, vérifiez le fichier livré et indiquez dans votre demande suivante les diapositives ou éléments à terminer.
