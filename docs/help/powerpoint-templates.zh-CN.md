# 填写或更新 PowerPoint 模板

编辑已有演示文稿需要配置具备 PowerPoint 依赖的沙箱运行环境。预览和 PDF 导出分别需要对应的工具链。

想沿用现有演示稿的页面结构，只更新指定内容时，可以使用已有的 PPTX。

## 发送请求

1. 在对话中附上 PPTX，或者指明对话中已有的 PPTX 文件。附上多份文件时，分别说明哪份是模板、哪份是数据。旧版 .ppt 文件无法读取，请先在 PowerPoint 或 WPS 中另存为 .pptx。
2. 说明要修改哪些页面、文字、表格或图表，以及要保留哪些部分。提供替换值，或指定要使用的已连接数据源和统计期间。例如「用 sales.xlsx 里的 10 月销售数据更新《季度汇报.pptx》的第 3–5 页，保留页序、版式和其他页面。」
3. 如果 Bowra 提出澄清问题，在原问题卡片上回答。如果可以使用示意数字，请明确说明，并查看回答标出了哪些示意值。

## 检查和下载

从回答或**成果**打开完成的 PPTX。查看页面预览，选择**全屏查看**放大核对版式，然后下载可编辑的 PPTX。普通对话直接把文件交付到成果。

检查统计期间、合计、图表标题、坐标轴和百分比格式，留意残留的示例文字或数字。若回答只列出了部分已检查页面，请另外核对其余页面。发送给别人前，先用实际要使用的演示软件打开文件，尤其是预览提示有字体替换时。

需要修改或转成 PDF 时，在同一对话中指明已交付的 PPTX 和具体要求。如果回答说明有部分工作未完成，先查看已交付文件，再在追问中列出待补的页面或内容。
