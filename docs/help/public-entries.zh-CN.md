# 设置公开入口

团队负责人和管理员打开**团队设置 → 公开入口**，管理 Bowhead 生成邀请、通知链接和回调时可使用的浏览器访问地址。

1. 选择「添加入口」，填写协议、主机名、可选端口和实际部署路径前缀，例如 /bowhead。使用收件人和外部服务能访问的地址，省略查询参数和片段。
2. 在能访问该地址的浏览器打开一次性验证链接，确认它回到当前 Bowhead 实例。验证链接过期后可重新签发。回到列表查看入口是否已启用。
3. 将后台工作生成团队链接时应使用的地址设为默认。换默认入口时，先验证替代地址，再停用旧入口。检查绑定旧入口的邀请和回调，按实际用途更新。

验证失败时，从接收方所在网络核对域名、代理转发和完整路径前缀。普通登录沿用访问者打开的地址。这里登记的入口用于生成链接和配置回调。
