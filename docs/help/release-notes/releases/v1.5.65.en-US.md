# v1.5.65

Turn team expertise into reusable Agents, continue complex work with less repetition, explore clearer charts, and manage adoption and costs with better visibility.

This is a cumulative summary of important updates from **September 20 to October 15, 2026**, through v1.5.65. Availability follows your installed version, team configuration, and permissions.

## Highlights

- **Build an assistant around your team's work.** Describe the job in chat, review the proposed Agent, and save a draft you can return to. Choose reusable Plugins, Tools, and Skills instead of rebuilding the same setup for every task. [Create an Agent](../../create-agent.en-US.md).
- **Improve an Agent before colleagues rely on it.** Coach helps prepare changes and evaluation cases; compare a candidate with the current version, see changed results and usage, and decide whether to apply or publish it. Evaluation and publication remain separate decisions.
- **Continue complex work without starting over.** Agents can collaborate on a task, and answering a clarification preserves completed work and available materials. A blocked plan offers a recovery action; simple metric questions return the requested result without unsolicited analysis.
- **Read the evidence behind a chart.** Explore time windows, compare related views, and inspect original values and source notes. Tables can show beginning and ending values, changes, and small trends, making comparisons easier to check.
- **Prepare presentations from your own template.** Upload a supported PPTX template and data, review the generated pages in Canvas, and explicitly confirm before publishing the editable PowerPoint and corresponding PDF. Complex charts and embedded objects remain outside the supported template workflow. [Reports and document drafts](../../revise-report.en-US.md).

## Improvements

- **Spend less time finding earlier work.** Search conversations by your own message text as well as titles, see matching excerpts, rename conversations, and load older items on demand. Reports also have paged browsing.
- **Keep reference material ready for the next question.** The reorganized knowledge base supports CSV and ZIP uploads, document matrices, and team templates. Files show processing status and retryable failures; citations lead back to the material you can access.
- **Deliver reports with less rework.** Follow-up requests can revise a named section, update its figures and charts, or preserve the original and create another report. PDF and PowerPoint exports use the default blue theme or your team's published brand colors.
- **Use one familiar interface across devices.** Unified navigation, clearer menus, adjustable text size, keyboard controls, and better phone layouts make everyday work easier. French and German join English and Chinese; answers follow the question's language unless an explicit preference or team rule takes precedence.
- **Keep useful preferences under your control.** Memory suggestions let you choose what to remember, use only for this turn, or edit before saving. Saved preferences have an undo action and can be managed in personal settings.
- **Connect the resources your team actually uses.** Datarc and Power BI support multiple named connections. Administrators can inspect changes to an MCP tool list before applying them, and see the resources used by an Agent. Team Plugins combine reusable tools and methods.
- **Review sensitive actions before they run.** Supported per-call confirmations put the decision with the person requesting the action. Email review shows the recipient, subject, and full message before sending.

## Fixes

- **More reliable follow-ups.** Clarification and recovery preserve attachments, verified results, and completed helper work across more paths, reducing repeated work and lost context.
- **More trustworthy chart reading.** Top-N ordering, small values, percentages, date order, units, and shared comparison scales are handled more consistently; selected observations retain their original values.
- **More reliable sign-in and external links.** Login, integration callbacks, invitation emails, and browser navigation retain the correct host and deployment path, including deployments below a URL prefix.
- **Failures explain the next step.** Model authentication, rate limits, and service failures have more specific guidance. Credit exhaustion explains why work cannot continue; the clarification card remains available after credits are replenished.

## Admin notes

- **See team adoption over time.** The operations report shows daily logins, new conversations, token use, and tool activity for completed days, without exposing members' questions or tool arguments. Older records may not contain every metric. [Team operations](../../team-operations.en-US.md).
- **Review the new credit calculation.** New work uses each model's input, cached-input, and output token rates; existing ledger entries keep their original amounts. All three rates default to 1, but separately reported cached input can still change the calculated total. Usage details and CSV exports help explain charges. [Credits](../../credits.en-US.md).
- **Configure models with clearer controls.** Connections, assignments, and external capabilities have separate tabs. Request parameters support model defaults, capability overrides, and a preview before saving. To use Agent references in chat, configure the participating models' context-window sizes. [Model settings](../../model-settings.en-US.md).
- **Check deployment settings when upgrading.** Several capabilities now default to enabled; explicit disabled settings remain authoritative. Review the deployment upgrade instructions for prerequisites, especially when retaining multiple reports in a conversation or enabling Team OpenAPI. Agent version automation still requires scoped authorization and owner review.
