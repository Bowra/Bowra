# v1.6.1

Agent configuration, evaluation and release review are clearer. Tasks expose progress and supported continuation after a limit; unrelated work can continue when Datarc is unavailable. Reports and charts are easier to read on narrow screens, document planning honors the selected model, and MCP reconnects refresh stored credentials. Shared dependency updates are included.

Follow the setup guide and upgrade precautions before starting this snapshot. Live models, external services and execution runtimes require operator configuration; this source update does not publish runtime images.
