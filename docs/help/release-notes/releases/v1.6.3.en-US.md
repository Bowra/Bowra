# v1.6.3

Model connections show output capacity separately from request limits. Ordinary requests leave room for input and honor configured limits. When output is cut off, the task can request a smaller complete action up to twice while keeping earlier successful results; incomplete Tool batches are not executed. AI rewrites keep the original passage if a replacement is cut off.

Model-service failure cards retain the available HTTP status, screened service explanation and suggested next step after refresh or reopening. An unconfirmed invocation stops automatic retries; ask an administrator to verify its outcome before sending again. A rejected Responses request requires checking the selected API and configuration; HTTP 400 alone does not establish incompatibility.

Choose **Revise in chat** on an available unpublished document review draft to select that exact version, describe your change and review the new preview. Earlier edits are retained. Presentation preview checks now respect supported text overflow settings. A failed follow-up capture shows **Question not created** so you can provide the missing details in chat. Complete short answers can receive evaluation grades; rerun earlier evaluations to obtain a new assessment.
