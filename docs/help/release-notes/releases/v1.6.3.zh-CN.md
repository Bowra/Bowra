# v1.6.3

模型连接分别显示输出容量与请求限制。普通请求会为输入保留空间，并遵循已配置的限制。输出被截断时，任务最多请求两次较小的完整操作，保留先前成功的结果，不执行不完整的工具批次。AI 改写被截断时会保留原文。

模型服务失败卡在刷新或重开对话后，仍保留可用的 HTTP 状态、经过筛选的服务说明和下一步建议。调用结果未确认时停止自动重试，请先让管理员核实再发送。Responses 请求被拒绝时应检查 API 选择和配置；仅凭 HTTP 400 不能认定接口不兼容。

在可用的未发布文档审阅草稿上选择“在对话中修改”，即可选定该版本，描述修改并审阅新预览，之前的编辑会保留。演示文稿预览检查现在尊重支持的文本溢出设置。追问保存失败时显示“问题未创建”，可以在对话中补充所需信息。完整短回答也可获得评估分数；历史评估需重新运行才能获得新判断。
