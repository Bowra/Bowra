# v1.6.43

Bowra now supports explicit knowledge ingestion, authorized source navigation and Agent knowledge-source bindings. Files join knowledge only through an explicit request; removing membership does not delete the original file.

Chart edits support compatible chart types, date and numeric display formats, legend and label visibility. Targeted edits preserve source values; reading views show clearer units, tables and sources.

Agent duration, step and Tool limits use one inherited configuration. Configuration suggestions retain field guidance and explain stale drafts. Coach results, clarification answers and Agent continuations preserve their original scope more reliably. Personal Skills retain complete revisions.

Model settings offer automatic context compaction and supported idle conversations offer manual compaction. Existing history remains available. Specialized document and other dedicated execution paths retain their own capacity rules.

HTML artifacts support isolated offline interaction. Fullscreen previews, report width, direct file presentation and exports recover more reliably. Frontend security patches, including Tiptap 3.32.0, remain included.

This is a source release. Database upgrades require a backup and the complete supplied migration chain. Operators must provide and qualify their own compatible sandbox runtime. Bowra's basic document Skills retain their stated limits; private PowerPoint template authoring and its helper images are not included.
