# v1.6.43

Bowra prend en charge l’ajout explicite de fichiers aux connaissances, la navigation dans les sources autorisées et leur association aux Agents. Retirer un fichier des connaissances ne supprime pas son original.

Les graphiques proposent des changements de type compatibles, des formats de dates et de nombres, ainsi que la visibilité des légendes et étiquettes. Les modifications ciblées préservent les valeurs sources ; les vues de lecture présentent plus clairement unités, tableaux et sources.

Les limites de durée, d’étapes et d’appels d’outils partagent une configuration héritée. Les suggestions de configuration conservent l’aide des champs et expliquent les brouillons périmés. Les résultats Coach, réponses aux clarifications et reprises Agent préservent mieux leur portée initiale. Les Skills personnels conservent leurs révisions complètes.

Les modèles peuvent résumer automatiquement l’ancien contexte. Les conversations inactives prises en charge offrent une organisation manuelle. L’historique original reste disponible ; les traitements documentaires spécialisés gardent leurs propres règles de capacité.

Les artefacts HTML permettent une interaction hors ligne isolée. Les aperçus plein écran, la largeur des rapports, la présentation de fichiers et la reprise des exports sont plus fiables. Les correctifs de sécurité frontend, dont Tiptap 3.32.0, restent inclus.

Cette publication fournit le code source. Sauvegardez la base avant la mise à jour et utilisez la chaîne de migrations complète. Les exploitants doivent fournir et vérifier un environnement sandbox compatible. Les Skills documentaires Bowra de base gardent leurs limites ; la création privée depuis des modèles PowerPoint et ses images helper ne sont pas incluses.
