# v1.6.43

Bowra 支持显式知识入库、按权限发现资料来源及 Agent 知识来源绑定。只有明确请求才会把文件加入知识库；移出知识库不会删除原始文件。

图表支持兼容类型切换、日期和数值显示格式、图例及标签开关。局部编辑保留来源数值，阅读视图更清楚地展示单位、表格和数据来源。

Agent 的时长、步数和工具调用上限采用统一继承配置。配置建议保留字段说明并解释过期草稿。Coach 结果、澄清回答和 Agent 续接更可靠地保留原始范围；个人 Skill 保存完整版本。

模型设置提供自动上下文压缩，受支持的空闲对话可手动整理上下文。原始历史仍可查看；专用文档生成等独立流程保留自己的容量规则。

HTML 产物支持隔离的离线交互。全屏预览、报告阅读宽度、已有文件展示和导出恢复更可靠。保留 Tiptap 3.32.0 等前端安全修复。

本次为源码发布。数据库升级前应备份，并使用完整迁移链。部署者需自行提供和验证兼容沙箱。Bowra 基础文档 Skill 保留原有功能限制，不包含私有 PowerPoint 模板创作及其 helper 镜像。
