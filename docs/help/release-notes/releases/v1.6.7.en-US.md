# v1.6.7

Team owners and administrators can set the duration of one model call and the result count for knowledge searches. Sandbox default and maximum durations and embedded HTML size limits have their own settings. Deployment ceilings still apply; new tasks use saved limits and running tasks keep their initial snapshot.

Where enabled, the Configuration Agent discovers supported settings and prepares typed suggestions with current choices and constraints. Review and confirm changes in the original settings workflow. Credentials, connection creation and model probes remain on their original pages.

Where Agent evaluation is enabled, Coach can propose edits to exact saved test cases while preserving their identity and history. Related suggestions can be adopted together or reviewed individually. Adoption does not run tests or publish the Agent; a changed suite requires a fresh review.

Report navigation, tables, source disclosures and saved Results selection work more reliably across screen sizes. Pending edits are protected. AI rewrite previews remain separate from saved reports until accepted, preserve multiline formatting, and warn about changed numeric or citation evidence. Distinct chart requests remain separate and updated charts reach the report.

The frontend dependencies and application build runtime receive security updates. Operators providing sandbox JavaScript must verify Node.js 24 compatibility separately. Generated interactive API documentation and its schema endpoint are no longer served; application and integration APIs remain available.
