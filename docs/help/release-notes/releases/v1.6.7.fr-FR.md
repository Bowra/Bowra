# v1.6.7

Les responsables et administrateurs peuvent régler la durée d’un appel de modèle et le nombre de résultats de recherche documentaire. Les durées par défaut et maximale du bac à sable et la taille du HTML intégré ont leurs propres réglages. Les plafonds du déploiement restent applicables ; les tâches en cours conservent leurs valeurs initiales.

Lorsque cette fonction est activée, le Configuration Agent découvre les réglages pris en charge et prépare des propositions typées avec leurs choix et contraintes actuels. Vérifier et confirmer dans le parcours de réglage d’origine. Les identifiants, créations de connexion et tests de modèle restent sur leurs pages dédiées.

Lorsque l’évaluation est activée, Coach peut proposer des modifications de cas enregistrés précis en conservant leur identité et leur historique. Adopter ensemble les propositions liées ou les examiner séparément. L’adoption ne lance aucun test et ne publie pas l’Agent. Une suite modifiée nécessite une nouvelle révision.

La navigation, les tableaux, les sources et la sélection des résultats enregistrés sont plus fiables sur différentes tailles d’écran. Les modifications en attente sont protégées. Les aperçus de réécriture IA restent séparés du rapport enregistré jusqu’à leur acceptation, conservent les retours à la ligne et signalent les changements de nombres ou de citations. Les demandes de graphiques distinctes restent séparées et les graphiques actualisés arrivent dans le rapport.

Les dépendances du frontend et la construction de l’application reçoivent des correctifs de sécurité. Les exploitants de leur propre bac à sable JavaScript doivent vérifier Node.js 24 séparément. La documentation API interactive générée et son point de terminaison de schéma ne sont plus fournis ; les API applicatives et d’intégration restent disponibles.
