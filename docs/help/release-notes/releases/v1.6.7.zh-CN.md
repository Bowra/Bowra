# v1.6.7

团队负责人和管理员可设置单次模型调用的时限与知识搜索结果数量。沙箱默认和最大执行时长、嵌入 HTML 大小上限具有独立设置。部署上限仍然适用；新任务使用保存的限制，运行中的任务保留启动时快照。

在已启用的范围内，Configuration Agent 会发现受支持的设置，并按当前选项和约束准备保留 JSON 类型的建议。请在原设置流程审阅并确认；凭据、连接创建和模型探测仍使用原页面。

Agent 评估已启用时，Coach 可建议修改精确的已保存用例，保留其身份与历史。相关建议可整组采纳或逐项审阅。采纳不会运行测试或发布 Agent；评测组变化后需重新审阅。

不同屏幕下的报告导航、表格、来源披露及已保存成果选择更加可靠，未完成编辑受到保护。AI 改写预览在接受前与已保存报告分离，保留多行格式，并提示数字或引用依据的变化。不同图表请求保持独立，更新后的图表会进入报告。

前端依赖与应用构建运行时已更新安全补丁。自行提供沙箱 JavaScript 的运营者需单独验证 Node.js 24 兼容性。生成式交互 API 文档与其 Schema 端点不再提供，应用和集成 API 仍可使用。
