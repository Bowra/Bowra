# v1.6.80

Knowledge sources now support authorized discovery, generated descriptions and navigation back to the selected source. Temporary Skill methods can be attached to a task while retaining their original access checks. If a retained knowledge source changes, live results, saved history and replay retain the same failure reason.

New charts use explicit horizontal, value and grouping fields; tables keep the requested columns and order. Sorting, aggregation and Top N remain explicit preparation choices. Existing saved charts retain their behavior.

Model connections and assignment editing have clearer verification states and safe empty-response diagnostics. Space members can leave an eligible Space through its settings menu. Agent delivery review distinguishes completed work from failed diagnostic attempts; clarification, retained files and follow-up feedback preserve the original task more reliably.

Report and file reads recheck the recipient's permissions. Sharing can be suspended by the deployment administrator while existing grants remain inspectable and revocable. HTML preview isolation and in-report navigation have been hardened.

This source release upgrades SQLite to a coordinated twelve-file layout. Stop all writers and preserve a complete recovery set, instance keys and the current deletion ledger before upgrading. Run the supplied migration coordinator before serving requests; interrupted upgrades resume forward. An older application must not open the new layout. Rollback requires the matching complete archive and compatible application, preserving the current deletion ledger.

Community retains its reviewed sandbox source and basic document Skills. The basic presentation consultant is available in the Agent list. Native template-authoring helpers and their runtime images remain outside this source release. Operators must qualify their compatible execution runtime.
