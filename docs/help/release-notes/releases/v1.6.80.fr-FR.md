# v1.6.80

Les sources de connaissances proposent une recherche autorisée, des descriptions générées et un retour à la source sélectionnée. Des méthodes Skill temporaires peuvent être jointes à une tâche avec les contrôles d’accès habituels. Lorsqu’une source de connaissances conservée change, les résultats en direct, l’historique enregistré et la relecture conservent le même motif d’échec.

Les nouveaux graphiques utilisent des champs explicites pour les axes, valeurs et groupes ; les tableaux conservent les colonnes choisies et leur ordre. Tri, agrégation et Top N restent des choix explicites de préparation. Les graphiques enregistrés conservent leur comportement.

Les connexions et affectations de modèles présentent des états de vérification plus clairs et des diagnostics sûrs pour les réponses vides. Les membres éligibles peuvent quitter un Space depuis son menu de paramètres. La revue Agent distingue le travail terminé des essais de diagnostic échoués ; questions, fichiers conservés et réponses de suivi préservent mieux la tâche initiale.

Les lectures de rapports et fichiers revérifient les droits du destinataire. L’administrateur peut suspendre le partage ; les autorisations existantes restent consultables et révocables. L’isolation et la navigation interne des aperçus HTML ont été renforcées.

Cette version source migre SQLite vers douze fichiers coordonnés. Avant la mise à jour, arrêter tous les processus d’écriture et conserver un ensemble complet de restauration, les clés de l’instance et le registre courant des suppressions. Exécuter le coordinateur fourni avant de servir les requêtes ; une migration interrompue reprend vers l’avant. Une ancienne application ne doit pas ouvrir la nouvelle organisation. Le retour arrière nécessite l’archive complète correspondante et une application compatible, tout en préservant le registre courant des suppressions.

Community conserve le code sandbox vérifié et les Skills documentaires de base. Le consultant en présentations simples est disponible dans la liste des Agents. Les outils natifs de création à partir de modèles et leurs images ne font pas partie de cette version source. Les exploitants doivent valider leur environnement d’exécution compatible.
