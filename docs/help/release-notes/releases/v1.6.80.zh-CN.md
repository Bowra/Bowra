# v1.6.80

知识来源支持按权限发现、生成说明及返回选定来源。可为单次任务附加临时 Skill 方法，继续遵守原有访问检查。 保留的知识来源变化导致任务停止时，实时结果、历史记录与回放保留一致的原因。

新图表明确指定横轴、数值及分组字段；表格保留指定列及顺序。排序、汇总和 Top N 需要明确提出，已有图表保留原有行为。

模型连接与模型分配的验证状态更清晰，空响应提供安全诊断。符合条件的成员可在 Space 设置菜单退出。Agent 交付复核区分已完成工作与失败诊断尝试；澄清、保留文件及后续反馈更可靠地延续原任务。

报告及文件读取重新核验接收者权限。部署管理员可暂停分享，已有授权仍可查看及撤销。HTML 预览隔离和报告内目录导航得到加强。

本次源码升级将 SQLite 调整为统一协调的十二文件布局。升级前停止全部写入，保留完整恢复集、实例密钥及当前删除回执账本；启动服务前运行随附迁移协调器，中断后向前续跑。旧应用不能打开新布局；回退须恢复匹配的完整归档和兼容应用，同时保留当前删除回执账本。

Community 保留已审核沙箱源码及基础文档技能。基础演示顾问可从 Agent 列表中选择。原生模板创作 helper 及其运行镜像不在本次源码发布范围；运营者须独立验证兼容执行环境。
