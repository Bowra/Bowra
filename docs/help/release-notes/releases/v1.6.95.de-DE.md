# v1.6.95

Beim erneuten Öffnen einer Unterhaltung sehen Sie, ob gespeicherte Ergebnisse noch geladen werden. Fordern Sie eine früher erzeugte Datei erneut an, um das Original herunterzuladen. Sie können eine ältere unbeantwortete Frage abbrechen, ohne neuere Aufgaben zu unterbrechen.

Fordern Sie einen Bericht nur mit Diagrammen an, nennen Sie die gewünschten KPI-Karten oder lassen Sie sie ganz weg. Die abschließende Antwort entspricht dem gespeicherten Bericht. Erfolgreiche Tool-Ergebnisse bleiben verfügbar.

Temporäre Skill-Referenzen funktionieren über die getrennten SQLite-Datenbanken hinweg. Beim Löschen von Text bleibt die aktive Pinyin-Eingabe erhalten.

Das SQLite-Update verringert Sperrkonflikte bei parallelen Unterhaltungen. Stoppen Sie vor dem Upgrade alle Schreibprozesse und sichern Sie den vollständigen Wiederherstellungssatz sowie das aktuelle Löschprotokoll. Folgen Sie der [Upgrade-Anleitung](../../../../deploy/README.md#upgrade-an-existing-installation).
