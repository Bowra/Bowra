# v1.6.95

Reopen a conversation to see when saved results are still loading. Ask for a previously generated file to download the original. Cancel an older unanswered question without interrupting newer work; if its status could not be checked, retry that check first.

Ask for a chart-only report, name the KPI cards you want, or explicitly request no cards. The final answer follows the saved report. Successful tool results stay available even when another attempt failed.

Temporary Skill references work across the split SQLite layout, and deleting text during Pinyin composition keeps the active composition intact.

The SQLite update reduces lock contention during overlapping conversations and protects account retirement when cached queries are reused. Before upgrading, stop all writers, keep the complete recovery set and the current deletion ledger, and follow the [upgrade instructions](../../../../deploy/README.md#upgrade-an-existing-installation).
