# v1.6.95

Quand vous rouvrez une conversation, vous voyez si les résultats enregistrés sont encore en cours de chargement. Redemandez un fichier déjà généré pour télécharger l’original. Vous pouvez annuler une ancienne question sans interrompre les tâches plus récentes.

Demandez un rapport composé uniquement de graphiques, indiquez les cartes d’indicateurs à inclure ou demandez un rapport sans cartes. La réponse finale correspond au rapport enregistré. Les résultats d’outils qui ont réussi restent disponibles.

Les références temporaires de Skills fonctionnent entre les bases SQLite séparées. La suppression de texte préserve la composition Pinyin en cours.

La mise à jour SQLite réduit les conflits de verrouillage entre conversations. Avant la mise à niveau, arrêtez tous les processus d’écriture et conservez la sauvegarde complète ainsi que le registre de suppression actuel. Suivez les [instructions de mise à niveau](../../../../deploy/README.md#upgrade-an-existing-installation).
