# v1.6.95

重新打开会话时，可以看到已保存成果是否仍在加载。再次索取此前生成的文件时，可以下载原件。取消旧的未回答问题不会打断较新的工作；如果无法确认问题状态，请先重试查询。

报告可以只放图表，也可以指定需要的指标卡，或明确要求不添加指标卡。最终回答与保存的报告一致。某次工具尝试失败后，已经成功的结果仍可查看。

临时 Skill 引用可以跨 SQLite 分库使用。使用拼音输入时，删除文字不会打断正在进行的拼音组合。

SQLite 更新减少多会话并行时的锁竞争，并防止复用缓存查询绕过账户退役保护。升级前请停止所有写入进程，保留完整恢复集和当前删除回执账本，并遵循[升级说明](../../../../deploy/README.md#upgrade-an-existing-installation)。
