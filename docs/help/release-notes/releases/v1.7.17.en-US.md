# v1.7.17

If a model connection drops, the existing retry policy can retry the call. Already displayed text from the interrupted attempt is withdrawn so live output and replay keep the same result.

Continue a conversation using its saved report sections and original files. Ask what a report says without requesting a rewrite; accessible source material is read again when needed, with current permissions checked. File actions retain the original identity and the final delivered revision.

Ask the assistant to change a supported chart series to an available palette color or restore the default. The data stays the same and exports follow the theme. Knowledge citations keep the cited passage in view. HTML previews preserve supported interactions and fill the Results pane.

Adding files and sources works consistently across composer sizes. Reference menus stay within the available space, follow-up questions preserve existing context, and browser navigation restores the appropriate result.

Notification settings and shared MCP tool confirmations are available when your deployment administrator enables them. Notifications show the Team responsible for the work. Eligible reminders and task emails have recorded delivery status. Review exact arguments before approving a non-read MCP call; administrators can confirm tool categories against the current schema.
