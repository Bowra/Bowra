# v1.7.17

Si la connexion au modèle est interrompue, la politique existante peut relancer l’appel. Le texte déjà affiché pour la tentative interrompue est retiré afin de garder le même résultat en direct et en lecture ultérieure.

Reprenez une conversation avec ses sections de rapport enregistrées et ses fichiers originaux. Posez une question sur un rapport sans demander sa réécriture. Les droits actuels sont vérifiés ; les actions sur les fichiers conservent leur identité et la version finale livrée.

Demandez de changer la couleur d’une série de graphique prise en charge dans la palette disponible, ou de rétablir la couleur par défaut. Les données ne changent pas et les exports suivent le thème. Les citations gardent le passage cité visible, et les aperçus HTML occupent le panneau des résultats.

L’ajout de fichiers et de sources utilise une entrée cohérente quelle que soit la taille du champ. Les menus de références tiennent compte de l’espace disponible. La navigation du navigateur restaure le résultat approprié.

Les options de notification et la confirmation des outils MCP d’équipe sont disponibles lorsque l’administration du déploiement les active. Vérifiez les arguments exacts avant d’autoriser un appel qui modifie des données. Les notifications indiquent l’équipe concernée ; le statut de livraison des rappels et courriels de tâches admissibles est consultable.

Cette mise à jour des sources comprend les migrations SQLite jusqu’à 0226. Arrêtez les écritures, conservez les bases, objets, configuration, clés et registre de suppression actuel, puis testez la mise à niveau. Suivez les [instructions](../../../../deploy/README.md#upgrade-an-existing-installation). L’édition native de modèles commerciaux et ses images d’exécution restent exclues de cette publication Community.
