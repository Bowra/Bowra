# v1.7.17

模型连接中断时，系统会按现有重试设置重新尝试调用。已显示的中断片段会被撤回，使实时结果与回放保持一致。

继续会话时可以使用已保存的报告章节和原文件。可以只询问报告内容，无需要求改写；需要时重新读取可访问的资料，并复核当前权限。文件操作保留原始身份和最终交付版本。

可以要求助手把支持的图表序列改为现有调色板中的颜色，或恢复默认颜色。图表数据不变，导出沿用主题。打开知识引用时，引用段落会保持在视野内；HTML 预览保留支持的交互，并填满成果区。

不同尺寸的输入框都能通过一致的入口添加文件和来源。引用菜单会放在可用空间内，追问保留已有上下文，浏览器前进和后退会恢复相应成果。

通知选项及团队 MCP 工具确认流程由部署管理员启用后提供。通知标明工作所属团队，符合条件的提醒邮件和任务邮件可查看投递状态。批准非只读 MCP 操作前，可以核对具体参数；管理员可以依据当前工具定义确认工具类别。

本次源码包含截至 0226 的 SQLite 迁移。升级前停止写入进程，保留完整数据库、对象文件、配置、密钥及当前删除回执账本，并先测试升级。详见[升级说明](../../../../deploy/README.md#upgrade-an-existing-installation)。Community 保留已审阅的基础文档 Skills 和独立验证的沙箱源码，商业版原生模板编辑及其运行镜像继续排除。
