# v1.7.24

- Ask to change a chart already delivered in the conversation: supported presentation changes update the original chart in place. Use an exact opaque HEX color for a series; it stays fixed across themes and exports. Unsupported edits explain the limitation without creating a replacement chart.

- Tool confirmations can appear below the waiting conversation step when enabled by your deployment administrator. Review the tool and exact arguments before approving; personal and Team MCP confirmations allow up to three minutes. Other-page notices lead back to the waiting conversation.

- Previously pinned files remain available through a question and its continuation, subject to their original access checks. Follow-up timing, reading position and failed-step recovery details are more consistent when reopening a conversation.

- Deleting a model connection shows which assignments will be replaced or cleared. Review and apply together; replacing an embedding model still requires confirmation to rebuild its index.

- Bowra model authorization can return to the browser address on intranet hosts, IP addresses and custom ports. Supported Anthropic-compatible models can continue tool loops with thinking enabled.

- When scheduled notifications are enabled, scheduled work can ask its owner a question after consulting an assistant, and an urgent run that already emails its owner avoids a duplicate alert email. Feishu can answer a message received during a running Turn; Slack and Teams explain when a conversation is busy.

- Security dependency updates cover sign-in, PDF processing, rendered formulas and shared package tooling. The executor source recipe uses a patched Docker CLI base; Community keeps its existing sandbox and document profile. This source update does not publish or deploy runtime images.
