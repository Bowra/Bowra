# v1.7.24

- 可要求修改对话中已交付的图表：支持的展示调整会原位更新原图。可为序列指定精确的不透明 HEX 颜色，跨主题与导出保持一致。不支持的修改会说明限制，不创建替代图表。

- 部署管理员启用后，工具确认可显示在对话的等待步骤下方。核对工具和完整参数后再批准；个人与团队 MCP 确认最多等待三分钟。位于其他页面时，通知可带你返回等待中的对话。

- 任务此前固定的文件可在提问和续接中保留，仍按原始访问权限检查。重新打开对话时，补充消息时间、阅读位置及失败步骤的处理说明更加一致。

- 删除模型连接前会显示哪些用途将替换或清空，可一并核对并应用；更换嵌入模型仍需确认重建索引。

- Bowra 模型授权可返回内网主机、IP 地址和自定义端口上的浏览器地址。支持的 Anthropic 兼容模型可在启用思考时继续调用工具。

- 启用计划通知后，计划任务咨询助手后可向所有者提问；紧急任务已自行给所有者发邮件时，避免再发重复提醒。飞书可回答执行期间收到的补充消息；Slack 与 Teams 会说明对话繁忙。

- 安全依赖更新覆盖登录、PDF 处理、公式渲染和共享包工具。执行器源码配方采用修补后的 Docker CLI 基础镜像；Community 保留既有沙箱和文档能力范围。本次源码更新不发布或部署运行时镜像。
