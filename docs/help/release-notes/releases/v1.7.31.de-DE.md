# v1.7.31

- Unterstützte eigenständige Berichtsdiagramme lassen sich ohne neue Datenbindung zwischen Linie, Säule, Balken und Fläche wechseln. Mehrere Reihen können auch gestapelte Säulen anbieten; zusammengesetzte Ansichten und ungeeignete Formen behalten ihren Typ. Flächendiagramme beginnen auf der Werteachse bei null.

- Code in Gesprächen, Berichten, Ausführungsschritten und Dateivorschauen erhält eine einheitliche Syntaxhervorhebung. Unbekannte Sprachen und große Eingaben bleiben Klartext; die Vorschauensuche markiert weiterhin genaue Treffer.

- Nach einer beantworteten Rückfrage bleiben tatsächlich gelesene Dateiinhalte erhalten, auch in Sitzungen mit vielen angehefteten Dateien. Fehlende Originalinhalte und verlorener Verzeichniszugriff haben unterschiedliche Wiederherstellungshinweise. Ursprüngliche Zugriffsprüfungen gelten weiter. Geänderte Formulierungen eingebauter Agents blockieren bei unveränderten Ausführungsrechten keine wartende Rückfrage.

- Bei aktivierten geplanten Aufgaben kann eine Aufgabe nach einer anfänglichen Rückfrage und der Antwort ihres Eigentümers fortfahren. Dringende Ergebnis-E-Mails vermeiden doppelte Warnungen; lehnt das Tageslimit eine Warnung ab, wird das normale Ergebnis trotzdem zugestellt.

- Abfragehinweise nennen erkannte Filterwerte, die im Abfragebericht fehlen, damit unerwartet breite Ergebnisse auffallen.

- Bei lokalen Installationen wird vor der Mitgliedsdeaktivierung geprüft, ob die Kontobereinigung verfügbar ist. Das Wiederherstellen eines Instanz-Snapshots stellt dessen Kontostand wieder her; ein Snapshot vor einer Kontolöschung kann das Konto wiederherstellen. Vollständige Wiederherstellungspunkte sind getrennt von automatischen SQLite-Migrationssicherungen aufzubewahren.

- Kurze Modellaufrufe für Titel oder Klassifizierung verbrauchen ihr Antwortbudget nicht mehr für teamweit aktiviertes Denken. Normale Aufrufe und Prüfungsansichten behalten ihre konfigurierte Denkregel.
