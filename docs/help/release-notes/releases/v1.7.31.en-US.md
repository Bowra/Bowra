# v1.7.31

- Switch supported standalone report charts between line, bar, horizontal bar and area types without rebinding their data. Multi-series charts can also offer stacked bars; composed views and unsupported shapes retain their current type. Area charts start their value axis at zero.

- Code in conversations, reports, execution steps and file previews uses consistent syntax highlighting. Unknown languages and large inputs remain readable as plain text; preview search continues to show exact matches.

- Tasks retain the file content they actually read when a question is answered, including Sessions with many pinned files. Missing original content and lost directory access now have distinct recovery guidance. Original file permissions still apply. Built-in Agent wording updates no longer strand a pending question when execution authority is unchanged.

- When scheduled tasks are enabled, tasks that ask before starting can continue after the owner answers. Urgent result emails avoid duplicate alert messages; when an alert is refused by its daily limit, the ordinary result still reaches its recipient.

- Query notices name recognized filter values absent from the query report, making unexpectedly broad results easier to spot.

- Local member deactivation checks account-cleanup readiness before changing membership or account state. Restoring an instance snapshot restores account state from that snapshot; restoring a snapshot taken before account deletion can restore that account. Keep complete recovery snapshots separately from automatic SQLite migration backups.

- Short model requests such as titles and classifiers no longer spend their answer allowance on Team-enabled thinking; ordinary model calls and verification previews retain their configured thinking policy.
