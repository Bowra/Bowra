# v1.7.31

- 可将支持的独立报告图表切换为折线图、柱状图、条形图或面积图，无需重新绑定数据；多序列图还可选择堆叠柱图。组合视图及不支持的形状保持当前类型。面积图的数值轴从零开始。

- 对话、报告、执行步骤和文件预览中的代码采用一致的语法高亮。未知语言或较大输入仍以纯文本显示；预览搜索继续标出准确匹配。

- 回答提问后，任务可保留此前实际读取的文件内容，包括固定了较多文件的会话。原始内容不可用与目录访问失效会给出不同的恢复说明，仍检查原有文件权限。内置 Agent 仅更新措辞且执行权限未变时，不再阻止待回答问题续接。

- 启用计划任务后，执行前先提问的任务可在所有者回答后继续。紧急结果邮件避免重复提醒；每日提醒额度拒绝发送提醒时，普通结果仍会送达收件人。

- 查询提示会列出已识别但未出现在查询报告中的筛选值，便于发现结果范围可能过大的情况。

- 本地部署停用成员前，会先检查账号清理是否就绪，再修改成员关系或账号状态。恢复实例快照会恢复快照中的账号状态；恢复账号删除前的快照可能恢复该账号。完整恢复快照需单独保存，不能只依赖自动 SQLite 迁移备份。

- 标题、分类等短模型请求不再将回答额度消耗在团队启用的思考上；普通模型调用与验证预览继续遵循各自的思考配置。
