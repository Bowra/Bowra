# v1.7.44

- Ask Bowra to revise a named file delivered earlier in the conversation. Results and Files show the latest version in one entry. The file menu opens Version History, and earlier conversation cards can download the version they originally delivered.

- Each file keeps its three newest versions. Reports, knowledge bases, documents, and export snapshots can protect earlier versions from cleanup. Deleting or restoring the file applies to its entire version history.

- Review tool confirmation requests in the conversation under the waiting step. The request shows how much time remains and keeps a record of your decision.

- Edit supported charts placed inside report text. Report revisions add only newly fetched data to Sources. Changing the chart type or wording keeps existing Sources.

- When a conversation asks a question, the collaboration deadline pauses while it waits. Conversations can recover after an unavailable checkpoint, and a task can explain what it completed when a tool fails.

- Concurrent saves and long conversations with file revisions are more reliable. Data-query notices identify recognized fields and filters that the executed query did not apply.
