# v1.7.44

- Nommez un fichier livré précédemment et indiquez la modification souhaitée. Résultats et Fichiers montrent la dernière version dans une seule entrée. Le menu du fichier ouvre l’historique. Une ancienne carte de conversation permet de télécharger sa version d’origine.

- Chaque fichier garde ses trois dernières versions. Les rapports, bases de connaissances, documents et instantanés d’export peuvent protéger les versions antérieures. La suppression ou la restauration s’applique à tout l’historique du fichier.

- Les confirmations d’outils apparaissent dans la conversation sous l’étape en attente. Elles montrent le temps restant et conservent votre décision.

- Modifiez les graphiques pris en charge directement dans le texte du rapport. Les révisions ajoutent aux sources seulement les données nouvellement récupérées. Un changement de type ou de texte conserve les sources existantes.

- Le délai de collaboration est suspendu pendant une question. La conversation peut reprendre si le point de reprise est indisponible. Après un échec d’outil, la tâche peut préciser le travail déjà réalisé.

- Les enregistrements simultanés et les longues conversations avec révisions sont plus fiables. Les avis de requête signalent les champs et filtres reconnus mais absents de la requête exécutée.
