# v1.7.44

- 说出对话中先前交付的文件和要修改的部分，即可请求修订。“成果”和“文件”以一条记录显示最新版，在文件菜单中可以查看版本历史，较早的对话卡片也可以下载当时交付的版本。

- 每个文件保留最新三个版本。报告、知识库、文档和导出快照可以保护较早的版本。删除或恢复文件时，操作适用于该文件的所有版本。

- 需要确认的工具操作会显示在对话中对应的等待步骤下。确认卡显示剩余时间，并记录你的决定。

- 可在报告正文中直接修改支持的图表。修订报告时，只有新获取的数据会加入“来源”。调整图表类型或措辞会保留原有来源。

- 任务等待你回答提问时，协作计时暂停。续接点不可用时，对话可以恢复。工具失败时，任务可以说明已经完成的工作。

- 并发保存和包含多次文件修订的长对话更加稳定。数据查询提示会指出已识别但实际查询未应用的字段和筛选条件。
