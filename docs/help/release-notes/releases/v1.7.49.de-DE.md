# v1.7.49

- Senden Sie in einem unterstützten laufenden Gespräch eine reine Textanweisung an den Lead. Er kann sie im nächsten Schritt oder beim Warten auf einen Helfer lesen. Nachrichten mit Anhängen oder Referenzen sowie während der endgültigen Antwort werden als Folgemeldungen eingereiht.

- Früher gelieferte Dateien lassen sich im Gespräch nach Namen suchen. Es gelten Ihre aktuellen Zugriffsrechte. Verwenden Sie für Wissensdokumente die Suche in der Wissensdatenbank.

- Verwalten Sie Team-Plugins auf einer eigenen Einstellungsseite. Der Editor gruppiert Tools und Skills und bietet eine Suche.

- Alte Dateiversionen werden erst bereinigt, wenn das Gespräch weder läuft noch auf eine Antwort wartet. Vorübergehend können mehr als drei Versionen sichtbar sein.

- Sandbox-Aufgaben können deklarierte Dateien aus Unterordnern liefern oder einen Ordner als ZIP verpacken. Prüfen Sie das Ergebnis auf fehlende oder nicht gespeicherte Dateien.

- Aufgaben erholen sich zuverlässiger von wiederholten Tool-Aufrufen und vorübergehender Speicherkonkurrenz.
