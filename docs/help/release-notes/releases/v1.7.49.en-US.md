# v1.7.49

- While a supported conversation is running, send a plain-text instruction to the Lead. The Lead can read it at its next step or while waiting for a helper. Instructions with attachments or references, and messages sent while the final answer is being written, queue as follow-ups.

- Ask an Agent to find a file delivered earlier in the conversation by name. Results respect your current access. Use knowledge-base search to find accessible knowledge documents.

- Manage Team Plugins on their own settings page. The editor groups Tools and Skills and lets you search them.

- File version cleanup waits until the conversation is no longer running or waiting for an answer. You may temporarily see more than three versions.

- Sandbox tasks can deliver a declared nested file or package a declared folder as a ZIP. Check the returned result for missing or unsaved items.

- Requests recover more reliably from repeated tool calls and temporary contention when saving.
