# v1.7.49

- 在支持的对话运行中，可向 Lead 发送纯文本补充指令。Lead 可在下一步或等待助手时读取。带附件或引用的消息，以及最终回答生成期间发送的消息，会作为后续消息处理。

- 可以按名称查找对话中先前交付的文件，结果遵循你当前的访问权限。知识文档仍可通过知识库搜索查找。

- 可在独立设置页面管理 Team Plugins。编辑器按 Tools 和 Skills 分组，并支持搜索。

- 对话仍在运行或等待回答时，暂缓清理旧文件版本，版本列表可能暂时显示超过三个版本。

- 沙箱任务可以交付声明的子目录文件，也可将声明的文件夹打包成 ZIP。请核对结果是否有缺失或未保存的文件。

- 遇到重复工具调用或暂时无法保存时，任务更容易恢复。
