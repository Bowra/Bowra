# v1.7.54

- Ein mit `/` gewählter Skill kann Folgefragen weiter unterstützen, solange seine Anweisungen im Gesprächsverlauf stehen. Eigene Modellverbindungen verarbeiten gewählte Skills zuverlässiger. Coach und die Agent- und Plugin-Editoren verwenden dieselben Auswahlmöglichkeiten und Berechtigungen.

- Überarbeitet ein Helfer dieselbe Ausgabe innerhalb eines Laufs, zeigt Ergebnisse die neueste Version. Frühere Fassungen bleiben im Ausführungsprotokoll sichtbar. Gleichnamige Dateien in unterschiedlichen Ordnern bleiben getrennt. Die Sandbox kann JavaScript- und CSS-Dateien liefern.

- Office-Dateien können bei fehlender Upload-Bestätigung anhand ihres Inhalts erkannt werden. Prüfen Sie nach dem Ausfüllen einer PowerPoint-Vorlage, welche Folien unverändert geblieben sind, auch gegenüber einer früheren Datei desselben Auftrags.

- Balkendiagramme mit Kategorien und Werten auf entgegengesetzten Achsen werden zuverlässiger erstellt. Antworten zu früherer Arbeit werden seltener wiederholt oder neu begonnen. Delegierungen können unbrauchbare optionale Angaben überspringen, ohne erforderliche Entscheidungen zu verlieren.

- Das Speichern von Space-Einstellungen und der Zugriff auf gemeinsame Dateien und Berichte sind bei gleichzeitiger Arbeit zuverlässiger. Ein blockierter Schreibvorgang meldet sich innerhalb einer begrenzten Wartezeit.
