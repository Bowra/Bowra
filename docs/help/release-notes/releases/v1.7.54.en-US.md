# v1.7.54

- A Skill selected with `/` can continue to guide follow-up requests while its instructions are still in the conversation history. Custom model connections handle selected Skills more reliably. Agent and Plugin editors and Coach use the same Skill choices and execution permissions.

- When one helper rewrites an output during a turn, Results shows the latest version and the run trace can still show earlier copies. Files with the same name in different folders remain separate. Sandbox outputs can include JavaScript and CSS files.

- Office files can be recognized from their contents when an upload receipt is missing. When filling a PowerPoint template, check which slides remained unchanged, including slides from an earlier copy in the task.

- Bar chart requests with a category and a value on opposite axes are handled more reliably. Answers about earlier work are less likely to be repeated or restarted, and delegation can recover from unusable optional details without ignoring required selections.

- Saving Space settings and working with shared files and reports are more reliable during concurrent work. A write that cannot proceed returns a busy message within a bounded wait.
