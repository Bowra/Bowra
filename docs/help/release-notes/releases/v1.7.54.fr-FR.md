# v1.7.54

- Un Skill sélectionné avec `/` peut guider les demandes suivantes tant que ses instructions figurent dans la conversation. Les connexions de modèles personnalisées gèrent mieux les Skills choisis. Coach et les éditeurs Agent et Plugin partagent les mêmes choix et droits d’exécution.

- Quand un assistant réécrit une sortie pendant une réponse, Résultats affiche la dernière version. La trace conserve les anciennes versions. Les fichiers de même nom situés dans des dossiers différents restent distincts. Le sandbox peut livrer des fichiers JavaScript et CSS.

- Les fichiers Office peuvent être reconnus à partir de leur contenu quand le reçu de téléversement manque. Après avoir rempli un modèle PowerPoint, vérifiez quelles diapositives sont restées identiques, y compris par rapport à un fichier produit plus tôt dans la tâche.

- Les graphiques à barres dont les catégories et valeurs occupent des axes opposés sont créés plus sûrement. Les réponses sur des travaux antérieurs sont moins souvent répétées ou relancées. La délégation peut écarter un détail facultatif inutilisable tout en conservant les sélections nécessaires.

- L’enregistrement des réglages du Space et les opérations sur les fichiers et rapports partagés résistent mieux au travail simultané. Une écriture bloquée renvoie un avis dans un délai borné.
