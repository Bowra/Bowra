# v1.7.54

- 用 `/` 选中的 Skill，其说明仍在对话历史中时，可继续指导后续请求。自定义模型连接处理所选 Skill 更可靠，Coach 与 Agent、Plugin 编辑器使用相同的 Skill 选项和执行权限。

- 同一助手在一轮内改写同一输出时，“成果”显示最新版，执行记录仍可查看较早的版本。不同文件夹里的同名文件仍分别显示，沙箱可以交付 JavaScript 和 CSS 文件。

- 没有上传回执时，系统也能通过文件内容识别 Office 文件。填写 PowerPoint 模板后，可以核对哪些幻灯片没有改动，包括任务前面生成的版本。

- 类别和值放在不同轴上的柱图更容易生成。询问此前做过的工作时，回答更少被重复或重启。派发遇到不可用的可选信息时可以恢复，同时保留必要的选择。

- 并行任务期间，Space 设置保存和共享文件、报告操作更可靠。写入无法继续时，会在有限时间内提示系统繁忙。
