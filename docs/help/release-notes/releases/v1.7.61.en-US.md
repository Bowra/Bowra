# v1.7.61

- Share an HTML result with people or groups in your Team, or choose Whole company. Recipients sign in to open the interactive file. Direct recipients receive a notification. The link follows the latest version and you can remove access.

- Download a report as a Word document from the report library. On phones, file actions are grouped in a readable menu, and large HTML previews remain more responsive.

- Unsubmitted clarification answers are restored in the same browser tab after a reload. Follow-up questions can use more context from stopped or failed tasks, including completed actions and recorded failures.

- Each account can enable up to twenty scheduled tasks. The scheduler shows the limit and available slots. Resource grants can be selected by name, and security sessions are grouped by device.

- Visual self-check supports HTML and SVG when the model accepts images and the operator supplies a compatible document executor advertising html-view-v1 with its Chromium worker. A runtime without that capability reports that the renderer is unavailable.
