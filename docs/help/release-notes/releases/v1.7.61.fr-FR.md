# v1.7.61

- Partagez un résultat HTML avec des personnes ou des groupes de votre Team, ou choisissez Whole company. Les destinataires se connectent pour utiliser le fichier. Les destinataires directs reçoivent une notification. Le lien suit la dernière version et vous pouvez retirer l’accès.

- Téléchargez un rapport au format Word depuis la bibliothèque de rapports. Sur mobile, les actions des fichiers sont regroupées dans un menu lisible, et les grandes prévisualisations HTML répondent mieux.

- Les réponses non envoyées aux demandes de précision sont restaurées après rechargement dans le même onglet. Les questions suivantes peuvent utiliser davantage de contexte des tâches arrêtées ou échouées, dont les actions terminées et les erreurs enregistrées.

- Chaque compte peut activer vingt tâches planifiées. La page indique la limite et les places disponibles. Les autorisations de ressources peuvent être sélectionnées par nom, et les sessions de sécurité sont regroupées par appareil.

- La vérification visuelle prend en charge HTML et SVG si le modèle accepte les images et si l’opérateur fournit un exécuteur de documents compatible annonçant html-view-v1 avec Chromium. Sans cette capacité, le moteur de rendu est signalé comme indisponible.
