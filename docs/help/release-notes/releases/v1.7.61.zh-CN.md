# v1.7.61

- 可将 HTML 成果分享给 Team 内的成员、群组或整个团队。接收者登录后即可打开并操作文件，直接接收者会收到通知。链接跟随最新版本，也可随时撤销访问。

- 可从报告库直接下载 Word 文档。手机上的文件操作集中在易读的菜单中，大型 HTML 预览的响应也有所改进。

- 刷新后，同一浏览器标签页会恢复尚未提交的澄清答案。任务停止或失败后，后续问题可利用更多已记录的上下文，包括已完成的操作与失败信息。

- 每个账号最多可启用二十个定时任务，调度页面显示上限与剩余名额。资源授权可按名称选择，安全会话按设备分组。

- 模型支持图片输入，且运维提供声明 html-view-v1 能力并包含 Chromium 工作进程的兼容文档执行器时，视觉自检可检查 HTML 和 SVG。运行时缺少该能力时，会提示渲染器不可用。
