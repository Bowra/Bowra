# v1.7.63

- Die Ausführung zeigt den Code, während Agents ihn schreiben. Schrittdetails erscheinen in der Oberflächensprache. Die Abschlusszeile fasst die erzeugten Ergebnistypen zusammen.

- In den Skill-Einstellungen können Paketdateien nach Pfad aufgelistet und mit den vorhandenen Berechtigungen bearbeitet werden. Ein mit / gewählter Skill behält Quelle und Version während der Aufgabe. Wählen Sie ihn bei Änderungen oder fehlender Verfügbarkeit erneut aus.

- Erzeugte PowerPoint-Dateien werden zuverlässiger gespeichert. Kann eine Ausgabe nicht gespeichert werden, erklärt das Ergebnis den Grund, damit Sie die Datei korrigieren können.

- Gestoppte Aufgaben erfassen ihren Verbrauch und bewahren mehr erledigte Arbeit sowie unterbrochene Antworten. Eine belegte Datenbank verhindert seltener den Abschluss einer erledigten Aufgabe.
