# v1.7.63

- The run trace shows code as agents write it. Step details use the interface language, and the finished line summarizes the types of results produced.

- Skill settings list and edit package files by their paths under the existing permissions. A Skill selected with / keeps its selected source and version throughout the task. Select it again if it changes or becomes unavailable.

- Generated PowerPoint files are saved more reliably. When an output cannot be saved, the result explains the refusal so you can correct the file.

- Stopped tasks record their usage and preserve more completed work and interrupted replies. A busy database is less likely to prevent a finished task from completing.
