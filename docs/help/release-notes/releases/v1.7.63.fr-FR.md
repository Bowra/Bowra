# v1.7.63

- La trace affiche le code pendant que les Agents l’écrivent. Les détails des étapes utilisent la langue de l’interface. La ligne finale résume les types de résultats produits.

- Les réglages des Skills permettent de lister et de modifier les fichiers du paquet par leur chemin avec les droits existants. Un Skill choisi avec / conserve sa source et sa version pendant la tâche. Sélectionnez-le à nouveau s’il change ou devient indisponible.

- Les fichiers PowerPoint générés sont enregistrés plus sûrement. Si une sortie ne peut pas être enregistrée, le résultat en explique la raison pour permettre de corriger le fichier.

- Les tâches arrêtées enregistrent leur utilisation et conservent davantage de travail terminé et de réponses interrompues. Une base de données occupée empêche moins souvent la clôture d’une tâche terminée.
