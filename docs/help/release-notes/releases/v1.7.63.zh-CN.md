# v1.7.63

- 运行过程会实时显示 Agent 编写的代码。步骤详情采用界面语言，完成摘要列出本轮产生的成果类型。

- 在现有权限内，Skill 设置可按路径列出并编辑包文件。用 / 选中的 Skill 会在任务中保留所选来源与版本；版本变化或不可用时，请重新选择。

- 生成的 PowerPoint 文件保存更可靠。文件无法保存时，成果会说明拒绝原因，便于修正文件。

- 停止任务后会记录用量，保留更多已完成工作及被中断的回答。数据库繁忙时，已完成任务更容易正常结束。
