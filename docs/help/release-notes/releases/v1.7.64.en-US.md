# v1.7.64

- When a task selects its deliverables, the answer’s result cards leave out unselected draft files. Drafts remain available in Files and the run trace. Selecting an earlier version of a file keeps the latest version produced in the current task.

- When task credits run out, the assistant identifies the exhausted balance and does not start another helper in that task.

- Chart creation accepts additional single-field axis formats and reports malformed values more clearly. Running history describes what each step did, and completed and archived tasks show their output counts consistently.

- Skill scripts accept paths from their package instructions. Concurrent access changes during Skill checks receive a distinct explanation instead of incorrectly reporting an edited Skill.

- Streamed answers preserve line breaks and spaces that arrive in separate chunks. File upload failures and remote MCP failures give more specific reasons.

- First-time setup uses official PyPI with the same locked versions and hashes. The Gateway startup command also loads local settings correctly with GNU Make 3.81. Local source startup also places the persistent privacy deletion ledger in a writable checkout directory.
