# v1.7.64

- Quand une tâche choisit ses livrables, les cartes de résultats écartent les brouillons non sélectionnés. Les brouillons restent dans Fichiers et dans la trace. Sélectionner une ancienne version conserve la dernière version produite dans la tâche actuelle.

- Quand les crédits de la tâche sont épuisés, l’assistant précise le solde concerné et ne lance plus de nouvel assistant dans cette tâche.

- Les graphiques acceptent davantage de formats d’axe à un seul champ et expliquent mieux les valeurs mal formées. L’historique décrit le travail de chaque étape. Les tâches terminées et archivées affichent les mêmes nombres de résultats.

- Les scripts des Skills acceptent les chemins de leur documentation. Les changements simultanés des droits pendant la vérification reçoivent une explication distincte au lieu de signaler à tort un Skill modifié.

- Les réponses diffusées conservent les sauts de ligne et espaces reçus séparément. Les échecs de téléversement et des appels MCP distants donnent une raison plus précise.

- La première installation utilise PyPI officiel avec les mêmes versions et empreintes verrouillées. Le démarrage du Gateway charge aussi les réglages locaux avec GNU Make 3.81. Le démarrage local place aussi le registre persistant des suppressions dans un dossier accessible en écriture du dépôt.
