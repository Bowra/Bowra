# v1.7.64

- 任务明确选择交付文件后，回答的成果卡片会排除未选中的草稿。草稿仍可在“文件”和运行过程中查看。 明确选择文件的旧版本时，会保留当前任务生成的最新版。

- 任务额度耗尽时，助手会说明耗尽的是哪项余额，并在该任务内停止启动新的协作助手。

- 图表创建支持更多单字段轴参数写法，并更明确地说明格式错误。运行历史说明各步骤完成的工作，刚完成和已归档的任务也会一致显示成果数量。

- Skill 脚本可按包说明中的路径调用。检查 Skill 时遇到并发权限变化会给出独立说明，避免误报为 Skill 被修改。

- 流式回答会保留单独到达的换行和空格。文件上传失败及远程 MCP 调用失败会提供更具体的原因。

- 首次安装改用官方 PyPI，锁定版本与哈希保持一致。GNU Make 3.81 启动 Gateway 时也会正确加载本地配置。 本地源码启动也会将持久隐私删除账本放在检出内的可写目录。
