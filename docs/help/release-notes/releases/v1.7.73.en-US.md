# v1.7.73

- Pin files and reports alongside conversations in the sidebar. Pins remain personal shortcuts, preserve access checks and open the latest available file version.

- Long streamed answers keep the conversation more responsive. Files, Trash and storage totals load more efficiently for accounts with many files.

- Continue conversations when a knowledge file used in earlier work changes or becomes unavailable. Earlier summaries may still be used; start a new conversation to exclude them. A file changed during the current task can still interrupt that task.

- Horizontal bar charts label every bar, leave room for negative values and page through long results with up to 50 categories per page. New bar-based charts accept up to 100 categories and pie charts up to 12 slices; space-limited exports state how many categories they show.

- Answer only the questions you can in a clarification card and continue with the others skipped. Narrow cards, progress feedback, legacy Office upload instructions and Skill invocation feedback are clearer.

- Report revisions update matching sections instead of duplicating them. An assistant can remove sections it wrote in the current task while preserving other authors and earlier work. Reports with several authors no longer automatically use one section’s KPI cards for the cover.

- CSV table previews handle the UTF-8 signature used by Excel. Answer delivery and retries preserve earlier visible work more reliably.
