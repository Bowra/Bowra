# v1.7.73

- 文件和报告可与对话一起固定到侧栏。固定项只是个人快捷入口，不改变访问权限，并会打开文件的最新可用版本。

- 长回答的流式显示更流畅；文件较多时，“文件”“回收站”和存储用量的读取更高效。

- 早先工作使用的知识文件发生变化或不可访问后，仍可继续对话。系统可能继续使用此前的摘要；如需排除旧内容，请新建对话。本次任务正在使用的文件发生变化时，仍可能中断任务。

- 横向条形图为每根条形显示数值，为负数标签留出空间，并支持每页最多 50 个类别的分页浏览。新建条形类图表最多支持 100 个类别，饼图最多 12 个扇区；空间有限的导出会说明实际显示的类别数。

- 澄清卡片可以只回答部分问题，未答问题按跳过处理。窄屏卡片、进度提示、旧版 Office 文件上传说明及 Skill 调用反馈更清楚。

- 修订报告时更新匹配章节，避免重复追加。助手可以删除自己在本次任务中写入的章节，同时保留其他作者与早先内容。多作者报告不再自动用某一章节的 KPI 卡片作为封面指标。

- CSV 表格预览支持 Excel 常用的 UTF-8 签名；回答交付与重试更可靠地保留此前已显示的内容。
