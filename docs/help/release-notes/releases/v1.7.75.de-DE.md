# v1.7.75

- Bearbeiten Sie unterstützte PowerPoint-Texte, Tabellenzellen und Diagrammwerte in Ergebnisse und speichern Sie eine neue Version. Texte und Zellen lassen sich direkt auf der Folie ändern; komplexe oder nicht unterstützte Elemente behalten ihre bisherigen Grenzen. Vorschauen benötigen die kompatible Dokumentenlaufzeit aus der Bereitstellungsanleitung.

- Verweisen Sie im Chat auf eine ganze Folie oder ein ausgewähltes Element. Schmale Ansichten, Eingabemethoden, Auswahl und Tastatursteuerung arbeiten zuverlässiger.

- Überarbeitet ein Assistent eine hochgeladene Datei, wird das Ergebnis als bearbeitete Kopie mit Verweis auf das Original gespeichert. Weitere Änderungen derselben Aufgabe aktualisieren diese Kopie.

- Heften Sie eine geteilte Datei direkt auf ihrer Freigabeseite an. Die Seitenleiste aktualisiert Pins nach Löschen, Wiederherstellen und Änderungen; Zugriffsprüfungen bleiben erhalten.

- Berichtsautoren können Kapitel mit anderem Titel ergänzen, ohne frühere Kapitel zu ersetzen. Aufgaben enden auch nach dem Entfernen eigener Abschnitte korrekt. Planantworten beschreiben erledigte und offene Arbeit in der Antwortsprache.

- Team-MCP-Verbindungen koordinieren gleichzeitige Anmeldeerneuerungen und erklären, wann ein Teamadministrator erneut autorisieren muss.

- Bearbeiten Sie bestehende Agent-Einstellungen auf der Verwaltungsseite statt im entfernten Chat-Editor des Konfigurationsassistenten.
