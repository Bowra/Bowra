# v1.7.75

- Edit supported PowerPoint text, table cells and chart values in Results, then save a new version. Text and table cells can be edited on the slide; complex or unsupported elements retain their existing limits. Document previews require the compatible document runtime described in the deployment guide.

- Reference a whole slide or a selected presentation element in chat. Narrow layouts, input-method entry, selection and keyboard behavior are more reliable.

- When an assistant revises an uploaded file, the result is saved as an edited copy linked to the original. Later revisions within the same task update that copy instead of treating it as an unrelated new file.

- Pin a file directly from its shared-file page. Sidebar pins update after files and reports are trashed, restored or changed, while preserving existing access checks.

- Report writers can add differently titled chapters without replacing earlier chapters. Tasks can finish after removing their own sections, and plan replies summarize completed and unfinished work in the answer language.

- Team MCP connections coordinate simultaneous sign-in renewal and explain when a Team administrator needs to authorize a connection again.

- For existing Agent settings, use its management page instead of the retired Configuration Agent chat-drawer editor.
