# v1.7.75

- Modifiez les textes, cellules et valeurs de graphiques PowerPoint pris en charge dans Résultats, puis enregistrez une nouvelle version. Les textes et cellules sont modifiables sur la diapositive ; les éléments complexes ou non pris en charge gardent leurs limites. Les aperçus nécessitent l’environnement documentaire compatible décrit dans le guide de déploiement.

- Référencez une diapositive entière ou un élément sélectionné dans le chat. Les vues étroites, méthodes de saisie, sélections et commandes clavier sont plus fiables.

- Quand un assistant révise un fichier importé, le résultat devient une copie modifiée reliée à l’original. Les révisions suivantes de la même tâche mettent cette copie à jour.

- Épinglez un fichier directement depuis sa page de partage. Les raccourcis latéraux se mettent à jour après suppression, restauration ou modification, en conservant les contrôles d’accès.

- Les auteurs peuvent ajouter des chapitres de titre différent sans remplacer les précédents. Les tâches se terminent correctement après la suppression de leurs propres sections. Les réponses de plan résument le travail terminé et restant dans la langue de réponse.

- Les connexions MCP d’équipe coordonnent les renouvellements simultanés et indiquent quand un administrateur doit autoriser à nouveau une connexion.

- Modifiez les réglages d’un Agent existant sur sa page de gestion ; l’ancien éditeur du tiroir de chat de l’assistant de configuration a été retiré.
