# v1.7.75

- 在“成果”中编辑支持的 PowerPoint 文本、表格单元格和图表数值，再保存为新版本。文本和单元格可以直接在幻灯片上编辑；复杂或不支持的元素仍保留原有限制。文档预览需要部署指南中说明的兼容文档运行环境。

- 可在对话中引用整张幻灯片或选中的演示文稿元素；窄屏布局、输入法输入、选择和键盘操作更可靠。

- 助手修改上传文件时，会将结果保存为与原件关联的修改副本。同一任务内继续修订时更新该副本，避免将修改结果当作无关新文件。

- 可从共享文件页面直接固定该文件；文件和报告被移入回收站、恢复或发生变化后，侧栏固定项及时更新，并继续遵循原访问权限。

- 报告作者可新增不同标题的章节，而不替换早先章节。删除自己写入的章节后，任务仍可正常完成；计划执行后的回复会使用回答语言说明已完成和未完成的工作。

- 团队 MCP 连接会协调同时发生的登录续期，并在需要团队管理员重新授权时给出明确说明。

- 修改已有智能体配置时，请使用其管理页；配置助手原先的聊天抽屉编辑入口已移除。
