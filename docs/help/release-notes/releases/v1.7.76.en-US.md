# v1.7.76

- For supported break-even questions, an editable scenario card lets you change unit price, variable cost per unit and fixed costs and immediately see the recalculated break-even quantity.

- Reference up to ten slides from one presentation together in chat. Presentation editing gives clearer save, keyboard entry, undo and chart-error feedback, and version history identifies your own edits.

- Model settings keep passing verification results, show progress and outcomes beside each capability, and focus confirmation on connections you edited. Save feedback and conflict recovery stay beside the action they explain.

- Sign in to supported MCP services with your own account from My Connections. Some services still require an administrator to register an app or callback before you can sign in.

- In a compatible visual-preview environment, assistants can inspect output throughout a task. Long HTML pages split at blank space when possible to avoid cutting through content.

- Chat preserves your reading position when its column changes width. Running time starts with the current task, and step labels use clearer wording without exposing internal values.
