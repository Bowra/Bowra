# v1.7.76

- Pour les questions de seuil de rentabilité prises en charge, modifiez le prix unitaire, le coût variable unitaire et les coûts fixes dans une carte de scénario. La quantité au seuil de rentabilité est recalculée immédiatement.

- Référencez jusqu’à dix diapositives d’une présentation ensemble dans le chat. Enregistrement, saisie clavier, annulation et erreurs de graphiques sont mieux expliqués ; l’historique identifie vos propres modifications.

- Les réglages des modèles conservent les vérifications réussies, affichent progression et résultat près de chaque capacité et ciblent la confirmation sur les connexions modifiées. Les indications d’enregistrement et de conflit restent près de l’action concernée.

- Connectez-vous aux services MCP pris en charge avec votre compte depuis Mes connexions. Certains services nécessitent toujours une application ou une adresse de rappel enregistrée par un administrateur.

- Dans un environnement d’aperçu compatible, les assistants peuvent inspecter les résultats pendant toute la tâche. Les longues pages HTML sont séparées aux espaces vides lorsque cela est possible.

- La position de lecture est préservée quand la largeur du chat change. La durée repart de la tâche actuelle et les libellés des étapes évitent les valeurs internes.
