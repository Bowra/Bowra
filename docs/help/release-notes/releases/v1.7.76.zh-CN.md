# v1.7.76

- 适用的盈亏平衡问题会显示可编辑的情景卡；修改销售单价、单位变动成本和固定成本后，即刻查看重新计算的盈亏平衡销量。

- 可在对话中同时引用同一演示文稿的最多十张幻灯片。演示文稿编辑的保存、键盘输入、撤销及图表错误提示更清楚，版本历史也会标明你自己的编辑。

- 模型设置会保留已通过的验证结果，在各能力旁显示验证进度和结果，并重点确认本次修改的连接。保存反馈和冲突恢复说明留在对应操作旁。

- 可从“我的连接”使用自己的账号登录支持的 MCP 服务；部分服务仍需管理员先注册应用或回调地址。

- 在兼容的可视预览环境中，助手可以在任务过程中持续检查成果。较长 HTML 页面会尽量在空白处分页，减少截断内容。

- 聊天列宽变化时保留阅读位置；运行时间从当前任务开始计算，步骤标签使用更清楚的表达，避免显示内部值。
