# v1.7.95

- Attach recent, Team, Space or personal library files from the composer, or paste an image into your draft. Access checks still apply to every selected file.

- Follow a task as a list, chips, lanes or a timeline. Your choice is saved in personal appearance settings and can be reviewed and changed through the Configuration Agent.

- Delivered files, report updates and work-file counts appear while a task runs. Open a task’s work-file line to filter Results to its files, then clear the filter for the full list. Saved versions and interrupted result loading recover more reliably.

- The Tools catalog groups built-in tools by purpose and external tools by source. Administrators manage sources separately, select their tools after authorization and enable them before use. Tools disabled by the Team are no longer offered to Agents.

- Use a connected Notion Team Knowledge Plugin to search and read pages and answer with source links. Administrators can also approve n8n workflows as Team tools; actions that write or delete retain their confirmation requirements.

- Document matrices support adding and removing files, reviewing answer history, filtering, bulk verification and exporting visible results with sources to Excel. Run estimates and changed-cell polling improve cost visibility and responsiveness.

- Excel dates in built-in East Asian formats are read correctly in previews and knowledge extraction. HTML and SVG review follows the output’s layout more precisely.

- Word editing, named knowledge-base organization, the revised file library and retention controls, and the Agent draft trial/release workbench depend on deployment availability. Their inclusion in this source release does not enable their default-off switches.

- The frontend includes the Next.js security patch from the shared source. Successfully resetting a password through the emailed reset link also verifies the email address.
