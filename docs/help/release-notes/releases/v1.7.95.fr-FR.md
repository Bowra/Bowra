# v1.7.95

- Joignez depuis le compositeur des fichiers récents, d’équipe, d’Espace ou personnels, ou collez une image dans le brouillon. Les contrôles d’accès restent appliqués à chaque fichier.

- Suivez une tâche sous forme de liste, de pastilles, de couloirs ou de chronologie. Le choix est enregistré dans l’apparence personnelle et peut être revu avec l’assistant de configuration.

- Fichiers livrés, modifications de rapport et nombre de fichiers de travail apparaissent pendant l’exécution. La ligne des fichiers ouvre Résultats filtré sur la tâche ; effacez le filtre pour tout afficher. Les versions enregistrées et les chargements interrompus se rétablissent plus sûrement.

- Le catalogue classe les outils intégrés par usage et les outils externes par source. Les administrateurs gèrent les sources séparément, choisissent les outils après autorisation puis les activent. Les outils désactivés par l’équipe ne sont plus proposés aux Agents.

- Un Plugin de connaissances Notion connecté permet de chercher et lire des pages et de répondre avec des liens sources. Les administrateurs peuvent approuver des workflows n8n comme outils d’équipe ; les écritures et suppressions conservent leurs confirmations.

- Les matrices documentaires permettent d’ajouter et retirer des fichiers, consulter l’historique, filtrer, vérifier en lot et exporter les résultats visibles avec leurs sources vers Excel. Les estimations et le suivi des cellules modifiées améliorent visibilité et réactivité.

- Les dates Excel aux formats est-asiatiques intégrés sont correctement lues dans les aperçus et l’extraction. La vérification HTML et SVG suit plus précisément la mise en page réelle.

- L’édition Word, les bases de connaissances nommées, la nouvelle bibliothèque et la conservation, ainsi que l’essai de brouillons et le nouveau panneau de publication d’Agents dépendent du déploiement. Cette version source n’active pas leurs options désactivées par défaut.

- Le frontend reprend le correctif de sécurité Next.js de la source commune. Réinitialiser un mot de passe avec succès via le lien reçu vérifie aussi cette adresse e-mail.
