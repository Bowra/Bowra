# v1.7.95

- 可从输入框选择最近、团队、空间或个人文件库中的文件，也可粘贴图片到草稿；选中文件仍需通过原有访问权限检查。

- 可用列表、标签、泳道或时间线查看运行过程。选择保存在个人外观设置中，也可通过配置助手审阅并修改。

- 任务运行时即可看到已交付文件、报告更新和工作文件数量。点击某次任务的工作文件行，可将“成果”筛选为该任务的文件，再清除筛选查看全部。已保存版本和中断后的成果加载更可靠。

- 工具目录按用途归类内置工具、按来源归类外部工具。管理员单独管理工具来源，在授权后选择并启用工具；团队已关闭的工具不会继续提供给智能体。

- 可通过已连接的 Notion 团队知识 Plugin 搜索、读取页面并附上来源链接回答。管理员也可将审阅后的 n8n 工作流批准为团队工具；写入或删除操作继续保留确认要求。

- 文档矩阵支持增删文件、查看回答历史、筛选、批量核验，并将可见结果及来源导出为 Excel。运行估算与仅轮询变化单元格改进了用量可见性和响应速度。

- Excel 内置东亚日期格式可在预览和知识提取中正确读取；HTML 与 SVG 的可视检查更贴近内容本身的布局。

- Word 编辑、命名知识库组织、新版文件库和保留管理、Agent 草稿试用及发布工作台取决于当前部署的开放范围；源码包含这些功能不代表已开启其默认关闭的开关。

- 前端同步共享源码的 Next.js 安全补丁；通过邮件重置链接成功设置新密码后，也会完成该邮箱的验证。
