# Modifier un rapport existant

Lorsqu’un rapport est déjà sur le canevas, poursuivez dans la même conversation pour demander des changements : Bowra modifie le rapport existant au lieu d’en écrire un nouveau.

Certains déploiements ne modifient pas encore les rapports sur place. Si votre demande complémentaire crée un nouveau rapport et déplace l’ancien dans « N rapports précédents dans cette session », votre déploiement produit un rapport à chaque demande. Dans ce cas, indiquez dans votre demande tout le périmètre et le contenu souhaités.

Exemples :

- Changer le périmètre : « Couvrez janvier à juin 2026. » Le corps, les cartes d’indicateurs clés et les graphiques sont actualisés ensemble ; les titres du rapport et des chapitres mentionnant l’ancienne période changent aussi.
- Modifier une partie : « Changez uniquement le chapitre 3 pour couvrir janvier à juin et conservez le reste. » Les autres chapitres et la conclusion finale restent tels quels. La réponse signale les incohérences éventuelles avec le nouveau périmètre.
- Modifier un graphique : « Gardez seulement les 10 premiers dans le classement des magasins » ou « Retirez le graphique de tendance mensuelle ».
- Ajouter du contenu : « Ajoutez une section comparant le chiffre d’affaires par ville. » Le contenu est ajouté à la fin du rapport existant.
- Écrire un rapport distinct : « Conservez le rapport d’origine et écrivez un rapport séparé pour janvier à juin. » L’original reste visible sur le canevas. Les modifications suivantes concernent le plus récent ; l’exportation du canevas inclut les deux.

## Graphiques remplacés ou retirés

Un graphique remplacé ou retiré n’est pas supprimé définitivement. Il rejoint la rubrique des graphiques mis de côté, à la fin du rapport. Développez-la pour le revoir.

## À savoir

- Si une réécriture par IA atteint la limite de sortie du modèle, la version incomplète est retirée et le passage d’origine est conservé. Sélectionnez un passage plus court, puis réessayez.

- Pour remplir un PPTX existant à partir du rapport, nommez le modèle et indiquez les sections, chiffres ou sources à utiliser. [Remplir ou mettre à jour un modèle PowerPoint](powerpoint-templates.fr-FR.md)

- Lorsque les brouillons Word sont disponibles, importez un DOCX ordinaire, désignez-le comme modèle et précisez les changements ou données Canvas à utiliser. Le texte et les cellules ordinaires non fusionnées peuvent être remplis en conservant les styles, sections et autres contenus. Relisez chaque page réelle dans le même Canvas ; un texte plus long peut ajouter des pages. Demandez Word seul ou Word avec PDF, puis confirmez une seule fois. Le PDF est converti depuis ce fichier Word exact. Les nouveaux paragraphes, graphiques, images, tableaux fusionnés/imbriqués et changements de structure ne font pas partie de cette première version. Vérifiez la prévisualisation et les substitutions de polices ; la mise en page Word native n’est pas certifiée. Les Agents personnalisés nécessitent le Plugin de modèles de documents ou sa méthode Word exacte en lecture seule.

- La réponse décrit les changements effectués et les graphiques mis de côté. Elle indique aussi si un ancien graphique reste présent ou si un indicateur n’a pas été actualisé pour le nouveau périmètre.
- Modifier une seule partie ne met pas à jour la conclusion finale. Demandez-le explicitement si vous souhaitez adapter aussi la conclusion.
- Si la partie citée ne correspond pas au rapport (par exemple « chapitre 5 » pour un rapport en quatre parties), Bowra ne devine pas d’après la position : il vous demande laquelle vous visez. S’il modifie une partie sous un autre nom, ou ajoute le contenu comme nouvelle section, la réponse l’indique. Le plus sûr est de nommer le chapitre, par exemple « seulement le chapitre sur les catégories ».
- Pour corriger un fichier livré plus tôt dans la conversation, par exemple les graphiques d’un rapport HTML ou une colonne d’un tableur, nommez le fichier et la partie à modifier. Bowra écrit une nouvelle version de ce fichier sous le même nom et la cite dans sa réponse. Le texte du rapport du Canvas reste inchangé ; une section qui intègre ce fichier HTML passe à la nouvelle version et indique « Mis à jour vers la version N ». « Résultats » n’affiche le fichier qu’une fois et ouvre sa dernière version ; les cartes de fichier plus anciennes de la conversation ouvrent aussi la dernière version. Si Bowra ne retrouve pas la partie citée dans le rapport du Canvas, sa question liste aussi les fichiers livrés plus tôt.
- Les documents de modèle publiés se modifient par leur processus documentaire, et non en demandant une nouvelle version de fichier dans la conversation.
