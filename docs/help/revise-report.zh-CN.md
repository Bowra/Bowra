# 修改已有报告

新表格默认展示所选结果的全部列；指定列时按你的顺序展示，常量列也保留。画图时说明横轴、数值字段和分组（或“不分组”），例如“横轴 Decile，纵轴医院数量，按区域分组”。要求分类轴时，数字 Decile 仍按分类展示。缺字段或不支持的数据形状会说明原因，不猜图；排序、汇总或 Top N 在准备数据时明确要求，渲染时不静默缩减准备结果。要把显式视图改成另一种图型，请在对话中说明所需字段，菜单不会猜新的绑定。已有图表保留保存的行为，直到你要求新修订。

要求生成新图表时，可以同时说明隐藏图例，以及显示或隐藏数据标签。组合图中需要某一张图采用不同设置时，请说明具体是哪张图。单系列图的图例可能自动省略。

画布上已经有一份报告时，你可以在同一个对话里接着提要求，Bowra 会在原报告上修改，而不是再写一份。

新生成报告的产品署名使用社区名称 Bowra。已经保存的报告以及你提供的文字保留原有内容。

有些部署暂时还不会在原报告上修改：如果接着提要求后画布上出现了一份新报告，原报告收进了「本次会话较早的 N 份报告」，说明当前部署会另写一份，下面的修改方式暂不适用。这时请在要求里写清完整的口径和内容。

常见说法：

- 改口径：“把报告改成 2026 年 1-6 月的口径”。正文、关键指标卡和图表会一起按新口径更新；报告标题和各章标题里写着旧口径的，也会一并改掉。
- 只改一部分：“只把第三章改成 1-6 月，其它不动”。没点到的章节和文末的综合结论保持原样；如果它们因此和新口径对不上，回复里会告诉你是哪几处。
- 改图：“门店排名那张图只保留前 10 名”“把月度趋势那张图删掉”。
- 加内容：“再加一节各城市营业额对比”。新内容接在原报告后面。
- 另写一份：“原报告别动，另外出一份 1-6 月的报告”。原报告会保留在画布上，不会被收起；之后接着提的修改会作用在最新的那份上。导出画布时两份报告都会包含在内。

## 编辑文字与 AI 改写

选择**编辑此报告**后可以直接修改文字。选中一段内容，或打开文字区块的 AI 操作，选择改写方式或输入“只根据已有事实扩写说明”等指令。手机端打开文字区块的「⋯」菜单，选择 **AI 改写**。

块级 AI 输入会显示章节名和目标文字的短摘录；发送前请核对。纯文字块可以整块改写；包含图表、表格或代码时，从符合条件的文字段落中选择一段，只有一段时自动选定，只改写该段。目标变化或校验失败会保留指令。选中文字不超过 12,000 字，指令不超过 1,000 字。此操作不会重新计算图表数据。

高亮的新内容是候选预览。选择**接受**替换原文，选择**撤销改写**保留原文，**停止**取消生成。完成编辑、导出或离开报告前，请先接受或撤销改写。接受后一次撤销即可恢复原段落。改写期间如果选中的原文发生变化，请重新选择，不应用旧候选。

请选择同一文字区块内的内容，不包含图表、表格或代码。中断或空结果不会删除原文，可以重试，或关闭提示继续编辑。

扩写只解释选中的文字，不会补查事实或重算图表数据。数字、日期或来源引用发生变化时，会提示先与原文核对再接受；格式变化也可能触发提示，没有提示不代表内容已经验证。接受后的换行在保存、重新打开后保持可见。如需改变图表数据或分析，请在聊天中提出，或使用图表提供的“追问这张图”入口。

## 被换掉或删掉的图表去哪了

新图取代了旧图，或你要求去掉某张图时，旧图不会被彻底删除，而是收进报告末尾的“已收起的图表”。展开就能再看到它们。

## 注意事项

- AI 改写如果达到模型单次输出上限，不完整的新内容会被撤回，原文保留。请选中更短的一段文字后再试。

- 悬停、固定详情和普通 Table 显示便于阅读的完整量级数值：金额默认最多 2 位小数，普通小数最多 4 位，已声明含义的百分比最多 2 位，去掉多余末尾零。很小的非零值仍会保留；明确要求整数显示时按整数舍入。已知金额量级先还原为基础单位，例如 0.0009 亿元显示为 90,000 元，Table 在表头注明单位。源文件下载保留原始数据。整数过大、无法精确绘图时，请用 Table 查看完整数字。
- 可以要求明确的小数位（最多 12 位），选择固定保留末尾零或最多保留指定精度。这只改变可得数字的读法，不重算分析，也不能恢复来源已经舍入的位数。未知百分比形状或币种不会凭列名猜测；Card 使用易读量级，轴保留绘制范围内的差异。正常设置编辑和重载会保留已有精度与币种。

- 来源明确给出日期和适用指标时，图中可显示已报告事件或部分期间说明。打开备注可核对原值与引用。缺少行不自动表示期间未结束。
- 已有时间窗口或帧选择器旁可选择**输入日期**，按显示格式输入一个已存在的期间。未知日期或反向范围不会改变视图；点击**应用**或按 Enter，按 Escape 取消。
- 合格 Table 可按实体显示共同期间的初值、终值、差值及小趋势；各行共用比例，缺失端点保持缺失，百分比差值以百分点表示。点击趋势查看该实体原始行；在原 More 菜单切换**显示原始行**／**显示趋势**。排序和下钻是临时浏览；正式报告导出使用保存的摘要视图，CSV 跟随当前表格。

- 在支持原始观测定位的组合图中，点击数据点、Table 行或图下备注，可固定查看该行原值；金额、百分比等保留各自单位。窄屏在底部详情中阅读，按 Escape 或关闭即可返回图表。排序不会改变所选原始行，切换范围或修订可能关闭详情。
- 阅读步骤如果关联已有备注，会定位并打开同一份详情。区间备注显示已有端点原值，不自动计算区间总量。详情显示适用于选中指标的说明；带明确引用的备注显示对应原文，这不等于证明因果；追问仍需主动点击。浏览与关闭详情不会保存报告修改。
- 新组合图的平级分析使用等宽排列，主图搭配辅助详情时可以让主图更宽。窄画布按阅读顺序堆叠。要调整已有组合图，可在编辑模式打开图表设置，选择布局并保存。

- 标准 PPT 下载按报告内容分页，不再套用固定七页样例。长文字和表格会延续到后续页面，章节标题以分隔页保留。标准降级导出无法还原的图表会以数据表呈现并注明原因；无法导出的图片或交互内容也会在 PPT 中标明。PPT 是分页演示稿，不是画布的逐像素复刻。

- 普通 PPTX 模板请求可在聊天上传 PPTX 和数据，明确说明哪个文件是模板、要改哪些内容。入口可用时，从 Canvas 标签栏的 **+**（打开…）菜单在共同 Canvas 打开当前或历史草稿，审阅页面、查看问题并明确确认发布。关闭只关闭视图，可从同一菜单重开；源文件／PDF 发布后使用原成果控件，已保存草稿及已发布文件保留。不能改交付一份重新排版的普通 PPT。复杂图表和嵌入对象暂不支持。「个人设置 → 数据导出」没有默认模板设置；会话中附带 PPT 不会自动成为报告导出模板。模板生成的 PDF 由对应 PPTX 转换，报告 PDF 下载仍是独立的报告快照。

- Word 模板生成可用时，上传普通 DOCX，说明它是模板，以及要填写的内容或使用的 Canvas 数据。可修改现有文字和普通未合并表格单元格，保留源样式、分节和无关内容；在同一 Canvas 查看每一页，文字变长可正常增页。可要求仅 Word 或 Word 加 PDF，再一次确认草稿；PDF 从这份 Word 转换。首批不支持新增段落、图表、图片、合并／嵌套表格和结构调整。请核对实际预览和字体替代，尚未认证原生 Word 排版。自定义 Agent 需选择文档模板 Plugin 或对应的精确只读 Word 方法资源。

- 回复会如实说明这一轮改了哪些内容、收起了哪些图。如果某张旧图仍在报告里，或关键指标卡还有没换成新口径的数，回复也会告诉你。
- 只改一部分时，文末的汇总结论不会跟着改。如果你希望结论也按新口径更新，请明确说出来。
- 如果你说的那一部分在报告里对不上（比如报告只有四部分，你说「改第五章」），Bowra 会先问你想改哪一部分，不会自己挑一章去改。按章节名称来说最稳妥，比如「只改品类那一章」。

- 修改私有文档时，从标签栏的 **+** 菜单打开原稿，入口可用时点击「在对话中修改」，在已有输入框填写要求并发送。切换或关闭文档 Tab 不改变输入框目标；新版仍需重新审阅并单独确认发布。发送后，你的消息下方会出现一张回执，写明正在基于哪一版生成新版，生成后变成「第 N 版草稿已生成」并提供「在画布中审阅」；原草稿始终保留。

- 文档流程支持时，就绪草稿会在检查权限后打开到同一 Canvas。你正在查看其他对象或输入下一条消息时，草稿会留在后台，准备好再切换，也可从标签栏的 **+** 菜单重开。打开和断线重连都不会替你确认发布。

- 如果检查期间原请求或附件已不可用，请检查文件访问权限，必要时重新附加文件后再发送。旧文件操作提案不会改用变化后的输入继续执行。

制作全新 PPTX 时，可以指定每页的逐点内容；这些列表项会保留为独立、可编辑的演示稿列表段落。

## 手机阅读与数值核对

手机上的报告、文件或代码直达链接会直接打开成果；选择「对话」可返回聊天。桌面和手机均从「更多 → 历史」查看既有修订。文档工具栏合并导航、编辑、导出、分享、状态和来源摘要；更多菜单区分文档操作、审核／状态和危险操作，可用项仍取决于原有权限。

- 窄图可能减少打印的日期或数值标签，为系列名称留出空间；全部观测仍可通过原值详情和 Table 查看。线尾名称放不下时，可通过图例辨认系列。
- 共享时间范围控件位于其影响的图表之前；旁边的范围说明标明哪些视图变化，以及导出包含什么。
- 来源与表格量级不同时，表格说明源单位和展示单位。例如来源以万元提供数值，Table 可以按元展示完整金额。来源检查仍保留供应的数值；缺少换算说明不代表未知单位相同。
- 长表可「展开全部」后「收起」，再次展开复用已加载数据。可操作的备注显示「查看详情」，图表获得键盘焦点时会显示操作说明。
- 手动编辑时，「完成」先保存尚未失焦的输入，保存失败保留编辑。刷新或关闭的离开保护也覆盖待提交输入和保存中状态；离开前请等待「已保存」。

Community 文档技能用于新建基础文件，不提供私有 PowerPoint 模板草稿的审阅／发布流程。Canvas 报告修改及普通报告导出使用各自的原有控件。

## 分享报告及其中的文件

从报告库或报告工具栏打开「分享」，查看受众、向获准接收者分享或撤销访问。接收者须登录并在你的团队内拥有相应权限；只复制链接不会授予访问权。文件直接分享暂未提供界面。

如果部署已关闭分享，你仍可查看或撤销自己有权管理的授权，但不能新增接收者或扩大受众。已有分享暂停，部署管理员重新开启后可能恢复。如果暂时无法确认是否允许分享，请重新打开弹层重试；仍可管理已有授权。

报告可能引用他人分享给作者的文件。报告接收者须独立有权读取该原件，否则该文件不可用，报告其余获准内容仍可阅读；请联系文件所有者授予适当权限。获准 HTML 保留正常交互与原件下载。撤销阻止后续获准读取，但不能收回已下载文件或清除浏览器中已经打开的内容。
