# 列表中的更多操作

行尾或卡片上的 **⋯** 菜单提供编辑、下载、移除或删除等操作。没有可用操作的行不显示菜单。

## 打开操作

1. 找到目标条目。电脑上的部分表格菜单在鼠标悬停或键盘聚焦该行时出现；触屏上按钮保持可见。
2. 选择 **⋯**，再选择操作。灰色操作会说明不可用原因。
3. 继续前阅读确认提示。选择 **取消** 或按 Esc 不会改变条目。

启停开关等状态控件，以及打开报告等主要操作，仍可能直接显示在行或卡片上。

## 常见位置

- 团队设置：成员与邀请、空间、模型和数据连接、工具、内置 Agent、工作流及定时任务。
- 空间设置：成员和空间指令。
- 个人设置：登录设备、记忆和最近清理。
- 资料库与报告：文件、提取表、报告链接和删除。
- Agent 与 Skill：当前支持的分享、管理和个人启停操作。

可用操作取决于你的权限和条目状态。能看到资源不代表可以修改它。

## 手机与危险操作

手机上的管理表格显示为紧凑列表，包含名称、主要信息和状态。操作较多的菜单可能从屏幕底部展开。可查看详情的额度行会打开成员的用量记录；空间访问行显示成员身份与角色。

不可逆操作需要确认。将记忆移入回收站或归档空间等支持恢复的操作，完成后可以提供 **撤销**。不可用操作会说明原因，例如不能移除空间唯一的管理员。操作显示进行中时不要重复提交。

## 注意事项

- 手机上，操作超过 6 项的「⋯」菜单（例如负责人看到的团队成员菜单）会从屏幕底部弹出，其余在按钮旁弹出；菜单的通用用法见[菜单的用法](menus.zh-CN.md)。
- 菜单里灰色、不能点的项表示当前不能执行，原因写在它下方，例如负责人的角色要通过转让变更、你是空间里唯一的管理员时不能移除自己、页面上还有一个操作没有完成。
- 撤销其他已登录设备、恢复最近的重置记录时，这一行的「⋯」会显示为进行中，完成后恢复。
- 审批与反馈收件箱里的「批准」「采纳」「拒绝」是处理结果，仍并排显示在行里。
- 注销或重新生成 OpenAPI 密钥、移除 DAX 模板、从群组移除成员、撤销资源授权这几项操作都会先请你确认。重新生成后旧密钥立即失效，需要把新密钥更新到对接方。停止外部流水线访问智能体：在团队设置 › OpenAPI 禁用或注销它用的密钥。撤销「拒绝」类授权是解除禁止，对方可能因其他授权重新获得访问。操作成功、那一行从列表里消失后，键盘焦点回到所在列表的标题上。
