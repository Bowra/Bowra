# Aufgabenmeldungen und Zustellung

Der Agent einer geplanten Aufgabe kann einen Lauf als relevant markieren, etwa wenn eine Kennzahl eine Schwelle überschreitet. Eine Notiz erscheint bei den Benachrichtigungen. Eine markierte Meldung kann zusätzlich als Browserhinweis erscheinen. Bei einer dringenden Meldung kann der Eigentümer eine E-Mail erhalten. Ist ohnehin eine Ergebnis-E-Mail an ihn vorgesehen, kann diese als dringend statt einer zusätzlichen E-Mail gesendet werden. [Benachrichtigungen](notification-center.de-DE.md)

## Ergebniszustellung wählen

Bearbeiten Sie die geplante Aufgabe und aktivieren Sie in den Benachrichtigungen die Ergebnis-E-Mail. Wählen Sie die Zustellung nach jedem erfolgreichen Lauf oder nur bei markierten Läufen. Die übrigen Läufe bleiben im Verlauf sichtbar.

Der Agent entscheidet anhand der Aufgabenanweisung, ob er einen Lauf markiert. Beschreiben Sie die Auslöser konkret. Wählen Sie eine Zustellung bei jedem Lauf, wenn eine ausgelassene Meldung Folgen hätte. Pro Lauf ist eine Warnung möglich, bis zu fünf täglich. Erreicht eine Aufgabe das Tageslimit, kann das Ergebnis eines weiteren markierten Laufs weiterhin regulär zugestellt werden. Dringende E-Mails setzen eine aktive Teammitgliedschaft und einen eingerichteten E-Mail-Dienst voraus.

Eine als dringend markierte Ergebnis-E-Mail wird nach Abschluss des Laufs gesendet. Wenn der Lauf fehlschlägt, auf eine Antwort wartet oder zehn Minuten nach der Meldung noch läuft, wird die Warn-E-Mail separat gesendet. Wenn Aufgabenmeldungen für Ihre Bereitstellung ausgeschaltet sind, werden Ergebnisse nach jedem Lauf zugestellt.
