# 定时任务提醒与推送

这些通知选项由部署管理员启用后提供。

定时任务在你忙别的事时运行。结果需要你马上看一眼时，任务里的 Agent 可以把这次运行标记给你；你也可以选择只在这类运行时才收到结果。

## 任务如何提醒你

运行中发现值得你留意的情况，比如任务盯的指标越过了界限、该有的数据没有出现，任务里的 Agent 会发出提醒，并从三个级别中选一个：

- **提示**：出现在你的通知里。
- **标记**：同时在打开的 Bowhead 标签页里弹出提醒；标签页处于后台时也会发浏览器通知（见[通知](notification-center.zh-CN.md)）。
- **紧急**：同时向你的账号邮箱发一封邮件。如果这个任务本来就会把结果邮件发给你，你会收到一封标明紧急的结果邮件，不会再多一封。

提醒只发给任务所有者。提醒里写明是哪个任务；打开它就能看到这次运行，Agent 在那里说明它发现了什么。每次运行最多提醒一次，每个任务每天最多五次。达到五次后，再需要提醒的运行不会发提醒；如果选的是 **仅在标记时**，这次运行的结果仍会照常推送给你。

## 选择何时推送结果

1. 打开 **团队设置 → 定时任务**，编辑这个任务。
2. 在 **通知投递** 里打开 **跑完发送摘要到邮箱**。
3. 在 **何时推送** 里选择：
   - **每次运行**：每次运行成功后都收到结果（默认）。
   - **仅在标记时**：只有任务里的 Agent 标记了这次运行，才收到结果；其他运行仍会出现在任务的运行记录里。
4. 点击 **保存**。

## 注意事项

- 在任务说明里写清楚什么情况值得标记，比如“日营收比前一天下降超过 20% 时提醒我”。
- 紧急邮件只发到你本人的账号邮箱，而且你必须是任务所在团队的有效成员、团队已配置邮件服务。
- 标明紧急的结果邮件在运行结束时发出。如果运行失败、停下来向你提问，或者提醒发出 10 分钟后还没跑完，提醒邮件会单独发出。
- 如果你所在的 Bowhead 部署关闭了这项提醒，无论你怎么选，每次运行都会照常推送。
