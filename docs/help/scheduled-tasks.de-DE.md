# Geplante Aufgaben erstellen und verwalten

Öffnen Sie geplante Aufgaben im Capability Center, wenn sie verfügbar sind. Die Verwaltungsseite zeigt die Aufgaben und ihre nächsten Läufe.

1. Legen Sie eine Aufgabe mit erkennbarem Namen an. Wählen Sie den Bereich und beschreiben Sie die Frage, das gewünschte Ergebnis und den Datenumfang. Prüfen Sie bei einem ausgewählten Agent oder Workflow dessen Zugriff auf die benötigten Quellen.
2. Wählen Sie beispielsweise täglich, werktags, wöchentlich oder manuell. Prüfen Sie Zeitzone und nächsten Lauf. Für andere Zeitpläne können Sie unter den erweiterten Einstellungen einen fünfteiligen Cron-Ausdruck angeben.
3. Wählen Sie eine neue Unterhaltung je Lauf oder die Fortsetzung der verknüpften Unterhaltung. Richten Sie bei Bedarf die E-Mail-Zustellung ein und speichern Sie.

Starten, bearbeiten, pausieren oder löschen Sie die Aufgabe über ihr Zeilenmenü. Im Laufverlauf sehen Sie das Ergebnis, die zugehörige Arbeit und den Zustellstatus. Rückfragen beantworten Sie auf der ursprünglichen Fragekarte. Wenn fehlender Zugriff auf einen Bereich, Agent oder ein Tool die Aufgabe pausiert hat, stellen Sie den Zugriff vor dem erneuten Aktivieren wieder her.
