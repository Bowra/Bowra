# 创建和管理定时任务

入口开放时，从**能力中心 → 定时任务**打开管理页，查看已有任务和下次运行时间。

1. 新建任务并填写容易辨认的名称。选择运行所在的 Space，写清问题、所需结果和数据范围。如果绑定了可用的智能体或工作流，核对它能否使用所需来源。
2. 选择每天、工作日、每周或手动等计划，核对时区和页面显示的下次运行时间。预设无法满足时，可在高级选项中填写五段式 Cron 表达式。
3. 选择每次新建对话，或继续使用关联对话，按需设置邮件交付后保存。

从行菜单选择「立即运行」、编辑、暂停或删除。在**运行历史**中查看结果、打开对应工作并核对邮件是否送达。如果运行在等信息，请回答原问题卡。若任务因失去 Space、智能体或工具访问而暂停，先恢复依赖再启用。[任务提醒与交付](scheduled-task-alerts.zh-CN.md)
