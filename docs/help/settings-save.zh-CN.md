# 设置页怎样保存

设置导航按**个人 → 空间 → 团队**排列，只显示当前角色有权进入且功能已开放的项目，没有可用项目的分组会隐藏。团队设置仅向团队负责人和团队管理员显示；空间管理员可见空间管理项目，其他空间成员只显示可读取的「空间说明」。直接打开链接不会让无权限或未开放的入口出现在导航中。

个人设置、团队设置和空间设置里的设置项按主题分组，每组一张卡片，每项一行：左边是名称和说明，右边是要改的内容（手机上上下排列）。

功能可用时，空间常规设置的“在 Canvas 中打开”在 Chat 右侧承载原常规页。名称和描述通过“保存”提交，下方偏好控件仍各自即时保存。即使只打开一个对象，也可用 Canvas 标签名称旁的关闭按钮 ×；页面里不再另设关闭按钮。有未保存的名称或描述时，关闭前会询问是否放弃；正在保存时会等保存完成再关闭。关闭视图不撤销已保存选择。可以让配置智能体 解释或调整支持的偏好，建议单独展示，确认后才保存。确认后原页面回读已保存值，保留较新的手动输入；建议准备期间页面若已变化，请先保存或放弃当前输入，再重新审阅；若建议依据的原值已改变，则重新提出建议。

Canvas 设置页仍在保存或确认中时，主动离开会展示原页面、空间名称及原因。等该操作结束后再离开；后台结果不会把你从另一个编辑器切走。

只修改并保存空间描述时，已保存的名称保持原样；只修改名称时，描述保持原样。

Canvas 打开多个页面时，先选择要操作的页面。刷新会重新打开选中的设置页；刷新前请先保存未保存文字。关闭后台 Agent 会保留当前设置页和未发送消息。从 Results 返回时，只恢复仍打开的页面。

设置旁出现问号按钮时，可以悬停或聚焦预览，点击或轻触后保持说明打开。说明包含字段用途以及适用的内容类型、范围或选项。按 Escape 关闭说明，所在编辑窗口会保留。查看帮助不会修改或保存输入，仍按原提示及保存／检查流程操作。

## 两种保存方式

- **开关、单选这类控件立即生效**：打开或关闭一个开关、选中一项，就已经保存了，不需要再点保存。
- **文字类的改动先暂存，在底部保存**：改了名称、描述、天数、配置项这类内容后，页面底部会出现一条保存栏，写着「有未保存的更改」，右边是「放弃」和「保存」（有的页面写作「保存选择范围」「检查并应用」）。
  - 点「保存」提交这次的全部改动；保存完成后保存栏消失。
  - 点「放弃」把这些改动恢复到上次保存的内容，不会提交任何东西。
  - 保存中按钮显示「保存中…」，这时不能再点，也不能放弃。

保存栏一直贴在屏幕底部，页面再长也不用翻到最后去找按钮。在手机上，页面最下面会留出保存栏的高度，最后一项不会被挡住；输入时屏幕键盘弹起，保存栏会移到键盘上方，正在输入的那一项会自动露出来。

## 离开页面

有没保存的改动时：

- 刷新页面或关闭浏览器标签页，浏览器会先问你是否离开；选择离开，这些改动就不会保存。
- 模型、飞书集成、图表样式等页面在你切换到别的页面时也会先提示；其余页面切换前请先保存或放弃。

## 哪些地方用到

- 个人设置：账号（显示名称、答案风格）
- 团队设置：模型（草稿，保存栏里是「检查并应用」）、飞书集成的连接配置、引用材料保留期限、图表样式的选择范围
- 空间设置：常规（空间名称与描述）

## 对话中的设置建议

如果 @配置智能体的消息因附件或其他引用无法发送，请移除这些内容，只保留配置智能体后重新发送。如果当前部署不支持该引用入口，请移除智能体引用，直接在对话中提出配置请求。尚未发送的请求不会修改设置。

配置智能体读取设置时会获取当前支持的字段、选项和限制。你也可以让它解释或建议修改空间说明：成员可以读取，空间管理员和团队管理者可在空间未归档时修改，审阅并确认后才保存。团队负责人和管理员还可以请求调整 Agent 执行上限、沙箱执行时长、HTML 大小上限、模型重试次数，或对已有模型连接、运行参数和模型分配提出建议。执行上限和重试建议确认后保存；模型建议会加载为原模型页面的草稿，仍需完成「检查并应用」以及必要的风险或索引重建确认。已有未保存输入会保留，请先保存或放弃再加载建议。如果其他管理员在建议生成后保存了模型设置，旧建议将无法加载或应用，请基于最新设置重新提出建议。

对话说已请求打开页面或建议已保存待审阅时，请以实际页面为准，再进行确认。未保存输入或页面已关闭可能暂时阻止审阅，但建议仍保留；先保存或放弃当前输入，打开原页面，再重新审阅已保存建议，这些步骤不会自动应用修改。

可以从明确请求开始，例如“把当前空间改名为财务分析”或“让我的文字大一点”，也可以在 Chat 的提及菜单选择配置智能体。修改共享空间需要该空间管理员权限；审阅建议值后再确认，打开页面或展示建议本身不会保存。

功能可用时，可以在 Chat 请求或直接提及“配置智能体”。它支持个人外观、长期回答语言，以及当前空间名称／描述及周起始日／数据语言；修改空间偏好仍需该空间管理员权限。其他智能体的修改归 Coach，打开页面本身不保存设置。

受支持的个人外观建议可修改模式、字体、字号、密度、圆角或动效，先检查并确认再保存；其他外观控件仍可在原页面手动使用。明确要求以后持续用某种语言回答时，对话直接保存该偏好；只让本次回答或某一段换语言不保存偏好，界面语言独立设置。

对话提供受支持的设置修改时，先检查当前值和建议值，再确认保存。准备或展示建议不会保存设置。空间周起始日和数据语言建议要求有管理该空间的权限，没有管理权限的成员仍可请求解释。

建议生成后，如果你手动保存了受影响的空间或个人外观设置，确认或撤销可能提示设置已变化。请基于最新值重新提出建议，以保留后来的修改；在原设置页直接选择选项仍按页面原有方式保存。

选中常规页时，对话建议覆盖名称和描述：名称必填、最多 120 字符，描述最多 2000 字符；审阅并确认后才保存。空间后来有更新可能导致冲突，请保留输入，重新打开最新已保存值后提出新建议。名称和描述不提供自动撤销，其余控件沿各自保存方式。

选中常规页时，如需询问周起始日或数据语言，先关闭该 Canvas，再发一条新消息，请配置智能体读取或打开空间偏好。智能体会打开对应的偏好编辑器。两组设置属于同一个空间设置页面，但每次对话选中的编辑器只覆盖各自字段；打开或关闭视图不会保存设置。

建议卡显示「没能应用」时，设置没有改动；点「重试」会重新应用同一条建议。应用后的建议收成一行：能完整恢复时行尾有「撤销」；名称和描述应用后不显示「撤销」，卡片会说明可以直接改回。

刷新或重新打开原设置页后，未确认的建议仍保留，但不会自动恢复确认权限。选择 **重新审阅已保存建议**，核对最新权限、已保存值和本地修改；这一步不保存设置。审阅通过后再确认。若原值已变化，请请求新的建议；未保存输入或正在保存时，先处理当前编辑。

已应用的周起始日或数据语言建议，重新打开原空间页面后，可选 **重新审阅已保存建议** 恢复 **撤销**。重审只读取；撤销核对当前已存值并恢复原选择，原先使用默认值时会移除后来保存的值。较新的手动修改或未保存输入可能阻止撤销。空间名称和描述不提供自动撤销。

界面语言控制菜单和标签，数据语言描述存储数据，回答语言控制生成的答复。配置智能体 目前不提供界面语言修改建议，请按已有权限使用原页面的界面语言控件；打开页面不保存选择，也不能用另一项设置代替它。

询问已保存设置时，显式保存的选择与当前生效的默认值会分开说明；没有保存选择时，配置智能体 解释当前默认值。当前使用默认值，不能说明过去是否保存过其他选择。

## 注意事项

- 保存失败时，页面上会写明原因，你的改动还在，可以修改后再保存，或点「放弃」。
- 启用或停用团队图表样式不会清掉你还没保存的选择范围；已停用的样式会从选择范围里去掉。
- 连接配置、邀请成员这类一次填好一组内容的表单，仍用表单自己的提交按钮。

## 保存或刷新失败时

保存错误会保留，便于你查看和处理。等待响应超时可能意味着结果尚未确认，请先核对当前设置，再决定是否重新提交。连接故障才提示检查网络；服务异常或未知错误不一定意味着你已断网。

个人设置可能部分成功：姓名已保存但回答风格尚未确认时，会分别说明。飞书连接配置和个人图表偏好也会区分保存成功与状态／外观刷新失败；选择**重新检查**或**刷新状态**只重新读取当前状态，不会重复提交已经保存的修改。

团队图表样式的发布、版本恢复和选择范围修改，也会保留已确认的结果，并单独说明历史或外观刷新失败。「重试刷新」只读取当前状态，不会再次发布或保存。Google Workspace 连接修改已确认后，状态刷新失败不会抹掉已确认的结果；可重新加载核对最新状态。如果操作没有收到确认响应，请先检查对应列表或设置，再决定是否重复提交。

如果对话未能完成设置操作的说明，请先检查原页面，再决定是否重新发送修改。已保存的建议仍需本人确认，已确认的设置保存不会因答复中断而撤销。补全说明不会重复修改设置；如果保存本身没有确认结果，请先核对当前已保存的值。

## 重置与支持范围

可以请求将受支持的外观选项恢复为继承的默认值，或恢复团队 Agent 执行或沙箱／HTML 分组的全部上限。重置会移除已保存覆盖值；设置「不限制步数」或「自动模型调用时限」是不同的选择，未提到的设置保持不变。重试次数为 0 表示不重试。

连接凭证、创建或删除连接、执行验证、集成、成员和权限策略仍走原工作流。配置助手只列出当前权限和功能范围内可用的配置面；未列出的设置仍可能在原页面手动操作。模型和团队配置不提供自动撤销，需要恢复时请重新审阅一项修改。
