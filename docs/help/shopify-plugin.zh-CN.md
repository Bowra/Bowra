# 连接 Shopify，分析经营数据和优化内容

Shopify 连接让选定的智能体读取店铺商品、订单、当前库存、集合、页面和文章，不包含客户信息。可用操作取决于 Shopify 实际授予 App 的读取权限。

团队负责人或管理员维护连接。成员通过配置了该插件的智能体使用这些工具，插件不会扩大成员权限。

## 连接店铺

1. 使用与店铺属于同一个 Shopify 组织的 App，发布配置并安装到店铺。
2. 授予任务需要的商品、订单、库存、地点和在线商店内容读取权限。超过 60 天的订单还需要获批的全历史订单权限；本插件不需要客户权限。
3. 打开 **能力中心 → 工具**，点击 **管理工具源**，在 **内置服务** 标签页点击 **添加内置服务** 并选择 **Shopify**，填写连接名称、`store.myshopify.com` 域名、Client ID 和 Client secret。
4. 点击 **验证并保存**。系统验证店铺身份并加密保存凭证，已保存的密钥不会显示。
5. 打开「能力中心 → 插件 → 管理团队插件」，点击 **新建插件**，在 **从模板开始** 中选择「Shopify 经营分析 · 店铺名」。表单会填好名称、介绍、该店铺的工具和 Shopify 分析技能；按需修改后点击保存。再到智能体编辑器选择该插件，按现有流程完成智能体验证和发布。

如果 Tools 选择器没有 Shopify，请联系部署管理员。本源码预览中的该实验集成默认关闭；包含源码不代表已经启用。

## 提出经营问题

例如：“对比上个月与前一个月的订单量”“找出可售库存偏低且启用了库存跟踪的 SKU”“提取商品描述与配送政策文案”。存在多个连接时，请说明店铺和日期范围。

订单汇总排除测试单，默认也排除取消单；使用店铺时区和订单当前快照，金额按币种分别计算。“当前订单金额”和“平均当前订单金额”**不是 Shopify 原生销售额或 AOV**。退款金额属于这些订单的整个生命周期，不一定发生在指定期间。

读取采用有上限的分页，不完整列表不能当作全量。订单汇总超过 1,000 单或时间预算时不会返回汇总金额；需要时可缩小为互不重叠的日期范围。库存为当前状态，未跟踪库存是未知值，不是零。首版不支持 ShopifyQL、客户分析、流量、转化、归因和历史利润。

## 优化商品与页面文案

功能可用时，用同样的方式在 **从模板开始** 中选择「Shopify 内容优化 · 店铺名」并保存，再到智能体编辑器选择它。它使用独立的内容技能；分析插件继续负责读取与分析。更新商品需要实际获准的商品写权限，普通页面需要在线商店页面／内容写权限。在 Shopify 更改 App 权限并批准后，应重新编辑、验证连接；没有写权限时仍可准备草稿。

要求“只给建议”会得到文案而不保存；需要写回时请明确要求更新。支持商品标题、描述、SEO 标题／描述，以及普通页面标题／正文。主题布局、发布状态、URL handle、页面 SEO、价格和库存不在此流程内。包含配送文案的普通页面也不等于 Shopify 专用配送政策设置。

更新时，在对话中正在等待的步骤下方的确认卡里检查店铺、目标及完整修改前后内容，再点击 **应用这些修改** 或 **拒绝更新**。HTML 以文本呈现供检查；不处理会到期，不执行更新。只有发起人能决定，更新要求当前浏览器对话及所在 Space 的有效成员权限。提交前原文被其他编辑改动时，应重新准备审阅；多人协作需协调，因为 Shopify 无法将原文检查与更新做成原子操作。

决定后，确认请求会在对话中留下一行记录。你在其他页面时，页面上会出现提示，点击即可回到该对话；浏览器标签页标题也会显示有几项操作在等待确认。

只有读回核验后才报告已保存。写入结果不明或核验不一致时，应先检查 Shopify 当前对象，再提出纠正，不盲目重复更新。核验不代表前台已经可见或搜索／转化表现改善。

## 维护访问权限

编辑连接可更换 Client secret，留空则保留已保存的密钥。先在 Shopify App 管理中重置密钥，再更新 Bowra 连接。轮换会使旧执行中的请求和续页令牌失效。已有连接不能切换店铺身份，其他店铺应单独创建连接。

停用或删除连接后，智能体和插件即使保留工具引用，也无法继续访问。恢复时应验证并启用指定连接，或更新智能体资源。部署实例的加密根密钥应在重启和备份恢复时保持稳定，否则已保存凭证可能无法读取。
