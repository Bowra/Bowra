# 空间说明

空间说明是一段文字，空间里的每一次对话都会遵循它。适合写那些本来每个人都得反复交代的事：回答写给谁看、默认做哪些对比、语气和篇幅、这个空间的工作背景等。它对空间里所有成员生效，也对在这个空间里工作的所有智能体生效，包括内置智能体和团队智能体。

## 编写或修改说明

空间管理员和团队管理员都可以修改；团队管理员不需要先加入空间。

1. 空间管理员：打开空间，进入 **空间设置 → 空间说明**。团队管理员：打开 **团队设置 → 空间**，在对应空间的 **更多操作** 菜单里选 **空间说明**。
2. 用平常的话写下说明。例如：“回答的读者是各大区销售经理。默认与去年同月对比，结论写短一些。”
3. 点 **保存**。

说明从空间里发出的下一条消息开始生效；正在生成的回复继续使用它开始时的版本。不想再使用说明时，清空文字并保存即可。

在团队设置的弹窗里，**保存** 在弹窗底部，保存后弹窗不会关闭。有未保存的修改时关闭弹窗，底栏会问你继续编辑还是放弃修改。

## 在对话里请助手修改

也可以直接在空间的对话里提出，例如：“把这条加到空间说明：新品指上市未满 24 个月的产品。”助手会读取当前说明，给出一张建议卡片，逐行标出要新增或删除的内容。在卡片上点 **应用** 之前不会保存任何内容，保存后会成为一个新版本。应用前请逐行看一遍：助手给出的是整段新文字，请确认你没提到的行没有被改动。

- 只有空间管理员和团队管理员会收到建议卡片；其他成员可以请助手说明当前的空间说明写了什么。
- 如果建议给出之后有人保存过说明，应用会被拦下，避免覆盖对方的修改。请在对话里重新提一次，让助手基于最新内容给出建议。
- 应用后卡片上没有撤销按钮；要撤回，在 **历史版本** 里恢复上一版即可。

## 成员查看说明

空间里的每位成员都能看到所在空间的说明：点页面顶部空间切换旁边的 **关于这个空间** 按钮（ⓘ 图标），会显示说明全文、最后保存的版本，以及想调整时该找哪几位空间管理员。也可以在 **设置** 左侧的空间分组里打开 **空间说明**，只读查看全文。

## 把采纳的建议写进说明

成员可以在对话里提出口径或措辞建议，建议会进入团队的建议收件箱。团队管理员采纳这类建议后，收件箱会列出建议来自哪些空间，以及每个空间里有几段对话提到它。

1. 在对应空间那一行点 **加到空间说明**。
2. 查看对照：上面是当前说明的末尾，下面是建议新增的行。这段文字来自成员反馈，请逐行读一遍。如果当前说明里已有相近的一行，会提示是第几行，方便你合并。
3. 勾选 **我已逐行审阅预填内容**，再点 **应用到编辑器**。按需修改后点 **保存**；在此之前不会保存任何内容。

保存后，这一行会显示“已加到第 N 版”，避免重复添加。以后回来继续处理时，在收件箱顶部切到 **已处理**：已采纳的口径建议会再次列出各来源空间和写入情况。其他空间按需逐个处理。如果建议的来源对话已经不在任何使用中的空间里，可以复制文字，再从 **团队设置 → 空间** 自己选择空间。

## 回到以前的版本

每次保存都会留下一个版本。在 **历史版本** 里点开某个版本，可以看到它和上一版相比改了哪些行，也可以点 **查看全文**。点 **恢复此版本**，内容会放进编辑框，编辑框上方会提示正在恢复哪一版；点 **撤回** 可以拿回你原来的文字。确认后点 **保存为第 N 版**。恢复会产生一个新版本，历史记录不受影响。

## 注意事项

- 成员在对话里的具体要求，以及他自己的个人记忆，对他本人优先于空间说明。
- 上限是 6000 字，超出无法保存，页面会显示当前字数。
- 如果你编辑期间另一位管理员保存了，你的保存会被拦下，避免对方的修改被悄悄覆盖。你写的内容仍留在编辑框里，历史版本会自动展开对方那一版改了哪些行。核对后，如果仍要用你的内容，点 **仍用我的内容保存**；否则点 **放弃我的修改**。
- 已归档的空间不能修改说明，需要先恢复空间。
- 智能体版本评测不使用空间说明，因此评测结果反映的是智能体本身的表现。
- 不是空间管理员的成员不能修改说明；需要调整时，请联系空间管理员，或在对话里提出建议，让它进入建议收件箱。
