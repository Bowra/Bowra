# 使用团队插件

插件是一组可重复使用的 Tool 和 Skill。团队管理员可以为它命名、写介绍，并从当前可用的资源中选择内容。例如，可以把常用的网页搜索工具和研究方法整理成“资料研究”。

内置名称默认使用英文；界面语言为中文时，会使用已提供的中文名称。你为自己的 Tool、Skill、插件和智能体填写的名称保持原样。

## 查看和使用

成员可在「能力中心 → 插件」查看已启用的插件。「内置插件」是系统自带的工具组合，例如“数据分析”“报告与画布”“联网研究”，名称后显示版本号。内置插件都可以选入你的自建智能体，包括「邮件」和「Google 交付」。设置类插件（外观、回答语言等）只供系统设置助手使用。它们和其他插件一样可以停用，停用后设置助手不再替你修改这类设置；它们不能选入自建智能体。

「团队插件」展示团队已启用的组合和所含资源；团队有团队插件时才显示这一组。创建或编辑自己的智能体时，打开「它能用什么」，勾选需要的团队插件，再保存配置。你也可以继续单独选择工具或技能。

智能体选择插件后，会在下一次执行时使用管理员维护的最新组合；已经开始的执行继续使用开始时的内容。如果某项插件被停用，使用它的智能体照常运行，只是不再获得这个插件带来的工具和技能；你单独选择的工具不受影响。

插件只是资源选择方式。能否实际调用某个 Tool 或 Skill，仍取决于当前用户、智能体和资源的权限与可用状态。

## 停用插件和内置工具

- **插件**：每个插件有「我」开关，关闭后只对你自己生效，底部提示条可以撤销。团队负责人和团队管理员还会看到「团队」开关；团队停用前会列出受影响的智能体（包括系统智能体）和定时任务，确认后从下一次运行开始生效。团队停用后，成员不能为自己重新开启。
- **内置工具**：在「能力中心 → 工具」中，内置工具按用途分组。团队负责人和团队管理员可以逐个启用或停用；停用工具会让所有智能体都用不了它，包括通过插件获得它的智能体。开启会向外部写入或发送内容的工具（如发送邮件、写入 Google 文档）时，需要先确认风险说明。在工具上选择「详情」，可以查看它的用途；团队负责人和管理员还能看到哪些智能体和定时任务在用它。工具没有「每次都要确认」开关：成员一旦授权，就不会再逐次询问。
- 停用不会修改任何智能体的配置，重新开启后自动恢复。

## 管理插件

团队负责人和团队管理员在「能力中心 → 插件」选择「管理团队插件」后，会先看到现有插件列表。管理页仍保留已停用的团队插件，方便管理员重新启用。如果还没有团队插件，页面会显示空状态；点击右上角「新建插件」开始创建。点击列表中的插件名称可编辑，点击「取消」可返回列表。填写名称和介绍，勾选所需工具和技能后保存。

工具分为「已添加的工具」和「系统工具」。已添加的工具包括团队配置并启用的内置第三方工具及团队工具源；页面会显示每项操作来自哪个连接，可按需勾选。未启用或当前不可选的连接操作不能加入插件。若已有插件引用的工具不再可用，可在编辑时取消勾选该引用，再保存。

编辑现有插件后，已选用它的智能体会在下一次执行时采用新内容。停用前请通知相关智能体的作者更新配置。

不再需要某项插件时，点击列表中的「删除」，查看受影响的智能体数量并确认。删除不可恢复，插件及其工具和技能会立即从这些智能体的后续执行中移除；正在进行的任务仍使用启动时的内容。智能体草稿中的选择也会移除。历史版本可供查看，但从旧版本恢复配置时不会重新选中已删除的插件。

「结果契约」（Outcome）是智能体向用户承诺的结果，例如“写报告”；它与这里管理的插件不是同一项配置。
