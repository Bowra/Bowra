# 处理建议和管理引用材料保留

## 建议收件箱

打开**团队设置 → 建议收件箱**。在「待处理」查看可处理的建议，在处理过的列表回看决定。展开详情，核对建议、证据和你有权查看的来源对话。

有「采纳」操作时，打开对应编辑器，核对预填内容后保存。采纳只是进入修改审阅。涉及智能体的改动由智能体负责人在编辑器中处理，并按发布流程生效。按角色和建议状态，也可能提供驳回、转交或撤回。[发布或更新智能体](permissions/publish-agent.zh-CN.md)

## 引用材料保留期限

团队负责人和管理员打开**团队设置 → 引用材料保留期限**。在 1 到 180 天之间选择期限，保存前核对影响。缩短期限也会应用到已有引用材料。过期材料会被清理，依赖这些材料的任务可能停止。

延长后的期限用于以后保存的材料。已有的更短过期时间和对话记录各按原有规则处理。如果任务失去必需的引用，请恢复访问，或发起新请求并重新提供材料。
