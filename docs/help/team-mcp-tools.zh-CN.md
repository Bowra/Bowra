# 添加团队 MCP 工具

团队负责人或管理员可以在「团队设置 → 工具源」中添加 MCP 工具，让团队中的智能体使用已选定的外部服务能力。添加的是一个 MCP 服务及其中选定的工具；它不会自动授予团队成员该外部服务的账号权限。

## 添加 MCP 服务并选择工具

1. 打开「团队设置 → 工具源」，点击「添加 MCP 工具」。
2. 选择「MCP 服务器」，填写服务地址；如服务要求认证，按提示填写凭据或完成授权。
3. 等待系统读取该服务提供的工具，勾选需要提供给团队智能体的工具。
4. 填写来源名称并确认添加。添加后可在工具列表中查看、验证、停用或编辑该来源。

凭据保存后不能读取或回显。请只连接可信服务，并使用权限最小的凭据。云端部署仅支持公网 HTTPS 地址；企业内网部署可以使用内网地址。

## 管理已添加的工具

每个来源都可以单独验证连通性、编辑名称或凭据，以及停用。停用后，新的调用不会再发往该服务；已开始的外部调用可能仍会完成。删除会同时清除该来源保存的凭据，且不可撤销。

## 刷新工具列表

MCP 服务新增或下线工具后，可以在该来源的操作中选择「刷新工具列表」（在卡片右侧的「⋯」菜单中）。系统会先读取服务当前提供的工具，并列出与已保存列表的差异：

- **新增工具**：服务新提供的工具。如果添加来源时只选择了部分工具，新增工具不会自动导入。
- **服务器已移除的工具**：服务不再提供、且未被导入的工具，移除不影响智能体。
- **将失效的已导入工具**：已导入但服务不再提供的工具。更新后智能体无法再调用它们，界面会同时列出受影响的智能体、运行中任务和定时任务；相关定时任务会暂停，确认依赖后才能恢复。如果该来源导入的工具全部被移除，更新后会自动停用该来源。
- **有变化的工具**：服务仍在提供、但说明或参数有变化的工具。每个工具会标明变化的内容以及是否已导入。更新后，智能体下次调用已导入的工具时即按新版本使用。

核对无误后点击「更新工具列表」才会生效；点击「取消」不会做任何更改。如果在你核对期间工具列表或其使用情况发生了变化，系统会重新读取并请你再次核对。没有任何新增、移除或变化时，界面会提示工具列表已是最新。

需要授权的 MCP 服务完成首次授权后才能刷新工具列表。

## 选择要导入的工具

如果要导入添加来源时没有勾选的工具，或刷新后新增的工具，可以在该来源的操作中选择「选择工具」（在卡片右侧的「⋯」菜单中）。如果来源只导入了部分工具，刷新新增工具后的提示中也会直接提供「选择工具」，新增工具会标为「新增」。

列表显示最近一次保存的全部工具，已导入的工具默认勾选。勾选需要提供给智能体的工具后点击「保存」。至少需要保留一个工具；如需停用全部工具，请关闭该来源。

如果取消勾选了当前已导入的工具，系统会先显示影响范围：将移除的工具，以及使用该来源的智能体、运行中任务和定时任务。点击「确认并保存」才会生效；点击「返回」可回到列表继续调整。保存后，智能体无法再调用被移除的工具，相关定时任务会暂停，确认依赖后才能恢复。

如果工具来源正被团队智能体、运行中的任务或定时任务使用，请先确认影响范围并修复相关依赖，再停用或删除它。外部服务可能执行不可撤销的操作，请在启用工具前确认团队的数据使用要求和该服务的权限范围。
