# 管理团队 OpenAPI

功能可用时，团队负责人和管理员打开**团队设置 → OpenAPI**。

1. 在「管理密钥」添加密钥，填写名称、所需权限和到期时间。留空默认 30 天。外部流水线要提交和评测智能体改动时，可以选择 Agent CI 预设。
2. 创建后立即复制完整密钥，把它保存在调用系统的凭据管理中。完整密钥只显示一次。
3. 在「接口帮助文档」查找基础路径、具体接口、所需权限和请求示例。调用时使用 Bearer 令牌，服务地址应是调用系统可访问的地址，包含部署路径前缀。页面也支持下载 Markdown 参考。
4. 调用失败时，在「调用日志」核对使用的密钥、操作和结果摘要，并检查接口要求的权限及密钥到期状态。

停用或撤销密钥会停止其访问，包括使用该密钥的流水线。重新生成会替换旧密钥，请更新调用方后再验证。撤销密钥会保留历史调用日志。
