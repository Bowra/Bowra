# Consulter les données d’activité de l’équipe

Les propriétaires et administrateurs d’équipe ouvrent **Paramètres → Équipe → Opérations → Données d’activité**. Cette page affiche la journée d’hier, les 7 derniers jours complets ou les 30 derniers jours complets. Le tableau quotidien contient les valeurs exactes ; le graphique montre l’évolution de la mesure sélectionnée. La journée en cours n’apparaît qu’une fois terminée.

Le fuseau du rapport est commun à toute l’équipe. Sélectionnez un fuseau horaire et enregistrez-le pour définir à quelle journée appartient chaque heure. Ce changement modifie uniquement le regroupement quotidien affiché ; il ne modifie pas l’activité sous-jacente.

- **Connexions quotidiennes** compte chaque personne une fois par jour après une connexion réussie. Si vous additionnez les valeurs quotidiennes d’une semaine, une personne est comptée à nouveau pour chaque jour où elle s’est connectée.
- **Nouvelles sessions** compte les sessions de discussion ordinaires créées ce jour-là. Les sessions de test et d’évaluation sont exclues.
- **Tokens de discussion** additionne les tokens d’entrée et de sortie des requêtes envoyées aux modèles de discussion. **Tokens d’arrière-plan** présente séparément les autres travaux de modèle attribués. Il s’agit de tokens, et non de crédits facturés.
- **Chargements de Skill** compte les lectures ou invocations effectives de Skills. **Chargements d’outil** compte les définitions d’outils fournies aux requêtes de modèle. **Appels d’outil** compte les tentatives d’exécution d’outils, y compris les appels en échec.

Les anciens enregistrements ne couvraient pas toutes les mesures. Une valeur non enregistrée s’affiche à **0** et peut sous-estimer l’activité antérieure. Les rapports présentent uniquement les totaux de l’équipe, sans noms de membres, prompts, contenu de Skills ni arguments d’outils.
