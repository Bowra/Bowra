# 查看团队运营数据

团队负责人和管理员可打开**设置 → 团队 → 日常管理 → 运营数据**。选择「昨天」「近 7 天」或「近 30 天」查看已结束的完整日期；逐日表格显示准确数值，趋势图显示选中指标的变化。当天尚未结束，不纳入统计。

报表时区由团队共用。选择时区并保存后，每天的起止时间会随之调整，原始活动不会改变。

- **登录用户（日累计）**：每天成功登录的用户去重计数。同一人在一周内多天登录，会在每天各计一次。
- **新建会话**：当天创建的普通对话会话，不含试运行和评测会话。
- **聊天 Token**：对话模型请求的输入和输出 Token 之和；**后台 Token**单独显示其他可归属模型工作。Token 数不是额度扣费数。
- **Skill 加载**：实际读取或调用 Skill 的次数。**工具加载**：模型请求收到的工具定义项次。**工具调用**：实际执行尝试次数，包括失败的调用。

较早的记录没有采集全部指标。未记录的值显示为 **0**，可能低于当时的真实使用量。报表只显示团队汇总，不包含成员姓名、提问内容、Skill 内容或工具参数。
