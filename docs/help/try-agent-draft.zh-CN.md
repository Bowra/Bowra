# 在对话里试用智能体的草稿

此功能取决于当前部署的开放范围。如果未显示相关入口，请先向管理员确认是否已启用。

作为智能体的所有者，你可以在发布前用保存的草稿真正对话，像成员一样用它：追问、让它调用工具、看它给出的图表和文件。成员照常用已发布的版本，试用只有你能看到。

## 开始试用

1. 打开你的智能体，在「配置」里改好。
2. 点发布条上的「试用草稿」，或者「测试用例」页「试用记录」里的「新的试用」。提交审批后等待处理时，按钮写「试用审批中的版本」。
3. 会新开一段对话，输入框里的智能体是固定的，输入框是空的：之前在新对话里留下没发的内容会被清掉。提示条和输入框会写明试的是草稿还是审批中的版本。宽屏上智能体的编辑器会在对话旁边打开，可以边试边改；窄屏上点「编辑草稿」全屏打开编辑器。页面不显示首页的建议，而是从你自己的测试用例里给出最多两个问题，点一下填进输入框，不会直接发送。

开始前会先保存没保存的修改：只改了「工作说明」时直接保存；别的字段也改过时，页面会写明是哪几项并先问你。「保存并试用」把它们存进草稿（存进去以后不能再放弃，但不影响正在用的版本）；「只用已保存的草稿」试的是之前保存的内容。

草稿还不能试用时，页面会写明是哪项检查没通过（比如安全检查），按钮直接带你去改那一项。没保存的修改还不能保存时（比如「谁能用」选了指定成员却没选人），试用不会提出先保存，而是写明问题，并带你去改那一节。

## 和草稿对话

- 对话顶部的紫色提示条说明这是试用：只有你能看到，工具会真实运行，按普通对话扣额度。
- 每条回答标着它用的草稿和这份草稿拿来试用的时间，比如「草稿 · 14:32 的版本」。两次提问之间保存过草稿，会插一行「草稿已更新 · 下面的回答用新草稿」。
- 发送时会按同样的规则先保存编辑器，所以下一条消息总是用最新保存的草稿；输入框上方会提示发送时要先保存。如果这次修改正在测试，试用会继续用正在测试的草稿，并告诉你。
- 每条回答下面，「存为用例」把这个问题加到智能体的「测试用例」，点「去写要点」到那里补完；能从智能体页直接开始使用智能体时，「用已发布 vN 问同一个问题」会新开一段普通对话，问题已经填好。

## 哪些会真的执行

试用不是沙盒：查数据、联网、跑代码、写外部系统的工具都会真的执行。需要你确认的操作照常会问，和普通对话一样，并提醒你确认后会真的执行。

## 试用里不能用的功能

计划模式、引用 MCP 工具或提示词、指定可选只读方法、运行中补充消息、把任务交给同一个智能体的另一个副本、模板文档工具，在试用里都不能用，页面会写明原因。试用里的回答不能评价，也不能分享给别人；试用里生成的文件不能用链接分享；试用对话也不能设成定时任务。

## 再次找到试用

试用对话不进侧栏。打开智能体页的「测试用例」，「试用记录」列出你最近 10 次试用：第一句问题、最后一次发消息的时间、轮数和用过几份草稿。「回到智能体」只是离开对话，之后可以从「试用记录」再打开。

草稿发布后，这段试用就结束了；在对话旁边的编辑器里发布时会立刻结束。对话还能看，「开始使用 vN」会用已发布的版本新开一段普通对话；没有这个按钮时，在新对话里 @ 这个智能体。之后再改的内容，开始新的试用来试。

如果这段试用用的草稿已经撤回或被替换，而保存的草稿现在和已发布的版本一样，这段试用也不能再继续。再打开时顶部会写明原因：先在「配置」里改草稿，再从智能体页开始新的试用。
