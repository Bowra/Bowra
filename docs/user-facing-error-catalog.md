# User-facing error contracts

English | [简体中文](user-facing-error-catalog.zh-CN.md)

The runtime catalogs in `config/i18n/errors/` define stable codes and localized messages. The tables below preserve the exact registered contracts, including Chinese user-facing translations and historical compatibility entries. A registered code does not imply that its originating feature is available in every edition.

When changing a visible error, update both runtime languages, the matching table, and the relevant response tests in the same change. Show actionable messages; never expose raw exceptions, internal paths, secrets, or stack traces. Diagnostic publication uses registered safe facts and enforces the caller's disclosure boundary.

Disclosure levels are `public-neutral` (anonymous, without confirming another subject's existence), `authenticated` (the caller's own permitted context), `admin` (authorized administration), and `protocol` (stable machine-facing contracts with localized messages).
