# 用合成示例体验 Bowra

[English](README.md) | 简体中文

从证据可核对的小任务开始。这些示例包含虚构数据、可复制的提示词，以及具体的结果检查标准。

| 示例                                             | 可以尝试什么                         | 检查什么                                   |
| ------------------------------------------------ | ------------------------------------ | ------------------------------------------ |
| [供应商评审](supplier-review/README.zh-CN.md)    | 比较三份报价并撰写决策备忘录         | 可比成本、来源引用、缺失证据和有条件的建议 |
| [收入复盘](revenue-review/README.zh-CN.md)       | 解释季度增长并生成报告               | 可复算指标、分组贡献，以及因果结论的边界   |
| [Agent 自动化](agent-automation/README.zh-CN.md) | 设计限定授权的提案 → 审阅 → 评测流程 | 精确版本标识、有限授权和所有者控制的发布   |

## 从收入复盘开始

1. 在已经配置好的 Bowra 中打开聊天。
2. 附加示例中的 CSV 和指标定义；如果部署不接受这些附件，可粘贴其内容。
3. 粘贴[任务提示词](revenue-review/task.zh-CN.md)，选择可用且适合计算、报告写作的 Agent 和资源。
4. 对照[可独立复算的预期结果](revenue-review/expected-results.md)核验输出。

任务仍需要已配置的模型、Agent 资源和正常权限。提示词不能启用 Tool、授予文件权限或开启可选功能。生成文件前可查看[文档 Skill 配置](../../docs/help/create-agent.zh-CN.md)。

## 查看真实参考文件

收入示例包含小型 [DOCX、PDF、XLSX 和 PPTX 文件](revenue-review/references/README.zh-CN.md)，由仓库独立的 `bowra-*` 文档 CLI 直接生成，使用已核验的合成数字展示支持的输出格式。这些是**独立生成的参考产物**，不是应用或 LLM 的实际运行记录。

![独立生成的合成收入 PDF 首页裁剪预览](revenue-review/references/report-preview.png)

## 示例可以证明什么

- 不需要账号或模型密钥，即可在本地核对输入和预期计算。
- 文档参考产物附带源输入和重新生成命令。
- 任务提示词供已配置的部署试用，不代表已经执行过产品工作流或 CI 流水线成功。
- 供应商、交易金额和场景均为虚构，不包含客户记录、私有服务地址或凭据。

修改实际画布报告时，请参考[报告修改帮助](../../docs/help/revise-report.zh-CN.md)。可下载文档、画布报告和经过审阅的模板草稿是不同产物，请说明需要哪一种。
