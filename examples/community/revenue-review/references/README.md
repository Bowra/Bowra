## Evidence behind the numbers

[revenue.csv](../revenue.csv) is the synthetic source. [Metric definitions](../metric-definitions.md) explain the denominators and missing context. [calculate.py](../calculate.py) uses standard-library decimal arithmetic; its totals were independently checked with grouped SQL sums. See [expected results](../expected-results.md) for hand-checkable calculations.

The workbook contains **values, not formulas**. `bowra-xlsx` does not create or evaluate formulas; this file is a reviewed snapshot, not a financial model that recalculates when edited. Re-run the calculation and update the JSON when changing the source data. The deck uses a new basic layout and does not preserve an uploaded template.

## Regenerate from the repository root

Use the repository's installed Python 3.12 environment and locked dependencies. These commands make no network requests and need no model key. Each CLI requires a new output workdir and returns an actual filename, size and SHA-256 in `result.json`.

```bash
reference_run=$(mktemp -d)

uv run --no-sync python packages/bowhead_skill/catalog/bowra-pdf/scripts/run.py \
  --input examples/community/revenue-review/references/report-input.json \
  --workdir "$reference_run/pdf"

uv run --no-sync python packages/bowhead_skill/catalog/bowra-docx/scripts/run.py \
  --input examples/community/revenue-review/references/report-input.json \
  --workdir "$reference_run/docx"

uv run --no-sync python packages/bowhead_skill/catalog/bowra-xlsx/scripts/run.py \
  --input examples/community/revenue-review/references/workbook-input.json \
  --workdir "$reference_run/xlsx"

uv run --no-sync python packages/bowhead_skill/catalog/bowra-pptx/scripts/run.py \
  --input examples/community/revenue-review/references/deck-input.json \
  --workdir "$reference_run/pptx"
```

Optional preview generation requires Poppler's `pdftoppm`, separately installed on the local machine:

```bash
pdftoppm -png -r 110 -singlefile -x 80 -y 105 -W 750 -H 890 \
  "$reference_run/pdf/report.pdf" "$reference_run/report-preview"
```

The crop removes page margins, keeping the report title, synthetic-data label, both tables, conclusions and source note. Re-check its bounds if you change the content. Document metadata may vary across runs, so semantic reproduction does not promise identical binary hashes.

Generation checks reopened all four formats and confirmed the expected content, sheet/slide counts and checked figures. The PDF preview was visually reviewed. The files are ordinary local documents; direct CLI execution does not register an Artifact, authorize a user, publish a report or verify an application's sandbox integration.
