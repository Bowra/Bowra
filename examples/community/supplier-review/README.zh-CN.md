# 供应商评审：把取舍说明白

[English](README.md) | 简体中文 | [全部示例](../README.zh-CN.md)

**合成场景：**团队需要供 80 人使用的服务台产品，要求八周内上线、首年税前预算不超过 24,000 美元，希望按年签约，退出时能够导出可用数据。

## 开始任务

附加三份虚构报价，再粘贴 [task.zh-CN.md](task.zh-CN.md)：

- [Atlas 报价](proposal-atlas.md)
- [Beacon 报价](proposal-beacon.md)
- [Cedar 报价](proposal-cedar.md)

如果不支持 Markdown 附件，可将三个文件连同文件名粘贴到聊天中。先要求决策备忘录。仅在所选 Agent 可以使用 **Word 文档**（`bowra-docx`）时，再要求独立 DOCX；回答中出现文件名不代表已经产生可下载文件。

## 怎样判断结果有用

结果应包含可比成本表、明确的不符合项、报价章节引用，以及会影响决策的补充问题。首年最便宜不一定最合适。对照[评审标准](review-criteria.md)核验答案；建议应以证据为条件，不能声称已核实这些虚构供应商。

可继续提问：“假设第 7 个月开始新增 20 名用户，请更新成本，并说明哪些预算判断发生变化。”
