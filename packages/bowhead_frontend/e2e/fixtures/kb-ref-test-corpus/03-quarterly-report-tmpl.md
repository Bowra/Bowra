# 季度经营报告模板

## 一、整体经营概况

本季度营业收入达成情况、增长趋势、与年度目标的对照。

关注:

- 收入同比 / 环比变化
- 毛利率变化
- 主营业务贡献占比

## 二、分品类表现

按品类拆分销售额、毛利、客流量。识别增长品类与下滑品类。

## 三、分渠道表现

线上 (官网 / 电商平台 / 直播) vs 线下 (门店 / 经销商) 的销售贡献与
增长率对比。新渠道孵化进展。

## 四、库存与供应链

库存周转天数、滞销 SKU 占比、供应链健康度。预警库存积压风险。

## 五、人力与成本

人均产出、销售费用率、管理费用率。判断成本控制情况。

## 六、风险与机会

宏观环境影响、政策变化、行业竞争格局变化。下一季度的核心机会与挑战。

## 七、行动建议

P0 / P1 / P2 优先级建议，明确负责人与执行时间表。
