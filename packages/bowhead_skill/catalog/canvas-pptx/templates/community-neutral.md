# Community neutral presentation template

English | [简体中文](community-neutral.zh-CN.md)

## Source and provenance

`community-neutral.pptx` is independently authored for the Community distribution. Its complete source is [`../scripts/build_community_template.py`](../scripts/build_community_template.py). The generator starts from `pptx.Presentation()` using the public `python-pptx` library's bundled empty presentation. It reads no existing project presentation, reference deck, restricted Skill, artwork, font file, company data, or external service.

All coordinates, colors and text are authored in the generator. Dynamic text slots start empty. The two native charts contain only the synthetic categories `Example A` / `Example B`, values `1` / `2`, and series `Synthetic example`. The sole visible fixed copy is functional labeling: recommendation, insight, owner, when, and thank you. Arial is requested by name; no font binary is embedded. Presentation and embedded workbook metadata are neutralized, and ZIP member order and timestamps are normalized.

Rebuild from the repository root with the locked Python dependencies:

```bash
uv sync --all-extras
uv run python packages/bowhead_skill/catalog/canvas-pptx/scripts/build_community_template.py
uv run python packages/bowhead_skill/catalog/canvas-pptx/scripts/build_community_template.py --check
```

Reproducibility is against the repository's locked `python-pptx` and workbook library versions; a dependency upgrade may intentionally change generated bytes and requires reviewing the regenerated file. The generator and output follow the containing repository's license. Third-party library licenses remain their own.

## Composition contract

The standalone renderer reads `templates/default.json`, a fixed packaged manifest with exactly `schema_version: 1` and `template`. Community selects `community-neutral.pptx`. The complete private distribution keeps its existing template selection. Missing files, unknown selections and paths outside the packaged template directory fail immediately. There is no environment selection or application-package dependency.

Standard exports without an explicit allowed, existing `template_path` use the content-driven renderer. The packaged role template is the fallback for an explicit empty presentation and can also be supplied explicitly from the allowed temporary/work directory. Community defaults generated labels to English; `locale: "zh-CN"` keeps the supported Chinese labels. Supplied report text is never translated. The existing explicit-template slot limits still apply.

The seven slides are 16:9 (13.333333 × 7.5 inches). Layout names and shape indices are the renderer's compatibility interface:

| Slide           | Layout        | Required shape slots                                                                                                    |
| --------------- | ------------- | ----------------------------------------------------------------------------------------------------------------------- |
| Cover           | `COVER`       | 0 eyebrow, 1 cleared document ID, 2 title, 3 subtitle, 4 cleared attribution, 5 date                                    |
| Summary         | `TITLE_ONLY`  | 1 section, 2 hero, 3 narrative, 5/6 + 8/9 + 11/12 finding label/text, 14 label, 15 recommendation                       |
| Metrics         | `KPI_GRID`    | 1 section, 2 title, 3 subtitle, 5/6/7 + 9/10/11 + 13/14/15 + 17/18/19 label/value/detail, 20 summary                    |
| Bar insight     | `CHART_SLIDE` | 1 section, 2 title, 3 subtitle, 4 native chart, 6 label, 7 thesis, 8 narrative                                          |
| Line insight    | `CHART_SLIDE` | Same as bar insight                                                                                                     |
| Recommendations | `TITLE_ONLY`  | 1 section, 2 title, 3 subtitle; priority/action/description/owner/timing at 7/8/9/11/13, 17/18/19/21/23, 27/28/29/31/33 |
| Closing         | `CLOSING`     | 0 closing label, 1 thank you, 2/3/4 cleared text, 5 date                                                                |

Other slots provide self-authored rectangles or empty spacing. Unused library layouts remain empty; the last layout supports the renderer's appended design-summary slides. Do not reorder slots when changing the design.

## Verification

Run `uv run --extra dev pytest packages/bowhead_skill/tests/test_community_pptx_template.py -q`. The tests reconstruct the exact template, inspect outer and nested workbook metadata and relationships, and run the real standalone renderer from a temporary Community-only Skill directory. They cover real chart replacement, empty-template fallback, missing visual removal, explicit Chinese text and invalid manifests. Review a rendered PDF visually after changing coordinates or fonts; structural tests cannot prove readable layout.
