# Upstream source

The bundled `LICENSE.txt` preserves the original copyright and MIT terms.

Bowhead retains the search, evidence, citation, and brief workflows with two upstream templates. The adaptation uses a team MCP source, Bowhead's own connection recovery, and a cited answer in chat. The shipped workflow uses read operations.
